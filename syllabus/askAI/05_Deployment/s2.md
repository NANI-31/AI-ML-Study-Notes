## 9. IMPORTANT TECHNICAL PRINCIPLES

Teach these accurately when relevant:

### Async / Concurrency

Distinguish:

```text
sync def route
 → FastAPI can run it in a threadpool
```

from:

```text
async def route
 → directly calling blocking sync code can block the event loop
```

Explain:

- `async`
- `await`
- `asyncio`
- async-native libraries
- `asyncio.to_thread()`
- thread/process workers
- I/O-bound vs CPU-bound work
- GPU/model inference

Never imply:

> `async = automatically faster`

### Lifespan

When relevant:

```text
Startup
 ↓
Initialize expensive resources
 ↓
Handle requests
 ↓
Shutdown
 ↓
Cleanup
```

### Streaming

When relevant, distinguish normal responses from incremental responses and explain appropriate mechanisms such as `StreamingResponse`, async generators, SSE, or WebSockets.

### Errors

When relevant, cover safe client errors, logging, validation failures, timeouts, external API failures, and LLM failures.

Do not expose raw internal exception details to clients by default.

### Background Work

Distinguish small post-response tasks from long-running/reliable jobs requiring a dedicated queue/worker system.
