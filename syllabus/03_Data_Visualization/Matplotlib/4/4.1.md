# Section: 4. Line Plots - 4.1 Basic Line Plot

## 1. Section Overview

### What This Section Is About
This section covers the core fundamentals of line plotting in Matplotlib using `plt.plot()`. It focuses on how continuous data is represented, how coordinates ($X$ and $Y$) are mapped to Cartesian 2D space, how single and multiple lines are drawn on a shared axis, and how continuous mathematical functions are approximated using discrete numeric arrays generated with NumPy.

### Why These Matplotlib Concepts Matter
The line plot is the foundational building block of 2D data visualization. Virtually all continuous monitoring in engineering, finance, and Machine Learning—such as training loss curves, evaluation metrics over iterations, stock price fluctuations, and time-series telemetry—relies on line plots. Understanding how Matplotlib connects coordinate pairs in sequence is essential for avoiding distorted graphs, misleading visualizations, and subtle runtime shape errors.

### Where They Are Used in Real Python/Data Science Projects
- **Deep Learning & ML Pipelines**: Tracking training loss vs. validation loss across epochs to diagnose underfitting and overfitting.
- **Financial Analytics**: Plotting moving averages, closing prices, and trading volumes over time.
- **Scientific Computing**: Simulating and visualizing differential equations, signal wave forms (e.g., sine, cosine, Fourier components), and experimental decay curves.
- **Sensor & IoT Telemetry**: Tracking temperature, pressure, or latency continuously sampled at fixed intervals.

### What a Fresher Should Be Able to Do After Completing This Section
- Create clean single-line and multi-line plots using `plt.plot()`.
- Explain how Matplotlib infers default X-coordinates when only a single argument is passed (`plt.plot(y)`).
- Prevent and resolve shape/dimension mismatch errors (`ValueError: x and y must have same first dimension`).
- Correctly generate smooth mathematical curves using `np.linspace()` and vectorized NumPy operations.
- Diagnose and fix common line-plotting bugs, such as un-ordered X coordinates producing zigzag/scribble artifacts.

## 2. Topic-Wise Interview Concepts

### Topic 1: `plt.plot()`
- **Concept**: `plt.plot()` is the primary function in Matplotlib's `pyplot` stateful interface used to draw 2D lines and markers connecting discrete coordinate points $(x_i, y_i)$ with straight line segments in sequential order.
- **Why it matters**: It is the most commonly used plotting call in exploratory data analysis (EDA). Interviewers use it to test whether a candidate understands how Matplotlib manages current figures and axes automatically behind the scenes.
- **Syntax / API**:
  ```python
  import matplotlib.pyplot as plt

  plt.plot(*args, **kwargs)
  # Standard signature: plt.plot(x, y) or plt.plot(y)
  ```
- **Example**:
  ```python
  import matplotlib.pyplot as plt

  y_values = [10, 25, 18, 30]
  plt.plot(y_values)
  plt.show()
  ```
- **Expected output**: A 2D window rendering a single continuous blue line connecting points $(0, 10)$, $(1, 25)$, $(2, 18)$, and $(3, 30)$.
- **Important parameters**:
  - `*args`: Coordinates passed as `(y)` or `(x, y)`.
  - `label`: String identifier used when generating a legend.
  - `color` (or `c`): Defines line color (name, hex, or RGB).
  - `linewidth` (or `lw`): Float value setting line thickness.
- **Common interview confusion**: Confusing `plt.plot(x, y)` with a scatter plot. `plt.plot()` connects points sequentially with lines; it does not simply drop disconnected dots unless an explicit marker-only format string is passed.

---

### Topic 2: X and Y Values
- **Concept**: Line plots map pairs of independent variables ($X$) and dependent variables ($Y$). If both $X$ and $Y$ are provided, they must be 1D iterable sequences (Python lists, NumPy 1D arrays, or Pandas Series) of identical length. If only one array is provided, Matplotlib automatically treats it as $Y$ and assigns $X = [0, 1, 2, \dots, N-1]$.
- **Why it matters**: Mismatched dimensions between $X$ and $Y$ is the #1 runtime error encountered by freshers in technical assessments.
- **Syntax / API**:
  ```python
  plt.plot(x, y)  # Explicit X and Y
  plt.plot(y)     # Implicit X = range(len(y))
  ```
- **Example**:
  ```python
  import matplotlib.pyplot as plt

  x = [1, 2, 4, 8]
  y = [2, 4, 8, 16]
  plt.plot(x, y)
  plt.show()
  ```
- **Expected output**: A line where coordinates increase unevenly along the X-axis at values 1, 2, 4, and 8, rather than evenly spaced indices.
- **Important parameters**:
  - Data structures: Must be 1-dimensional array-like iterables.
- **Common interview confusion**: Assuming `plt.plot(data)` automatically detects timestamps or column names. When passed a single list, $X$ is strictly zero-indexed integers (`0` to `len(data) - 1`).

---

### Topic 3: Single Line
- **Concept**: A single line plot connects points from index $0$ to $N-1$ in the exact sequence they appear in the data arrays. Matplotlib does not sort $X$ values; it draws a segment from $(x_i, y_i)$ to $(x_{i+1}, y_{i+1})$.
- **Why it matters**: Understanding point-to-point traversal explains why unsorted data produces crisscrossing "scribble" plots rather than smooth functional curves.
- **Syntax / API**:
  ```python
  plt.plot(x, y)
  ```
- **Example**:
  ```python
  import matplotlib.pyplot as plt

  x = [1, 2, 3, 4, 5]
  y = [1, 4, 9, 16, 25]
  plt.plot(x, y)
  plt.show()
  ```
- **Expected output**: A smooth, upward-curving line showing quadratic growth ($y = x^2$) plotted across five discrete points.
- **Important parameters**:
  - `linestyle` (or `ls`): `'-'`, `'--'`, `':'`, `'-.'`
- **Common interview confusion**: Believing Matplotlib internally sorts $X$ coordinates before rendering. If $X$ is scrambled, the line zigzags backwards and forwards.

---

### Topic 4: Multiple Lines
- **Concept**: Multiple line series can be drawn on the same coordinate axes by making successive calls to `plt.plot()` before calling `plt.show()`. Matplotlib automatically cycles through its default color cycle (`tab10`: blue, orange, green, red, etc.) for each line.
- **Why it matters**: Multi-line plots are critical for comparative analytics: benchmarking models, tracking train vs. test loss, or comparing company revenues over time.
- **Syntax / API**:
  ```python
  plt.plot(x, y1, label='Series 1')
  plt.plot(x, y2, label='Series 2')
  # Alternatively in a single call: plt.plot(x, y1, x, y2)
  ```
- **Example**:
  ```python
  import matplotlib.pyplot as plt

  epochs = [1, 2, 3, 4]
  train_loss = [0.8, 0.5, 0.3, 0.15]
  val_loss = [0.85, 0.55, 0.4, 0.38]

  plt.plot(epochs, train_loss)
  plt.plot(epochs, val_loss)
  plt.show()
  ```
- **Expected output**: A single graph containing two distinct lines (one blue, one orange) sharing the same X and Y scales.
- **Important parameters**:
  - `label`: Essential when plotting multiple lines to differentiate series when a legend is added.
- **Common interview confusion**: Thinking that calling `plt.plot()` a second time overwrites the first plot. It overlays onto the active Axes until `plt.close()` or `plt.show()` creates a new state.

---

### Topic 5: Plotting Mathematical Functions
- **Concept**: Computers cannot plot continuous infinite functions directly. To visualize a mathematical function (e.g., $f(x) = \sin(x)$), you create a high-density discrete array of $X$ values using `numpy.linspace(start, stop, num_points)` and compute the corresponding $Y$ values using vectorized NumPy operations.
- **Why it matters**: Demonstrates the bridge between analytical mathematics, NumPy vectorization, and Matplotlib graphical output.
- **Syntax / API**:
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  x = np.linspace(start, stop, num=500)
  y = np.sin(x)
  plt.plot(x, y)
  ```
- **Example**:
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  x = np.linspace(-np.pi, np.pi, 200)
  y = np.sin(x)

  plt.plot(x, y)
  plt.show()
  ```
- **Expected output**: A smooth, continuous-looking sinusoidal wave oscillating between -1 and +1 from $-\pi$ to $+\pi$.
- **Important parameters**:
  - `num` in `np.linspace`: Number of sample points (too few causes jagged linear edges; too many wastes memory).
- **Common interview confusion**: Using Python's standard `math.sin` instead of `np.sin`. Standard library math functions cannot operate over array elements and throw `TypeError`.

## 3. Fresher Interview Questions

### A. Basic Questions

#### Q1: What does `plt.plot()` do if you pass only one list or array of numbers?
**Answer**: If only a single 1D sequence `y` is passed (e.g., `plt.plot([10, 20, 30])`), Matplotlib assumes these are the $Y$-coordinates. It automatically generates default $X$-coordinates as consecutive integers starting from $0$ up to $N-1$ (`[0, 1, 2, ..., len(y)-1]`).

#### Q2: Why are line plots preferred over bar charts or scatter plots for time-series data?
**Answer**: Line plots explicitly connect sequential observations, emphasizing continuity, direction, and rate of change over an ordered independent variable (such as time). Bar charts suggest discrete categorical comparisons, and scatter plots display isolated data points without conveying continuity.

#### Q3: What is the requirement regarding the dimensions of $X$ and $Y$ in `plt.plot(x, y)`?
**Answer**: $X$ and $Y$ must have the exact same length (first dimension). If `len(x) != len(y)`, Matplotlib raises `ValueError: x and y must have same first dimension`.

#### Q4: How do you plot multiple lines on the exact same graph in Matplotlib?
**Answer**: Call `plt.plot()` multiple times sequentially before calling `plt.show()`. All lines will be drawn onto the currently active Axes object with distinct colors from the default color cycle.

---

### B. Intermediate Questions

#### Q1: Matplotlib draws curves as straight lines between points. How do you make a mathematical curve appear smooth?
**Expected answer**: Increase the sampling density using `np.linspace()` with a sufficiently large number of points (e.g., 200 to 1000 points).
**Explanation**: Matplotlib does not perform true continuous analog curve rendering. It performs piecewise linear interpolation between consecutive points $(x_i, y_i)$ and $(x_{i+1}, y_{i+1})$. When the points are placed sufficiently close together, human visual perception perceives the segments as a smooth curve.

#### Q2: What happens if the $X$ coordinates passed to `plt.plot(x, y)` are not sorted in ascending order?
**Expected answer**: The rendered line will loop back and forth, resulting in a jagged, crisscrossing "scribble" plot.
**Explanation**: `plt.plot()` connects points sequentially based on array index $(x_0, y_0) \to (x_1, y_1) \to (x_2, y_2)$, regardless of their numerical value along the X-axis. It does not sort coordinates before drawing.

#### Q3: Does calling `plt.show()` clear or reset the plot?
**Expected answer**: Yes. In the `pyplot` stateful workflow, `plt.show()` displays the current figure window and resets the active figure state. Any subsequent `plt.plot()` calls will create a brand new figure rather than adding to the prior one.

### E. Debugging Questions

#### Q1: Shape Mismatch Error
- **Problem**: Script crashes on execution.
- **Incorrect code**:
  ```python
  import matplotlib.pyplot as plt

  x = [1, 2, 3, 4]
  y = [10, 20, 30]
  plt.plot(x, y)
  ```
- **Expected correction**:
  ```python
  import matplotlib.pyplot as plt

  x = [1, 2, 3, 4]
  y = [10, 20, 30, 40]  # Match length of x
  plt.plot(x, y)
  ```
- **Explanation**: Matplotlib maps points in pairs. 4 values of X cannot be mapped to 3 values of Y.

#### Q2: Jagged Function Curve
- **Problem**: Mathematical curve looks like connected angular line segments instead of a smooth circle/curve.
- **Incorrect code**:
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  x = np.linspace(0, 2 * np.pi, 5)
  y = np.sin(x)
  plt.plot(x, y)
  ```
- **Expected correction**:
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  x = np.linspace(0, 2 * np.pi, 200)  # Increased sample count
  y = np.sin(x)
  plt.plot(x, y)
  ```
- **Explanation**: 5 points across a $2\pi$ range are insufficient to capture the curvature of a sine function, producing noticeable polygon edges.

#### Q3: Standard Library Math TypeError
- **Problem**: Calling a math function on an array throws `TypeError: only size-1 arrays can be converted to Python scalars`.
- **Incorrect code**:
  ```python
  import math
  import numpy as np
  import matplotlib.pyplot as plt

  x = np.linspace(0, 5, 50)
  y = math.sin(x)
  plt.plot(x, y)
  ```
- **Expected correction**:
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  x = np.linspace(0, 5, 50)
  y = np.sin(x)  # Vectorized NumPy function
  plt.plot(x, y)
  ```
- **Explanation**: Standard Python `math` module functions only accept single scalars. `numpy` mathematical functions are vectorized to execute over entire arrays.

## 4. Top Questions to Definitely Prepare

### Must Know
1. **Q**: What is the difference between passing one argument vs. two arguments to `plt.plot()`?
   - **Answer**: Passing two arguments (`plt.plot(x, y)`) maps explicit coordinates for both axes. Passing one argument (`plt.plot(y)`) treats the array as $Y$ values and generates integer indices $0$ to $N-1$ for the X-axis.
2. **Q**: How does `plt.plot()` decide which color to assign when drawing multiple lines?
   - **Answer**: Matplotlib cycles through a default sequence of colors defined in its active property cycle (`rcParams['axes.prop_cycle']`), defaulting to the `tab10` categorical palette (blue, orange, green, red, purple, etc.).
3. **Q**: Why must $X$ and $Y$ have identical lengths?
   - **Answer**: Because each plotted vertex represents a coordinate pair $(x_i, y_i)$ in 2D Cartesian space. A mismatch leaves points undefined.

### Good to Know
1. **Q**: What happens behind the scenes when you plot multiple mathematical functions sequentially?
   - **Answer**: Each call to `plt.plot()` creates a new `Line2D` artist object and registers it with the current `Axes`. The axis auto-scaling algorithm recalculates the bounding limits $[x_{\min}, x_{\max}]$ and $[y_{\min}, y_{\max}]$ to accommodate the bounds of all plotted series.
2. **Q**: Why does passing an unsorted $X$ array cause visual distortions?
   - **Answer**: `plt.plot()` renders data in the sequential order of array elements, connecting $(x_i, y_i) \to (x_{i+1}, y_{i+1})$. Unsorted $X$ values force the drawing pen to traverse backwards along the horizontal axis, creating loops or crisscrossing lines.

### Bonus
1. **Q**: Can `plt.plot()` handle non-numerical values for X or Y directly?
   - **Answer**: Yes, Matplotlib has built-in unit converters for categorical string labels (e.g., `['Jan', 'Feb', 'Mar']`) and `datetime` objects. It assigns categorical strings to discrete integer positions internally ($0, 1, 2\dots$) while rendering the string as tick labels.

## 5. Mistakes to Avoid

### Mistake 1: Array Dimension Mismatch
- **Why it happens**: Generating $X$ with one range (e.g., `range(10)`) and $Y$ with another (e.g., slice of 9 elements).
- **Correct approach**: Always assert `len(x) == len(y)` or derive $Y$ directly from $X$ via vectorized calculations.
- **Example**:
  ```python
  # INCORRECT
  x = [1, 2, 3]
  y = [10, 20]
  plt.plot(x, y)  # Crashes with ValueError

  # CORRECT
  x = [1, 2, 3]
  y = [10, 20, 30]
  plt.plot(x, y)
  ```

### Mistake 2: Plotting Unsorted $X$ Values for Continuous Curves
- **Why it happens**: Extracting $X$ and $Y$ columns from a DataFrame that was shuffled or unsorted by date/value.
- **Correct approach**: Sort both arrays based on $X$ before calling `plt.plot()`.
- **Example**:
  ```python
  # INCORRECT
  x = [3, 1, 4, 2]
  y = [9, 1, 16, 4]
  plt.plot(x, y)  # Zigzag lines

  # CORRECT
  sorted_pairs = sorted(zip(x, y))
  x_sorted = [p[0] for p in sorted_pairs]
  y_sorted = [p[1] for p in sorted_pairs]
  plt.plot(x_sorted, y_sorted)
  ```

### Mistake 3: Insufficient Sampling for Mathematical Plots
- **Why it happens**: Using `range()` or low `num` parameters in `np.linspace()` when plotting non-linear functions.
- **Correct approach**: Use at least 100–500 points in `np.linspace()` for trigonometric or polynomial curves.
- **Example**:
  ```python
  # INCORRECT
  x = np.arange(0, 10, 2)  # Only 5 points
  plt.plot(x, np.sin(x))   # Ugly polygonal shape

  # CORRECT
  x = np.linspace(0, 10, 300)
  plt.plot(x, np.sin(x))   # Smooth curve
  ```

## 6. Matplotlib API Confusions

### 1. `plt.plot(x, y)` vs. `plt.scatter(x, y)`
- **Main difference**: `plt.plot()` connects points with line segments (primarily optimized for continuous functional or time-series relationships). `plt.scatter()` renders individual markers without connecting lines and supports dynamic marker sizes and colors per individual point.
- **When to use each**: Use `plt.plot()` for continuous sequential trends, line charts, and mathematical functions. Use `plt.scatter()` to show relationships, clusters, and distributions between two continuous variables where each point represents an independent sample.
- **Example**:
  ```python
  # Line Plot (Connected)
  plt.plot([1, 2, 3], [10, 20, 15])

  # Scatter Plot (Discrete Points)
  plt.scatter([1, 2, 3], [10, 20, 15])
  ```

### 2. `plt.plot(y)` vs. `plt.plot(x, y)`
- **Main difference**: `plt.plot(y)` auto-assigns $X$ as integer index positions `0, 1, ..., N-1`. `plt.plot(x, y)` maps values explicitly against the provided $X$ coordinates.
- **When to use each**: Use `plt.plot(y)` for quick inspections where physical unit spacing on $X$ is irrelevant or strictly uniform (like sequential epoch numbers starting from 0). Use `plt.plot(x, y)` whenever $X$ represents meaningful physical units, irregular timestamps, or mathematical domains.
- **Example**:
  ```python
  # Default indices: X = [0, 1, 2]
  plt.plot([100, 200, 300])

  # Explicit coordinates: X = [10, 50, 100]
  plt.plot([10, 50, 100], [100, 200, 300])
  ```

## 7. Interview Traps

### Trap 1: "Does `plt.plot()` automatically sort data before rendering?"
- **The Trap**: Beginners assume Matplotlib knows that $X$ should flow left-to-right.
- **Expected Reasoning**: No. Matplotlib is an explicit rendering engine. It draws vectors strictly in the order elements are indexed in memory. If $X$ is disordered, it will draw lines moving backwards across the canvas. Sorting is the data engineer's responsibility.

### Trap 2: "If I call `plt.plot()` twice, does the second call overwrite the first?"
- **The Trap**: Candidates familiar with some GUI libraries might think a new drawing command replaces the canvas.
- **Expected Reasoning**: In Matplotlib, drawing calls are cumulative on the current active `Axes`. The second call draws an additional line on top of the first, auto-updating axis limits and cycling to the next color in the color palette.

### Trap 3: "What happens if you pass a 2D array to `plt.plot()`?"
- **The Trap**: Candidates assume `plt.plot()` only takes 1D lists.
- **Expected Reasoning**: If a 2D array is passed (e.g., shape $(M, N)$), Matplotlib treats each column as a separate line series and plots $N$ lines across $M$ points simultaneously.

## 8. Real-World Data Science Questions

#### Q1: In an ML project, how do you plot training and validation loss curves together?
- **Answer**: Create an epoch vector `epochs = np.arange(1, num_epochs + 1)`. Call `plt.plot(epochs, train_losses, label='Train Loss')` followed immediately by `plt.plot(epochs, val_losses, label='Val Loss')`. Finally, invoke `plt.legend()` and `plt.show()` to display the comparative curves.

#### Q2: Why is `np.linspace()` preferred over `np.arange()` when plotting continuous mathematical functions?
- **Answer**: `np.linspace(start, stop, num)` allows exact control over the total number of evaluation points and guarantees inclusion of both the `start` and `stop` endpoint boundaries. `np.arange(start, stop, step)` can lead to floating-point precision accumulation issues where the final endpoint may be unexpectedly omitted or included.

## 11. "Fix This Code" Questions

### Question 1: Unordered X Coordinates Bug
- **Broken code**:
  ```python
  import matplotlib.pyplot as plt

  x = [4, 1, 3, 2]
  y = [16, 1, 9, 4]
  # Candidate expects a smooth upward curve y = x^2
  plt.plot(x, y)
  plt.show()
  ```
- **Expected behavior**: A clean parabolic curve where values increase steadily from left to right.
- **Solution**:
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  x = np.array([4, 1, 3, 2])
  y = np.array([16, 1, 9, 4])

  sort_idx = np.argsort(x)
  plt.plot(x[sort_idx], y[sort_idx])
  plt.show()
  ```
- **Explanation**: `np.argsort()` finds the index ordering that sorts $x$ ascendingly (`[1, 3, 2, 0]`), reordering both $X$ and $Y$ so the line connects points from left to right.

## 14. Matplotlib Interview Cheat Sheet

### Important APIs
- `plt.plot(x, y)` → Draws line connecting coordinates $(x_i, y_i)$.
- `plt.plot(y)` → Draws line with auto-generated integer indices on X.
- `plt.show()` → Renders visual window and clears active figure state.

### Important Parameters
- `x, y` → 1D array-like coordinate sequences.
- `color` → Sets line color (`'red'`, `'#FF0000'`).
- `linewidth` (or `lw`) → Sets thickness of line in points.
- `linestyle` (or `ls`) → Controls dash pattern (`'-'`, `'--'`, `':'`).

### Common Comparisons
- `plt.plot` vs `plt.scatter` → `plot` connects points with line segments; `scatter` plots disconnected, independently styleable markers.
- `np.linspace` vs `np.arange` → `linspace` specifies total point count and guarantees endpoints; `arange` specifies step interval.

### Common Mistakes
- Length mismatch between $X$ and $Y$ → Ensure both vectors share the same 1D length.
- Unsorted $X$ array → Always sort coordinate pairs before continuous plotting.

- **Weak Answer**: "It just plots the numbers on a graph."
- **Stronger Fresher Answer**: "When passed a single 1D array or list, Matplotlib assigns those values to the Y-axis. It automatically generates default X-coordinates as zero-indexed integers ranging from $0$ to $N-1$, where $N$ is the length of the supplied sequence."

#### Question: Why did my sine wave plot come out with sharp corners?
- **Weak Answer**: "Because Matplotlib is bad at drawing circles and curves."
- **Stronger Fresher Answer**: "Matplotlib renders lines by connecting discrete coordinate points with straight linear segments. When the sampling density of $X$ is too low, those straight segments become visually apparent. To fix this, we increase the number of evaluation points using `np.linspace(start, stop, 500)` to produce a perceptually smooth curve."

## 16. Questions That Test Understanding

- **Q: What happens if $X$ contains duplicate values at different points in the array?**  
  **A**: The line will create vertical or retrograding segments because `plt.plot()` connects vertices index-by-index. It does not treat the line as a single-valued mathematical function $y = f(x)$.
- **Q: What happens if your array contains `np.nan` values?**  
  **A**: Matplotlib breaks the line at the `NaN` coordinate, leaving a visible gap between the adjacent valid points rather than interpolating across the missing value.
