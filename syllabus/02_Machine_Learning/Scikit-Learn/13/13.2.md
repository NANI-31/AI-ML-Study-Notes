## 2. Topic-Wise Interview Concepts

### Topic 5: Principal Component Analysis (Foundations)
- **Concept**: Principal Component Analysis is an unsupervised, linear, non-parametric statistical technique that transforms a set of correlated observations into a set of linearly uncorrelated orthogonal variables called **principal components**, ordered such that the first few components retain the maximum possible variance of the original dataset.
- **Why it matters**: Evaluates whether a candidate understands the foundational duality of PCA: maximizing projected variance along coordinate axes is mathematically identical to minimizing the mean squared orthogonal reconstruction error.
- **Mathematical / Algorithmic Intuition**:
  Let $\mathbf{X} \in \mathbb{R}^{N \times D}$ be a mean-centered data matrix ($\sum_{i=1}^N \mathbf{x}_i = \mathbf{0}$).
  1. **Variance Maximization**: We seek a unit-norm direction vector $\mathbf{w}_1 \in \mathbb{R}^D$ ($\|\mathbf{w}_1\|_2 = 1$) such that the variance of the projected data $\mathbf{z}_1 = \mathbf{X} \mathbf{w}_1$ is maximized:
     $$\mathbf{w}_1 = \arg\max_{\|\mathbf{w}\|=1} \frac{1}{N} \|\mathbf{X} \mathbf{w}\|_2^2 = \arg\max_{\|\mathbf{w}\|=1} \mathbf{w}^T \left(\frac{1}{N} \mathbf{X}^T \mathbf{X}\right) \mathbf{w} = \arg\max_{\|\mathbf{w}\|=1} \mathbf{w}^T \mathbf{\Sigma} \mathbf{w}$$
     where $\mathbf{\Sigma} = \frac{1}{N} \mathbf{X}^T \mathbf{X}$ is the sample covariance matrix.
     Formulating the Lagrangian:
     $$\mathcal{L}(\mathbf{w}, \lambda) = \mathbf{w}^T \mathbf{\Sigma} \mathbf{w} - \lambda (\mathbf{w}^T \mathbf{w} - 1)$$
     Setting the derivative with respect to $\mathbf{w}$ to zero:
     $$\nabla_{\mathbf{w}} \mathcal{L} = 2 \mathbf{\Sigma} \mathbf{w} - 2 \lambda \mathbf{w} = \mathbf{0} \implies \mathbf{\Sigma} \mathbf{w} = \lambda \mathbf{w}$$
     This is the standard **eigenvalue equation**. The vector $\mathbf{w}_1$ must be an eigenvector of the covariance matrix $\mathbf{\Sigma}$, and the projected variance is:
     $$\text{Var}(\mathbf{z}_1) = \mathbf{w}_1^T \mathbf{\Sigma} \mathbf{w}_1 = \mathbf{w}_1^T (\lambda_1 \mathbf{w}_1) = \lambda_1 \|\mathbf{w}_1\|^2 = \lambda_1$$
     To maximize variance, $\mathbf{w}_1$ must be the eigenvector corresponding to the **largest eigenvalue** $\lambda_1$.
  2. **Singular Value Decomposition (SVD)**:
     In practice, forming $\mathbf{\Sigma} = \frac{1}{N} \mathbf{X}^T \mathbf{X}$ has numerical instability and requires $O(N \cdot D^2)$ operations. Scikit-Learn performs SVD directly on mean-centered $\mathbf{X}$:
     $$\mathbf{X} = \mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T$$
     where $\mathbf{U} \in \mathbb{R}^{N \times N}$ and $\mathbf{V} \in \mathbb{R}^{D \times D}$ are orthogonal matrices ($\mathbf{U}^T \mathbf{U} = \mathbf{I}$, $\mathbf{V}^T \mathbf{V} = \mathbf{I}$), and $\mathbf{\Sigma}_{\text{svd}} \in \mathbb{R}^{N \times D}$ contains singular values $s_1 \ge s_2 \ge \dots \ge s_{\min(N, D)} \ge 0$.
     The right singular vectors (columns of $\mathbf{V}$, or rows of $\mathbf{V}^T$) are the exact eigenvectors of $\mathbf{X}^T \mathbf{X}$:
     $$\mathbf{X}^T \mathbf{X} = (\mathbf{V} \mathbf{\Sigma}_{\text{svd}}^T \mathbf{U}^T)(\mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T) = \mathbf{V} \mathbf{\Sigma}_{\text{svd}}^2 \mathbf{V}^T$$
     The eigenvalues of the sample covariance matrix are related to the singular values by:
     $$\lambda_j = \frac{s_j^2}{N - 1}$$
- **Syntax / Scikit-Learn API**:
  `sklearn.decomposition.PCA(n_components=None, copy=True, whiten=False, svd_solver='auto', tol=0.0, iterated_power='auto', n_oversamples=10, power_iteration_normalizer='auto', random_state=None)`.
- **Minimal Working Example**:
  ```python
  import numpy as np
  from sklearn.decomposition import PCA

  # Generate 2D Gaussian data with high correlation
  rng = np.random.RandomState(42)
  X = rng.randn(200, 2) @ np.array([[2.0, 1.0], [1.0, 1.5]])

  # Mean center and apply PCA
  pca = PCA(n_components=2)
  Z = pca.fit_transform(X)

  print("Data Mean (computed during fit):", pca.mean_)
  print("Principal Component 1 (Direction of Max Variance):", pca.components_[0])
  print("Eigenvalues (Explained Variance):", pca.explained_variance_)
  ```
- **Expected Output / Interpretation**:
  Output shows `pca.mean_` close to the sample centroid. `pca.components_[0]` points along the diagonal of maximum spread. `pca.explained_variance_` contains the sorted eigenvalues $\lambda_1 > \lambda_2$.
- **Important Hyperparameters & Parameters**:
  - `components_`: Array of shape `(n_components, n_features)` containing the right singular vectors $\mathbf{V}_d^T$.
  - `explained_variance_`: Array of shape `(n_components,)` holding eigenvalues $\lambda_j$.
- **Common Interview Confusion**: Thinking PCA computes the covariance matrix and inverts it. PCA uses SVD on $\mathbf{X}$ directly without explicitly computing $\mathbf{X}^T \mathbf{X}$ or performing any matrix inversion.

### Topic 6: PCA in Scikit-Learn (`svd_solver` & Algorithms)
- **Concept**: The computational engine of Scikit-Learn's `PCA` is governed by the `svd_solver` parameter, which dictates whether exact LAPACK routines, truncated iterative ARPACK Arnoldi iterations, or randomized matrix approximations are used.
- **Why it matters**: Demonstrates whether a candidate can optimize computational complexity, memory consumption, and numerical precision across varied data dimensions ($N \gg D$, $D \gg N$, or massive streaming matrices).
- **Mathematical / Algorithmic Intuition**:
  Scikit-Learn supports four distinct solvers:
  1. `'full'`: Calls standard LAPACK solver `gesdd` to compute the full SVD. Computational complexity is $O(\min(N \cdot D^2, N^2 \cdot D))$. Exact, but unusable for massive matrices.
  2. `'arpack'`: Calls SciPy's wrapper around ARPACK (`scipy.sparse.linalg.svds`), implementing the implicitly restarted Arnoldi iteration. Efficient when extracting a very small number of components $d \ll \min(N, D)$, scaling as $O(d \cdot N \cdot D)$.
  3. `'randomized'`: Implements the randomized algorithm of Halko, Martinsson, and Tropp (2011). Projects $\mathbf{X}$ onto a random low-dimensional subspace of dimension $d + \text{n\_oversamples}$ using power iterations (`iterated_power`). It finds an approximate low-rank SVD in $O(N \cdot D \cdot d)$ time without calculating full matrices.
  4. `'auto'`: Selects the optimal solver based on input shape:
     - If $\max(N, D) > 500$ and $d < 0.8 \times \min(N, D)$, it defaults to `'randomized'`.
     - Otherwise, it falls back to `'full'`.
- **Syntax / Scikit-Learn API**:
  ```python
  from sklearn.decomposition import PCA
  # For massive matrices with few target components:
  pca_fast = PCA(n_components=10, svd_solver='randomized', iterated_power=3, random_state=42)
  ```
- **Minimal Working Example**:
  ```python
  import time
  import numpy as np
  from sklearn.decomposition import PCA

  # Large matrix: 5,000 samples, 1,000 features
  X = np.random.randn(5000, 1000)

  # Full LAPACK SVD
  t0 = time.perf_counter()
  pca_full = PCA(n_components=20, svd_solver='full').fit(X)
  t_full = time.perf_counter() - t0

  # Randomized SVD
  t0 = time.perf_counter()
  pca_rand = PCA(n_components=20, svd_solver='randomized', random_state=42).fit(X)
  t_rand = time.perf_counter() - t0

  print(f"Full LAPACK Fit Time: {t_full*1000:.2f} ms")
  print(f"Randomized Fit Time:  {t_rand*1000:.2f} ms (Speedup: {t_full/t_rand:.1f}x)")
  print(f"Variance Difference:  {abs(pca_full.explained_variance_ratio_.sum() - pca_rand.explained_variance_ratio_.sum()):.6f}")
  ```
- **Expected Output / Interpretation**:
  Randomized solver executes $3\text{--}10\times$ faster than `'full'` while the difference in total explained variance is negligible ($< 10^{-4}$).
- **Important Hyperparameters & Parameters**:
  - `iterated_power`: Number of power iterations for randomized SVD (default `'auto'`). Increasing it improves accuracy when singular values decay slowly.
  - `n_oversamples`: Additional random subspace dimensions (default 10) to guard against projection error.
- **Common Interview Confusion**: Trying to pass float variance thresholds (e.g. `n_components=0.95`) with `svd_solver='randomized'`. Fractional thresholds strictly require `svd_solver='full'` because the solver needs to evaluate the entire eigenvalue spectrum to determine the cutoff.

### Topic 7: Principal Components (`components_`)
- **Concept**: The `components_` attribute in Scikit-Learn's fitted `PCA` object represents the principal axes in feature space, corresponding to the right singular vectors (the rows of $\mathbf{V}_d^T$). Each component is a unit vector ($\|\mathbf{v}_k\|_2 = 1$) representing a linear combination of the original features.
- **Why it matters**: Evaluates whether a candidate can interpret component loadings, compute variable contributions, and diagnose which raw features drive latent variance.
- **Mathematical / Algorithmic Intuition**:
  The fitted attribute `pca.components_` has shape `(n_components, n_features)`:
  $$\mathbf{V}_d^T = \begin{bmatrix} v_{1,1} & v_{1,2} & \dots & v_{1,D} \\ v_{2,1} & v_{2,2} & \dots & v_{2,D} \\ \vdots & \vdots & \ddots & \vdots \\ v_{d,1} & v_{d,2} & \dots & v_{d,D} \end{bmatrix}$$
  The $k$-th transformed coordinate $z_{ik}$ for sample $i$ is calculated as the dot product between the centered sample vector and the $k$-th row of `components_`:
  $$z_{ik} = \sum_{j=1}^D (x_{ij} - \mu_j) v_{k,j}$$
  - **Component Loadings**: The covariance between the original standardized feature $x_j$ and the latent component $z_k$ is termed the **loading**:
    $$\text{Loading}(x_j, z_k) = v_{k,j} \sqrt{\lambda_k}$$
  - **Sign Ambiguity (Indeterminacy)**: The sign of any eigenvector is mathematically arbitrary: if $\mathbf{\Sigma} \mathbf{v} = \lambda \mathbf{v}$, then $\mathbf{\Sigma} (-\mathbf{v}) = \lambda (-\mathbf{v})$. Scikit-Learn resolves this via deterministic **sign flipping** (`svd_flip`), forcing the maximum absolute entry in each column of $\mathbf{V}$ to be positive to ensure reproducibility across machines.
- **Syntax / Scikit-Learn API**:
  ```python
  # Access right singular vectors
  projection_matrix = pca.components_ # Shape: (n_components, n_features)
  ```
- **Minimal Working Example**:
  ```python
  import pandas as pd
  from sklearn.datasets import load_iris
  from sklearn.decomposition import PCA
  from sklearn.preprocessing import StandardScaler

  iris = load_iris()
  X_scaled = StandardScaler().fit_transform(iris.data)

  pca = PCA(n_components=2, random_state=42).fit(X_scaled)

  # Display component loadings as a readable DataFrame
  loadings_df = pd.DataFrame(
      pca.components_,
      columns=iris.feature_names,
      index=['PC1', 'PC2']
  )
  print("Principal Component Loadings (V^T):")
  print(loadings_df.round(3))
  ```
- **Expected Output / Interpretation**:
  Output shows feature weights for each principal component. In PC1, `petal length` and `petal width` have large positive weights ($\approx +0.58$), confirming that PC1 primarily captures overall flower size.
- **Important Hyperparameters & Parameters**:
  - `components_`: Crucial for reconstructing raw signals and mapping transformed features back to domain variables.
- **Common Interview Confusion**: Confusing the transformed data matrix $\mathbf{Z} = \text{pca.transform}(\mathbf{X})$ (shape $N \times d$) with the projection matrix $\mathbf{V}_d^T = \text{pca.components\_}$ (shape $d \times D$).

### Topic 8: Explained Variance (`explained_variance_`)
- **Concept**: The `explained_variance_` attribute stores the empirical variance of the data projected onto each principal component. Mathematically, these values correspond exactly to the sorted eigenvalues $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_d$ of the sample covariance matrix.
- **Why it matters**: Demonstrates knowledge of variance accounting, eigenvalue calculations, and total variance conservation in linear algebra.
- **Mathematical / Algorithmic Intuition**:
  For mean-centered data $\mathbf{X}$, the projected data onto component $k$ is $\mathbf{z}_k = \mathbf{X} \mathbf{v}_k \in \mathbb{R}^N$.
  The sample variance of $\mathbf{z}_k$ with Bessel's correction ($N - 1$ degrees of freedom) is:
  $$\text{Var}(\mathbf{z}_k) = \frac{1}{N - 1} \sum_{i=1}^N (z_{ik} - \bar{z}_k)^2 = \frac{1}{N - 1} \mathbf{z}_k^T \mathbf{z}_k = \lambda_k$$
  From the SVD decomposition $\mathbf{X} = \mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T$, the singular values are $s_k$.
  The explained variance is computed directly from singular values without forming the covariance matrix:
  $$\lambda_k = \frac{s_k^2}{N - 1}$$
  - **Trace Conservation Theorem**: The sum of all $D$ eigenvalues of the covariance matrix equals the total variance of the original features:
    $$\sum_{j=1}^D \lambda_j = \text{Tr}(\mathbf{\Sigma}) = \sum_{j=1}^D \text{Var}(X_j)$$
  If features were standardized using `StandardScaler`, $\text{Var}(X_j) = 1.0$ for all $j$, meaning:
  $$\sum_{j=1}^D \lambda_j = D$$
- **Syntax / Scikit-Learn API**:
  `pca.explained_variance_`: 1D NumPy array of shape `(n_components,)` holding eigenvalues in descending order.
- **Minimal Working Example**:
  ```python
  from sklearn.datasets import load_wine
  from sklearn.preprocessing import StandardScaler
  from sklearn.decomposition import PCA
  import numpy as np

  X, _ = load_wine(return_X_y=True)
  X_scaled = StandardScaler().fit_transform(X)

  pca = PCA(n_components=X.shape[1]).fit(X_scaled)

  print("Sum of eigenvalues (explained variance):", np.sum(pca.explained_variance_).round(4))
  print("Number of original standardized features:", X.shape[1])
  print("First 3 eigenvalues:", pca.explained_variance_[:3].round(3))
  ```
- **Expected Output / Interpretation**:
  The sum of all 13 eigenvalues evaluates to exactly `13.0000`, validating the Trace Conservation Theorem for standardized data. The first eigenvalue is large ($\approx 4.7$), capturing over 35% of the total 13-dimensional variance.
- **Important Hyperparameters & Parameters**:
  - `singular_values_`: Stored singular values $s_k = \sqrt{(N - 1) \lambda_k}$.
- **Common Interview Confusion**: Forgetting Bessel's correction. In Scikit-Learn, `explained_variance_` divides by $N - 1$, matching `np.var(ddof=1)`. Using population variance ($\div N$) causes slight numerical discrepancies.

### Topic 9: Explained Variance Ratio (`explained_variance_ratio_`)
- **Concept**: The `explained_variance_ratio_` attribute quantifies the percentage of the dataset's total variance captured by each individual principal component, computed as the ratio of each eigenvalue to the sum of all eigenvalues.
- **Why it matters**: Essential for communicating information retention to stakeholders and determining cumulative thresholds for dimensionality reduction.
- **Mathematical / Algorithmic Intuition**:
  The explained variance ratio for component $k$ is:
  $$\text{EVR}_k = \frac{\lambda_k}{\sum_{j=1}^D \lambda_j} = \frac{s_k^2}{\sum_{j=1}^D s_j^2}$$
  Properties:
  1. $\text{EVR}_k \in [0, 1]$ for all $k$.
  2. $\text{EVR}_1 \ge \text{EVR}_2 \ge \dots \ge \text{EVR}_d$.
  3. The **cumulative explained variance ratio** across $d$ retained components is:
     $$\text{Cumulative EVR}(d) = \sum_{k=1}^d \text{EVR}_k = \frac{\sum_{k=1}^d \lambda_k}{\sum_{j=1}^D \lambda_j}$$
  The discarded variance ratio represents the proportional reconstruction error:
  $$\text{Error Ratio} = 1 - \text{Cumulative EVR}(d) = \frac{\sum_{j=d+1}^D \lambda_j}{\sum_{j=1}^D \lambda_j}$$
- **Syntax / Scikit-Learn API**:
  `pca.explained_variance_ratio_`: 1D array of shape `(n_components,)` containing proportions summing to $\le 1.0$.
- **Minimal Working Example**:
  ```python
  import numpy as np
  from sklearn.datasets import load_breast_cancer
  from sklearn.preprocessing import StandardScaler
  from sklearn.decomposition import PCA

  X, _ = load_breast_cancer(return_X_y=True)
  X_scaled = StandardScaler().fit_transform(X)

  pca = PCA(n_components=5).fit(X_scaled)
  evr = pca.explained_variance_ratio_
  cum_evr = np.cumsum(evr)

  for i in range(5):
      print(f"PC{i+1}: Individual = {evr[i]:6.2%} | Cumulative = {cum_evr[i]:6.2%}")
  ```
- **Expected Output / Interpretation**:
  PC1 captures $\approx 44.3\%$, PC2 captures $\approx 19.0\%$, PC3 captures $\approx 9.4\%$. The cumulative variance captured across 5 components is $\approx 84.7\%$, demonstrating that 5 components compress 30 features with only $\approx 15.3\%$ total information loss.
- **Important Hyperparameters & Parameters**:
  - `noise_variance_`: Estimated background isotropic noise variance $\sigma^2 = \frac{1}{D - d} \sum_{j=d+1}^D \lambda_j$ when using probabilistic PCA (`n_components < D`).
- **Common Interview Confusion**: Thinking that `pca.explained_variance_ratio_` sums to $1.0$ when $d < D$. It only sums to $1.0$ if all $D$ components are extracted ($d = D$).

### Topic 10: Number of Components (`n_components`)
- **Concept**: The `n_components` parameter governs the target latent dimensionality $d$. Scikit-Learn offers flexible options: an explicit integer ($d \ge 1$), a variance percentage float in $(0, 1)$, or Minka's automated Bayesian model selection (`'mle'`).
- **Why it matters**: Tests whether a candidate can automate hyperparameter selection and balance information retention against model complexity.
- **Mathematical / Algorithmic Intuition**:
  1. **Integer ($d \in [1, \min(N, D)]$):** Explicitly specifies the number of principal axes to extract.
  2. **Float ($0.0 < \alpha < 1.0$):** Retains the minimum integer $d$ such that:
     $$\sum_{k=1}^d \text{EVR}_k \ge \alpha$$
     Requires `svd_solver='full'`.
  3. **Minka's MLE (`n_components='mle'`):** Implements Thomas Minka's Bayesian model selection for probabilistic PCA (2000). It assumes data is generated by $d$ true latent Gaussian factors corrupted by isotropic noise $\sigma^2 \mathbf{I}$. It maximizes the Laplace approximation of the marginal likelihood $P(\mathbf{X} \mid d)$ to automatically detect the intrinsic dimension.
  4. **None (`n_components=None`):** Retains all $d = \min(N, D)$ components.
- **Syntax / Scikit-Learn API**:
  ```python
  # Option A: Fixed integer
  pca_int = PCA(n_components=10)
  # Option B: 95% variance threshold
  pca_var = PCA(n_components=0.95, svd_solver='full')
  # Option C: Automated MLE estimation
  pca_mle = PCA(n_components='mle', svd_solver='full')
  ```
- **Minimal Working Example**:
  ```python
  from sklearn.datasets import load_digits
  from sklearn.decomposition import PCA

  X, _ = load_digits(return_X_y=True)

  # Automated selection for 90% variance retention
  pca_90 = PCA(n_components=0.90, svd_solver='full').fit(X)
  # Automated selection via Minka's MLE
  pca_mle = PCA(n_components='mle', svd_solver='full').fit(X)

  print(f"Original feature count:       {X.shape[1]}")
  print(f"Components for 90% variance:  {pca_90.n_components_}")
  print(f"Components selected via MLE:  {pca_mle.n_components_}")
  ```
- **Expected Output / Interpretation**:
  Output shows reduction from 64 original pixel features down to 21 components for 90% variance, while MLE selects $\approx 40$ components as the intrinsic dimensionality of the digit manifold.
- **Important Hyperparameters & Parameters**:
  - `n_components_`: The actual integer number of components estimated and stored after fitting.
- **Common Interview Confusion**: Attempting to use `n_components='mle'` when $N < D$ or on sparse inputs. MLE assumes $N > D$ and requires full dense matrices.

### Topic 11: PCA Visualization (Scree Plots, Scatter Projections, Biplots)
- **Concept**: PCA visualization translates high-dimensional relationships into interpretable visual diagnostics: **Scree Plots** (eigenvalue decay), **2D/3D Scatter Projections** (cluster separability in latent space), and **Biplots** (joint visualization of observations and original feature loading vectors).
- **Why it matters**: Evaluates whether an engineer can translate abstract matrix factorizations into visual business insights and detect cluster separation, outliers, and feature correlations.
- **Mathematical / Algorithmic Intuition**:
  1. **Scree Plot**: Plots eigenvalue $\lambda_k$ (or EVR) against component index $k$. The "elbow" marks the transition from structured signal to the flat isotropic noise floor.
  2. **2D Projection Scatter**: Plots coordinates $(z_{i1}, z_{i2})$ where $\mathbf{z}_i = (\mathbf{x}_i - \boldsymbol{\mu}) \mathbf{V}_2$. Distances between points approximate Euclidean distances in the original space.
  3. **PCA Biplot**: Overlays feature loading vectors $\mathbf{v}_{\cdot, j} = [v_{1,j}, v_{2,j}]^T$ on top of the observation scatter plot:
     - The **length** of a loading arrow reflects the variance of feature $j$ captured in the 2D plane.
     - The **cosine of the angle** between two loading arrows approximates the correlation between those two original features:
       $$\cos(\theta_{jk}) \approx \text{Corr}(X_j, X_k)$$
       Arrows pointing in identical directions indicate strong positive correlation; orthogonal arrows indicate zero correlation; opposite arrows indicate negative correlation.
- **Syntax / Scikit-Learn API**:
  Executed using `matplotlib.pyplot` combined with `pca.explained_variance_ratio_`, `pca.transform()`, and `pca.components_`.
- **Minimal Working Example**:
  ```python
  import numpy as np
  from sklearn.datasets import load_iris
  from sklearn.preprocessing import StandardScaler
  from sklearn.decomposition import PCA

  iris = load_iris()
  X_scaled = StandardScaler().fit_transform(iris.data)

  pca = PCA(n_components=2).fit(X_scaled)
  Z = pca.transform(X_scaled)
  loadings = pca.components_.T # Shape: (4, 2)

  print(f"Transformed coordinates shape: {Z.shape}")
  print(f"Loading vectors for 4 features:\n{loadings.round(3)}")
  # Angle between petal length (idx 2) and petal width (idx 3):
  cos_angle = np.dot(loadings[2], loadings[3]) / (np.linalg.norm(loadings[2]) * np.linalg.norm(loadings[3]))
  print(f"Cosine similarity between petal length and width loading vectors: {cos_angle:.4f}")
  ```
- **Expected Output / Interpretation**:
  Outputs 2D coordinates `(150, 2)` and loading vectors. The cosine similarity between petal length and petal width arrows is $> 0.99$, visually and mathematically confirming their near-perfect correlation.
- **Important Hyperparameters & Parameters**:
  - Biplot scaling: Loading vectors are scaled by a factor (e.g. $\times 3$) to match the visual extent of the projected data scatter.
- **Common Interview Confusion**: Thinking the orientation of loading arrows in a biplot indicates the original spatial axes. Loading arrows show the projection of the original basis vectors into the PCA plane.

### A. Basic Questions (Exactly 20 Questions)

#### Q1: What is Principal Component Analysis (PCA)?
**Answer**: Principal Component Analysis is an unsupervised linear dimensionality reduction algorithm that projects high-dimensional data onto orthogonal coordinate axes that maximize variance and minimize reconstruction error. It decomposes the empirical covariance matrix of mean-centered features into eigenvalues and eigenvectors, where each eigenvector serves as a new principal component axis. In Scikit-Learn, it is imported via `from sklearn.decomposition import PCA` and conforms to the standard transformer API (`.fit()`, `.transform()`, `.fit_transform()`). A critical requirement is that input features must be standardized using `StandardScaler` prior to fitting, otherwise features with large raw numerical scales will artificially dominate the principal axes.

#### Q2: What are "principal components" in PCA?
**Answer**: Principal components are the sequence of mutually orthogonal unit vectors that define the new coordinate system of the data, ordered such that each successive component captures the maximum possible remaining variance. Mathematically, they correspond to the eigenvectors of the sample covariance matrix or the right singular vectors $\mathbf{V}^T$ in the Singular Value Decomposition $\mathbf{X} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^T$. In Scikit-Learn, these vectors are accessed via the fitted attribute `pca.components_`, which has shape `(n_components, n_features)`. A common interview trap is confusing the principal components (the projection vectors in `pca.components_`) with the transformed data coordinates (the projected samples returned by `pca.transform(X)`).

#### Q3: What is the difference between `pca.explained_variance_` and `pca.explained_variance_ratio_`?
**Answer**: `pca.explained_variance_` stores the raw empirical variance (eigenvalues $\lambda_j$) along each principal component in the units of squared feature values, whereas `pca.explained_variance_ratio_` expresses this variance as a normalized fraction of total dataset variance ($\lambda_j / \sum \lambda_k$). In Scikit-Learn, both are 1D NumPy arrays of length `n_components` sorted in strictly descending order. For standardized data where each feature has unit variance, `explained_variance_` values sum to the original number of features $D$, while `explained_variance_ratio_` values sum to $1.0$ if all components are retained. Novices often mistakenly expect `explained_variance_ratio_` to sum to $1.0$ even when only a truncated subset of components ($d < D$) is extracted.

#### Q4: Why does PCA require data to be mean-centered?
**Answer**: PCA requires mean-centering so that the first principal component aligns with the axis of maximum statistical variance rather than pointing toward the spatial offset of the data's center of mass. Mathematically, sample covariance is defined as $\mathbf{\Sigma} = \frac{1}{N - 1} \sum (\mathbf{x}_i - \boldsymbol{\mu})(\mathbf{x}_i - \boldsymbol{\mu})^T$; without subtracting $\boldsymbol{\mu}$, SVD optimizes the second moment matrix $\mathbf{X}^T \mathbf{X}$, whose dominant singular vector merely captures the distance from the origin to $\boldsymbol{\mu}$. In Scikit-Learn, `PCA` subtracts the empirical feature means automatically during `.fit()` and stores them in `pca.mean_`. However, this automatic centering converts sparse matrices into dense arrays, which is why `TruncatedSVD` must be used for sparse data instead.

#### Q5: How do you select the number of components using a variance threshold in Scikit-Learn?
**Answer**: You select the number of components by passing a floating-point value strictly between $0.0$ and $1.0$ to the `n_components` parameter, which instructs Scikit-Learn to retain the minimum number of components required to capture that fraction of total variance. For example, initializing `PCA(n_components=0.95, svd_solver='full')` will automatically compute eigenvalues and select $d$ such that $\sum_{k=1}^d \text{EVR}_k \ge 0.95$. In Scikit-Learn, the actual number of selected components can be inspected after fitting via the trailing attribute `pca.n_components_`. A subtle pitfall is that passing a float requires `svd_solver='full'`; attempting to use a float with `svd_solver='randomized'` will raise an immediate `ValueError`.

#### Q6: What does the `whiten=True` parameter do in Scikit-Learn's `PCA`?
**Answer**: The `whiten=True` parameter divides each projected coordinate by the square root of its corresponding eigenvalue ($z_{ik} \leftarrow z_{ik} / \sqrt{\lambda_k}$), forcing all transformed principal component features to have strictly identical unit variance ($\sigma^2 = 1.0$). By default, `whiten=False`, meaning that while components are uncorrelated, their variances are unequal ($\text{Var}(z_k) = \lambda_k$). In Scikit-Learn, whitening is implemented inside `pca.transform()` and is essential when feeding compressed representations into downstream estimators like RBF-kernel SVMs or distance-based nearest neighbors that assume isotropic spherical distributions. However, whitening must be avoided if trailing components contain high-frequency noise, as it artificially amplifies noise dimensions to equal magnitude with primary signals.

#### Q7: What is an eigenvalue in the context of PCA?
**Answer**: An eigenvalue $\lambda_k$ is a scalar that quantifies the total statistical variance of the data when projected along its corresponding eigenvector (principal component) $\mathbf{v}_k$. In the spectral equation $\mathbf{\Sigma} \mathbf{v}_k = \lambda_k \mathbf{v}_k$, the eigenvalue represents the factor by which the covariance matrix stretches space along the direction of $\mathbf{v}_k$. In Scikit-Learn, eigenvalues are stored in the fitted attribute `pca.explained_variance_`. A critical mathematical property is that the sum of all eigenvalues equals the trace of the sample covariance matrix, ensuring complete conservation of total multivariate variance.

#### Q8: What is an eigenvector in the context of PCA?
**Answer**: An eigenvector $\mathbf{v}_k$ is a non-zero unit vector that defines the spatial direction of a principal component axis, satisfying the condition that multiplying it by the covariance matrix yields a parallel vector scaled by its eigenvalue ($\mathbf{\Sigma} \mathbf{v}_k = \lambda_k \mathbf{v}_k$). Eigenvectors are mutually orthogonal ($\mathbf{v}_j^T \mathbf{v}_k = 0$ for $j \ne k$), ensuring that the new coordinate system has zero collinearity between axes. In Scikit-Learn, the eigenvectors are stored as the rows of `pca.components_`. Because eigenvectors are determined only up to a sign flip ($\pm \mathbf{v}$), Scikit-Learn enforces deterministic sign conventions via `svd_flip` to guarantee consistent outputs across runs.

#### Q9: What is a Scree Plot, and how is it used?
**Answer**: A scree plot is a 2D line graph that plots the eigenvalues or explained variance ratios on the vertical axis against the component indices on the horizontal axis in descending order. Analysts inspect the plot to locate the "elbow" or "knee"—the point where the curve sharply flattens out—which indicates that additional components contribute only negligible background noise. In Python, scree plots are generated using Matplotlib by plotting `plt.plot(np.arange(1, len(pca.explained_variance_) + 1), pca.explained_variance_, 'o-')`. The components before the elbow are retained for downstream modeling, while components after the elbow are safely discarded.

#### Q10: What does the `pca.inverse_transform()` method do?
**Answer**: The `pca.inverse_transform(Z)` method projects lower-dimensional latent coordinates $\mathbf{Z} \in \mathbb{R}^{N \times d}$ back into the original high-dimensional feature space $\mathbb{R}^{N \times D}$ using the transpose of the projection matrix: $\mathbf{\hat{X}} = \mathbf{Z} \mathbf{V}_d^T + \boldsymbol{\mu}$. It is primarily used to evaluate reconstruction quality, visualize compressed images, and perform unsupervised anomaly detection. In Scikit-Learn, if $d < D$, the reconstructed data $\mathbf{\hat{X}}$ will not match the original input $\mathbf{X}$ exactly because the variance along the discarded components $\sum_{j=d+1}^D \lambda_j$ was permanently lost. The reconstructed points are strictly constrained to lie on the fitted $d$-dimensional hyperplane.

#### Q11: What is the `svd_solver` parameter in Scikit-Learn's `PCA`?
**Answer**: The `svd_solver` parameter controls the underlying numerical linear algebra algorithm used to compute the Singular Value Decomposition of the mean-centered data matrix. It accepts four options: `'auto'` (dynamically chooses based on matrix size), `'full'` (exact standard LAPACK solver), `'arpack'` (truncated Arnoldi iteration for few components), and `'randomized'` (Halko et al.'s fast randomized matrix approximation). In Scikit-Learn, the default is `'auto'`, which switches to `'randomized'` when $N, D > 500$ and $d < 0.8 \times \min(N, D)$. Choosing `'randomized'` provides orders-of-magnitude speedups on large matrices with virtually zero loss in explained variance accuracy.

#### Q12: Why is PCA considered an unsupervised algorithm?
**Answer**: PCA is considered an unsupervised algorithm because its objective function optimizes variance and reconstruction loss purely over the feature matrix $\mathbf{X}$ without using or referencing target labels $y$. It seeks orthogonal directions that describe the geometric shape and spread of the input cloud regardless of how those directions relate to classes or regression targets. In Scikit-Learn, invoking `pca.fit(X, y)` simply ignores the `y` argument. A major consequence is that PCA can inadvertently discard low-variance dimensions that contain the entire class-discriminating signal if noise dominates total variance.

#### Q13: What is the difference between PCA and Linear Discriminant Analysis (LDA)?
**Answer**: PCA is an unsupervised technique that finds orthogonal axes maximizing total feature variance, whereas LDA is a supervised technique that finds axes maximizing the ratio of between-class scatter to within-class scatter. In Scikit-Learn, PCA is imported from `sklearn.decomposition` and optimizes variance blindly, while LDA is imported from `sklearn.discriminant_analysis` and requires target labels $y$ during `.fit(X, y)`. Furthermore, while PCA can extract up to $\min(N, D)$ components, LDA is mathematically restricted to extracting at most $C - 1$ components, where $C$ is the number of target classes. LDA is superior when class separation is the primary objective, whereas PCA is superior for unsupervised compression and noise removal.

#### Q14: How does PCA handle multicollinearity in linear models?
**Answer**: PCA eliminates multicollinearity completely by rotating the feature coordinate system onto the orthogonal eigenvectors of the sample covariance matrix, ensuring that all transformed principal components have exactly zero linear correlation ($\text{Cov}(z_j, z_k) = 0$). When multicollinearity is present, the raw data matrix $\mathbf{X}^T \mathbf{X}$ is ill-conditioned with near-zero eigenvalues, causing ordinary least squares coefficients to suffer from massive estimation variance and numerical instability. In Scikit-Learn, fitting `LogisticRegression()` or `LinearRegression()` on `PCA(n_components=d).fit_transform(X)` replaces collinear raw features with orthogonal variables, stabilizing parameter estimation and condition numbers.

#### Q15: What is Minka's MLE option in `PCA(n_components='mle')`?
**Answer**: Minka's MLE is an automated Bayesian model selection technique that estimates the true intrinsic dimensionality of a dataset by maximizing the Laplace approximation of the marginal data likelihood under a Probabilistic PCA generative model. When `n_components='mle'` is set, Scikit-Learn evaluates candidate dimensions $d$ assuming the data is generated by $d$ Gaussian latent factors corrupted by isotropic Gaussian noise $\sigma^2 \mathbf{I}$. It is invoked via `PCA(n_components='mle', svd_solver='full')`. It eliminates subjective manual tuning of scree plot elbows, but requires dense arrays and assumes sample size $N$ is strictly greater than feature dimension $D$.

#### Q16: What is a PCA Biplot?
**Answer**: A PCA biplot is a joint 2D visualization that simultaneously displays the projected sample coordinates as scatter points and the original feature loading vectors as directional arrows originating from the center. In Scikit-Learn, sample coordinates are obtained from `pca.transform(X)[:, :2]` and loading arrows are extracted from the first two rows of `pca.components_`. The direction and length of each arrow indicate how strongly that original feature contributes to PC1 and PC2, while the cosine of the angle between two arrows approximates the correlation between those two original features. Biplots provide a unified visual diagnostic for inspecting cluster separation alongside variable relationships.

#### Q17: What is the maximum number of components PCA can extract from an $N \times D$ matrix?
**Answer**: The maximum number of components PCA can extract is mathematically bounded by the rank of the mean-centered data matrix, which is at most $\min(N - 1, D)$. Mean-centering subtracts the sample mean vector, which imposes one linear constraint on the $N$ sample rows and restricts the data to an $(N - 1)$-dimensional affine subspace. In Scikit-Learn, passing `n_components=None` will extract exactly $\min(N, D)$ components, but if $N \le D$, the $N$-th component will have an eigenvalue of strictly $0.0$. Attempting to request `n_components > min(N, D)` raises a `ValueError`.

#### Q18: What is the relationship between PCA and Singular Value Decomposition (SVD)?
**Answer**: PCA on mean-centered data is mathematically equivalent to the Singular Value Decomposition of the centered data matrix divided by $\sqrt{N - 1}$. For a mean-centered matrix $\mathbf{X}_c$, the SVD is $\mathbf{X}_c = \mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T$; the right singular vectors $\mathbf{V}$ are the exact principal components (eigenvectors of $\mathbf{X}_c^T \mathbf{X}_c$), the singular values satisfy $s_j = \sqrt{(N - 1) \lambda_j}$, and the projected coordinates are $\mathbf{Z} = \mathbf{U} \mathbf{\Sigma}_{\text{svd}}$. In Scikit-Learn, `PCA` executes SVD directly rather than computing the covariance matrix $\mathbf{\Sigma} = \frac{1}{N - 1} \mathbf{X}_c^T \mathbf{X}_c$, achieving superior numerical stability and avoiding floating-point roundoff errors associated with matrix squaring.

#### Q19: What is `pca.mean_` and why is it stored?
**Answer**: The `pca.mean_` attribute is a 1D NumPy array of shape `(n_features,)` that stores the empirical mean of each original feature computed across the training samples during `.fit()`. It is stored so that subsequent calls to `pca.transform()` and `pca.inverse_transform()` can center new test data and un-center reconstructed vectors consistently: $\mathbf{Z}_{\text{test}} = (\mathbf{X}_{\text{test}} - \boldsymbol{\mu}) \mathbf{V}_d$ and $\mathbf{\hat{X}} = \mathbf{Z} \mathbf{V}_d^T + \boldsymbol{\mu}$. In Scikit-Learn, this ensures that out-of-sample test vectors are projected onto the coordinate system defined by the training data centroid without introducing data leakage.

#### Q20: Why should you never fit PCA on test data?
**Answer**: Fitting PCA on test data introduces severe data leakage because the learned projection axes and mean-centering offsets will incorporate the statistical distribution, variance, and outliers of the test set. If test data is used during fitting, downstream model evaluation metrics will be overly optimistic and will fail to generalize to true production inference streams. In Scikit-Learn, the correct workflow is to encapsulate PCA inside a `Pipeline([('scaler', StandardScaler()), ('pca', PCA(n_components=10)), ('clf', LogisticRegression())])` and call `.fit(X_train, y_train)`. Calling `pipeline.predict(X_test)` guarantees that test samples are transformed strictly using the frozen training parameters.

#### Q21: What is the exact mathematical proof that the eigenvectors of $\mathbf{X}^T \mathbf{X}$ maximize projected variance?
**Expected Answer**: Using the Rayleigh quotient and Lagrange multipliers, maximizing the projected variance $\mathbf{w}^T \mathbf{\Sigma} \mathbf{w}$ subject to $\|\mathbf{w}\|_2 = 1$ leads directly to the characteristic eigenvalue equation $\mathbf{\Sigma} \mathbf{w} = \lambda \mathbf{w}$.
**Technical Deep-Dive**: Let $\mathbf{X} \in \mathbb{R}^{N \times D}$ be mean-centered, with sample covariance matrix $\mathbf{\Sigma} = \frac{1}{N} \mathbf{X}^T \mathbf{X}$.
The projection of $\mathbf{X}$ onto a unit vector $\mathbf{w} \in \mathbb{R}^D$ is $\mathbf{z} = \mathbf{X} \mathbf{w}$. The variance of $\mathbf{z}$ is:
$$\text{Var}(\mathbf{z}) = \frac{1}{N} \mathbf{z}^T \mathbf{z} = \frac{1}{N} \mathbf{w}^T \mathbf{X}^T \mathbf{X} \mathbf{w} = \mathbf{w}^T \mathbf{\Sigma} \mathbf{w}$$
We formulate the constrained optimization problem:
$$\max_{\mathbf{w}} \mathbf{w}^T \mathbf{\Sigma} \mathbf{w} \quad \text{subject to} \quad \mathbf{w}^T \mathbf{w} = 1$$
We construct the Lagrangian function with multiplier $\lambda$:
$$\mathcal{L}(\mathbf{w}, \lambda) = \mathbf{w}^T \mathbf{\Sigma} \mathbf{w} - \lambda (\mathbf{w}^T \mathbf{w} - 1)$$
Taking the vector derivative with respect to $\mathbf{w}$ and setting to zero:
$$\nabla_{\mathbf{w}} \mathcal{L} = 2 \mathbf{\Sigma} \mathbf{w} - 2 \lambda \mathbf{w} = \mathbf{0} \implies \mathbf{\Sigma} \mathbf{w} = \lambda \mathbf{w}$$
This proves that any stationary point $\mathbf{w}$ must be an eigenvector of $\mathbf{\Sigma}$, and the scalar $\lambda$ is its corresponding eigenvalue.
Premultiplying both sides by $\mathbf{w}^T$:
$$\mathbf{w}^T \mathbf{\Sigma} \mathbf{w} = \lambda \mathbf{w}^T \mathbf{w} = \lambda$$
Thus, the projected variance is mathematically equal to the eigenvalue $\lambda$. To achieve the global maximum variance, $\mathbf{w}$ must be chosen as the eigenvector corresponding to the largest eigenvalue $\lambda_{\max} = \lambda_1$. Successive orthogonal components are derived by imposing orthogonality constraints $\mathbf{w}_k^T \mathbf{w}_j = 0$ for $j < k$, yielding successive eigenvectors.

#### Q22: How does the Randomized SVD algorithm of Halko et al. (2011) work inside Scikit-Learn?
**Expected Answer**: It projects the data matrix onto a random Gaussian subspace to find a low-rank orthonormal basis $\mathbf{Q}$, then computes a standard SVD on the tiny projected matrix $\mathbf{B} = \mathbf{Q}^T \mathbf{X}$.
**Technical Deep-Dive**: Computing full SVD on a massive matrix $\mathbf{X} \in \mathbb{R}^{N \times D}$ requires $O(\min(N D^2, N^2 D))$ operations.
When only $d \ll \min(N, D)$ components are required, Scikit-Learn implements `svd_solver='randomized'`:
1. **Random Projection**: Generate a random Gaussian matrix $\mathbf{\Omega} \in \mathbb{R}^{D \times (d + p)}$, where $p$ is an oversampling parameter (`n_oversamples=10`).
2. **Subspace Sampling**: Compute sample matrix $\mathbf{Y} = \mathbf{X} \mathbf{\Omega} \in \mathbb{R}^{N \times (d + p)}$. To accelerate singular value decay and suppress noise, apply $q$ power iterations (`iterated_power=auto`): $\mathbf{Y} = (\mathbf{X} \mathbf{X}^T)^q \mathbf{X} \mathbf{\Omega}$.
3. **QR Factorization**: Compute QR decomposition $\mathbf{Y} = \mathbf{Q} \mathbf{R}$, where $\mathbf{Q} \in \mathbb{R}^{N \times (d + p)}$ has orthonormal columns spanning the dominant range of $\mathbf{X}$.
4. **Subspace Projection**: Project $\mathbf{X}$ onto the low-dimensional basis: $\mathbf{B} = \mathbf{Q}^T \mathbf{X} \in \mathbb{R}^{(d + p) \times D}$.
5. **Small SVD**: Compute standard LAPACK SVD on the tiny matrix $\mathbf{B} = \mathbf{\tilde{U}} \mathbf{\Sigma} \mathbf{V}^T$.
6. **Reconstruction**: Set left singular vectors $\mathbf{U} = \mathbf{Q} \mathbf{\tilde{U}}$. Truncate matrices to the top $d$ components.
Complexity drops to $O(N \cdot D \cdot d)$, producing near-exact principal components in a fraction of the time.

#### Q23: Why does Scikit-Learn perform deterministic sign flipping (`svd_flip`) on singular vectors?
**Expected Answer**: SVD has inherent sign ambiguity ($\pm \mathbf{v}$ are both valid eigenvectors); `svd_flip` forces the largest absolute entry in each column of $\mathbf{V}$ to be positive to ensure deterministic outputs.
**Technical Deep-Dive**: If $\mathbf{X} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$, then negating both singular vectors simultaneously leaves the decomposition unchanged:
$$\mathbf{X} = (-\mathbf{U}) \mathbf{\Sigma} (-\mathbf{V}^T) = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$$
Because numerical LAPACK and ARPACK solvers rely on random initializations or machine-dependent floating-point roundoff, identical code executed on different CPU architectures or BLAS libraries can produce components with inverted signs ($\mathbf{v}$ vs $-\mathbf{v}$).
While the variance captured $\lambda$ is unaffected, inverted signs cause downstream model predictions, weights, and visualizations to flip inconsistently.
Scikit-Learn calls `sklearn.utils.extmath.svd_flip(u, v)`:
For each component $k$, it locates the row index $j = \arg\max_m |v_{k, m}|$. If $v_{k, j} < 0$, it multiplies both $\mathbf{u}_k$ and $\mathbf{v}_k$ by $-1$. This guarantees strict cross-platform reproducibility.

#### Q24: What is the mathematical connection between PCA and the Eckart-Young-Mirsky Low-Rank Approximation Theorem?
**Expected Answer**: The theorem proves that truncating the SVD of $\mathbf{X}$ to $d$ components provides the globally optimal rank-$d$ approximation minimizing the Frobenius norm error.
**Technical Deep-Dive**: The Eckart-Young-Mirsky Theorem (1936) states that given a matrix $\mathbf{X} \in \mathbb{R}^{N \times D}$ with SVD $\mathbf{X} = \sum_{j=1}^r s_j \mathbf{u}_j \mathbf{v}_j^T$ where $s_1 \ge s_2 \ge \dots \ge s_r > 0$, the optimal rank-$d$ matrix $\mathbf{X}_d$ ($d < r$) that minimizes the Frobenius norm distance satisfies:
$$\mathbf{X}_d = \arg\min_{\text{rank}(\mathbf{A}) \le d} \|\mathbf{X} - \mathbf{A}\|_F = \sum_{j=1}^d s_j \mathbf{u}_j \mathbf{v}_j^T$$
Furthermore, the minimum approximation error is strictly bounded by the discarded singular values:
$$\min_{\text{rank}(\mathbf{A}) \le d} \|\mathbf{X} - \mathbf{A}\|_F^2 = \sum_{j=d+1}^r s_j^2$$
Because PCA on mean-centered $\mathbf{X}$ computes this exact truncated SVD projection $\mathbf{\hat{X}} = \mathbf{X} \mathbf{V}_d \mathbf{V}_d^T$, PCA is mathematically guaranteed to be the best possible linear rank-$d$ reconstruction of the original dataset in terms of squared Euclidean distance.

#### Q25: How does Minka's Bayesian model selection for PCA (`n_components='mle'`) work?
**Expected Answer**: It evaluates the marginal likelihood of the data under a Probabilistic PCA model across dimensions $d$ using the Laplace approximation, selecting $d$ where likelihood peaks.
**Technical Deep-Dive**: Probabilistic PCA (Tipping & Bishop, 1999) reformulates PCA as a generative latent variable model:
$$\mathbf{x} = \mathbf{W} \mathbf{z} + \boldsymbol{\mu} + \boldsymbol{\epsilon}, \quad \mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_d), \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I}_D)$$
Thomas Minka (2000) formulated Bayesian dimensionality selection by treating $d$ as a discrete model index and computing the integrated evidence $P(\mathbf{X} \mid d) = \int P(\mathbf{X} \mid \mathbf{W}, \sigma^2, d) P(\mathbf{W}, \sigma^2) d\mathbf{W} d\sigma^2$.
Because the integral is intractable, Minka applied the Laplace approximation around the maximum likelihood estimates:
$$\ln P(\mathbf{X} \mid d) \approx \ln P(\mathbf{X} \mid \mathbf{\hat{W}}, \hat{\sigma}^2) + \frac{m_d}{2} \ln(2\pi) - \frac{1}{2} \ln |\mathbf{H}_d|$$
where $m_d = d \cdot D - d(d - 1)/2$ is the number of free parameters and $\mathbf{H}_d$ is the Hessian of negative log-likelihood.
In Scikit-Learn, `PCA(n_components='mle', svd_solver='full')` evaluates this closed-form approximation across all candidate values $d \in [1, D - 1]$ and selects the integer $d$ that maximizes the approximate evidence.

#### Q26: Why does PCA fail to capture non-linear variance and how does Kernel PCA solve it?
**Expected Answer**: PCA is restricted to finding flat linear subspaces; Kernel PCA uses the kernel trick to map data into a high-dimensional feature space where non-linear structures become linearly separable.
**Technical Deep-Dive**: Standard PCA finds hyperplanes $\mathbf{Z} = \mathbf{X} \mathbf{V}_d$. If the data lies on a non-linear manifold (e.g. concentric circles or spirals), no flat plane can separate the structures without crushing them together.
Kernel PCA (`sklearn.decomposition.KernelPCA`) applies a non-linear mapping $\Phi: \mathbb{R}^D \to \mathcal{H}$ to a Reproducing Kernel Hilbert Space $\mathcal{H}$.
Instead of computing the intractable covariance matrix in $\mathcal{H}$, it computes the $N \times N$ Gram kernel matrix $K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j) = \langle \Phi(\mathbf{x}_i), \Phi(\mathbf{x}_j) \rangle$ using Mercer kernels (such as RBF $k(\mathbf{x}, \mathbf{y}) = \exp(-\gamma \|\mathbf{x} - \mathbf{y}\|^2)$).
The centered Gram matrix $\mathbf{\tilde{K}}$ is diagonalized: $\mathbf{\tilde{K}} \boldsymbol{\alpha}_k = \lambda_k \boldsymbol{\alpha}_k$.
The non-linear projection of a sample $\mathbf{x}$ onto the $k$-th eigenvector is:
$$z_k(\mathbf{x}) = \sum_{i=1}^N \alpha_{k,i} k(\mathbf{x}_i, \mathbf{x})$$
This allows Kernel PCA to untangle complex non-linear manifolds, though it sacrifices linear invertibility and scales as $O(N^2)$ memory.

#### Q27: How does `IncrementalPCA` maintain exact or approximate singular values across streaming batches?
**Expected Answer**: It merges the current batch's singular values and means with the historical estimates using a rank-$d$ SVD update theorem without storing raw samples.
**Technical Deep-Dive**: Given historical summary statistics from $N_{\text{old}}$ samples with mean $\boldsymbol{\mu}_{\text{old}}$, singular values $\mathbf{S}_{\text{old}} \in \mathbb{R}^d$, and components $\mathbf{V}_{\text{old}} \in \mathbb{R}^{d \times D}$:
When a new batch $\mathbf{X}_{\text{batch}} \in \mathbb{R}^{B \times D}$ arrives with $B$ samples and mean $\boldsymbol{\mu}_{\text{batch}}$:
1. Compute the updated global mean:
   $$\boldsymbol{\mu}_{\text{new}} = \frac{N_{\text{old}} \boldsymbol{\mu}_{\text{old}} + B \boldsymbol{\mu}_{\text{batch}}}{N_{\text{old}} + B}$$
2. Mean-center the new batch against the updated mean: $\mathbf{\tilde{X}}_{\text{batch}} = \mathbf{X}_{\text{batch}} - \boldsymbol{\mu}_{\text{new}}$.
3. Compute the mean adjustment vector: $\boldsymbol{\Delta} = \sqrt{\frac{N_{\text{old}} \cdot B}{N_{\text{old}} + B}} (\boldsymbol{\mu}_{\text{old}} - \boldsymbol{\mu}_{\text{batch}})$.
4. Form the combined matrix $\mathbf{M} \in \mathbb{R}^{(d + B + 1) \times D}$:
   $$\mathbf{M} = \begin{bmatrix} \mathbf{S}_{\text{old}} \mathbf{V}_{\text{old}} \\ \mathbf{\tilde{X}}_{\text{batch}} \\ \boldsymbol{\Delta} \end{bmatrix}$$
5. Compute SVD on $\mathbf{M} = \mathbf{U}_M \mathbf{S}_{\text{new}} \mathbf{V}_{\text{new}}^T$.
6. Truncate $\mathbf{V}_{\text{new}}$ and $\mathbf{S}_{\text{new}}$ to the top $d$ rows.
In `sklearn.decomposition.IncrementalPCA`, this allows sequential out-of-core updates in $O(B \cdot D \cdot d)$ time and $O(B \cdot D)$ memory.

#### Q28: What is the relationship between the Condition Number of $\mathbf{X}^T \mathbf{X}$ and PCA dimensionality reduction?
**Expected Answer**: Dimensionality reduction truncates small eigenvalues, transforming an ill-conditioned system with condition number $\kappa \to \infty$ into a well-conditioned system with $\kappa = \lambda_1 / \lambda_d$.
**Technical Deep-Dive**: The $L_2$ condition number of the sample covariance matrix $\mathbf{\Sigma} \in \mathbb{R}^{D \times D}$ is:
$$\kappa(\mathbf{\Sigma}) = \frac{\lambda_{\max}}{\lambda_{\min}} = \frac{\lambda_1}{\lambda_D}$$
When features are highly collinear or when $D > N$, $\lambda_D \approx 0$, causing $\kappa(\mathbf{\Sigma}) \to \infty$.
In ordinary least squares regression $\boldsymbol{\hat{\beta}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$, the relative error in parameter estimation is bounded by:
$$\frac{\|\delta \boldsymbol{\hat{\beta}}\|}{\|\boldsymbol{\hat{\beta}}\|} \le \kappa(\mathbf{X}^T \mathbf{X}) \frac{\|\delta \mathbf{y}\|}{\|\mathbf{y}\|}$$
If $\kappa > 10^8$, small measurement perturbations in $\mathbf{y}$ cause massive swings in estimated weights.
By projecting data onto $d$ principal components, the transformed covariance matrix is $\mathbf{\Sigma}_Z = \text{diag}(\lambda_1, \dots, \lambda_d)$.
The condition number of the reduced system is strictly bounded by:
$$\kappa(\mathbf{\Sigma}_Z) = \frac{\lambda_1}{\lambda_d}$$
By choosing $d$ such that $\lambda_d$ remains comfortably above the noise floor, PCA guarantees a well-conditioned, numerically stable regression problem (Principal Component Regression).

#### Q29: How does the presence of extreme outliers distort PCA projections, and how is Robust PCA different?
**Expected Answer**: Because PCA minimizes squared Euclidean reconstruction errors ($L_2$ loss), extreme outliers exert massive leverage on the covariance matrix, tilting principal components toward the outliers.
**Technical Deep-Dive**: The empirical covariance matrix $\mathbf{\Sigma} = \frac{1}{N} \sum (\mathbf{x}_i - \boldsymbol{\mu})(\mathbf{x}_i - \boldsymbol{\mu})^T$ squares the distance of every point from the centroid.
A single extreme outlier $\mathbf{x}_{\text{out}}$ with magnitude $100\sigma$ contributes $(100\sigma)^2 = 10,000\sigma^2$ to the covariance sum, dominating all inlier variance.
As a result, the first principal component $\mathbf{v}_1$ will rotate away from the true data manifold and point directly toward the outlier.
- **Robust PCA (RPCA)**: Decomposes data matrix $\mathbf{X}$ into a low-rank matrix $\mathbf{L}$ plus a sparse outlier matrix $\mathbf{S}$:
  $$\min_{\mathbf{L}, \mathbf{S}} \|\mathbf{L}\|_* + \lambda \|\mathbf{S}\|_1 \quad \text{subject to} \quad \mathbf{X} = \mathbf{L} + \mathbf{S}$$
  where $\|\mathbf{L}\|_* = \sum s_i(\mathbf{L})$ is the nuclear norm (surrogate for matrix rank) and $\|\mathbf{S}\|_1 = \sum |S_{ij}|$ is the $L_1$ norm (enforcing sparsity).
RPCA isolates gross corruptions and sensor glitches into $\mathbf{S}$ while extracting the true uncorrupted low-rank manifold in $\mathbf{L}$.

#### Q30: What is the difference between PCA and Factor Analysis regarding the uniqueness variance $\mathbf{\Psi}$?
**Expected Answer**: PCA models total variance without separating noise; Factor Analysis explicitly models feature-specific uniqueness noise as a diagonal matrix $\mathbf{\Psi}$, capturing only shared common variance in $\mathbf{W}\mathbf{W}^T$.
**Technical Deep-Dive**:
- **PCA**: Decomposes total covariance $\mathbf{\Sigma} = \mathbf{V} \mathbf{\Lambda} \mathbf{V}^T$. It assumes every feature's variance is equally valid signal. If feature $x_1$ has high independent measurement noise, PCA absorbs that noise into its primary components.
- **Factor Analysis (`sklearn.decomposition.FactorAnalysis`)**: Assumes a generative linear model:
  $$\mathbf{x} = \mathbf{W} \mathbf{z} + \boldsymbol{\mu} + \boldsymbol{\epsilon}, \quad \mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_d), \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{\Psi})$$
  where $\mathbf{\Psi} = \text{diag}(\psi_1, \psi_2, \dots, \psi_D)$ with $\psi_j > 0$.
  The model covariance decomposes into:
  $$\mathbf{\Sigma}_{\text{model}} = \mathbf{W} \mathbf{W}^T + \mathbf{\Psi}$$
  Here, $\mathbf{W} \mathbf{W}^T$ represents **common variance** (correlation shared across features), while $\mathbf{\Psi}$ represents **uniqueness variance** (noise unique to each feature).
Factor Analysis fits $\mathbf{W}$ and $\mathbf{\Psi}$ via Expectation-Maximization. Unlike PCA, Factor Analysis components are invariant to independent feature noise additions.

#### Q31: What is the exact mathematical formula for the PCA loading matrix and its correlation with raw features?
**Expected Answer**: The loading matrix is $\mathbf{L} = \mathbf{V}_d \mathbf{\Lambda}_d^{1/2}$; the entry $L_{jk} = v_{k,j} \sqrt{\lambda_k}$ represents the exact covariance between raw feature $x_j$ and principal component $z_k$.
**Technical Deep-Dive**: Let $\mathbf{x} \in \mathbb{R}^D$ be standardized ($\mathbb{E}[x_j] = 0, \text{Var}(x_j) = 1$), and let $\mathbf{z} = \mathbf{V}_d^T \mathbf{x} \in \mathbb{R}^d$ be the latent coordinates.
The covariance between original feature $x_j$ and component $z_k$ is:
$$\text{Cov}(x_j, z_k) = \mathbb{E}[x_j z_k] = \mathbb{E}\left[x_j \sum_{m=1}^D v_{k,m} x_m\right] = \sum_{m=1}^D v_{k,m} \mathbb{E}[x_j x_m] = \sum_{m=1}^D v_{k,m} \Sigma_{jm}$$
In vector notation, this is the $j$-th entry of $\mathbf{\Sigma} \mathbf{v}_k$. Since $\mathbf{\Sigma} \mathbf{v}_k = \lambda_k \mathbf{v}_k$:
$$\text{Cov}(x_j, z_k) = \lambda_k v_{k,j}$$
The Pearson correlation coefficient between standardized feature $x_j$ and $z_k$ is:
$$\text{Corr}(x_j, z_k) = \frac{\text{Cov}(x_j, z_k)}{\sqrt{\text{Var}(x_j)} \sqrt{\text{Var}(z_k)}} = \frac{\lambda_k v_{k,j}}{1 \cdot \sqrt{\lambda_k}} = v_{k,j} \sqrt{\lambda_k}$$
This proves that multiplying the eigenvector weight $v_{k,j}$ by the square root of its eigenvalue $\sqrt{\lambda_k}$ gives the exact correlation between original feature $j$ and latent component $k$.

#### Q32: What happens when PCA is applied to discrete binary or one-hot encoded categorical features?
**Expected Answer**: PCA assumes continuous Gaussian geometries; applying it to sparse binary features produces distorted, non-orthogonal categorical planes, violating variance assumptions.
**Technical Deep-Dive**: One-hot encoded features are discrete indicator variables ($x_j \in \{0, 1\}$) whose variance is constrained by Bernoulli distribution mechanics: $\text{Var}(x_j) = p_j (1 - p_j)$.
1. **Variance Distortion**: Rare categories ($p_j = 0.01$) have tiny variance ($0.0099$) compared to common categories ($p_j = 0.5 \implies \text{Var} = 0.25$), causing PCA to ignore rare categories regardless of their predictive significance.
2. **Geometric Incompatibility**: Subtracting the mean turns binary variables into negative and positive fractional offsets, projecting discrete vertices of a hypercube onto continuous Euclidean hyperplanes.
3. **Correct Alternative**: For categorical data, the mathematically rigorous counterpart to PCA is **Multiple Correspondence Analysis (MCA)**, which normalizes by chi-squared distances rather than Euclidean covariance, or **Factor Analysis of Mixed Data (FAMD)**.

#### Q33: How does the `copy=False` parameter in `PCA` impact memory usage and input data integrity?
**Expected Answer**: `copy=False` mean-centers the input array in-place, reducing memory overhead by avoiding duplicate array allocation, but permanently overwriting the input data.
**Technical Deep-Dive**: By default, `copy=True`. During `.fit(X)`, Scikit-Learn allocates a new array of shape `(N, D)` to hold the mean-centered data: $\mathbf{X}_c = \mathbf{X} - \boldsymbol{\mu}$.
For a dataset with 50,000 samples and 10,000 float64 features, allocating $\mathbf{X}_c$ requires an additional $50,000 \times 10,000 \times 8 \text{ bytes} \approx 4 \text{ Gigabytes}$ of RAM.
If memory is constrained, setting `copy=False` executes in-place subtraction: `X -= mean`.
- **Critical Risk**: The original variable `X` passed by the user is permanently modified in place. Subsequent pipeline steps or evaluation routines that expect original raw features will silently operate on zero-mean centered values, potentially corrupting downstream models.

#### Q34: How does PCA handle isotropic noise, and what is the PPCA noise floor $\sigma^2$?
**Expected Answer**: Isotropic noise distributes equally across all dimensions; in the eigenvalue spectrum, signal components rise above a flat horizontal noise floor $\lambda_j \approx \sigma^2$.
**Technical Deep-Dive**: In Probabilistic PCA, observed covariance decomposes into signal covariance plus isotropic noise:
$$\mathbf{\Sigma} = \mathbf{W} \mathbf{W}^T + \sigma^2 \mathbf{I}_D$$
Let the true signal rank be $d$. The eigenvalues of $\mathbf{\Sigma}$ satisfy:
$$\lambda_j = \lambda_j^{\text{signal}} + \sigma^2 \quad \text{for } j \le d, \qquad \lambda_j = \sigma^2 \quad \text{for } j = d + 1, \dots, D$$
The trailing $D - d$ eigenvalues are all strictly equal to the noise variance $\sigma^2$.
In Scikit-Learn, when `n_components=d` ($d < D$), the attribute `pca.noise_variance_` computes the maximum likelihood estimate of the isotropic noise variance:
$$\hat{\sigma}^2 = \frac{1}{D - d} \sum_{j=d+1}^D \lambda_j$$
This value represents the average variance per discarded dimension, providing a formal statistical estimate of background sensor noise.

#### Q35: What is the difference between UMAP, t-SNE, and PCA for exploratory data visualization?
**Expected Answer**: PCA is a linear projection preserving global variance; t-SNE is non-linear and preserves local pairwise probabilities; UMAP preserves both local clustering and global topological structure using Riemannian geometry.
**Technical Deep-Dive**:
- **PCA**: Computes orthogonal projections minimizing global squared distance. Global Euclidean relationships are preserved, but complex non-linear cluster separation cannot be resolved in 2D.
- **t-SNE (`sklearn.manifold.TSNE`)**: Converts Euclidean distances into Gaussian probabilities in high dimensions and Student-t probabilities in low dimensions, minimizing KL divergence. It excels at separating discrete clusters, but global inter-cluster distances and cluster volumes are arbitrary and cannot be interpreted.
- **UMAP**: Assumes data lies on a Riemannian manifold with local metric spaces, optimizing cross-entropy between fuzzy topological simplicial complexes. It is substantially faster than t-SNE, scales to large sample sizes, preserves global inter-cluster topology significantly better, and supports an inductive `.transform()` method for out-of-sample data.

#### Q36: Why can PCA components be sensitive to feature engineering like polynomial features?
**Expected Answer**: Polynomial expansions create non-linear powers ($x_j^2, x_j^3$) with rapidly growing variances and heavy-tailed distributions that distort the linear covariance matrix.
**Technical Deep-Dive**: Expanding features via `PolynomialFeatures(degree=3)` generates cross-products and power terms.
If $x_j \sim \mathcal{N}(0, \sigma^2)$, then $x_j^2$ follows a chi-squared distribution with variance $2\sigma^4$, and $x_j^3$ has variance $15\sigma^6$.
Higher-order powers exhibit extreme variance disparities and heavy skewness.
When PCA is applied to polynomial features, the top eigenvectors align almost entirely with the highest-degree power terms due to their massive raw numerical variance, rather than capturing underlying structural relationships.
Furthermore, polynomial features are inherently collinear, exacerbating ill-conditioning. If polynomial features are required, robust scaling or regularization (`Ridge`) must precede PCA.

#### Q37: How do you perform out-of-sample validation of a PCA projection matrix?
**Expected Answer**: Project an independent test split using the frozen training projection matrix, compute the reconstruction error, and verify that test variance explained matches training variance.
**Technical Deep-Dive**: Let $\mathbf{V}_d \in \mathbb{R}^{D \times d}$ and $\boldsymbol{\mu}_{\text{train}} \in \mathbb{R}^D$ be fitted on `X_train`.
To validate stability:
1. Transform test data: $\mathbf{Z}_{\text{test}} = (\mathbf{X}_{\text{test}} - \boldsymbol{\mu}_{\text{train}}) \mathbf{V}_d$.
2. Reconstruct test data: $\mathbf{\hat{X}}_{\text{test}} = \mathbf{Z}_{\text{test}} \mathbf{V}_d^T + \boldsymbol{\mu}_{\text{train}}$.
3. Compute test reconstruction error:
   $$\text{MSE}_{\text{test}} = \frac{1}{N_{\text{test}}} \|\mathbf{X}_{\text{test}} - \mathbf{\hat{X}}_{\text{test}}\|_F^2$$
4. Compute the test explained variance ratio:
   $$\text{EVR}_{\text{test}} = 1 - \frac{\|\mathbf{X}_{\text{test}} - \mathbf{\hat{X}}_{\text{test}}\|_F^2}{\|\mathbf{X}_{\text{test}} - \boldsymbol{\mu}_{\text{train}}\|_F^2}$$
If $\text{EVR}_{\text{test}} \ll \text{EVR}_{\text{train}}$, the principal components overfit to idiosyncratic training correlations, indicating that $d$ was chosen too large.

#### Q38: What is Principal Component Regression (PCR) and how does it compare to Partial Least Squares (PLS)?
**Expected Answer**: PCR fits linear regression on unsupervised PCA components; PLS is a supervised alternative that finds latent components that maximize the covariance between $\mathbf{X}$ and target $\mathbf{y}$.
**Technical Deep-Dive**:
- **Principal Component Regression (PCR)**: Two-stage pipeline: (1) `Z = PCA(n_components=d).fit_transform(X)`; (2) `model = LinearRegression().fit(Z, y)`. Because PCA is unsupervised, the extracted components maximize $\text{Var}(\mathbf{X})$ without reference to $\mathbf{y}$. If the true regression relationship aligns with a low-variance direction, PCR fails completely.
- **Partial Least Squares (`sklearn.cross_decomposition.PLSRegression`)**: A supervised latent factor method that iteratively finds unit vectors $\mathbf{w}$ and $\mathbf{c}$ that maximize the squared covariance between projected features and projected targets:
  $$\max_{\|\mathbf{w}\|=1, \|\mathbf{c}\|=1} [\text{Cov}(\mathbf{X} \mathbf{w}, \mathbf{y} \mathbf{c})]^2$$
PLS guarantees that every extracted latent component carries predictive information regarding $\mathbf{y}$, frequently achieving higher predictive accuracy than PCR with fewer latent dimensions.

#### Q39: What is Sparse PCA (`SparsePCA`) and why is it used?
**Expected Answer**: Sparse PCA adds an $L_1$ penalty on component loading weights to produce sparse eigenvectors with many exact zeros, restoring direct physical feature interpretability.
**Technical Deep-Dive**: Standard PCA components are dense linear combinations where virtually every original feature has a non-zero loading $v_{k,j} \ne 0$. In a model with 500 features, interpreting a component requires reasoning about 500 simultaneous variables.
`sklearn.decomposition.SparsePCA` formulates dimensionality reduction as a penalized matrix decomposition:
$$\min_{\mathbf{U}, \mathbf{V}} \frac{1}{2} \|\mathbf{X} - \mathbf{U} \mathbf{V}^T\|_F^2 + \alpha \sum_{k=1}^d \|\mathbf{v}_k\|_1 \quad \text{subject to} \quad \|\mathbf{u}_k\|_2 = 1$$
The $L_1$ penalty ($\alpha$) drives non-essential feature weights strictly to zero.
Each resulting principal component is a linear combination of only a small handful of active original features (e.g., 5 out of 500), allowing domain experts to assign clear semantic identities to latent axes.
The trade-off is that Sparse PCA components are no longer strictly orthogonal, and solving it requires iterative coordinate descent rather than fast SVD.

#### Q40: How does PCA handle missing data, and how do you impute data in a PCA pipeline?
**Expected Answer**: Scikit-Learn's PCA cannot handle missing data and raises a `ValueError` if NaNs are present; missing data must be imputed using `SimpleImputer` or `IterativeImputer` inside a pipeline prior to PCA.
**Technical Deep-Dive**: Standard SVD requires complete numerical matrices to compute inner products. If a single entry $X_{ij} = \text{NaN}$, computing the mean $\mu_j$ or matrix product $(\mathbf{X} - \boldsymbol{\mu})^T (\mathbf{X} - \boldsymbol{\mu})$ evaluates to NaN, crashing LAPACK.
In Scikit-Learn, missing values are resolved by prepending an imputer:
```python
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer, KNNImputer
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler()),
    ('pca', PCA(n_components=5))
])
```
Advanced statistical alternatives include **Probabilistic PCA with Missing Data (PPCA-EM)**, which uses Expectation-Maximization to estimate component loadings directly around missing entries without imputation, though this requires custom estimators outside core Scikit-Learn.

  2. By the Trace Conservation Theorem, the total variance of the covariance matrix is $\text{Tr}(\mathbf{\Sigma}) = \sum_{j=1}^{10} \text{Var}(X_j) = 10 \times 1.0 = 10.0$.

  4. Because all components are retained, the sum of `explained_variance_ratio_` represents 100% of total variance, evaluating to `1.0`.

## 4. Top Questions to Definitely Prepare

### Must Know (Non-Negotiable Core)
1. **Explain the mathematical relationship between PCA, Covariance Eigendecomposition, and SVD.**
   - *Model Answer*: For a mean-centered data matrix $\mathbf{X}$, PCA computes the spectral decomposition of the sample covariance matrix $\mathbf{\Sigma} = \frac{1}{N - 1} \mathbf{X}^T \mathbf{X} = \mathbf{V} \mathbf{\Lambda} \mathbf{V}^T$, where eigenvectors $\mathbf{V}$ are the principal component directions and eigenvalues $\mathbf{\Lambda}$ are the projected variances. Equivalently, SVD decomposes $\mathbf{X} = \mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T$; the right singular vectors $\mathbf{V}$ are identical to the eigenvectors, and the singular values satisfy $s_j = \sqrt{(N - 1) \lambda_j}$. Scikit-Learn uses SVD directly because it avoids forming $\mathbf{X}^T \mathbf{X}$, offering superior numerical precision and stability.
2. **What is the difference between `explained_variance_` and `explained_variance_ratio_`?**
   - *Model Answer*: `explained_variance_` stores the absolute variance (eigenvalues $\lambda_j$) along each principal component in squared measurement units. `explained_variance_ratio_` divides each eigenvalue by the sum of all eigenvalues ($\lambda_j / \sum \lambda_k$), expressing the variance as a normalized proportion between $0$ and $1$. For standardized data, `explained_variance_` values sum to the original feature count $D$, while `explained_variance_ratio_` sums to $1.0$ if all components are retained.
3. **Why must you use `TruncatedSVD` instead of `PCA` for sparse TF-IDF matrices?**
   - *Model Answer*: Standard `PCA` mean-centers the data matrix by subtracting the empirical column means $\boldsymbol{\mu}$. In sparse matrices (e.g., text TF-IDF where 99.8% of entries are zero), centering subtracts a non-zero mean from every zero, turning the entire sparse matrix into a massive dense array and causing an immediate out-of-memory crash. `TruncatedSVD` avoids mean-centering entirely, operating natively on sparse CSR pointers to extract latent semantic components in constant RAM.
4. **How do you dynamically select the number of components to retain 95% variance in Scikit-Learn?**
   - *Model Answer*: Pass a float value `0.95` to the `n_components` parameter: `PCA(n_components=0.95, svd_solver='full')`. Scikit-Learn evaluates the full singular value spectrum, computes the cumulative sum of explained variance ratios, and automatically selects the minimum integer $d$ such that $\sum_{k=1}^d \text{EVR}_k \ge 0.95$. The chosen integer can be queried after fitting via `pca.n_components_`.
5. **What does `whiten=True` do in Scikit-Learn's PCA, and when should you use it?**
   - *Model Answer*: `whiten=True` divides each principal component by the square root of its eigenvalue ($z_{ik} \leftarrow z_{ik} / \sqrt{\lambda_k}$), scaling all latent features to have exactly unit variance and transforming the latent covariance matrix to the identity matrix $\mathbf{I}$. It is used when feeding features into downstream estimators that assume isotropic spherical distance distributions (such as RBF-kernel SVMs, K-Means, or Nearest Neighbors). However, it should not be used if trailing components contain high-frequency noise, as it amplifies noise to the same scale as dominant signals.

### Good to Know (Distinguishing Strong Candidates)
6. **How does the `svd_solver='randomized'` algorithm accelerate PCA on large datasets?**
   - *Model Answer*: Randomized SVD (Halko et al., 2011) projects the $N \times D$ data matrix onto a random Gaussian subspace of size $d + \text{n\_oversamples}$ using power iterations to find an orthonormal basis $\mathbf{Q}$. It then computes SVD on the tiny projected matrix $\mathbf{Q}^T \mathbf{X} \in \mathbb{R}^{(d+p) \times D}$ in $O(N \cdot D \cdot d)$ time, completely avoiding full $O(\min(ND^2, N^2D))$ LAPACK factorizations while achieving virtually identical explained variance accuracy.
7. **What is Minka's MLE option in `PCA(n_components='mle')`?**
   - *Model Answer*: It implements Thomas Minka's Bayesian model selection for Probabilistic PCA, which models data as $d$ Gaussian latent variables corrupted by isotropic Gaussian noise $\sigma^2 \mathbf{I}$. It uses the Laplace approximation of the marginal log-likelihood to evaluate candidate dimensions $d$ and automatically selects the intrinsic dimensionality that maximizes model evidence.
8. **What is sign indeterminacy in PCA and how does Scikit-Learn solve it?**
   - *Model Answer*: Eigenvectors are determined only up to a sign flip: if $\mathbf{\Sigma} \mathbf{v} = \lambda \mathbf{v}$, then $-\mathbf{v}$ is also an equally valid eigenvector. Across different BLAS/LAPACK libraries, components can flip signs arbitrarily. Scikit-Learn enforces deterministic reproducibility via `svd_flip`, which forces the maximum absolute element in each column of the projection matrix $\mathbf{V}$ to be strictly positive.
9. **How do you interpret the length and angle of arrows in a PCA Biplot?**
   - *Model Answer*: In a biplot, loading arrows represent the projection of original feature axes into the 2D PCA plane. The length of an arrow reflects the amount of variance of that feature captured in the 2D representation. The cosine of the angle $\theta$ between two feature arrows approximates their Pearson correlation: arrows pointing in the same direction indicate strong positive correlation ($\cos \theta \approx 1$), orthogonal arrows indicate zero correlation ($\cos \theta \approx 0$), and opposite arrows indicate strong negative correlation ($\cos \theta \approx -1$).
10. **What is the mathematical proof that PCA minimizes reconstruction error?**
    - *Model Answer*: By the Eckart-Young-Mirsky theorem, the rank-$d$ matrix approximation minimizing the Frobenius norm error $\|\mathbf{X} - \mathbf{A}\|_F^2$ is obtained by truncating the SVD to the top $d$ singular values: $\mathbf{\hat{X}} = \mathbf{X} \mathbf{V}_d \mathbf{V}_d^T$. The resulting mean squared error per sample is analytically equal to the sum of the discarded eigenvalues $\frac{1}{N}\|\mathbf{X} - \mathbf{\hat{X}}\|_F^2 = \sum_{j=d+1}^D \lambda_j$.

### Bonus (Exceptional Depth & Production Maturity)
11. **How does `IncrementalPCA` update SVD components across streaming batches without storing raw data?**
    - *Model Answer*: When a new batch arrives, `IncrementalPCA` updates the global mean vector, centers the batch against the updated mean, and forms a combined matrix $\mathbf{M}$ containing the historical singular values $\mathbf{S}_{\text{old}} \mathbf{V}_{\text{old}}$, the centered new batch, and a mean-correction rank-1 shift vector. It computes SVD on $\mathbf{M}$ and truncates back to the top $d$ components, maintaining exact or near-exact SVD representations in $O(B \cdot D \cdot d)$ time and constant RAM.
12. **What is the difference between Probabilistic PCA (PPCA) and Factor Analysis?**
    - *Model Answer*: Both model data as $\mathbf{x} = \mathbf{W}\mathbf{z} + \boldsymbol{\mu} + \boldsymbol{\epsilon}$. However, PPCA assumes isotropic spherical noise $\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$, where all features share the exact same noise variance. Factor Analysis assumes diagonal anisotropic uniqueness noise $\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{\Psi})$ where $\mathbf{\Psi} = \text{diag}(\psi_1, \dots, \psi_D)$, allowing each individual feature to have an independent noise variance.
13. **How does PCA reconstruction error enable unsupervised anomaly detection?**
    - *Model Answer*: Fitting PCA on normal data learns the dominant low-rank correlation manifold. Normal inliers reconstruct accurately with tiny residuals $\|\mathbf{x} - \mathbf{\hat{x}}\|^2 \approx 0$. Outliers that violate normal feature correlations have large components orthogonal to the fitted hyperplane along the discarded eigenvectors, producing massive reconstruction errors that exceed empirical percentile thresholds.

## 5. Common Beginner Mistakes (Exactly 10 Mistakes)

### Mistake 1: Forgetting Feature Standardization Before PCA
- **Why it happens**: Beginners assume PCA normalizes feature scale internally.
- **Correct approach**: Prepend `StandardScaler()` inside a Scikit-Learn `Pipeline` so that features with large numerical ranges (e.g. salary) do not artificially dominate the covariance matrix over small-scale features (e.g. age).
- **Code Demonstration**:
```python
# ❌ INCORRECT (High-Magnitude Features Dominate Unscaled PCA)
from sklearn.decomposition import PCA
import numpy as np

X = np.column_stack([np.random.normal(100000, 20000, 100), np.random.normal(5, 1, 100)])
pca_unscaled = PCA(n_components=1).fit(X)
print("Unscaled PC1 component weights:", pca_unscaled.components_[0]) # [0.99999, 0.00005]

# ✅ CORRECT (Standardization Ensures Balanced Covariance Contribution)
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

pipe = make_pipeline(StandardScaler(), PCA(n_components=1))
pipe.fit(X)
print("Scaled PC1 component weights:", pipe.named_steps['pca'].components_[0])
```

### Mistake 2: Data Leakage by Calling `fit_transform()` on the Entire Dataset
- **Why it happens**: Developers fit PCA on all data before splitting into train and test sets, contaminating the training set with test set covariance structures.
- **Correct approach**: Fit the PCA transformer strictly on `X_train`, and apply `.transform()` to `X_test`.
- **Code Demonstration**:
```python
# ❌ INCORRECT (Data Leakage: Test Data Leaks into PCA Components)
from sklearn.decomposition import PCA
from sklearn.model_selection import train_test_split
import numpy as np

X, y = np.random.randn(200, 20), np.random.randint(0, 2, 200)
X_pca = PCA(n_components=5).fit_transform(X) # LEAK!
X_train, X_test, y_train, y_test = train_test_split(X_pca, y, test_size=0.25)

# ✅ CORRECT (Fit Exclusively on Training Split via Pipeline)
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)
pipeline = Pipeline([
    ('pca', PCA(n_components=5, random_state=42)),
    ('clf', LogisticRegression())
])
pipeline.fit(X_train, y_train)
test_accuracy = pipeline.score(X_test, y_test)
```

### Mistake 5: Confusing Component Loadings (`components_`) with Projected Data (`transform()`)
- **Why it happens**: Novice engineers attempt to inspect `pca.components_` expecting it to have $N$ rows (sample coordinates).


## 6. Scikit-Learn API Confusions

| Concept 1 | Concept 2 | Key Architectural Difference | When to Use Which |
| :--- | :--- | :--- | :--- |
| **`PCA`** | **`TruncatedSVD`** | `PCA` centers data before SVD, measuring variance around sample mean. `TruncatedSVD` factors uncentered data, preserving matrix sparsity. | Use `PCA` for dense continuous data. Use `TruncatedSVD` for sparse matrices (TF-IDF text, user-item matrices). |
| **`PCA`** | **`IncrementalPCA`** | `PCA` requires the entire dataset in RAM for SVD. `IncrementalPCA` updates SVD sequentially in mini-batches via `partial_fit()`. | Use `PCA` when data fits in memory. Use `IncrementalPCA` when data exceeds system RAM (out-of-core learning). |

| **`PCA`** | **`FactorAnalysis`** | `PCA` decomposes total observed variance. `FactorAnalysis` is a probabilistic model separating common factor covariance from independent uniqueness noise. | Use `PCA` for reconstruction and geometric compression. | **`PCA`** | **`LinearDiscriminantAnalysis`** | `PCA` is unsupervised (maximizes total feature variance). `LDA` is supervised (maximizes class separation, limited to $\le C - 1$ components). | Use `PCA` for unsupervised clustering and compression. Use `LDA` when target labels are available and class separation is the goal. |

## 7. Interview Traps (Exactly 10 Traps)

### Trap 1: "Does PCA guarantee that the transformed components are statistically independent?"
- **Naive Candidate Answer**: "Yes, because PCA components are orthogonal, they are completely independent."
- **The Trap Unveiled**: Orthogonality guarantees **zero linear correlation** ($\text{Cov}(z_i, z_j) = 0$), but zero correlation implies statistical independence **only if the data is multivariate Gaussian**. For non-Gaussian data, components can have strong non-linear statistical dependencies while having zero linear covariance.
- **Winning Response**: "PCA guarantees that the components are linearly uncorrelated because the covariance matrix of $\mathbf{Z}$ is diagonal. However, statistical independence requires $P(z_1, z_2) = P(z_1)P(z_2)$, which involves all higher-order statistical moments. Zero correlation implies independence strictly under a multivariate normal distribution. If the data has non-linear dependencies, PCA components remain dependent. To pursue true statistical independence for non-Gaussian signals, one must use Independent Component Analysis (`FastICA`)."

### Trap 2: "Can PCA increase classification error even if it captures 98% of total variance?"
- **Naive Candidate Answer**: "No, retaining 98% of variance preserves almost all the information, so accuracy will not drop."
- **The Trap Unveiled**: PCA is unsupervised; it maximizes total variance across $\mathbf{X}$ completely blind to target labels $y$. The class-discriminating signal may reside in a low-variance direction that PCA discards as noise.
- **Winning Response**: "Yes, absolutely. Because PCA is completely unsupervised, it maximizes total variance, not class separability. Consider a dataset where the predictive signal separates two classes along a subtle direction with variance $\sigma^2 = 0.5$, while uninformative background sensor noise fluctuates wildly along orthogonal directions with variance $\sigma^2 = 100$. A PCA model set to retain 98% of variance will keep the noisy dimensions and discard the low-variance predictive axis as noise, crippling downstream classifier accuracy."

### Trap 3: "Why does `pca.explained_variance_` sum to $D$ for standardized features?"
- **Naive Candidate Answer**: "It's just a coincidence based on the number of samples."
- **The Trap Unveiled**: The Trace Conservation Theorem proves that the sum of the eigenvalues of a matrix equals the trace of the matrix: $\sum \lambda_j = \text{Tr}(\mathbf{\Sigma})$. For standardized features, the diagonal entries of the covariance matrix are all exactly $1.0$, meaning $\text{Tr}(\mathbf{\Sigma}) = D \times 1.0 = D$.
- **Winning Response**: "By the spectral theorem in linear algebra, the sum of all eigenvalues of the sample covariance matrix is mathematically identical to the trace of the covariance matrix: $\sum_{j=1}^D \lambda_j = \text{Tr}(\mathbf{\Sigma}) = \sum_{j=1}^D \text{Var}(X_j)$. When data is preprocessed with `StandardScaler`, every single feature is normalized to have unit variance ($\text{Var}(X_j) = 1.0$). Therefore, the trace of the standardized covariance matrix is $\sum_{j=1}^D 1.0 = D$. Consequently, the sum of all eigenvalues in `pca.explained_variance_` must evaluate exactly to $D$."

### Trap 4: "What is the exact mathematical relationship between SVD singular values $s_j$ and eigenvalues $\lambda_j$ in Scikit-Learn?"
- **Naive Candidate Answer**: "Singular values are just the square roots of the eigenvalues."
- **The Trap Unveiled**: Singular values are derived from the raw data matrix $\mathbf{X}$, while eigenvalues are derived from the sample covariance matrix $\mathbf{\Sigma} = \frac{1}{N - 1} \mathbf{X}^T \mathbf{X}$. The sample size Bessel correction factor $N - 1$ connects the two: $\lambda_j = \frac{s_j^2}{N - 1}$.
- **Winning Response**: "Given a mean-centered data matrix $\mathbf{X} \in \mathbb{R}^{N \times D}$ with SVD $\mathbf{X} = \mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T$, the singular values $s_j$ satisfy $\mathbf{X}^T \mathbf{X} = \mathbf{V} \mathbf{\Sigma}_{\text{svd}}^2 \mathbf{V}^T$. The sample covariance matrix incorporates Bessel's correction with $N - 1$ degrees of freedom: $\mathbf{\Sigma} = \frac{1}{N - 1} \mathbf{X}^T \mathbf{X}$. Therefore, the eigenvalues $\lambda_j$ stored in `pca.explained_variance_` relate to the singular values in `pca.singular_values_` via $\lambda_j = \frac{s_j^2}{N - 1}$, or equivalently $s_j = \sqrt{(N - 1) \lambda_j}$."

### Trap 5: "Why does `n_components='mle'` fail on high-dimensional text data or when $N < D$?"
- **Naive Candidate Answer**: "MLE only fails because text data has too many zeros."
- **The Trap Unveiled**: Minka's MLE evaluates the Laplace approximation of the marginal likelihood of Probabilistic PCA, which mathematically assumes dense Gaussian distributions and requires an estimate of the noise variance over $D - d$ dimensions. If $N < D$, the sample covariance matrix is singular, and the noise variance cannot be estimated.
- **Winning Response**: "Minka's MLE relies on the Probabilistic PCA model, which assumes data is generated by continuous Gaussian latent factors plus isotropic noise. When $N < D$, the sample covariance matrix is strictly rank-deficient ($\text{rank} \le N - 1$). The model cannot separate the signal subspace from the noise floor because the trailing eigenvalues are identically zero rather than positive isotropic noise $\sigma^2$. Furthermore, text matrices are sparse and multinomial rather than Gaussian. In Scikit-Learn, `PCA(n_components='mle')` requires full dense matrices and mathematically enforces $N > D$."

### Trap 6: "Does `copy=False` in `PCA` save memory at the cost of corrupting raw inputs?"
- **Naive Candidate Answer**: "No, `copy=False` is just an optimization flag that makes PCA run faster without side effects."
- **The Trap Unveiled**: `copy=False` avoids allocating a new centered array $\mathbf{X}_c$ by performing in-place subtraction: `X -= mean`. This permanently mutates the caller's original data variable in memory.
- **Winning Response**: "Yes, setting `copy=False` performs in-place mean-centering directly on the memory buffer of the input array `X`. While this saves significant RAM by avoiding the allocation of an identical $N \times D$ array, it permanently modifies the original data matrix to have zero mean. Any downstream code or concurrent threads that reference the original variable will receive centered data rather than original feature values. In production pipelines, `copy=False` should only be used if memory is strictly constrained and the raw input is discarded immediately after transformation."

### Trap 7: "What does `pca.noise_variance_` measure and when does it exist?"
- **Naive Candidate Answer**: "It measures the variance of the residuals after training a regression model."
- **The Trap Unveiled**: `pca.noise_variance_` is an attribute of Probabilistic PCA that measures the average variance of the discarded eigenvalues: $\hat{\sigma}^2 = \frac{1}{D - d} \sum_{j=d+1}^D \lambda_j$. It exists only when $d < \min(N, D)$.
- **Winning Response**: "In Probabilistic PCA, data is modeled as $d$ signal factors corrupted by isotropic Gaussian noise $\sigma^2 \mathbf{I}$. When `n_components=d` is strictly less than $\min(N, D)$, Scikit-Learn computes the maximum likelihood estimate of the isotropic noise variance as the arithmetic mean of the discarded eigenvalues: $\hat{\sigma}^2 = \frac{1}{D - d} \sum_{j=d+1}^D \lambda_j$. This is stored in `pca.noise_variance_`. If all components are retained ($d = \min(N, D)$), no dimensions are discarded, and `noise_variance_` evaluates to exactly `0.0`."

### Trap 8: "Can you run PCA on categorical one-hot encoded features without geometric distortion?"
- **Naive Candidate Answer**: "Yes, one-hot encoding converts categories to numbers, so PCA works normally."
- **The Trap Unveiled**: PCA assumes continuous, unbounded Gaussian geometries and minimizes Euclidean distances. Applying it to binary indicator variables projects discrete vertices of a simplex onto continuous hyperplanes, distorting categorical distances and violating variance assumptions.
- **Winning Response**: "No, applying standard PCA to one-hot encoded features causes significant geometric and statistical distortion. Binary features ($x_j \in \{0, 1\}$) violate the continuous Gaussian assumption, and their variance is strictly tied to marginal probabilities: $\text{Var}(x_j) = p_j(1 - p_j)$. PCA treats these variances as metric spread, heavily penalizing rare categories. Furthermore, centering binary variables subtracts fractional means, mapping discrete vertices of a hypercube onto continuous Euclidean hyperplanes. For categorical data, the mathematically proper technique is **Multiple Correspondence Analysis (MCA)**, which normalizes by chi-squared metric distances."

### Trap 9: "Why does a 2D PCA projection preserve global Euclidean distances while t-SNE does not?"
- **Naive Candidate Answer**: "Because PCA is newer and has a better loss function than t-SNE."
- **The Trap Unveiled**: PCA is a linear orthogonal projection that minimizes global squared reconstruction error; t-SNE is a non-linear probability matching algorithm that preserves local neighborhoods while intentionally warping global distances.
- **Winning Response**: "PCA is an orthogonal linear projection that minimizes the global squared Euclidean distance between original points and their low-dimensional projections ($\min \|\mathbf{X} - \mathbf{X}\mathbf{V}_d\mathbf{V}_d^T\|_F^2$). Consequently, global relative distances between distant clusters in a 2D PCA plot approximate true original Euclidean separations. In contrast, t-SNE minimizes the Kullback-Leibler divergence between high-dimensional Gaussian affinities and low-dimensional Student-t affinities. Its objective aggressively forces immediate neighbors together while allowing global distances between clusters to expand or contract arbitrarily. In a t-SNE plot, the distance between separate clusters has zero metric meaning."

### Trap 10: "If two features are perfectly negatively correlated ($r = -1.0$), what will PCA do with them?"
- **Naive Candidate Answer**: "PCA will assign them to two different orthogonal components."
- **The Trap Unveiled**: Two collinear features ($x_2 = -x_1$) form a 1-dimensional line in 2D space. PCA collapses them into a single principal component that captures 100% of their joint variance.
- **Winning Response**: "PCA evaluates geometric variance, not correlation sign. Two features with $r = -1.0$ form a perfectly straight diagonal line ($x_2 = -c \cdot x_1$). Because all data points lie exactly along this line, PCA will align its first principal component directly along this diagonal axis, capturing 100% of the total bivariate variance. The second orthogonal eigenvalue will be exactly zero. Thus, PCA compresses the two perfectly negatively correlated features into a single latent component without losing any information."

## 8. Real-World Scikit-Learn & Production Engineering

### Production Pattern 1: Serializing PCA Pipelines with Artifact Integrity
Deploying a raw PCA projection matrix without its accompanying `StandardScaler` offsets causes severe **training-serving skew** in production microservices. Encapsulating both inside a Scikit-Learn `Pipeline` guarantees that mean centering and unit variance scaling are applied atomically at inference time.

```python
import joblib
import numpy as np
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression

# 1. Construct atomic, leak-free pipeline
pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('pca', PCA(n_components=10, random_state=42)),
    ('classifier', LogisticRegression(random_state=42))
])

# 2. Simulate training on historical data
X_train = np.random.randn(1000, 50)
y_train = np.random.randint(0, 2, 1000)
pipeline.fit(X_train, y_train)

# 3. Serialize entire atomic artifact
artifact_path = "pipeline_artifact.joblib"
joblib.dump(pipeline, artifact_path, compress=3)

# 4. Production serving: Load and score single incoming vector without skew
loaded_pipeline = joblib.load(artifact_path)
raw_request = np.random.randn(1, 50)
prediction = loaded_pipeline.predict(raw_request)
print("Production inference successful. Prediction:", prediction)
```

### Production Pattern 2: Out-of-Core Dimensionality Reduction with `IncrementalPCA`
When training on enterprise datasets exceeding system RAM (e.g. 100 GB of genomic telemetry or image embeddings), standard `PCA` crashes with `MemoryError`. `IncrementalPCA` solves this by computing sequential low-rank SVD updates over mini-batches via `partial_fit()`.

```python
import numpy as np
from sklearn.decomposition import IncrementalPCA

# Simulate massive streaming dataset (10,000 samples, 100 features) in batches
n_samples = 10000
n_features = 100
batch_size = 500
n_components = 10

ipca = IncrementalPCA(n_components=n_components, batch_size=batch_size)

# Out-of-core streaming loop
for batch_idx in range(0, n_samples, batch_size):
    # Simulate loading batch from disk / network stream
    X_batch = np.random.randn(batch_size, n_features)
    ipca.partial_fit(X_batch)

print("IncrementalPCA streaming training complete.")
print(f"Total variance ratio explained: {np.sum(ipca.explained_variance_ratio_):.4f}")
```

### Production Pattern 3: Custom Transformer for Dynamic Variance Thresholding
Production systems often need to retain an adaptive number of components based on real-time variance drift. We implement a custom, scikit-learn compatible transformer adhering to the `BaseEstimator` and `TransformerMixin` contracts.

```python
import numpy as np
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.utils.validation import check_is_fitted, check_array
from sklearn.decomposition import PCA

class AdaptiveVariancePCA(BaseEstimator, TransformerMixin):
    """Dynamically retains components satisfying a variance retention ratio."""
    def __init__(self, variance_threshold=0.95):
        self.variance_threshold = variance_threshold

    def fit(self, X, y=None):
        X = check_array(X, accept_sparse=False)
        # Fit full PCA to inspect complete eigenvalue spectrum
        self.pca_full_ = PCA(svd_solver='full', random_state=42).fit(X)
        
        cumulative_variance = np.cumsum(self.pca_full_.explained_variance_ratio_)
        self.n_components_ = int(np.searchsorted(cumulative_variance, self.variance_threshold) + 1)
        self.n_components_ = min(self.n_components_, X.shape[1])
        
        # Store truncated projection matrix
        self.components_ = self.pca_full_.components_[:self.n_components_]
        self.mean_ = self.pca_full_.mean_
        return self

    def transform(self, X):
        check_is_fitted(self, ['components_', 'mean_', 'n_components_'])
        X = check_array(X, accept_sparse=False)
        return (X - self.mean_) @ self.components_.T

# Verification
X_test = np.random.randn(200, 40)
custom_pca = AdaptiveVariancePCA(variance_threshold=0.85).fit(X_test)
Z_custom = custom_pca.transform(X_test)
print(f"Adaptive PCA compressed 40 features to {custom_pca.n_components_} dimensions.")
```

- **Interview Question**: *"Walk me through this code. What is the output shape, why does setting `n_components=None` produce this specific dimension, and what mathematical theorem governs this behavior?"*
- **Ideal Interview Answer**:
  - The input data matrix has 200 samples and 50 features, but the target vector $y$ contains only $C = 2$ binary classes (`[0, 1]`).
  - When `n_components=None`, Scikit-Learn defaults to the maximum rank allowed by the between-class scatter matrix: $\min(n\_features, n\_classes - 1)$.
  - Here, $n\_classes - 1 = 2 - 1 = 1$. The between-class scatter matrix $\mathbf{S}_B$ is formed by outer products of class mean differences $(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T$, which has a mathematical matrix rank of strictly $1$.
  - Therefore, LDA projects the 50-dimensional input onto a **single 1-dimensional line** ($X_{\text{proj}} \in \mathbb{R}^{200 \times 1}$).
  - Output is `Output shape: (200, 1)`.

### Question 2: Why Does Reconstructing via `inverse_transform` Not Match the Original Array?
```python
from sklearn.decomposition import PCA
import numpy as np

X = np.array([[10, 20, 30], [40, 50, 60], [70, 80, 100]], dtype=float)
pca = PCA(n_components=1)
X_recon = pca.inverse_transform(pca.fit_transform(X))

print("Residual norm:", np.linalg.norm(X - X_recon))
print("Are arrays identical:", np.allclose(X, X_recon))
```
- **Interview Question**: *"Why does `np.allclose(X, X_recon)` return `False` despite using `inverse_transform`? Explain what mathematical operation is happening under the hood."*
- **Ideal Interview Answer**:
  - `PCA(n_components=1)` projects the 3-dimensional data onto a single 1-dimensional principal component axis: $\mathbf{Z} = (\mathbf{X} - \boldsymbol{\mu}) \mathbf{v}_1$.
  - `inverse_transform` computes $\mathbf{\hat{X}} = \mathbf{Z} \mathbf{v}_1^T + \boldsymbol{\mu}$. It attempts to reconstruct original 3D coordinates, but its values are mathematically constrained to lie strictly on the 1D line defined by $\mathbf{v}_1$ passing through $\boldsymbol{\mu}$.
  - The variation along eigenvectors $\mathbf{v}_2$ and $\mathbf{v}_3$ was permanently discarded during the forward compression step.
  - The residual norm $\|X - X_{\text{recon}}\|$ is strictly positive and equals the square root of the sum of the discarded eigenvalues $\sqrt{\lambda_2 + \lambda_3}$.
  - The output prints `Are arrays identical: False`.

### Question 3: How Does This Pipeline Guarantee Zero Test Set Contamination?
```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
import numpy as np

X, y = np.random.randn(100, 20), np.random.choice([0, 1], 100)

clf_pipe = Pipeline([
    ('scale', StandardScaler()),
    ('pca', PCA(n_components=5)),
    ('model', LogisticRegression())
])

scores = cross_val_score(clf_pipe, X, y, cv=5)
```
- **Interview Question**: *"Explain step-by-step how Scikit-Learn's `cross_val_score` interacts with `Pipeline` to prevent data leakage during scaling and dimensionality reduction."*
- **Ideal Interview Answer**:
  - `cross_val_score` partitions `X` and `y` into 5 distinct training and validation folds.
  - In each fold, `clf_pipe.fit()` is called **only on the 80% training slice**.
  - `StandardScaler.fit()` computes empirical means $\mu_{\text{train}}$ and variances $\sigma^2_{\text{train}}$ strictly from the training slice.
  - `PCA.fit()` calculates the sample covariance matrix and orthogonal projection matrix $\mathbf{V}_5$ strictly from the training slice.
  - When evaluating on the remaining 20% validation slice, `clf_pipe.score()` applies `scale.transform()` using the stored training parameters and projects using the stored training $\mathbf{V}_5$.
  - Zero information from the validation fold ever enters the PCA covariance calculation, completely preventing optimistic validation bias.

### Scenario 1: Dimensionality Reduction for Ultra-High-Dimensional Sparse E-Commerce Search
- **Context**: An e-commerce search engine indexes 10,000,000 product catalog items with a vocabulary of 250,000 tokens (TF-IDF sparse format). Real-time search query matching must execute in $< 5\text{ ms}$.

  - *Feature Selection (`VarianceThreshold`)*: Prunes rare tokens, but fails to capture synonyms (e.g. "sneakers" vs "running shoes").
  - *TruncatedSVD (Latent Semantic Analysis)*: Directly compresses sparse matrices to 128 dense dimensions without centering.
- **Production Solution**:
  1. Ingest raw text through `TfidfVectorizer(max_df=0.8, min_df=5, sublinear_tf=True)`.
  2. Stream batches through `TruncatedSVD(n_components=128, algorithm='randomized')`.
  3. Store the 128-dimensional dense vectors in a vector search index (e.g., FAISS or Milvus) utilizing HNSW graphs.
  4. Query vectors are transformed via `svd.transform(query_tfidf)` in $< 0.5\text{ ms}$, achieving the $< 5\text{ ms}$ retrieval SLA while capturing semantic synonymy.

### Scenario 2: Preprocessing Massive Genomics Data ($N = 2,000, D = 100,000$)

| 1 | What mathematical matrix does PCA decompose? | The empirical sample covariance matrix $\mathbf{\Sigma} = \frac{1}{N - 1} \mathbf{X}_c^T \mathbf{X}_c$ of mean-centered data. | In practice, Scikit-Learn performs SVD directly on $\mathbf{X}_c$ without forming $\mathbf{\Sigma}$. |

| 3 | What is stored in `pca.explained_variance_`? | The eigenvalues $\lambda_j$ of the sample covariance matrix in descending order. | Values represent empirical variance along each component. |
| 4 | What is the Trace Conservation Theorem in PCA? | The sum of all eigenvalues equals the sum of the variances of all original features. | For standardized data, $\sum \lambda_j = D$ (number of features). |
| 5 | What is the relation between SVD singular values $s_j$ and eigenvalues $\lambda_j$? | $\lambda_j = \frac{s_j^2}{N - 1}$ (or $s_j = \sqrt{(N - 1) \lambda_j}$). | Incorporates Bessel's sample degrees of freedom correction ($N - 1$). |

| 8 | What is `pca.mean_`? | The 1D array of original feature empirical means computed during `.fit()`. | Used to center test vectors during `.transform()` and uncenter in `inverse_transform()`. |
| 9 | What does `pca.noise_variance_` represent? | The average of the discarded eigenvalues: $\hat{\sigma}^2 = \frac{1}{D - d} \sum_{j=d+1}^D \lambda_j$. | Estimates the isotropic noise floor in Probabilistic PCA ($d < \min(N, D)$). |
| 10 | What does `n_components='mle'` do? | Uses Thomas Minka's Bayesian model selection to automatically estimate intrinsic dimension. | Requires full dense arrays and mathematically assumes $N > D$. |
| 11 | What is sign indeterminacy in PCA? | Eigenvectors are symmetric ($\mathbf{\Sigma} \mathbf{v} = \lambda \mathbf{v} \implies \mathbf{\Sigma} (-\mathbf{v}) = \lambda (-\mathbf{v})$). | Resolved deterministically in Scikit-Learn via `svd_flip`. |
| 12 | What is the mathematical formula for PCA reconstruction? | $\mathbf{\hat{X}} = \mathbf{Z} \mathbf{V}_d^T + \boldsymbol{\mu} = (\mathbf{X} - \boldsymbol{\mu}) \mathbf{V}_d \mathbf{V}_d^T + \boldsymbol{\mu}$. | Reconstruction MSE equals the sum of discarded eigenvalues. |
| 13 | Why should PCA never be fitted on test data? | Fitting on test data introduces data leakage, biasing validation and test metrics. | Always encapsulate PCA inside a Scikit-Learn `Pipeline`. |
| 14 | What is an elbow point on a PCA Scree Plot? | The inflection point where eigenvalue decay transitions from signal to isotropic noise. | Guides heuristic selection of optimal latent dimensionality $d$. |
| 15 | What is the angle between arrows in a PCA Biplot? | The cosine of the angle approximates the correlation between the two original features. | Collinear arrows imply $r \approx \pm 1$; orthogonal arrows imply $r \approx 0$. |
| 16 | What happens if $D > N$ in PCA? | The sample covariance matrix has rank at most $N - 1$; components beyond $N - 1$ have zero variance. | Scikit-Learn extracts at most $\min(N, D)$ components without error. |
| 17 | What does `svd_solver='auto'` choose for large matrices? | Switches to `'randomized'` if $\max(N, D) > 500$ and $d < 0.8 \times \min(N, D)$. | Provides major speedups using Halko's randomized matrix approximation. |

| 19 | What does `copy=False` do in PCA? | Performs in-place mean centering on the input array, saving RAM but mutating data. | Overwrites the caller's original variable in memory. |

## 16. Fresher Answer Patterns (Weak vs Strong Responses)

### Question 1: "How does PCA work mathematically, and why does Scikit-Learn use SVD instead of eigendecomposition?"

#### Weak Candidate Response:
> "PCA finds the directions where the data is spread out the most. It calculates the covariance matrix of the features and then finds the eigenvalues and eigenvectors. The biggest eigenvectors are the principal components. Scikit-Learn uses SVD because SVD is a built-in Python function that is faster."

#### Interviewer Critique:
The answer is superficial. The candidate knows the acronyms but fails to explain the objective function (Rayleigh quotient, variance maximization vs reconstruction loss), cannot explain what SVD is mathematically, and doesn't understand the numerical instability of explicitly computing $\mathbf{X}^T \mathbf{X}$.

#### Winning Fresher Answer:
> "Mathematically, PCA solves a constrained optimization problem: it seeks orthogonal unit vectors $\mathbf{w}$ that maximize projected data variance $\mathbf{w}^T \mathbf{\Sigma} \mathbf{w}$ subject to $\|\mathbf{w}\|_2 = 1$. By the Lagrangian multiplier formulation, this is equivalent to the characteristic eigenvalue equation $\mathbf{\Sigma} \mathbf{w} = \lambda \mathbf{w}$, where $\mathbf{\Sigma} = \frac{1}{N - 1} \mathbf{X}_c^T \mathbf{X}_c$ is the sample covariance matrix of mean-centered data.
> 
> In theory, one could compute $\mathbf{\Sigma}$ and perform eigendecomposition. However, Scikit-Learn executes Singular Value Decomposition (SVD) directly on the mean-centered data matrix: $\mathbf{X}_c = \mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T$.
> 
> Scikit-Learn uses SVD for two crucial numerical reasons:
> 1. **Numerical Stability**: Explicitly computing $\mathbf{X}^T \mathbf{X}$ squares the condition number of the matrix ($\kappa(\mathbf{X}^T \mathbf{X}) = \kappa(\mathbf{X})^2$). If $\mathbf{X}$ has small singular values near machine precision ($10^{-8}$), squaring them drops them below floating-point precision ($10^{-16}$), causing catastrophic cancellation. SVD operates directly on $\mathbf{X}$ without squaring.
> 2. **Computational Complexity**: When extracting $d \ll D$ components from large matrices, randomized SVD (`svd_solver='randomized'`) finds the low-rank basis in $O(N \cdot D \cdot d)$ time without ever allocating an $O(D^2)$ covariance matrix in RAM."

---

### Question 2: "What is the difference between PCA component weights (`components_`) and transformed data coordinates (`transform()`)?"

#### Weak Candidate Response:
> "They are basically the same thing just in different formats. `components_` is the array of components that PCA found, and `transform()` applies those components to the data so you get the new features."

#### Interviewer Critique:
The candidate confuses the transformation operator (the basis vectors) with the transformed representations of the observations. They do not know the array shapes ($d \times D$ vs $N \times d$) and cannot explain how one produces the other.

#### Winning Fresher Answer:
> "They represent fundamentally different linear algebra entities:
> 
> 1. **`pca.components_` is the Projection Matrix ($\mathbf{V}_d^T$)**: It has shape `(n_components, n_features)`. Each row is an orthonormal unit vector in feature space ($\|\mathbf{v}_k\|_2 = 1$) that defines the direction of a principal axis. The values $v_{k, j}$ are the **loadings** or weights of original feature $j$ in forming latent component $k$. It does not contain data samples; it contains feature coefficients.
> 
> 2. **`pca.transform(X)` is the Projected Data Matrix ($\mathbf{Z}$)**: It has shape `(n_samples, n_components)`. Each row represents an individual observation expressed in the new latent coordinate system. It is computed via matrix multiplication: $\mathbf{Z} = (\mathbf{X} - \boldsymbol{\mu}) \mathbf{V}_d$.
> 
> In summary, `components_` defines the orthogonal rotation axes, while `transform(X)` computes the coordinates of data points along those axes."

## 17. Questions That Test Understanding (Perturbation Analysis)

### Perturbation 1: Multiplying a Single Feature by 1,000 Before Unscaled PCA
- **Perturbation**: Feature $x_1$ is multiplied by 1,000 in raw unscaled data.
- **Effect on Covariance**: $\text{Var}(x_1)$ expands by $1,000^2 = 10^6$. The sample covariance matrix is completely dominated by column 1.
- **Effect on PCA**: The first principal component $\mathbf{v}_1$ aligns almost perfectly with the $x_1$ axis ($v_{1,1} \approx 1.0, v_{1,j} \approx 0$). Component 1 explains $\approx 99.99\%$ of variance solely due to unit scale, masking true multivariate correlation.
- **Mitigation**: Standardize features using `StandardScaler` so that all variables have unit variance ($\text{Var}=1.0$).

### Perturbation 2: Appending Duplicate Collinear Columns ($x_{\text{new}} = x_1$)
- **Perturbation**: An exact copy of feature $x_1$ is appended to the dataset.
- **Effect on Covariance**: The joint variance of feature 1 doubles.
- **Effect on PCA**: The eigenvalue associated with feature 1's subspace increases by a factor of 2. The principal component direction remains unchanged, but its relative importance in the eigenvalue spectrum is artificially inflated. The second duplicate dimension produces an eigenvalue of strictly $0.0$.
- **Lesson**: PCA handles multicollinearity seamlessly by compressing identical collinear columns into a single component with zero residual variance.

### Perturbation 3: Adding Isotropic Gaussian Noise to All Features ($\mathbf{X}_{\text{noisy}} = \mathbf{X} + \epsilon, \epsilon \sim \mathcal{N}(0, \sigma^2 \mathbf{I})$)
- **Perturbation**: Independent white noise of variance $\sigma^2$ is added to every feature.
- **Effect on Covariance**: Because the noise is independent and isotropic, $\text{Cov}(\epsilon) = \sigma^2 \mathbf{I}$. The new covariance matrix is $\mathbf{\Sigma}_{\text{noisy}} = \mathbf{\Sigma}_{\text{signal}} + \sigma^2 \mathbf{I}$.
- **Effect on Eigenvalues**: By Weyl's inequality in matrix perturbation theory, every single eigenvalue shifts upward by exactly the noise variance: $\lambda_j^{\text{noisy}} = \lambda_j^{\text{signal}} + \sigma^2$. The eigenvectors $\mathbf{v}_j$ remain completely unchanged!
- **Lesson**: PCA is robust to isotropic noise; it raises the baseline noise floor but leaves principal component directions intact.

The sample covariance matrix eigenvalues satisfy $\lambda_j = \frac{s_j^2}{N - 1}$.

### Distance Metrics & Clustering
- In high-dimensional spaces, distance concentration degrades K-Means and DBSCAN. Projecting data onto the top $d$ principal components strips out orthogonal noise dimensions, restoring pairwise distance contrast and dramatically accelerating convergence.

## 25. Final Revision Summary (2-Minute Drill)

- **Core Formula**: $\mathbf{\Sigma} \mathbf{v}_k = \lambda_k \mathbf{v}_k$. Eigendecomposition of sample covariance matrix. Scikit-Learn executes SVD on mean-centered $\mathbf{X} = \mathbf{U} \mathbf{\Sigma}_{\text{svd}} \mathbf{V}^T$.
- **Attributes**: `components_` = $\mathbf{V}_d^T$ (shape $d \times D$); `explained_variance_` = $\lambda_j$; `explained_variance_ratio_` = $\lambda_j / \sum \lambda_k$.
- **Eigenvalue-Singular Value Link**: $\lambda_j = \frac{s_j^2}{N - 1}$.
- **Trace Conservation**: For standardized data, $\sum_{j=1}^D \lambda_j = D$.
- **Reconstruction Loss**: $\text{MSE} = \sum_{j=d+1}^D \lambda_j$.
- **Whitening**: `whiten=True` scales by $1/\sqrt{\lambda_j}$, forcing $\text{Cov}(\mathbf{Z}) = \mathbf{I}$.
- **Top Trap**: Never pass float variance thresholds with `svd_solver='randomized'`; strictly use `svd_solver='full'`.

### The Golden Code Snippet
```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV

# Production-grade, leak-free, cross-validated PCA pipeline
pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('pca', PCA(svd_solver='full', random_state=42)),
    ('clf', LogisticRegression(max_iter=1000, random_state=42))
])

param_grid = {
    'pca__n_components': [0.85, 0.90, 0.95] # Optimize variance retention threshold
}

grid = GridSearchCV(pipeline, param_grid, cv=5, scoring='accuracy', n_jobs=-1)
grid.fit(X_train, y_train)

print(f"Optimal variance threshold: {grid.best_params_['pca__n_components']}")
print(f"Components selected: {grid.best_estimator_.named_steps['pca'].n_components_}")
print(f"Test Accuracy: {grid.score(X_test, y_test):.4f}")
```
