## 1. Section Overview

Outlier detection represents one of the foundational preprocessing and diagnostic pillars in applied machine learning. In production systems, data distributions are rarely pristine Gaussian manifolds; they are contaminated by sensor dropouts, transmission errors, adversarial injections, recording artifacts, and legitimate extreme events (such as market crashes or credit card fraud). 

Understanding the mathematical, statistical, and architectural properties of outliers is critical because machine learning estimators possess varying degrees of robustness (quantified formally by their **breakdown point** $\epsilon^*$). When unmitigated outliers enter a non-robust training pipeline:
1. Quadratic loss functions ($L_2$ norms in Linear Regression and Neural Networks) over-penalize extreme residuals, tilting hyperplanes away from the true data-generating distribution.
2. Centroid-based and distance-based estimators ($k$-Means, $k$-NN, Euclidean density estimators) suffer distance distortion, causing cluster centers to migrate and nearest-neighbor graphs to disconnect.
3. Feature preprocessing transforms (specifically `StandardScaler`) calculate biased empirical moments ($\bar{x}$ and $s^2$), causing the dynamic range of normal observations to collapse toward zero while outlier values dominate numerical scale.

This module formalizes the taxonomy of outliers, explores the mathematical mechanisms driving statistical deviation, contrasts the critical paradigms of **Outlier Detection vs. Novelty Detection** as codified in Scikit-Learn's API architecture, and analyzes the downstream degradation of machine learning estimators.

## 2. Topic-Wise Interview Concepts

### Topic 1: What is an Outlier?

#### 1. Formal Mathematical Definition
An **outlier** is an observation (or subset of observations) that deviates so significantly from the underlying probability density function $P(X)$ that it arouses suspicion that it was generated by a different mechanism $Q(X)$.

Formally, consider a mixture model:
$$P(X) = (1 - \gamma) P_{\text{inlier}}(X) + \gamma P_{\text{outlier}}(X)$$
where $\gamma \in [0, 0.5)$ represents the contamination rate, $P_{\text{inlier}}(X)$ represents the authentic nominal distribution, and $P_{\text{outlier}}(X)$ represents the contamination distribution characterized by heavy tails or disjoint support.

#### 2. Univariate vs. Multivariate Outliers
* **Univariate Outlier**: An observation that possesses an extreme value within the marginal distribution of a single isolated feature $x_j$, regardless of other dimensions.
  - *Standard Score (Z-Score)*: $Z_i = \frac{x_i - \mu}{\sigma}$. Observations with $|Z_i| > 3$ are flagged under Gaussian assumptions (covering $99.73\%$ of nominal mass).
  - *Tukey Fences (IQR)*: Based on quartiles $Q_1$ and $Q_3$, defining interquartile range $\text{IQR} = Q_3 - Q_1$.
    $$\text{Inner Fences (Outliers)}: [Q_1 - 1.5 \cdot \text{IQR}, \; Q_3 + 1.5 \cdot \text{IQR}]$$
    $$\text{Outer Fences (Extreme Outliers)}: [Q_1 - 3.0 \cdot \text{IQR}, \; Q_3 + 3.0 \cdot \text{IQR}]$$
  - *Median Absolute Deviation (MAD)*: Robust alternative to standard deviation with a $50\%$ breakdown point:
    $$\text{MAD} = \text{median}(|x_i - \text{median}(X)|)$$
    $$\text{Modified Z-Score}: M_i = \frac{0.6745 \cdot (x_i - \tilde{x})}{\text{MAD}}$$
* **Multivariate Outlier**: An observation whose individual feature values are completely normal within their respective 1D marginal distributions, but whose joint combination violates the multi-dimensional correlation structure.
  - Univariate metrics (like $Z$-score or Tukey fences) **completely fail** to detect multivariate outliers.
  - *Mahalanobis Distance*: Accounts for covariance structure $\boldsymbol{\Sigma}$:
    $$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})}$$
    Under multivariate normality $\mathbf{x} \sim \mathcal{N}_p(\boldsymbol{\mu}, \boldsymbol{\Sigma})$, the squared Mahalanobis distance follows a Chi-square distribution:
    $$D_M^2(\mathbf{x}) \sim \chi^2_p$$
    where $p$ is the dimensionality of feature space.

#### 3. Outlier Typologies in Regression: Leverage vs. Residual vs. Influence
In regression modeling ($y = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\epsilon}$), extreme data points are categorized along three distinct axes:
* **High Leverage Points ($h_{ii}$)**: Observations with extreme or unusual values in the feature space $\mathbf{X}$, far from the centroid $\bar{\mathbf{X}}$. Measured via the diagonal entries of the **Hat Matrix** $\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T$:
  $$h_{ii} = \mathbf{x}_i^T (\mathbf{X}^T\mathbf{X})^{-1} \mathbf{x}_i, \quad 0 \le h_{ii} \le 1, \quad \sum_{i=1}^n h_{ii} = p$$
  A point is considered high leverage if $h_{ii} > \frac{2p}{n}$ or $\frac{3p}{n}$.
* **Vertical Outliers (High Residuals $e_i$)**: Points that deviate significantly in the target dimension $y$ relative to the fitted surface, characterized by large studentized residuals:
  $$r_i = \frac{e_i}{s_{(i)} \sqrt{1 - h_{ii}}}$$
* **Influential Observations (Cook\'s Distance $D_i$)**: Points that exert substantial leverage AND possess large residuals, drastically shifting the parameter vector $\hat{\boldsymbol{\beta}}$ when removed:
  $$D_i = \frac{\sum_{j=1}^n (\hat{y}_j - \hat{y}_{j(i)})^2}{p \cdot s^2} = \frac{r_i^2}{p} \left(\frac{h_{ii}}{1 - h_{ii}}\right)$$
  Points with $D_i > 1$ or $D_i > \frac{4}{n}$ demand immediate investigative intervention.

### Topic 3: Effects of Outliers on ML Models

The sensitivity of an estimator to outliers is formally governed by its **Breakdown Point ($\epsilon^*$)**: the smallest fraction of arbitrarily large contaminated observations an estimator can handle before yielding arbitrarily incorrect estimates.

$$\epsilon^* = \min \left\{ \frac{m}{n} : \sup_{\mathbf{Z}'} \|\hat{\boldsymbol{\theta}}(\mathbf{Z}') - \hat{\boldsymbol{\theta}}(\mathbf{Z})\| = \infty \right\}$$

```
+---------------------------------------------------------------------------------------------------+
| MODEL / TRANSFORM          | BREAKDOWN POINT | MECHANISM OF DEGRADATION                           |
+----------------------------+-----------------+----------------------------------------------------+
| Sample Mean / OLS Reg.     | epsilon* = 1/n  | L2 quadratic loss squares errors:                  |
|                            | (0% asymptotically)| d/de (e^2) = 2e (unbounded gradient pull)         |
+----------------------------+-----------------+----------------------------------------------------+
| StandardScaler             | epsilon* = 1/n  | Biased sample variance s^2 inflates, shrinking     |
|                            | (0% asymptotically)| all standard z-scores of inliers toward zero       |
+----------------------------+-----------------+----------------------------------------------------+
| Principal Component Anal.  | epsilon* = 1/n  | Sample covariance matrix S is rotated toward the   |
| (Standard PCA)             | (0% asymptotically)| direction of maximal outlier dispersion            |
+----------------------------+-----------------+----------------------------------------------------+
| Support Vector Machine     | Finite positive | Hard-margin: Infeasible optimization               |
| (Linear / RBF SVM)         | (governed by C) | Soft-margin: Outliers become support vectors       |
+----------------------------+-----------------+----------------------------------------------------+
| k-Nearest Neighbors /      | Finite positive | Metric space distortion: Distant outlier shifts    |
| k-Means Clustering         | (governed by k) | Voronoi cell boundaries; cluster center pulled     |
+----------------------------+-----------------+----------------------------------------------------+
| Sample Median / MAD        | epsilon* = 50%  | Order-statistic based; invariant to magnitude of   |
|                            | (Optimal)       | extreme upper and lower quantiles                  |
+----------------------------+-----------------+----------------------------------------------------+
| RobustScaler               | epsilon* = 50%  | Scales using Median and IQR; immune to extreme     |
|                            |                 | values in tails                                    |
+----------------------------+-----------------+----------------------------------------------------+
| Tree-Based Models          | Invariant       | Monotonic ranking partitions: Splits are based on  |
| (Decision Trees, XGBoost)  | (Feature space) | order statistics, immune to extreme values in X    |
+----------------------------+-----------------+----------------------------------------------------+
```

#### Mathematical Proof: Why $L_2$ Loss Collapses Under Outliers
Consider ordinary least squares fitting a single parameter $\theta$:
$$J(\theta) = \sum_{i=1}^{n-1} (y_i - \theta)^2 + (y_{\text{outlier}} - \theta)^2$$
Setting $\frac{\partial J}{\partial \theta} = 0$:
$$-2 \sum_{i=1}^{n-1} (y_i - \theta) - 2(y_{\text{outlier}} - \theta) = 0 \implies \hat{\theta} = \frac{1}{n} \left(\sum_{i=1}^{n-1} y_i + y_{\text{outlier}}\right)$$
As $y_{\text{outlier}} \to \infty$, $\hat{\theta} \to \infty$. A single contaminated point drives the estimator to infinity ($\epsilon^* = 1/n \to 0$ as $n \to \infty$).

In contrast, under $L_1$ Mean Absolute Error loss:
$$J_{L_1}(\theta) = \sum_{i=1}^n |y_i - \theta| \implies \frac{\partial J}{\partial \theta} = -\sum_{i=1}^n \text{sign}(y_i - \theta) = 0$$
The derivative is bounded: $\left|\frac{\partial}{\partial e}\right| \le 1$. The solution is the **median**, which has a maximal asymptotic breakdown point of $50\%$.

### Topic 4: Outlier Detection vs. Anomaly / Novelty Detection

In standard machine learning literature and Scikit-Learn\'s architectural design, an essential distinction is drawn between **Outlier Detection** and **Novelty Detection**.

```
+----------------------------------------------------------------------------------------------------+
| ATTRIBUTE                  | OUTLIER DETECTION                    | NOVELTY DETECTION              |
+----------------------------+--------------------------------------+--------------------------------+
| Training Set Contamination | Contaminated ($P(X)$ contains rare   | Clean / Pristine               |
|                            | anomalies and noise)                 | ($P(X)$ contains ONLY nominal) |
+----------------------------+--------------------------------------+--------------------------------+
| Learning Paradigm          | Unsupervised / Transductive          | Semi-Supervised / Inductive    |
+----------------------------+--------------------------------------+--------------------------------+
| Core Objective             | Fit central mode while insulating    | Model regular envelope around  |
|                            | boundary from contaminated points    | known nominal class            |
+----------------------------+--------------------------------------+--------------------------------+
| Primary Application        | Data cleaning, robust estimation,    | Intrusion detection, engine    |
|                            | exploratory analysis on noisy sets   | fault monitoring, new trends   |
+----------------------------+--------------------------------------+--------------------------------+
| Scikit-Learn API Calls     | `fit_predict(X)`                     | `fit(X_clean)` then            |
|                            | (Evaluates training observations)    | `predict(X_novel)`             |
+----------------------------+--------------------------------------+--------------------------------+
| Scikit-Learn Estimators    | - `IsolationForest`                  | - `OneClassSVM`                |
|                            | - `LocalOutlierFactor(novelty=False)`| - `LocalOutlierFactor(novelty=True)`|
|                            | - `EllipticEnvelope`                 | - `IsolationForest`            |
+----------------------------+--------------------------------------+--------------------------------+
```

#### Key API Nuance: `LocalOutlierFactor`
* When `novelty=False` (default): LOF acts strictly as an **Outlier Detector**. It has no `predict()` method! It only provides `fit_predict(X)` and `negative_outlier_factor_` for in-sample training observations.
* When `novelty=True`: LOF acts as a **Novelty Detector**. It enables `predict()`, `decision_function()`, and `score_samples()` on brand-new out-of-sample data points, but cannot execute `fit_predict(X)` directly on training data.

## 3. Fresher Interview Questions

### A. Basic Questions (Exactly 20 Questions)

#### Q1: What is an outlier in simple terms?
**Answer:**
An outlier is a data point that differs significantly from other observations in the same dataset. It lies at an abnormal distance from the other values and does not follow the general pattern or distribution established by the remaining population.

#### Q2: What is the difference between a univariate and a multivariate outlier?
**Answer:**
A univariate outlier is anomalous when looking at a single individual feature in isolation (e.g., human age = 250 years). A multivariate outlier looks completely normal within every individual 1D feature distribution, but represents an impossible or anomalous combination when two or more features are considered jointly (e.g., human age = 4 years AND height = 6 feet 2 inches).

#### Q3: What is the 3-Sigma Rule (Empirical Rule)?
**Answer:**
For data following an approximately normal (Gaussian) distribution:
* $68.27\%$ of data falls within $\mu \pm 1\sigma$.
* $95.45\%$ of data falls within $\mu \pm 2\sigma$.
* $99.73\%$ of data falls within $\mu \pm 3\sigma$.
Any data point with $|Z| > 3$ ($x > \mu + 3\sigma$ or $x < \mu - 3\sigma$) occurs with less than $0.27\%$ probability and is conventionally flagged as an outlier.

#### Q4: How do Tukey Fences detect outliers using IQR?
**Answer:**
Tukey\'s method computes the First Quartile ($Q_1$, 25th percentile) and Third Quartile ($Q_3$, 75th percentile) to find the Interquartile Range $\text{IQR} = Q_3 - Q_1$. It establishes bounds:
* Lower Bound: $Q_1 - 1.5 \times \text{IQR}$
* Upper Bound: $Q_3 + 1.5 \times \text{IQR}$
Any point outside these fences is categorized as an outlier. It requires no assumption of Gaussian normality.

#### Q5: Why is the median more robust than the mean in the presence of outliers?
**Answer:**
The sample mean sums all values and divides by $n$. A single arbitrarily large outlier ($x \to \infty$) pulls the mean to infinity. The median is an order statistic: it only depends on the middle rank. Changing the most extreme value to infinity does not change the middle element, giving the median a 50% breakdown point compared to the mean\'s $1/n$ breakdown point.

#### Q6: What is a leverage point in regression?
**Answer:**
A leverage point is an observation with extreme values in the independent feature space ($X$). It is located far from the centroid of the predictor variables. Leverage is measured by the diagonal elements $h_{ii}$ of the Hat matrix $\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T$. High leverage points have the potential to exert strong control over the fitted regression line.

#### Q7: What is an influential observation, and how is it measured?
**Answer:**
An influential observation is a data point whose removal substantially alters the estimated regression coefficients. It combines high leverage in feature space $X$ with a large residual in target space $y$. It is most commonly measured via Cook\'s Distance:
$$D_i = \frac{e_i^2}{p \cdot s^2} \left(\frac{h_{ii}}{(1 - h_{ii})^2}\right)$$
Points with Cook\'s Distance greater than $1.0$ (or $4/n$) are considered highly influential.

#### Q8: What is Cook\'s Distance in simple terms?
**Answer:**
Cook\'s Distance measures how much all fitted values in the model ($\hat{y}_1, \dots, \hat{y}_n$) would change if the $i$-th observation were completely omitted from model training. If removing one point drastically shifts the entire prediction line, that point is influential.

#### Q9: Can an outlier be a high leverage point without being influential?
**Answer:**
Yes. If an observation has an extreme value in feature space $X$ (high leverage), but its target value $y$ falls exactly along the regression trend line formed by all other points (residual $e_i \approx 0$), its Cook\'s distance will be near zero. It does not alter the estimated slope $\hat{\beta}$, so it is not influential.

#### Q10: What is the Breakdown Point of a statistical estimator?
**Answer:**
The breakdown point ($\epsilon^*$) is the smallest proportion of arbitrary contamination an estimator can endure before returning arbitrarily incorrect or infinite estimates. For example, the sample mean has $\epsilon^* = 1/n$ (collapses with 1 outlier), while the sample median has $\epsilon^* = 0.5$ (can handle up to 50% corrupted points).

#### Q11: What is Novelty Detection?
**Answer:**
Novelty detection is a semi-supervised learning paradigm where the training dataset is assumed to be clean and uncontaminated by outliers. The algorithm learns the boundary or density profile of the "normal" class. It then evaluates whether future, unseen test instances belong to this known distribution or represent a novel pattern.

#### Q12: What is Outlier Detection in Scikit-Learn?
**Answer:**
Outlier detection is an unsupervised learning task where the training dataset is known to be contaminated with anomalous points. The algorithm attempts to fit the central concentrated region of the training data while ignoring or identifying the anomalous points present in that very same training sample.

#### Q13: Why does `StandardScaler` fail when data contains extreme outliers?
**Answer:**
`StandardScaler` uses the empirical sample mean ($\mu$) and standard deviation ($\sigma$). Outliers heavily inflate $\sigma$ and pull $\mu$. As a result, inliers get compressed into an extremely narrow range close to zero, destroying the feature resolution for gradient-based or distance-based algorithms.

#### Q14: Which Scikit-Learn scaler is specifically designed to handle outliers?
**Answer:**
`RobustScaler`. It removes the median and scales the data according to the Interquartile Range (IQR, between the 25th and 75th percentiles). Because both median and IQR have high breakdown points, extreme outliers do not distort the scaling parameters.

#### Q15: How do outliers affect $k$-Means clustering?
**Answer:**
$k$-Means minimizes the sum of squared Euclidean distances to cluster centroids. Outliers pull the centroids toward themselves, frequently creating artificial clusters containing only 1 or 2 outlier points, while merging legitimate distinct clusters together.

#### Q16: How do outliers affect linear regression?
**Answer:**
Linear regression minimizes residual sum of squares ($\sum e_i^2$). Squaring errors causes large residuals to dominate the loss function. A single extreme outlier forces the regression plane to pivot toward it to minimize its squared penalty, degrading predictive performance on all normal observations.

#### Q17: Are decision trees sensitive to outliers in input features?
**Answer:**
No. Decision trees use rank-order splitting criteria (e.g., "is feature $x_j > \theta$?"). The exact numeric magnitude of extreme points does not matter; only whether they fall to the left or right of a threshold. Therefore, trees and tree ensembles (Random Forests, Gradient Boosting) are completely robust to outliers in feature space $X$.

#### Q18: Are decision trees sensitive to outliers in regression targets $y$?
**Answer:**
Yes. In regression trees, the leaf prediction is the mean of all target values landing in that leaf. If an outlier with an extreme $y$-value lands in a leaf, it inflates the mean prediction of that entire terminal node unless a robust split criterion (like Mean Absolute Error) is specified.

#### Q19: What is the difference between an error and an anomaly?
**Answer:**
An error is incorrect data generated by measurement failure, transmission loss, or human typo (noise to be cleaned). An anomaly is a genuine, valid real-world observation that deviates from typical behavior (such as credit card fraud or rare diseases) and carries high business or scientific value.

#### Q20: What is the Mahalanobis Distance and why is it preferred over Euclidean distance for outlier detection?
**Answer:**
Mahalanobis distance measures the distance between a point $\mathbf{x}$ and a distribution with mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$:
$$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})}$$
Unlike Euclidean distance, it scales features by their variance and accounts for multi-feature correlations, preventing false flags in highly correlated feature spaces.

### B. Intermediate Questions (Exactly 20 Questions)

#### Q21: What is the masking effect in outlier detection?
**Answer:**
Masking occurs when the presence of multiple outliers clusters closely together, causing them to hide each other from detection algorithms. For example, a cluster of high outliers inflates the sample mean and variance to such a degree that their individual $Z$-scores drop below the threshold (e.g., $Z < 3$), masking their anomalous nature.

#### Q22: What is the swamping effect?
**Answer:**
Swamping occurs when a cluster of extreme outliers artificially inflates the sample variance or covariance so drastically that completely normal inlier observations are falsely identified as outliers.

#### Q23: Why does the standard Z-score suffer from both masking and swamping?
**Answer:**
Because the parameters $\mu$ and $\sigma$ used to calculate $Z_i = (x_i - \mu)/\sigma$ are themselves computed from the contaminated sample. Outliers inflate both $\mu$ and $\sigma$ simultaneously. To resolve this, statisticians use the **Modified Z-Score** based on the median and Median Absolute Deviation (MAD).

#### Q24: How is the Modified Z-Score calculated using MAD?
**Answer:**
$$\text{MAD} = \text{median}(|x_i - \tilde{x}|)$$
$$\text{Modified } Z_i = \frac{0.6745 \cdot (x_i - \tilde{x})}{\text{MAD}}$$
The factor $0.6745$ is the reciprocal of the 75th percentile of the standard normal distribution ($\Phi^{-1}(0.75) \approx 0.6745$), ensuring that for pure Gaussian data, $\text{MAD} / 0.6745 \approx \sigma$. Observations with $|\text{Modified } Z_i| > 3.5$ are flagged.

#### Q25: Why is Euclidean distance fundamentally flawed for multivariate outlier detection?
**Answer:**
Euclidean distance assumes that all feature dimensions are spherical, uncorrelated, and possess identical variance. If two features are correlated (e.g., height and weight), a point lying far outside the correlation axis will have a short Euclidean distance to the center, leading to false negatives.

#### Q26: How does the Chi-Square distribution relate to Mahalanobis distance?
**Answer:**
If $\mathbf{x} \in \mathbb{R}^p$ follows a multivariate normal distribution $\mathcal{N}_p(\boldsymbol{\mu}, \boldsymbol{\Sigma})$, the squared Mahalanobis distance follows a Chi-square distribution with $p$ degrees of freedom:
$$D_M^2(\mathbf{x}) \sim \chi^2_p$$
This allows exact $p$-value computation. An observation is flagged at significance level $\alpha$ (e.g., $\alpha = 0.001$) if $D_M^2(\mathbf{x}) > \chi^2_{p, 1-\alpha}$.

#### Q27: What is the Minimum Covariance Determinant (MCD) estimator?
**Answer:**
Standard sample covariance $\mathbf{S}$ has a breakdown point of $0\%$. The Minimum Covariance Determinant (MCD, implemented in Scikit-Learn\'s `EllipticEnvelope`) finds a subset of $h$ observations (where $n/2 < h < n$) whose sample covariance matrix has the smallest possible determinant. It provides robust estimates of location $\boldsymbol{\mu}_{\text{MCD}}$ and scatter $\boldsymbol{\Sigma}_{\text{MCD}}$ with a breakdown point up to $50\%$.

#### Q28: How does an outlier impact a Support Vector Machine with linear kernel?
**Answer:**
In a Hard-Margin SVM, a single linearly non-separable outlier makes optimization mathematically impossible (no feasible solution exists). In a Soft-Margin SVM, the slack variable $\xi_i$ penalty is controlled by $C$:
* High $C$: Heavy penalty for violations; the margin narrows drastically to fit the outlier.
* Low $C$: Tolerates larger margins by allowing the outlier to cross the margin with bounded slack penalty $\sum \xi_i$.

#### Q29: What happens to Logistic Regression weights when an extreme outlier is present?
**Answer:**
Logistic Regression uses cross-entropy loss: $\mathcal{L} = -\sum [y \log \hat{p} + (1-y) \log(1 - \hat{p})]$. If an observation is completely misclassified with extreme leverage ($y_i = 1$ but $\mathbf{x}_i^T\mathbf{w} \ll 0$), the predicted probability $\hat{p}_i \approx 0$, causing $-\log(\hat{p}_i) \to \infty$. This extreme gradient forces the weight vector $\mathbf{w}$ to rotate aggressively toward the outlier.

#### Q30: How does Ridge Regression ($L_2$) compare to Lasso Regression ($L_1$) under target outliers?
**Answer:**
Both Ridge and Lasso use squared error loss for regression ($\sum (y_i - \hat{y}_i)^2$), so both are equally sensitive to extreme target outliers. The regularization terms ($\lambda \|\mathbf{w}\|_2^2$ vs $\lambda \|\mathbf{w}\|_1$) only penalize coefficient magnitudes, not residual errors. To achieve robustness against target outliers, one must change the loss function to Huber Loss or Quantile Loss.

#### Q31: What is Huber Loss and how does it provide robustness?
**Answer:**
Huber loss combines the smoothness of $L_2$ loss for small errors with the linearity of $L_1$ loss for large errors:
$$L_\delta(e) = \begin{cases} \frac{1}{2} e^2 & \text{for } |e| \le \delta \\ \delta (|e| - \frac{1}{2} \delta) & \text{for } |e| > \delta \end{cases}$$
Its derivative is bounded: $\left|\frac{\partial L}{\partial e}\right| \le \delta$. As residuals grow arbitrarily large due to outliers, the gradient remains constant ($\pm \delta$), preventing the estimator from being hijacked.

#### Q32: What is the difference between transductive and inductive outlier detection?
**Answer:**
* **Transductive**: The algorithm can only assign outlier scores to the specific dataset provided during fitting. It cannot predict on new unseen points (e.g., `LocalOutlierFactor(novelty=False)` with only `fit_predict`).
* **Inductive**: The algorithm learns a decision boundary or density estimator that can be serialized and applied to classify brand new test points (e.g., `IsolationForest` or `OneClassSVM` with `predict()`).

#### Q33: Why does high dimensionality degrade traditional distance-based outlier detection?
**Answer:**
Due to the **Curse of Dimensionality**:
1. Distance concentration: As $d \to \infty$, the ratio $\frac{D_{\max} - D_{\min}}{D_{\min}} \to 0$. All points become nearly equidistant from one another.
2. Density sparsity: Data space grows exponentially, making the concept of local density undefined without astronomical sample sizes.
3. Irrelevant features add noise that swamps the distance calculations of genuine outliers.

#### Q34: What is Studentized Residual vs Standardized Residual?
**Answer:**
* Standardized residual divides raw error by standard deviation: $e_i / (s \sqrt{1 - h_{ii}})$.
* Studentized (externally studentized / deleted) residual estimates error variance $s_{(i)}$ with the $i$-th observation omitted:
  $$t_i = \frac{e_i}{s_{(i)} \sqrt{1 - h_{ii}}}$$
  It follows an exact Student-$t$ distribution with $n - p - 1$ degrees of freedom, making it far more sensitive for detecting extreme vertical outliers.

#### Q35: What is DFBETAS in regression diagnostics?
**Answer:**
DFBETAS measures how much a specific regression parameter $\beta_j$ changes (in units of standard error) when the $i$-th observation is omitted:
$$\text{DFBETAS}_{j(i)} = \frac{\hat{\beta}_j - \hat{\beta}_{j(i)}}{\text{SE}(\hat{\beta}_{j(i)})}$$
A common cutoff threshold is $|\text{DFBETAS}| > 2/\sqrt{n}$.

#### Q36: How does Principal Component Analysis (PCA) behave in the presence of outliers?
**Answer:**
PCA finds directions maximizing empirical sample variance $\mathbf{X}^T\mathbf{X}$. Because sample variance squares deviations, a small cluster of outliers will dominate the total variance, forcing the first principal component to align directly toward the outlier cluster rather than the true variance axis of inliers.

#### Q37: How can PCA be used as an outlier detection algorithm?
**Answer:**
By measuring **Reconstruction Error**. An observation $\mathbf{x}$ is projected onto the top $k$ principal components and then reconstructed back to full dimension: $\hat{\mathbf{x}} = \mathbf{U}_k \mathbf{U}_k^T \mathbf{x}$. Normal data points align well with the top components and have small reconstruction errors $\|\mathbf{x} - \hat{\mathbf{x}}\|^2$. Outliers violate the low-rank subspace and produce large reconstruction errors.

#### Q38: What is the contamination parameter in Scikit-Learn outlier estimators?
**Answer:**
The `contamination` parameter defines the expected proportion of outliers present in the dataset (bounded in $(0, 0.5]$). It is used to automatically determine the decision threshold on the raw anomaly scores (`decision_function()`). If set to $0.05$, the algorithm sets the threshold at the 5th percentile of training scores, classifying the 5% most anomalous points as $-1$.

#### Q39: What happens if `contamination='auto'` is selected in `IsolationForest`?
**Answer:**
When set to `'auto'`, Scikit-Learn sets the threshold at an offset of $0.0$ on the raw decision function. Points with mean path length shorter than the theoretical average tree depth are categorized as anomalies without forcing an arbitrary fixed percentage.

#### Q40: Why should you never use `MinMaxScaler` on data containing extreme outliers?
**Answer:**
`MinMaxScaler` maps data linearly to $[0, 1]$ using $x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$. If an extreme outlier exists ($x_{\max} = 1,000,000$ while normal points are in $[0, 10]$), the denominator expands drastically. All normal observations get squashed into a microscopic cluster $[0.00000, 0.00001]$, destroying feature variance.

def modified_z_score(x: np.ndarray, threshold: float = 3.5):
    """Detect outliers using robust Median Absolute Deviation."""
    median = np.median(x)
    mad = np.median(np.abs(x - median))
    if mad == 0:

        mad = np.mean(np.abs(x - median))

    return outlier_mask, mod_z

#### Code Q3: Calculate Mahalanobis Distance and Flag Multivariate Outliers

import numpy as np
from scipy.stats import chi2

def mahalanobis_outliers(X: np.ndarray, alpha: float = 0.01):
    """Detect multivariate outliers using Mahalanobis distance with Chi-square cutoff."""
    n_samples, n_features = X.shape
    mu = np.mean(X, axis=0)
    cov = np.cov(X, rowvar=False)
    inv_cov = np.linalg.pinv(cov)
    
    diff = X - mu
    # D^2 = sum_j sum_k diff_j * inv_cov_jk * diff_k
    d2 = np.sum(diff @ inv_cov * diff, axis=1)
    
    # Critical threshold from Chi-Square distribution
    threshold = chi2.ppf(1.0 - alpha, df=n_features)
    outlier_mask = d2 > threshold
    return outlier_mask, d2, threshold

# Generate correlated 2D Gaussian

# Add multivariate outlier: individual coordinates normal, but violates correlation

print(f"Outlier D2: {d2_vals[-1]:.2f} (Threshold: {thresh:.2f})")

#### Code Q4: Compute Hat Matrix Diagonals (Leverage) in Linear Regression

import numpy as np

def compute_leverage(X: np.ndarray):
    """Compute leverage values (diagonal of Hat matrix)."""
    # Add intercept column
    X_design = np.column_stack([np.ones(len(X)), X])
    # H = X (X^T X)^(-1) X^T
    XtX_inv = np.linalg.inv(X_design.T @ X_design)
    H_diag = np.sum(X_design @ XtX_inv * X_design, axis=1)
    
    p = X_design.shape[1]
    n = len(X)
    leverage_threshold = 2 * p / n
    high_leverage_mask = H_diag > leverage_threshold
    return H_diag, high_leverage_mask, leverage_threshold

X_simple = np.array([[1.0], [2.0], [2.1], [1.9], [2.2], [2.0], [25.0]])

print(f"Leverages: {np.round(h_diag, 3)}, Cutoff: {thresh:.3f}")

#### Code Q5: Compute Cook\'s Distance for Identifying Influential Data Points
```python
import numpy as np

def compute_cooks_distance(X: np.ndarray, y: np.ndarray):
    """Compute Cook's distance for linear regression."""
    X_design = np.column_stack([np.ones(len(X)), X])
    n, p = X_design.shape
    
    # OLS coefficients
    beta = np.linalg.pinv(X_design.T @ X_design) @ X_design.T @ y
    y_pred = X_design @ beta
    residuals = y - y_pred
    
    # Mean Squared Error
    mse = np.sum(residuals**2) / (n - p)
    
    # Leverage (hat values)
    H_diag = np.sum(X_design @ np.linalg.pinv(X_design.T @ X_design) * X_design, axis=1)
    
    # Cook's Distance formula: D_i = (e_i^2 / (p * mse)) * (h_ii / (1 - h_ii)^2)
    cooks_d = (residuals**2 / (p * mse)) * (H_diag / (1.0 - H_diag)**2)
    return cooks_d, beta

X = np.arange(10).reshape(-1, 1).astype(float)
y = 2.0 * X.flatten() + 1.0
# Introduce influential point (high leverage + high residual)
X = np.append(X, [[50.0]], axis=0)
y = np.append(y, [-100.0])

d_vals, beta_est = compute_cooks_distance(X, y)
assert d_vals[-1] > 1.0
print(f"Influential Point Cook's D: {d_vals[-1]:.2f} (Threshold > 1.0)")
```
