# 45. Advanced AI EDA Projects

## 45.2 RAG-Based Data Analyst

Build an AI analyst that combines:
Dataset + Documentation + Business Knowledge + LLM
For example:
User Question
↓
LangGraph
↓
Understand Question
↓
Retrieve Business Documentation
↓
Analyze Dataset
↓
Generate Chart
↓
Validate Result
↓
LLM Explanation
↓
Final Answer

Use:
- Pandas → data analysis
- NumPy → numerical operations
- Matplotlib/Seaborn → visualization
- Plotly → interactive charts
- ChromaDB → vector storage
- RAG → business-document retrieval
- LangChain → components
- LangGraph → workflow
- OpenAI → LLM
- Pydantic → structured outputs
- SQLite → conversation/history storage
- LangSmith → tracing/evaluation
