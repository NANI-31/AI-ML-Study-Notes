# 44. EDA + LLM Projects

## 44.1 AI Data Analyst

Build an application where a user uploads a CSV and asks:
"What are the top-selling products?"
"Are there missing values?"
"Which features are correlated?"
"Show me the sales trend."
The system:
1. Accepts CSV
2. Uses Pandas for analysis
3. Uses NumPy for calculations
4. Generates Matplotlib/Seaborn charts
5. Uses Plotly for interactive charts
6. Uses an LLM to understand questions
7. Generates Python/Pandas analysis
8. Executes safe analysis
9. Explains results
10. Returns insights
Stack: Pandas + NumPy + Matplotlib + Seaborn + Plotly + OpenAI + Pydantic
