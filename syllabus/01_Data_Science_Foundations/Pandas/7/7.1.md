### 2. Topic-Wise Interview Concepts

#### Topic 1: Understanding Missing Values

- **Concept**: Missing data in Pandas represents absent, unobserved, or unrecorded information. Historically, Pandas relied on NumPy's `np.nan` (IEEE 754 floating-point Not-a-Number) and Python's `None` (for object dtypes). Because `np.nan` is inherently a floating-point scalar, storing it in an integer or boolean column previously forced the entire column to upcast to `float64` or `object`. Pandas 1.0 introduced `pd.NA` and nullable data types (`Int64`, `boolean`, `string`) using separate boolean validity bitmasks to represent missingness across any data type without type coercion.
- **Why it matters**: IEEE 754 defines `NaN` such that `NaN != NaN` is always `True`. Freshers who write `val == np.nan` introduce silent bugs that never match missing values. Furthermore, understanding dtype upcasting prevents subtle numerical bugs in downstream processing.
- **Technical / Algorithmic Intuition**: At the hardware and memory level, `np.nan` is an IEEE 754 floating-point bit pattern with an exponent of all ones and a non-zero fraction. In contrast, `pd.NA` is a singleton object paired with an Apache Arrow or NumPy-backed boolean validity mask that tracks whether each slot contains a valid value or missing data, achieving true type-safe nullability.
- **Syntax / Pandas API**:
  - `import numpy as np; np.nan`
  - `pd.NA`
  - `None`
  - `s = pd.Series([1, 2, None], dtype='Int64')` (nullable integer)
- **Minimal Working Example**:
  ```python
  import pandas as pd
  import numpy as np

  s_float = pd.Series([1, 2, np.nan])
  s_nullable = pd.Series([1, 2, pd.NA], dtype='Int64')

  print("Float Series dtype:", s_float.dtype)
  print("Nullable Int Series dtype:", s_nullable.dtype)
  print("Equality check (np.nan == np.nan):", np.nan == np.nan)
  ```
- **Output**:
  ```text
  Float Series dtype: float64
  Nullable Int Series dtype: Int64
  Equality check (np.nan == np.nan): False
  ```
  - *Line-by-line explanation*: `s_float` upcasts integers 1 and 2 to `float64` because `np.nan` is a float. `s_nullable` uses `'Int64'` to retain 64-bit integer representation alongside `pd.NA`. The direct equality check evaluates to `False` by IEEE 754 definition.
- **Complexity & Performance**: Allocating a Series with missing values is $O(N)$ memory and time. Nullable types add a 1-bit-per-row mask overhead, which is negligible compared to upcasting integers to 64-bit floats.
- **Common Interview Gotcha**: Checking `if val == np.nan:` or `df[df['col'] == np.nan]`. It returns `False` for all rows, returning an empty DataFrame with zero warning.

#### Topic 2: `isnull()`

- **Concept**: `isnull()` is a method on Series and DataFrames that evaluates each element and returns an identically shaped boolean object with `True` where the value is missing (`np.nan`, `None`, or `pd.NA`) and `False` elsewhere.
- **Why it matters**: `isnull()` is a legacy alias inherited from R's `is.null()`. Knowing that `isnull()` is an exact synonym of `isna()` demonstrates historical API literacy and prevents candidates from confusing the two in interview code.
- **Technical / Algorithmic Intuition**: Calling `Series.isnull()` or `DataFrame.isnull()` invokes the exact same C-extension dispatch function as `isna()`. In the Pandas source code, `isnull = isna`.
- **Syntax / Pandas API**:
  - `Series.isnull()`
  - `DataFrame.isnull()`
- **Minimal Working Example**:
  ```python
  import pandas as pd
  import numpy as np

  s = pd.Series([10, np.nan, 30, None])
  print(s.isnull())
  ```
- **Output**:
  ```text
  0    False
  1     True
  2    False
  3     True
  dtype: bool
  ```
  - *Line-by-line explanation*: Index 0 and 2 contain valid numbers (`False`). Index 1 (`np.nan`) and Index 3 (`None`) are identified as missing (`True`).
- **Complexity & Performance**: Time complexity is $O(N)$ for a Series and $O(N \times M)$ for a DataFrame of $N$ rows and $M$ columns. Memory allocated is 1 byte per boolean element.
- **Common Interview Gotcha**: Thinking `isnull()` checks only for Python `None` while `isna()` checks for `np.nan`. They are 100% functionally identical aliases.

#### Topic 3: `isna()`

- **Concept**: `isna()` is the modern, preferred canonical method in Pandas for detecting missing values. It returns an element-wise boolean mask marking `np.nan`, `None`, `pd.NA`, and `NaT` (Not-a-Time for datetimes) as `True`.
- **Why it matters**: `isna()` is the standard convention recommended in official Pandas documentation because it mirrors `notna()` and avoids terminology confusion with Python's `None` (null vs NA).
- **Technical / Algorithmic Intuition**: For floating-point arrays, `isna()` vectorizes `np.isnan()`. For object arrays, it checks for `None`, `NaN`, and `pd.NA` references. For nullable Arrow/extension arrays, it directly returns the underlying bitmask buffer.
- **Syntax / Pandas API**:
  - `s.isna()`
  - `df.isna()`
  - `df[df['col'].isna()]`
- **Minimal Working Example**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({
      'name': ['Alice', None, 'Charlie'],
      'score': [95.0, np.nan, 88.0]
  })
  print(df.isna())
  ```
- **Output**:
  ```text
      name  score
  0  False  False
  1   True   True
  2  False  False
  ```
  - *Line-by-line explanation*: Evaluates each cell independently. Row 1 has missing entries in both `'name'` (`None`) and `'score'` (`np.nan`), yielding `True` in both columns.
- **Complexity & Performance**: $O(N \times M)$ time complexity, executing via compiled vectorized loops in C/Cython.
- **Common Interview Gotcha**: Applying `isna()` to a native Python scalar without Pandas (`isna(x)` requires `pd.isna(x)`).

#### Topic 4: `notnull()`

- **Concept**: `notnull()` is the complementary legacy alias of `notna()`. It returns a boolean mask with `True` for valid, present values and `False` for missing values (`np.nan`, `None`, `pd.NA`, `NaT`).
- **Why it matters**: Used in legacy codebases and interview challenges. It satisfies the boolean identity `s.notnull() == ~s.isnull()`.
- **Technical / Algorithmic Intuition**: In the Pandas codebase, `notnull` is defined directly as `notnull = notna`. It delegates to the same vectorized C routines as `notna()`.
- **Syntax / Pandas API**:
  - `s.notnull()`
  - `df.notnull()`
  - `df[df['col'].notnull()]`
- **Minimal Working Example**:
  ```python
  import pandas as pd
  import numpy as np

  s = pd.Series([100, np.nan, 300])
  print(s.notnull())
  ```
- **Output**:
  ```text
  0     True
  1    False
  2     True
  dtype: bool
  ```
  - *Line-by-line explanation*: Returns `True` at indices 0 and 2 because they contain non-null numbers, and `False` at index 1 where `np.nan` is detected.
- **Complexity & Performance**: $O(N)$ operations for Series of length $N$, vectorized in C.
- **Common Interview Gotcha**: Thinking `notnull()` runs slower than `~isnull()`. In fact, `notnull()` avoids an extra bitwise inversion operation, running slightly faster or identically.

#### Topic 5: `notna()`

- **Concept**: `notna()` is the modern canonical method for detecting non-missing values in Pandas. It returns an element-wise boolean mask with `True` wherever data is present and valid.
- **Why it matters**: Filtering out incomplete rows before training a machine learning model or computing business metrics is almost always written using `df[df['col'].notna()]`.
- **Technical / Algorithmic Intuition**: Evaluates the complement of the missing-value bitmask. For floating-point NumPy arrays, it wraps `~np.isnan(arr)` at the C level.
- **Syntax / Pandas API**:
  - `s.notna()`
  - `df.notna()`
  - `df[df['col'].notna()]`
- **Minimal Working Example**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({
      'user_id': [1, 2, 3],
      'email': ['a@test.com', np.nan, 'c@test.com']
  })
  valid_users = df[df['email'].notna()]
  print(valid_users)
  ```
- **Output**:
  ```text
     user_id       email
  0        1  a@test.com
  2        3  c@test.com
  ```
  - *Line-by-line explanation*: `df['email'].notna()` produces `[True, False, True]`. Subsetting `df` with this mask retains rows 0 and 2, filtering out row 1.
- **Complexity & Performance**: $O(N)$ time for a column check; memory overhead is the single boolean array allocation.
- **Common Interview Gotcha**: Forgetting that `notna()` retains empty strings `""` and whitespace `"   "`. An empty string is NOT considered a null value by `notna()`.

#### Topic 6: Detecting Missing Values

- **Concept**: Detecting missing values involves summarizing boolean masks to answer higher-level questions: "Does this column have any missing values?", "Does this row have any missing values?", or "Is this row completely empty?". This is accomplished by chaining `.isna()` with reduction methods `.any()` or `.all()`.
- **Why it matters**: Running exploratory checks before building ETL pipelines requires fast assertions. For example, `assert not df['id'].isna().any()` verifies that a primary key column has zero nulls.
- **Technical / Algorithmic Intuition**:
  - `df.isna().any(axis=0)`: Evaluates column-wise ($O(N \times M)$), returning a boolean Series indexed by column names.
  - `df.isna().any(axis=1)`: Evaluates row-wise, returning a boolean Series indexed by row indices (`True` if the row has at least one null).
  - `df.isna().all(axis=1)`: Returns `True` only if every single column in that row is null.
- **Syntax / Pandas API**:
  - `df.isna().any()` (default `axis=0`, checks per column)
  - `df.isna().any(axis=1)` (checks per row)
  - `df.isna().all()` (checks if entire column is null)
  - `df[df.isna().any(axis=1)]` (extract all rows with at least one null)
- **Minimal Working Example**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({
      'A': [1, 2, np.nan],
      'B': [np.nan, 5, 6],
      'C': [7, 8, 9]
  })
  print("Columns with missing values:\n", df.isna().any())
  print("\nRows with at least one missing value:\n", df[df.isna().any(axis=1)])
  ```
- **Output**:
  ```text
  Columns with missing values:
   A     True
  B     True
  C    False
  dtype: bool

  Rows with at least one missing value:
        A    B  C
  0  1.0  NaN  7
  2  NaN  6.0  9
  ```
  - *Line-by-line explanation*: `df.isna().any()` confirms columns `'A'` and `'B'` have nulls, while `'C'` does not. `df.isna().any(axis=1)` identifies rows 0 and 2 as having null entries.
- **Complexity & Performance**: Short-circuits internally when possible in Cython; $O(N \times M)$ worst-case time complexity.
- **Common Interview Gotcha**: Forgetting to specify `axis=1` when filtering rows with missing values. Writing `df[df.isna().any()]` raises an indexing alignment error or evaluates columns incorrectly.

#### Topic 7: Counting Missing Values

- **Concept**: Counting missing values aggregates the boolean mask produced by `.isna()` using numerical summation (`.sum()`) and proportional averaging (`.mean()`).
- **Why it matters**: Data profiling reports require exact missing value counts and percentages. In data science interviews, candidates are routinely asked: "Write a one-liner to return a summary table showing total nulls and missing percentage for every column sorted descending."
- **Technical / Algorithmic Intuition**: In Python and NumPy, boolean `True` evaluates to integer `1` and `False` to `0`. Summing a boolean Series counts the `True` entries. Taking the mean computes $\frac{\sum \text{True}}{N}$, which is the exact fraction of missing values.
- **Syntax / Pandas API**:
  - `df.isna().sum()` (nulls per column)
  - `df.isna().sum(axis=1)` (nulls per row)
  - `df.isna().sum().sum()` (total nulls across the entire DataFrame)
  - `(df.isna().mean() * 100).round(2)` (missing percentage per column)
- **Minimal Working Example**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({
      'colA': [1, np.nan, np.nan, 4],
      'colB': ['x', 'y', 'z', 'w'],
      'colC': [np.nan, np.nan, np.nan, 10.0]
  })

  null_summary = pd.DataFrame({
      'null_count': df.isna().sum(),
      'null_pct': (df.isna().mean() * 100).round(1)
  })
  print(null_summary)
  print("\nTotal DataFrame Nulls:", df.isna().sum().sum())
  ```
- **Output**:
  ```text
        null_count  null_pct
  colA           2      50.0
  colB           0       0.0
  colC           3      75.0

  Total DataFrame Nulls: 5
  ```
  - *Line-by-line explanation*: `colA` has 2 nulls out of 4 (50%), `colB` has 0 nulls (0%), and `colC` has 3 nulls out of 4 (75%). The total count across all cells is $2 + 0 + 3 = 5$.
- **Complexity & Performance**: Fast vectorized sum in $O(N \times M)$ time. Highly memory-efficient as intermediate boolean counts are accumulated into scalar registers.
- **Common Interview Gotcha**: Calling `len(df[df['col'].isna()])` instead of `df['col'].isna().sum()`. The former allocates an entire filtered DataFrame in memory just to count rows, which is slow and memory-intensive on large datasets.

### 3. Fresher Interview Questions

#### A. Basic Questions (20 Questions)

##### Q1: What is the difference between `np.nan`, `None`, and `pd.NA` in Pandas?
- **Direct Answer**: `np.nan` is a floating-point IEEE 754 value; `None` is Python's native null singleton object; `pd.NA` is Pandas 1.0+'s custom sentinel object designed for nullable data types (`Int64`, `boolean`, `string`) without forced type coercion.
- **Detailed Explanation**: In traditional Pandas, numeric missingness used `np.nan`. Because `np.nan` is a float, storing it in an integer column converted integers to `float64`, losing precision and changing semantics. `None` is used in object dtype columns. `pd.NA` provides uniform missing value semantics across all extension types while maintaining boolean three-valued logic (Kleene logic).
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  s1 = pd.Series([1, np.nan])            # upcasts to float64
  s2 = pd.Series(['a', None])            # object dtype
  s3 = pd.Series([1, pd.NA], dtype='Int64') # remains Int64

  print(s1.dtype, s2.dtype, s3.dtype)
  ```
- **Follow-up Twist**: What happens if you run `pd.NA == pd.NA` vs `np.nan == np.nan`? `np.nan == np.nan` returns `False`, whereas `pd.NA == pd.NA` returns `<NA>` (missing boolean), reflecting Kleene logic.

##### Q2: Is there any functional difference between `isna()` and `isnull()` in Pandas?
- **Direct Answer**: No, there is zero functional difference. `isnull()` is an exact alias of `isna()`.
- **Detailed Explanation**: In the Pandas source code, `isnull = isna`. The method was originally named `isnull` to match R syntax, but the community later established `isna()` as canonical to emphasize "Not Available" and create symmetry with `notna()`.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  s = pd.Series([1, np.nan, 3])
  print(s.isna().equals(s.isnull()))  # True
  ```
- **Follow-up Twist**: Why does the official documentation recommend `isna()` over `isnull()`? To avoid confusion with Python's built-in `None` (which means "null" in database terminology) and to match `notna()`.

##### Q3: Is `notnull()` identical to `notna()`?
- **Direct Answer**: Yes, `notnull()` is an exact alias of `notna()`.
- **Detailed Explanation**: Both methods return an element-wise boolean mask with `True` for non-missing values and `False` for missing values (`np.nan`, `None`, `pd.NA`, `NaT`).
- **Python Code**:
  ```python
  import pandas as pd

  s = pd.Series([10, None, 30])
  print(s.notna().equals(s.notnull()))  # True
  ```
- **Follow-up Twist**: How does `s.notna()` relate to `s.isna()` mathematically? `s.notna()` is strictly equivalent to `~s.isna()`.

##### Q4: Why does `df['col'] == np.nan` fail to detect missing values?
- **Direct Answer**: According to the IEEE 754 floating-point specification, `NaN` is not equal to anything, including itself (`np.nan == np.nan` evaluates to `False`).
- **Detailed Explanation**: Equality comparison on a Series containing `np.nan` evaluates `x == np.nan` element-wise. Because `np.nan == np.nan` is `False`, every cell evaluates to `False`. To detect missing values, one must use `.isna()`, `np.isnan()`, or `pd.isna()`.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  s = pd.Series([1.0, np.nan, 3.0])
  print("Using == :", s[s == np.nan])   # Empty Series!
  print("Using .isna():", s[s.isna()])  # Correctly returns index 1
  ```
- **Follow-up Twist**: How does Python's identity check `x is np.nan` behave? It evaluates to `True` for the specific singleton object, but cannot be vectorized across a Pandas Series.

##### Q5: How do you count the number of missing values in each column of a DataFrame?
- **Direct Answer**: By calling `df.isna().sum()`.
- **Detailed Explanation**: `df.isna()` creates a boolean DataFrame where `True` represents a missing cell. `.sum()` defaults to `axis=0` (column-wise reduction), treating `True` as 1 and `False` as 0, yielding the count of missing values per column.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'A': [1, np.nan, 3], 'B': [np.nan, np.nan, 4]})
  print(df.isna().sum())
  ```
- **Follow-up Twist**: How do you count missing values per row? Call `df.isna().sum(axis=1)`.

##### Q6: How do you calculate the percentage of missing values in each column?
- **Direct Answer**: Call `df.isna().mean() * 100`.
- **Detailed Explanation**: `.mean()` calculates the average of boolean values along each column. Since `True` is 1 and `False` is 0, the mean is the ratio of missing rows to total rows. Multiplying by 100 converts the ratio to a percentage.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'A': [1, np.nan, 3, np.nan], 'B': [1, 2, 3, 4]})
  print(df.isna().mean() * 100)
  ```
- **Follow-up Twist**: How would you format the output to two decimal places? Use `(df.isna().mean() * 100).round(2)`.

##### Q7: How do you find the total number of missing values across the entire DataFrame?
- **Direct Answer**: Call `df.isna().sum().sum()`.
- **Detailed Explanation**: The first `.sum()` sums along columns, producing a Series of column missing counts. The second `.sum()` sums that Series into a single scalar value.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'A': [1, np.nan], 'B': [np.nan, np.nan]})
  print("Total missing:", df.isna().sum().sum())  # 3
  ```
- **Follow-up Twist**: In modern Pandas / NumPy, is there another way without calling `.sum()` twice? Yes: `df.isna().to_numpy().sum()`.

##### Q8: How do you check if a DataFrame has ANY missing values anywhere?
- **Direct Answer**: Call `df.isna().any().any()` or `df.isna().values.any()`.
- **Detailed Explanation**: `df.isna().any()` returns a boolean Series indicating whether each column has at least one missing value. Chaining another `.any()` checks if any column returned `True`.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'x': [1, 2], 'y': [3, np.nan]})
  print("Has any null:", df.isna().any().any())  # True
  ```
- **Follow-up Twist**: Which method is computationally faster on a 10-million row DataFrame? `df.isna().to_numpy().any()`, because it evaluates the contiguous C boolean array directly and short-circuits.

##### Q9: How do you filter and display only rows that have a missing value in a specific column?
- **Direct Answer**: Use boolean indexing: `df[df['col_name'].isna()]`.
- **Detailed Explanation**: `df['col_name'].isna()` produces a 1D boolean Series where missing rows are `True`. Passing this into square brackets filters the DataFrame to retain only matching rows.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'id': [1, 2, 3], 'val': [10.0, np.nan, 30.0]})
  print(df[df['val'].isna()])
  ```
- **Follow-up Twist**: How do you filter rows where the column is NOT missing? Use `df[df['val'].notna()]`.

##### Q10: How do you filter rows that have at least one missing value across ANY column?
- **Direct Answer**: Use `df[df.isna().any(axis=1)]`.
- **Detailed Explanation**: `df.isna()` produces a boolean DataFrame. Calling `.any(axis=1)` checks across columns for each row, returning `True` if any column in that row contains a null value.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'A': [1, np.nan, 3], 'B': [4, 5, np.nan], 'C': [7, 8, 9]})
  print(df[df.isna().any(axis=1)])
  ```
- **Follow-up Twist**: How do you filter rows that are completely missing across ALL columns? Use `df[df.isna().all(axis=1)]`.

##### Q11: What is `NaT` in Pandas?
- **Direct Answer**: `NaT` stands for "Not-a-Time" and is Pandas' sentinel value for missing or unparseable datetime and timedelta data.
- **Detailed Explanation**: Just as `np.nan` represents missing floating-point numbers, `pd.NaT` represents missing timestamps. It is compatible with `datetime64[ns]` dtypes and is correctly recognized as missing by `isna()`.
- **Python Code**:
  ```python
  import pandas as pd

  dates = pd.Series(['2023-01-01', None, 'invalid_date'])
  dt_series = pd.to_datetime(dates, errors='coerce')
  print(dt_series)
  print("Is NA:\n", dt_series.isna())
  ```
- **Follow-up Twist**: Does `pd.NaT == pd.NaT` evaluate to `True` or `False`? Like `NaN`, `pd.NaT == pd.NaT` evaluates to `False`.

##### Q12: Does an empty string `""` count as a missing value in `isna()`?
- **Direct Answer**: No, an empty string `""` is a valid string object and is evaluated as `False` (not missing) by `isna()`.
- **Detailed Explanation**: Pandas `isna()` only flags `np.nan`, `None`, `pd.NA`, and `NaT`. Empty strings, whitespace strings (`" "`), and sentinel numbers (`-999`, `0`) are considered valid present data.
- **Python Code**:
  ```python
  import pandas as pd

  s = pd.Series(["", "hello", None])
  print(s.isna())
  ```
- **Output**:
  ```text
  0    False
  1    False
  2     True
  dtype: bool
  ```
- **Follow-up Twist**: How do you convert empty strings to missing values so `isna()` can detect them? Use `s.replace("", np.nan)`.

##### Q13: Does boolean `False` count as missing in `isna()`?
- **Direct Answer**: No, `False` is a valid boolean value and returns `False` when checked with `isna()`.
- **Detailed Explanation**: Freshers sometimes confuse falsy values in Python with missing values in Pandas. `0`, `0.0`, and `False` are all valid data points and evaluate to `False` under `isna()`.
- **Python Code**:
  ```python
  import pandas as pd

  s = pd.Series([False, 0, 0.0, None])
  print(s.isna())
  ```
- **Follow-up Twist**: If a column has `dtype='bool'`, can it contain `np.nan` in classic Pandas? No, classic boolean dtype cannot store `NaN`; assigning `NaN` forces the column to `object` dtype unless using the nullable `'boolean'` dtype.

##### Q14: What happens to the data type of an integer column when a missing value is introduced in classic Pandas?
- **Direct Answer**: The entire column is automatically upcast from `int64` to `float64`.
- **Detailed Explanation**: Because NumPy has no native representation for missing integers, classic Pandas uses `np.nan`, which is a 64-bit float. Storing a float in an integer array requires upcasting the entire array to `float64`.
- **Python Code**:
  ```python
  import pandas as pd
  import numpy as np

  s = pd.Series([1, 2, 3])
  print("Before:", s.dtype)
  s[1] = np.nan
  print("After:", s.dtype)
  ```
- **Output**:
  ```text
  Before: int64
  After: float64
  ```
- **Follow-up Twist**: Why can this upcasting cause critical bugs in IDs or phone numbers? Large 64-bit integers (e.g., 18-digit transaction IDs) can lose precision when converted to floating-point representation.

##### Q21: Explain Three-Valued Logic (Kleene Logic) in `pd.NA`.
- **Direct Answer**: Kleene logic supports three truth values: `True`, `False`, and `Unknown` (`<NA>`). Logical operations with `pd.NA` return `<NA>` unless the result is mathematically determined regardless of the unknown value.
- **Detailed Explanation**: Under Kleene logic:
  - `True | pd.NA` evaluates to `True` (because `True OR anything` is always `True`).
  - `False & pd.NA` evaluates to `False` (because `False AND anything` is always `False`).
  - `False | pd.NA` evaluates to `<NA>` (because the outcome depends on whether the unknown value is `True` or `False`).
  - `True & pd.NA` evaluates to `<NA>`.
- **Python Code**:
  ```python
  import pandas as pd

  print("True | NA  :", True | pd.NA)   # True
  print("False & NA :", False & pd.NA)  # False
  print("False | NA :", False | pd.NA)  # <NA>
  print("True & NA  :", True & pd.NA)   # <NA>
  ```
- **Follow-up Twist**: How does NumPy's `np.nan` behave in boolean operations? Bitwise operations with `np.nan` often raise `TypeError` or treat `nan` as truthy (`bool(np.nan)` is `True`), leading to logical errors.

##### Q68: Generating a Data Cleanliness Scorecard for Senior Stakeholders
- **Context**: A business intelligence team requires a summary scorecard of a newly acquired database table before approval for customer reporting. The scorecard must return:

  2. Total number of missing cells across the table.

### 5. Common Beginner Mistakes (10 Mistakes)

#### Mistake 1: Checking Missingness with `== np.nan`
- **Wrong Code**:
  ```python
  missing = df[df['score'] == np.nan]
  ```
- **Why it fails**: IEEE 754 specifies `NaN != NaN`. The condition returns `False` for every single row, resulting in an empty DataFrame.
- **Right Code**:
  ```python
  missing = df[df['score'].isna()]
  ```
- **Key Rule**: Never use comparison operators (`==`, `!=`) to test for `NaN`. Always use `.isna()` or `.notna()`.

#### Mistake 2: Using Python's `is` Operator for Vectorized Checks
- **Wrong Code**:
  ```python
  missing = df[df['score'] is None]
  ```
- **Why it fails**: The `is` operator tests scalar identity in Python memory. It cannot be vectorized across a Series and raises a `TypeError` or evaluates the identity of the entire Series object.
- **Right Code**:
  ```python
  missing = df[df['score'].isna()]
  ```
- **Key Rule**: Vectorized operations in Pandas require element-wise methods, not Python identity keywords.

#### Mistake 3: Omitting `axis=1` When Filtering Rows with Any Null
- **Wrong Code**:
  ```python
  null_rows = df[df.isna().any()]
  ```
- **Why it fails**: `df.isna().any()` defaults to `axis=0`, producing a boolean Series indexed by column names. Subsetting `df` with column labels along the row axis triggers an indexing alignment error or unexpected results.
- **Right Code**:
  ```python
  null_rows = df[df.isna().any(axis=1)]
  ```
- **Key Rule**: When filtering *rows* based on cross-column conditions, always specify `axis=1`.

#### Mistake 4: Calling `len(df[df['col'].isna()])` to Count Nulls
- **Wrong Code**:
  ```python
  count = len(df[df['col'].isna()])
  ```
- **Why it fails**: Subsetting `df[...]` allocates a new DataFrame slice in memory containing all matched rows, which is slow and memory-wasteful.
- **Right Code**:
  ```python
  count = int(df['col'].isna().sum())
  ```
- **Key Rule**: Accumulate boolean values with `.sum()` rather than slicing DataFrames to count occurrences.

#### Mistake 5: Assuming `df.count()` Returns the Number of Nulls
- **Wrong Code**:
  ```python
  null_count = df['col'].count()
  ```
- **Why it fails**: `df.count()` counts *non-null* (valid) entries. If a column of 100 rows has 20 nulls, `df['col'].count()` returns 80.
- **Right Code**:
  ```python
  null_count = df['col'].isna().sum()
  ```
- **Key Rule**: `count()` counts present data; `isna().sum()` counts absent data.

#### Mistake 6: Assuming Empty Strings `""` Are Null
- **Wrong Code**:
  ```python
  df['city'].isna().sum()  # Expecting it to catch blank user inputs ""
  ```
- **Why it fails**: An empty string `""` is a valid string scalar with length 0. It is NOT `NaN` or `None`.
- **Right Code**:
  ```python
  df['city'].replace('', np.nan).isna().sum()
  # Or: (df['city'].isna() | (df['city'] == '')).sum()
  ```
- **Key Rule**: Text fields must be sanitized by mapping empty strings or whitespace to `NaN` before checking `isna()`.

#### Mistake 7: Using Python `if val:` to Check for Non-Null Values
- **Wrong Code**:
  ```python
  for val in df['metric']:
      if val:  # Thinking this filters out np.nan
          process(val)
  ```
- **Why it fails**: In Python, `bool(np.nan)` evaluates to `True` because it is a non-zero floating-point number.
- **Right Code**:
  ```python
  for val in df['metric']:
      if pd.notna(val):
          process(val)
  ```
- **Key Rule**: Always use `pd.notna(val)` or `pd.isna(val)` when testing scalar values in control flow.

#### Mistake 8: Unintended Integer-to-Float Conversion in Classic Pandas
- **Wrong Code**:
  ```python
  s = pd.Series([1, 2, 3], dtype='int64')
  s[0] = np.nan  # Silently converts entire series to float64
  ```
- **Why it fails**: NumPy arrays have fixed dtypes. Injecting a float `NaN` forces the entire column to `float64`, causing potential precision issues with IDs.
- **Right Code**:
  ```python
  s = pd.Series([1, 2, 3], dtype='Int64')
  s[0] = pd.NA  # Retains Int64 nullable integer type
  ```
- **Key Rule**: Use uppercase nullable dtypes (`'Int64'`, `'boolean'`, `'string'`) when null values must coexist with integers.

#### Mistake 9: Inverting Boolean Masks with `not` Instead of `~`
- **Wrong Code**:
  ```python
  valid = df[not df['col'].isna()]
  ```
- **Why it fails**: Python's `not` evaluates the truth value of the entire Series, raising `ValueError: The truth value of a Series is ambiguous`.
- **Right Code**:
  ```python
  valid = df[~df['col'].isna()]
  # Or: valid = df[df['col'].notna()]
  ```
- **Key Rule**: Invert Series boolean masks using the bitwise tilde operator `~` or call `.notna()`.

#### Mistake 10: Chained Masking Without Parentheses
- **Wrong Code**:
  ```python
  df[df['a'].isna() & df['b'] > 10]
  ```
- **Why it fails**: Bitwise `&` has higher precedence than `>`. Python tries to evaluate `df['isna'] & df['b']` first, causing a `TypeError`.
- **Right Code**:
  ```python
  df[df['a'].isna() & (df['b'] > 10)]
  ```
- **Key Rule**: Always enclose relational comparisons in parentheses when combining them with bitwise operators.

#### Confusion 1: `isna()` vs `isnull()`

| Dimension | `isna()` | `isnull()` |
|---|---|---|
| **Underlying Function** | Canonical C/Cython implementation | Exact alias pointing to `isna` |
| **Historical Origin** | Introduced to standardize "NA" terminology | Inherited from R's `is.null()` |
| **PEP 8 / Modern Recommendation** | Strongly recommended in modern Pandas 2.x | Maintained purely for backwards compatibility |
| **Performance Difference** | Identical ($0\%$ difference) | Identical ($0\%$ difference) |
| **Symmetry Partner** | `notna()` | `notnull()` |

#### Confusion 2: `np.nan` vs `pd.NA` vs `None`

| Dimension | `np.nan` | `pd.NA` | `None` |
|---|---|---|---|
| **Source Library** | NumPy (IEEE 754 Float) | Pandas 1.0+ Extension Type | Python Standard Library |
| **Underlying Type** | `float` | `pandas._libs.missing.NAType` | `NoneType` |
| **Equality Check (`x == x`)** | `False` | `<NA>` (Kleene Logic) | `True` |
| **Behavior in Int Column** | Forces upcast to `float64` | Retains integer (`Int64`) | Forces upcast to `object` |
| **Boolean Truthiness (`bool(x)`)** | `True` (Dangerous trap!) | Raises `TypeError` | `False` |

```python
import pandas as pd
import numpy as np

print("np.nan == np.nan :", np.nan == np.nan)  # False
print("pd.NA == pd.NA   :", pd.NA == pd.NA)      # <NA>
print("None == None     :", None == None)        # True
```

#### Confusion 3: `df.isna().any(axis=0)` vs `df.isna().any(axis=1)`

| Dimension | `axis=0` (`axis='index'`) | `axis=1` (`axis='columns'`) |
|---|---|---|
| **Direction of Scan** | Vertical (down rows, column-by-column) | Horizontal (across columns, row-by-row) |
| **Output Type & Shape** | Series of length = number of columns | Series of length = number of rows |
| **Index of Output** | Column names (`df.columns`) | Row labels (`df.index`) |
| **Common Use Case** | "Which columns have missing data?" | "Which rows contain at least one null?" |
| **Filtering Application** | `df.loc[:, df.isna().any(axis=0)]` | `df[df.isna().any(axis=1)]` |


#### Confusion 4: `df.isna().sum()` vs `df.count()`

### 7. Interview Traps (10 Traps)

#### Trap 1: The Identity Comparison Trap (`val is np.nan`)
- **Trap Description**: The candidate writes `if val is np.nan:` assuming Python identity comparison will reliably detect missing values.
- **Tricky Snippet**:
  ```python
  import numpy as np
  a = float('nan')
  print(a is np.nan)
  ```
- **Naive Response**: "It prints `True` because `a` is a NaN value."
- **Winning Response**: "It prints `False`! While `a` is mathematically a NaN, it is a different object instance in Python heap memory than `np.nan`. Python's `is` checks memory addresses, not IEEE 754 value properties. Always use `pd.isna(a)` or `math.isnan(a)`."

#### Trap 2: The `bool(np.nan)` Truthiness Trap
- **Trap Description**: Checking whether a cell has a valid number using standard Python truthiness (`if cell:`).
- **Tricky Snippet**:
  ```python
  import numpy as np
  val = np.nan
  if val:
      print("Valid Value")
  else:
      print("Missing Value")
  ```
- **Naive Response**: "It prints 'Missing Value' because `NaN` means not a number."
- **Winning Response**: "It prints 'Valid Value'! In Python, all float values except `0.0` evaluate to `True` in a boolean context. `np.nan` is considered truthy. To test for missingness, use `if pd.notna(val):`."

#### Trap 3: The Empty String Stealth Null Trap
- **Trap Description**: Ingesting a CSV with blank fields where some columns load as empty strings `""` rather than `NaN`.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  df = pd.DataFrame({'notes': ['Good', '', 'Average', '   ']})
  print(df['notes'].isna().sum())
  ```
- **Naive Response**: "It prints `2` because two rows have no text."
- **Winning Response**: "It prints `0`. Pandas `isna()` detects `np.nan`, `None`, and `pd.NA`, but empty and whitespace strings are valid string objects. You must strip whitespace and map empty strings to `NaN` using `df['notes'].str.strip().replace('', np.nan)` before running `isna()`."

#### Trap 4: The Silent Integer Upcast Trap
- **Trap Description**: Inserting `np.nan` into an integer ID column.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  import numpy as np
  s = pd.Series([9007199254740993, 9007199254740994])
  s.loc[2] = np.nan
  print(s.loc[0])
  ```
- **Naive Response**: "It prints `9007199254740993`."
- **Winning Response**: "It prints `9007199254740992.0` (precision corrupted)! Introducing `np.nan` upcasts the series to `float64`. Standard 64-bit floats have only 53 bits of mantissa, losing integer precision beyond $2^{53}$ ($9,007,199,254,740,992$). To prevent data corruption, use `dtype='Int64'` with `pd.NA`."

#### Trap 5: The Vectorized Null Check Equality Trap
- **Trap Description**: Filtering rows with `df[df['col'] == None]`.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  s = pd.Series([1, 2, None])
  print(s[s == None])
  ```
- **Naive Response**: "It returns the row with index 2."
- **Winning Response**: "It returns an empty Series! In numeric or float Series, Pandas converts `None` to `np.nan`. Comparing `s == None` performs element-wise equality, where `np.nan == None` evaluates to `False`. Always use `s.isna()`."

#### Trap 6: The Row vs Column Axis Inversion Trap in Detection
- **Trap Description**: The interviewer asks for rows with missing values, but the candidate runs default `.any()`.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  import numpy as np
  df = pd.DataFrame({'a': [1, np.nan], 'b': [2, 3]})
  print(df[df.isna().any()])
  ```
- **Naive Response**: "It returns the row containing `NaN`."
- **Winning Response**: "It raises an alignment error or produces incorrect rows because `df.isna().any()` aggregates along `axis=0` by default, producing column labels `['a', 'b']`. To filter rows, you must explicitly pass `axis=1`: `df[df.isna().any(axis=1)]`."

#### Trap 7: The Ambiguous Boolean Trap with `pd.NA`
- **Trap Description**: Using `pd.NA` in Python native logical statements.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  val = pd.NA
  try:
      if val:
          print("True")
  except Exception as e:
      print(type(e).__name__)
  ```
- **Naive Response**: "It prints 'True' or 'False' depending on whether `NA` is truthy."
- **Winning Response**: "It raises a `TypeError`! Unlike `np.nan` (which evaluates to `True`) or `None` (which evaluates to `False`), `pd.NA` enforces Kleene three-valued logic. Its truth value is strictly ambiguous, so Python refuses to convert it to a boolean."

#### Trap 8: The Total Missing Count Trap
- **Trap Description**: Counting total missing values using `df.isna().count()`.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  import numpy as np
  df = pd.DataFrame({'a': [1, np.nan], 'b': [np.nan, np.nan]})
  print(df.isna().count())
  ```
- **Naive Response**: "It prints the count of nulls: `a: 1, b: 2`."
- **Winning Response**: "It prints `a: 2, b: 2`! `df.isna()` produces a boolean DataFrame of `True` and `False`. Calling `.count()` counts non-null boolean values, which is 2 for both columns! To count missing values, you must call `.sum()`: `df.isna().sum()`."

#### Trap 9: The Dictionary Null Check Trap
- **Trap Description**: Checking missing values in an object column storing dictionary records.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  s = pd.Series([{'user': 'Alice'}, {}, None])
  print(s.isna().tolist())
  ```
- **Naive Response**: "It prints `[False, True, True]` because `{}` is empty."
- **Winning Response**: "It prints `[False, False, True]`. An empty dictionary `{}` is a valid instantiated object in memory, not a missing reference. `isna()` only flags `None` or `NaN`. To catch empty containers, you must check `s.apply(lambda x: len(x) == 0 if isinstance(x, dict) else pd.isna(x))`."

#### Trap 10: The Inverted Condition Mask Precedence Trap
- **Trap Description**: Forgetting parentheses when inverting a missing value check alongside another condition.
- **Tricky Snippet**:
  ```python
  import pandas as pd
  import numpy as np
  df = pd.DataFrame({'A': [1, np.nan, 3], 'B': [True, False, True]})
  # Candidate writes: df[~df['A'].isna() & df['B']]
  ```
- **Naive Response**: "It might cause a syntax error without parentheses."
- **Winning Response**: "In this specific case, `~df['A'].isna()` evaluates correctly due to method call precedence, but combining it with numerical comparisons like `~df['A'].isna() & df['A'] > 1` triggers a `TypeError` because bitwise `&` binds tighter than `>`. Safe production style requires explicit grouping: `(~df['A'].isna()) & (df['A'] > 1)` or using the cleaner `df['A'].notna() & (df['A'] > 1)`."

### 8. Real-World Pandas Engineering Questions

#### Scenario 1: Scalable Missing Value Profiler for 10GB DataFrames
- **Question**: You have a 100-column DataFrame with 20 million rows (~10GB in RAM). How do you compute a missingness report (column name, missing count, missing percentage) with minimal memory footprint and execution time?
- **Engineering Solution**:
  ```python
  import pandas as pd
  import numpy as np

  def profile_missing_memory_efficient(df: pd.DataFrame) -> pd.DataFrame:
      n_rows = len(df)
      report = []
      # Iterate column by column to avoid allocating a full 10GB boolean DataFrame at once
      for col in df.columns:
          null_count = int(df[col].isna().sum())
          if null_count > 0:
              null_pct = round((null_count / n_rows) * 100, 2)
              report.append({'column': col, 'null_count': null_count, 'null_pct': null_pct})

      if not report:
          return pd.DataFrame(columns=['column', 'null_count', 'null_pct'])

      return pd.DataFrame(report).sort_values(by='null_pct', ascending=False).reset_index(drop=True)
  ```
- **Architectural Trade-off**: Calling `df.isna()` on the entire 10GB DataFrame at once allocates an intermediate 20M x 100 boolean array (~2GB of RAM). Looping over columns processes one 20M boolean vector (~20MB) at a time, drastically reducing peak memory and preventing Out-Of-Memory (OOM) crashes in memory-constrained container environments.

#### Scenario 2: Data Drift Detection via Missing Value Distribution Shift
- **Question**: In an ML inference microservice, incoming batch payloads must be audited against training baseline missingness. If any feature exhibits a missingness rate drift $> 5\%$ compared to baseline, route the batch to a fallback model.
- **Engineering Solution**:
  ```python
  import pandas as pd

  def detect_missingness_drift(incoming_batch: pd.DataFrame, baseline_rates: dict, tolerance: float = 0.05) -> bool:
      batch_rates = incoming_batch.isna().mean().to_dict()
      drifted_features = []

      for feature, base_rate in baseline_rates.items():
          current_rate = batch_rates.get(feature, 1.0)
          if abs(current_rate - base_rate) > tolerance:
              drifted_features.append((feature, base_rate, current_rate))

      if drifted_features:
          print(f"Drift alert: Features exceeded tolerance {tolerance}: {drifted_features}")
          return True  # Drift detected, trigger fallback
      return False
  ```
- **Architectural Trade-off**: Uses vectorized `.isna().mean()` across the batch in a single pass ($O(N \times M)$), ensuring sub-50ms latency checks during real-time batch scoring.

#### Scenario 3: Missing Value Matrix Sparsity Assertion for Sparse Formats
- **Question**: You are preparing a feature matrix for an XGBoost model. If the overall missingness across the matrix exceeds 60%, it is more memory-efficient to convert the dataset to a `scipy.sparse.csr_matrix` or Pandas `SparseDtype`. How do you calculate overall matrix sparsity efficiently?
- **Engineering Solution**:
  ```python
  import pandas as pd
  import numpy as np

  def should_convert_to_sparse(df: pd.DataFrame, threshold: float = 0.60) -> bool:
      total_cells = df.size  # rows * cols without re-computing shape
      total_nulls = df.isna().to_numpy().sum()
      sparsity = total_nulls / total_cells
      print(f"Dataset Sparsity: {sparsity * 100:.2f}%")
      return sparsity >= threshold
  ```
- **Architectural Trade-off**: `df.size` is a metadata property ($O(1)$). `df.isna().to_numpy().sum()` delegates directly to a contiguous C-buffer reduction, bypassing Series index overhead and calculating overall sparsity in milliseconds.

```python
clean_subset = df[df.notna().sum(axis=1) >= 3]
```
- `df.notna()` produces a boolean DataFrame of identical dimensions to `df`, with `True` representing non-null values.
- `.sum(axis=1)` sums across the columns horizontally for each individual row, producing a Series where each value represents the exact number of valid, non-null features in that row.
- `>= 3` creates a 1D boolean Series where rows having 3 or more non-missing columns are `True`.
- `df[...]` filters the parent DataFrame, retaining only observations that satisfy the minimum data completeness threshold of 3 attributes.

#### Snippet 3: Finding Completely Null Columns
```python
empty_columns = df.columns[df.isna().all(axis=0)]
```
- `df.isna()` computes element-wise missingness booleans.
- `.all(axis=0)` evaluates vertically down each column. It returns `True` only for columns where *every single row* evaluates to `True` (i.e., columns containing zero valid data points).
- `df.columns[...]` indexes into the Index object of column names using the boolean mask, returning an Index slice of column names that are 100% missing.

### 11. "Fix This Code" Questions

#### Snippet 1: The Invisible NaN Comparison
- **Buggy Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'age': [25, np.nan, 30]})
  # Attempting to replace NaN with 0
  df[df['age'] == np.nan] = 0
  ```
- **Expected Behavior**: Set missing values in `'age'` to `0`.
- **Corrected Code**:
  ```python
  df.loc[df['age'].isna(), 'age'] = 0
  ```
- **Root Cause Analysis**: `df['age'] == np.nan` evaluates to `False` for all rows due to IEEE 754 float specifications. The boolean mask contains zero `True` values, leaving the DataFrame unchanged. Furthermore, using `.loc` guarantees safe in-place assignment without chained indexing warnings.

#### Snippet 2: Cross-Column Null Row Filtering Error
- **Buggy Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'A': [1, np.nan], 'B': [2, 3]})
  # Goal: Filter rows that have nulls in column A or column B
  bad_rows = df[df[['A', 'B']].isna().any()]
  ```
- **Expected Behavior**: Return rows where either `'A'` or `'B'` contains `NaN`.
- **Corrected Code**:
  ```python
  bad_rows = df[df[['A', 'B']].isna().any(axis=1)]
  ```
- **Root Cause Analysis**: Without `axis=1`, `.any()` defaults to `axis=0`. It produces a boolean Series of length 2 indexed by `['A', 'B']`. When passed to `df[...]`, Pandas attempts to align the column labels against row index labels `[0, 1]`, raising an alignment or indexing error. Adding `axis=1` aggregates row-wise.

#### Snippet 3: Counting Nulls via `count()`
- **Buggy Code**:
  ```python
  import pandas as pd
  import numpy as np

  df = pd.DataFrame({'category': ['Tech', np.nan, 'Finance', np.nan]})
  missing_count = df['category'].count()
  ```
- **Expected Behavior**: Compute the count of missing entries in `'category'` (2).
- **Corrected Code**:
  ```python
  missing_count = int(df['category'].isna().sum())
  ```
- **Root Cause Analysis**: In Pandas, `.count()` counts the number of *non-null* records. For this Series of length 4 with 2 nulls, `.count()` returns `2` by coincidence, but on a Series with 3 valid values and 1 null, `.count()` returns `3` instead of `1`. The correct method to count missing values is `.isna().sum()`.

### 13. Flashcard Section (16 Active Recall Cards)

### Card 1: IEEE 754 NaN Equality Rule
**Front:** Why does `x == np.nan` fail to find missing values in a Pandas Series?  
**Back:** Under IEEE 754 floating-point standards, `NaN` is undefined and compares unequal to every value, including itself (`np.nan == np.nan` is `False`). You must use `Series.isna()` or `pd.isna()`.

---

### Card 2: `isna()` vs `isnull()`
**Front:** Is there any algorithmic or performance difference between `df.isna()` and `df.isnull()`?  
**Back:** Zero difference. In the Pandas source code, `isnull = isna`. They resolve to the exact same function pointer in memory. `isna()` is preferred in modern PEP 8 code.

---

### Card 3: Python `None` vs `np.nan`
**Front:** How does Pandas treat Python `None` when placed in a numeric Series?  
**Back:** Pandas automatically coerces `None` to `np.nan`, forcing the Series to `float64` unless a nullable extension dtype (e.g., `'Int64'`) is explicitly specified.

---

### Card 4: `pd.NA` and Three-Valued Logic
**Front:** How does `pd.NA` evaluate in `True | pd.NA` vs `False | pd.NA`?  
**Back:** Under Kleene logic: `True | pd.NA` evaluates to `True` (since `True OR anything` is `True`), whereas `False | pd.NA` evaluates to `<NA>` (since the outcome depends on the unknown value).

---

### Card 5: Missing Percentage Formula
**Front:** What is the most idiomatic, vectorized one-liner to get missing value percentages per column?  
**Back:** `(df.isna().mean() * 100).round(2)`. In boolean masks, `True == 1` and `False == 0`, so the mean directly represents the proportion of missing cells.

---

### Card 6: Total Missing Cells Count
**Front:** How do you count all missing values across an entire DataFrame in a single line?  
**Back:** `df.isna().sum().sum()` or `int(df.isna().to_numpy().sum())`. The first `.sum()` sums per column; the second sums the column counts into a scalar.

---

### Card 7: Axis Mechanics in `df.isna().any()`
**Front:** What is the difference between `df.isna().any(axis=0)` and `df.isna().any(axis=1)`?  
**Back:** `axis=0` aggregates vertically down columns, returning a Series indexed by column names. `axis=1` aggregates horizontally across rows, returning a Series indexed by row labels.

---

### Card 8: Filtering Rows with Any Null
**Front:** Why does `df[df.isna().any()]` fail to filter rows containing nulls?  
**Back:** `df.isna().any()` defaults to `axis=0`, returning column labels. Passing column labels to row-filtering `df[...]` triggers an index alignment error. You must pass `axis=1`: `df[df.isna().any(axis=1)]`.

---

### Card 9: `df.count()` vs `df.isna().sum()`
**Front:** What mathematical identity links `df.count()` and `df.isna().sum()`?  
**Back:** For every column, `df[col].count() + df[col].isna().sum() == len(df)`. `count()` tallies valid elements; `isna().sum()` tallies missing elements.

---

### Card 10: Empty String Fallacy
**Front:** Does `df['text'].isna()` catch empty strings `""` or `" "`?  
**Back:** No! Empty strings and whitespace strings are valid string objects with length $\ge 0$. To catch them, you must strip and replace: `df['text'].str.strip().replace('', np.nan).isna()`.

---

### Card 11: Integer Precision Loss Trap
**Front:** Why can introducing `np.nan` into an integer column corrupt 18-digit transaction IDs?  
**Back:** `np.nan` forces conversion to `float64`. IEEE 754 64-bit floats have only 53 bits of mantissa, losing precision for integers beyond $2^{53} \approx 9 \times 10^{15}$.

---

### Card 12: `pd.NaT` Characteristics
**Front:** What is `pd.NaT` and how does it compare to itself?  
**Back:** `pd.NaT` is the missing value sentinel for datetime and timedelta data (`datetime64[ns]`). Like `NaN`, `pd.NaT == pd.NaT` evaluates to `False`.

---

### Card 13: Finding Completely Null Columns
**Front:** How do you extract the names of columns that contain 100% missing values?  
**Back:** `df.columns[df.isna().all()]`. `.all()` returns `True` only when every row in that column evaluates to `True` under `isna()`.

---

### Card 14: Categorical Missing Values
**Front:** What is the underlying representation of `NaN` inside a `pd.Categorical` series?  
**Back:** It is stored as an integer code of `-1`. It is excluded from the list of valid categories (`s.cat.categories`).

---

### Card 15: Memory Footprint of Boolean Masks
**Front:** How much memory does `df.isna()` allocate compared to `df`?  
**Back:** It allocates a full boolean DataFrame of identical dimensions occupying 1 byte (`bool_`) per cell, which is 1/8th the size of an 8-byte `float64` or `int64` column.

---

### Card 16: Safe In-Place Null Flagging
**Front:** Why should you use `df.loc[df['col'].isna(), 'flag'] = True` instead of `df[df['col'].isna()]['flag'] = True`?  
**Back:** The latter uses chained indexing, which mutates a temporary intermediate slice and raises `SettingWithCopyWarning`. `.loc` guarantees direct, in-place modification on the parent DataFrame.

To summarize missingness, I run `df.isna().sum()` to get counts per column, or `df.isna().mean() * 100` to get the percentage of missing data per column. ---

### Question 2: "What is the difference between `None`, `np.nan`, and `pd.NA`?"

- **Weak Answer**:  
  *"They are all null values, but `np.nan` is NumPy and `None` is Python."*
- **Interviewer Critique**:  
  Fails to address type coercion, memory impact, or why Pandas introduced `pd.NA`.
- **Winning Fresher Response**:  
  *"They originate from different layers and carry distinct typing semantics:
  1. `None` is Python's native singleton of type `NoneType`. In numeric Series, Pandas coerces it to `np.nan`.
  2. `np.nan` is an IEEE 754 floating-point scalar from NumPy. Storing it in an integer column forces the entire column to upcast to `float64`, which risks precision loss for large integers.

### Question 3: "How do you filter all rows from a DataFrame that contain at least one missing value?"

- **Interviewer Critique**:

- **Winning Fresher Response**:  
  *"I write `df[df.isna().any(axis=1)]`. It is critical to specify `axis=1` (or `axis='columns'`) because `.any()` defaults to `axis=0`. Aggregating along `axis=1` evaluates across columns for each individual row, producing a boolean Series indexed by row labels. If I needed rows where every column was missing, I would use `df.isna().all(axis=1)`."*

- **Interviewer Critique**:

- **Winning Fresher Response**:

Because NumPy arrays require a homogeneous C data type per column, an integer array cannot store a float without upcasting the entire buffer to `float64`.       mask1 = df[col1].isna()
  ```python
      mask2 = df[col2].isna()

      both_null = int((mask1 & mask2).sum())
      only_col1_null = int((mask1 & ~mask2).sum())
      only_col2_null = int((~mask1 & mask2).sum())
      neither_null = int((~mask1 & ~mask2).sum())

          f"only_{col1}_missing": only_col1_null,
          f"only_{col2}_missing": only_col2_null,
          "both_present": neither_null,
          "is_fully_coupled": is_fully_coupled
  ```

## 18. Cross-Concept Bridges

### NumPy Bridge
- Under the hood, Pandas floating-point Series are backed by 1D NumPy arrays of `dtype('float64')`.
- `s.isna()` delegates directly to `np.isnan(arr)` for numeric columns.
- The fundamental rule `NaN != NaN` comes directly from NumPy's adoption of the IEEE 754 floating-point standard.
- Calculating `df.isna().to_numpy().sum()` avoids Series metadata overhead and computes total table missingness directly on the contiguous C buffer.

### SQL Bridge
- In SQL, missing data is represented by `NULL`.
- SQL `WHERE column IS NULL` $\Longleftrightarrow$ Pandas `df[df['column'].isna()]`.
- SQL `WHERE column IS NOT NULL` $\Longleftrightarrow$ Pandas `df[df['column'].notna()]`.
- In SQL, comparing `column = NULL` is invalid and always yields `UNKNOWN` (falsy in `WHERE`). This mirrors Pandas' rule where `df['col'] == np.nan` evaluates to `False` for every row.
- SQL `COUNT(column)` ignores `NULL`s, which is identical to Pandas `df['column'].count()`.

### Scikit-Learn Bridge
- Scikit-learn estimators (e.g., `StandardScaler`, `LogisticRegression`) assume complete numerical matrices.
- Running `SimpleImputer()` or `KNNImputer()` in Scikit-Learn requires identifying missing values marked specifically as `np.nan`.
- `MissingIndicator` in `sklearn.impute` generates binary indicator features that are mathematically equivalent to `df[col].isna().astype(int)`.

### Python Native Bridge
- Python represents missing references using the singleton `None` of type `NoneType`.
- While Python `None == None` evaluates to `True`, Pandas numeric columns convert `None` to `np.nan` where `np.nan == np.nan` is `False`.
- Native Python `bool(np.nan)` evaluates to `True` (truthy), making `if val:` an anti-pattern when checking for missingness. The polymorphic function `pd.isna(val)` bridges native Python logic safely.

   - `np.nan == np.nan` is ALWAYS `False`. Never use `== np.nan` or `!= np.nan`.
3. **The `count()` Identity**:
   - `df['col'].count()` counts *valid* entries. `df['col'].isna().sum()` counts *missing* entries. Their sum is always `len(df)`.

## 20. What a Fresher Should Understand

1. **The Floating-Point Upcasting Mechanism**:
   Why traditional Pandas converts integer columns to `float64` when missing values occur: NumPy arrays have fixed C-level memory buffers with no bit reserved for integer nulls. Floating-point numbers have a dedicated IEEE 754 bit pattern for `NaN`. Thus, storing `NaN` forces an array-wide cast to `float64`.
2. **Nullable Extension Dtypes (`pd.NA`)**:
   How Pandas 1.0 solved integer upcasting: By decoupling the data array from a parallel boolean validity bitmask. This allows `'Int64'` and `'boolean'` types to store missing values safely without changing types or losing precision.
3. **Vectorized Boolean Reductions vs Python Loops**:
   Why `df['col'].isna().sum()` is thousands of times faster than `sum(1 for x in df['col'] if pd.isna(x))`: Vectorized operations execute compiled SIMD loops directly in C, bypassing Python object creation and interpreter overhead.

## 24. Final 2-Minute Revision Summary

- **Core Detection Methods**:
  - `s.isna()` / `df.isna()`: Canonical methods returning element-wise boolean masks.
  - `s.notna()` / `df.notna()`: Canonical methods for detecting present, valid data.
  - `isnull()` and `notnull()` are exact historical aliases.
- **The Golden Rule of IEEE 754**:
  - `np.nan == np.nan` is ALWAYS `False`. Never use `== np.nan` or `!= np.nan`.
- **Counting & Percentage Profiling**:
  - Null count per column: `df.isna().sum()`.
  - Null percentage per column: `df.isna().mean() * 100`.
  - Total table null count: `df.isna().to_numpy().sum()`.
  - Present value count: `df.count()`. Identity: `df.count() + df.isna().sum() == len(df)`.
- **Axis Direction Rule**:
  - `axis=0` (default): Aggregates vertically down rows (results indexed by column names).
  - `axis=1`: Aggregates horizontally across columns (results indexed by row labels).
  - Filtering rows with nulls requires `axis=1`: `df[df.isna().any(axis=1)]`.
- **Data Type & Sentinels**:
  - `np.nan`: IEEE 754 float; upcasts classic integer columns to `float64`.
  - `pd.NA`: Nullable extension type sentinel; preserves `'Int64'` and implements Kleene logic.
  - `pd.NaT`: Datetime missing sentinel.
  - Empty strings `""` and whitespace `" "` are NOT null; sanitize with `.str.strip().replace('', np.nan)`.
- **Truthiness Trap**:
  - `bool(np.nan)` evaluates to `True`! Never use `if val:` to check for valid numbers; use `if pd.notna(val):`.
- **Safe Mutation**:
  - Always use 2D indexing: `df.loc[df['col'].isna(), 'target'] = val`. Never use chained assignment `df[mask]['col'] = val`.
