# 21. Pandas with Matplotlib and Seaborn

## 21.1 Pandas Plotting

### 1. Section Overview

The Pandas plotting API is a high-level, declarative data visualization layer built directly on top of Matplotlib (`matplotlib.pyplot`). Instead of requiring data scientists to manually extract raw arrays, instantiate figure and axes handles, and manually configure labels and legends, Pandas integrates tabular metadata (column headers, row indices, categorical dtypes, and datetimes) directly into the rendering pipeline.

Pandas exposes its visualization interface through the unified `.plot` accessor on both `Series` and `DataFrame` objects. This accessor supports two equivalent invocation styles:
1. **Generic dispatcher**: `df.plot(kind="line", ...)`
2. **Method-based accessors**: `df.plot.line()`, `df.plot.bar()`, `df.plot.hist()`, `df.plot.box()`, `df.plot.scatter()`, `df.plot.area()`, and `df.plot.pie()`.

Under the hood, Pandas creates and manipulates Matplotlib `Figure` and `AxesSubplot` objects. Crucially, every call to a Pandas plotting method returns the underlying `matplotlib.axes.Axes` object (or an `ndarray` of `Axes` when `subplots=True`). This design enables seamless hybrid workflows: users leverage Pandas for rapid exploratory visualization, and then apply standard Matplotlib object-oriented methods (`ax.set_title()`, `ax.axhline()`, `ax.xaxis.set_major_formatter()`) for publication-grade customization.

#### Master Summary of Pandas Core Plot Types

| Plot Type | Method Accessor | Primary Data Structure | Key Parameters | Statistical & Business Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **Line Plot** | `df.plot.line()` | Numeric Series or DataFrame (indexed by time/sequence) | `x`, `y`, `secondary_y`, `style`, `logy` | Trend analysis, time-series tracking, multi-metric progression. Default plot type. |
| **Bar Chart** | `df.plot.bar()`, `df.plot.barh()` | Discrete categories vs numeric metrics | `stacked`, `rot`, `width`, `color`, `position` | Comparing discrete categories, ranking frequencies, financial balance sheets. |
| **Histogram** | `df.plot.hist()` | Continuous numerical variables | `bins`, `density`, `cumulative`, `alpha`, `orientation` | Distribution shape, skewness, modality, variance, and spread analysis. |
| **Box Plot** | `df.plot.box()` | Continuous variables grouped by category | `by`, `vert`, `whis`, `showcaps`, `showmeans` | Five-number summary (Min, Q1, Median, Q3, Max), IQR spread, and outlier detection. |
| **Scatter Plot** | `df.plot.scatter()` | Paired numeric columns (2D/3D continuous) | `x`, `y`, `c` (color), `s` (size), `colormap` | Bivariate relationships, correlation discovery, clusters, and bubble charts. |
| **Area Plot** | `df.plot.area()` | Non-negative numeric metrics across ordered index | `stacked`, `alpha`, `x`, `y` | Part-to-whole cumulative progression over time, volume accumulation. |
| **Pie Chart** | `df.plot.pie()` | 1D categorical frequency Series / single column | `y`, `autopct`, `explode`, `labels`, `startangle` | Proportional share of a whole (best limited to <= 5 distinct slices). |

### 2. Topic-Wise Interview Concepts

#### 2.1 Line Plots (`df.plot.line()`)
- **Default Representation**: If no `kind` is specified, `df.plot()` defaults to a line plot. By default, the DataFrame `index` forms the horizontal X-axis, and each numerical column generates a distinct line on the vertical Y-axis.
- **Index Sensitivity**: If the DataFrame has a `DatetimeIndex`, Pandas delegates formatting to Matplotlib date locators and formatters, providing clean date labels. If the index is unordered or string-based, lines connect points in physical row sequence, which can produce zig-zag artifacts if unsorted.
- **Dual Y-Axes (`secondary_y`)**: When plotting metrics with vastly different scales (e.g. Website Visitors in millions vs Conversion Rate as a percentage), `secondary_y=["conversion_rate"]` creates an aligned right-hand Y-axis.
- **Handling Missing Values (`NaN`)**: By default, Matplotlib line plots break when encountering `np.nan` values (leaving gaps). If continuity is desired, data must be explicitly interpolated via `df.interpolate()` or forward-filled.

#### 2.2 Bar Charts (`df.plot.bar()`, `df.plot.barh()`)
- **Vertical vs Horizontal**: Vertical bar charts (`df.plot.bar()`) place categories along the X-axis. For categories with long text labels (e.g., country names, medical diagnoses), `df.plot.barh()` places categories on the Y-axis, preventing label overlap and eliminating the need for steep rotation angles (`rot=90`).
- **Grouped vs Stacked**:
  - By default, multiple columns render as side-by-side grouped bars, facilitating intra-category comparison across series.
  - Setting `stacked=True` stacks columns vertically for each index category, illustrating part-to-whole cumulative totals.
- **Label Rotation Gotcha**: Pandas bar plots set X-tick rotation to 90 degrees by default (`rot=90`). To make labels horizontal, you must explicitly pass `rot=0`.

#### 2.3 Histograms (`df.plot.hist()`)
- **Binning Mechanics**: By default, Pandas divides the range of values into 10 equally spaced bins (`bins=10`). For production analytics, the Freedman-Diaconis rule ($h = 2 \cdot \text{IQR} \cdot n^{-1/3}$) or Sturges' formula ($k = \lceil \log_2 n \rceil + 1$) should be used to specify explicit bin counts or edges.
- **Density Normalization**: Setting `density=True` normalizes the histogram so that the total area under the bars sums to 1.0, enabling direct visual overlay of continuous Probability Density Functions (PDFs).
- **Subplots and Overlap**: Calling `df.plot.hist(alpha=0.5)` overlays semi-transparent distributions. Calling `df.plot.hist(subplots=True, layout=(2, 2))` separates columns into dedicated subplots with shared or independent axes.

#### 2.4 Box Plots (`df.plot.box()`)
- **Tukey's Five-Number Summary**: Visualizes the minimum, first quartile ($Q_1$, 25th percentile), median ($Q_2$, 50th percentile), third quartile ($Q_3$, 75th percentile), and maximum.
- **Interquartile Range (IQR) & Outliers**: The box height represents $\text{IQR} = Q_3 - Q_1$. Whiskers extend by default to $1.5 \times \text{IQR}$ beyond $Q_1$ and $Q_3$. Data points falling outside $[Q_1 - 1.5 \times \text{IQR}, Q_3 + 1.5 \times \text{IQR}]$ are designated as outliers (fliers) and rendered as individual markers.
- **Grouping with `by`**: Unlike other plot methods, `df.boxplot(column="salary", by="department")` partitions continuous data across categories, creating comparative side-by-side distributions.

#### 2.5 Scatter Plots (`df.plot.scatter()`)
- **Strict Bivariate Requirements**: Unlike line or bar charts, `df.plot.scatter(x="col_A", y="col_B")` requires explicit `x` and `y` column names. It cannot operate on the index unless the index is reset into a column (`df.reset_index().plot.scatter(...)`).
- **Color Mapping (`c`)**: Passing a third numerical column name to `c="col_C"` colors points along a continuous gradient defined by `colormap="viridis"`, automatically appending a colorbar to the figure.
- **Marker Size Scaling (`s`)**: Passing a numerical column or Series to `s=df["revenue"] / 1000` scales the marker area proportionally, creating a multi-dimensional bubble chart.

#### 2.6 Area Plots (`df.plot.area()`)
- **Cumulative Volume Representation**: Area plots fill the space between the baseline ($y = 0$) and the line curve.
- **Stacked by Default**: By default, `df.plot.area(stacked=True)` stacks all numeric columns sequentially. Each column's visual height represents its marginal contribution to the overall sum.
- **Non-Negative Value Constraint**: Stacked area plots require strictly non-negative values ($y \ge 0$). Negative numbers cause visual collisions and rendering distortions. Unstacking with `stacked=False` creates overlapping semi-transparent polygons (`alpha=0.5`).

#### 2.7 Pie Charts (`df.plot.pie()`)
- **Proportional Composition**: Pie charts map values from a single Series (or a specified DataFrame column `y="col"`) into angular slices of a circle, where slice angle $\theta_i = 360^\circ \times \frac{x_i}{\sum x}$.
- **Labels & Percentages**: Passing `autopct="%1.1f%%"` calculates and renders percentage annotations directly onto the slices.
- **Donut Chart Conversion**: Slicing the center with Matplotlib's `wedgeprops=dict(width=0.4, edgecolor='w')` transforms a solid pie chart into a modern donut chart, improving readability.
- **Cognitive Visualization Pitfall**: Human vision is inherently poor at comparing two-dimensional angular areas compared to linear lengths. Interviewers frequently test whether a candidate knows when to replace a crowded pie chart with a horizontal bar chart.

### 3. Fresher Interview Questions

#### A. Basic Conceptual Questions (20 Questions)

##### Q1: What is the primary plotting accessor in Pandas and what library powers it?
- **Concept / Definition**: Pandas provides a unified plotting interface via the `.plot` accessor on `Series` and `DataFrame` objects.
- **How Pandas & Matplotlib Handle It**: Pandas translates DataFrame column names, index values, and numeric vectors into Matplotlib `Figure` and `Axes` calls, returning the `Axes` object.
- **Syntax / Code Example**:
  ```python
  import pandas as pd
  df = pd.DataFrame({"sales": [100, 150, 200]}, index=["Jan", "Feb", "Mar"])
  ax = df.plot(kind="line")  # Returns matplotlib.axes.Axes
  ```
- **Interview Tip**: Emphasize that Pandas does not reinvent rendering; it is an ergonomic wrapper over Matplotlib.

##### Q2: What is the difference between `df.plot(kind="bar")` and `df.plot.bar()`?
- **Concept / Definition**: They are syntactically distinct but functionally identical ways to invoke the bar plot dispatcher.
- **How Pandas & Matplotlib Handle It**: `df.plot.bar(**kwargs)` is syntactic sugar that delegates internally to `df.plot(kind="bar", **kwargs)`.
- **Syntax / Code Example**:
  ```python
  ax1 = df.plot(kind="bar")
  ax2 = df.plot.bar()  # Identical output
  ```
- **Interview Tip**: Mention that `df.plot.<kind>()` provides superior IDE tab-completion and parameter discovery.

##### Q3: What object is returned by a standard Pandas `.plot()` call?
- **Concept / Definition**: It returns a Matplotlib `AxesSubplot` (or `matplotlib.axes.Axes`) object.
- **How Pandas & Matplotlib Handle It**: If `subplots=True` is passed with multiple columns, it returns a 1D or 2D NumPy `ndarray` of `Axes` objects.
- **Syntax / Code Example**:
  ```python
  ax = df.plot.line()
  print(type(ax))  # <class 'matplotlib.axes._axes.Axes'>
  axes_array = df.plot(subplots=True)
  print(type(axes_array), axes_array.shape)  # <class 'numpy.ndarray'> (N,)
  ```
- **Interview Tip**: Knowing the return type proves you understand how to customize the plot further using native Matplotlib methods.

##### Q4: What does Pandas use as the default X-axis in a line plot?
- **Concept / Definition**: The DataFrame's `Index`.
- **How Pandas & Matplotlib Handle It**: Pandas maps `df.index` directly to the X-axis tick positions and labels.
- **Syntax / Code Example**:
  ```python
  df = pd.DataFrame({"metric": [10, 20, 15]}, index=[2020, 2021, 2022])
  ax = df.plot.line()  # X-axis will be 2020, 2021, 2022
  ```
- **Interview Tip**: If you want a column other than the index as X, you must pass `x="column_name"`.

##### Q5: Why do X-axis labels in `df.plot.bar()` often appear vertical by default?
- **Concept / Definition**: Pandas sets the default rotation parameter for bar plots to `rot=90`.
- **How Pandas & Matplotlib Handle It**: It assumes categorical labels may be long strings that would collide horizontally.
- **Syntax / Code Example**:
  ```python
  # Default is rot=90; pass rot=0 to make labels horizontal:
  df.plot.bar(rot=0)
  ```
- **Interview Tip**: Always remember `rot=0` for clean presentation in technical interviews.

##### Q6: How do you plot a horizontal bar chart in Pandas?
- **Concept / Definition**: Use `df.plot.barh()` or `df.plot(kind="barh")`.
- **How Pandas & Matplotlib Handle It**: Reverses axes: categories are mapped to the Y-axis and numerical magnitudes to the X-axis.
- **Syntax / Code Example**:
  ```python
  df["sales"].plot.barh(color="teal", title="Sales by Department")
  ```
- **Interview Tip**: Horizontal bar charts are ideal when category names are long sentences or complex product names.

##### Q7: What is the purpose of the `bins` parameter in `df.plot.hist()`?
- **Concept / Definition**: It defines the number of discrete intervals (bins) into which the continuous data range is divided.
- **How Pandas & Matplotlib Handle It**: Defaults to `bins=10`. Passing an integer creates equal-width bins; passing a list/array defines custom bin edges.
- **Syntax / Code Example**:
  ```python
  df["age"].plot.hist(bins=20, edgecolor="black")
  df["age"].plot.hist(bins=[0, 18, 35, 60, 100])  # Custom edges
  ```
- **Interview Tip**: Explain that too few bins cause oversmoothing (underfitting distribution), while too many bins cause noisy spikes (overfitting).

##### Q8: What does the `density=True` parameter do in a histogram?
- **Concept / Definition**: Normalizes the histogram so that the total area of all bins equals 1.0.
- **How Pandas & Matplotlib Handle It**: Divides bin counts by total sample size and bin width, transforming raw counts into probability densities.
- **Syntax / Code Example**:
  ```python
  df["height"].plot.hist(density=True, alpha=0.6)
  ```
- **Interview Tip**: This allows direct comparison between datasets of different sample sizes or plotting alongside a theoretical PDF.

##### Q9: How do you identify outliers in a Pandas box plot?
- **Concept / Definition**: Points plotted beyond the whiskers are classified as outliers (fliers).
- **How Pandas & Matplotlib Handle It**: Whiskers extend by default to $1.5 	imes 	ext{IQR}$ from the first and third quartiles. Points beyond $[Q_1 - 1.5 	ext{IQR}, Q_3 + 1.5 	ext{IQR}]$ render as distinct points.
- **Syntax / Code Example**:
  ```python
  df.plot.box(sym="r+")  # sym sets outlier marker style (red plus)
  ```
- **Interview Tip**: Mention that `whis=3.0` can be passed to flag only extreme outliers.

##### Q10: Why does `df.plot.scatter()` require explicit `x` and `y` arguments?
- **Concept / Definition**: A scatter plot visualizes paired bivariate coordinates $(x_i, y_i)$.
- **How Pandas & Matplotlib Handle It**: Unlike line plots, which default to using the index and all columns, a scatter plot cannot infer which columns form the coordinate pair without explicit names.
- **Syntax / Code Example**:
  ```python
  df.plot.scatter(x="ad_spend", y="revenue")
  ```
- **Interview Tip**: Passing non-existent column names raises an immediate `KeyError`.

##### Q11: How do you add a continuous color dimension to a Pandas scatter plot?
- **Concept / Definition**: Use the `c` argument to map point colors to a third numerical column.
- **How Pandas & Matplotlib Handle It**: Normalizes column values and applies a Matplotlib colormap, automatically appending a colorbar.
- **Syntax / Code Example**:
  ```python
  df.plot.scatter(x="horsepower", y="mpg", c="weight", colormap="viridis")
  ```
- **Interview Tip**: This creates a 3D visualization on a 2D plane without 3D projection distortion.

##### Q12: What is the difference between a stacked and unstacked area plot?
- **Concept / Definition**: Stacked area plots accumulate values vertically; unstacked area plots show independent overlapping shapes.
- **How Pandas & Matplotlib Handle It**: `df.plot.area(stacked=True)` is the default. Setting `stacked=False` renders semi-transparent overlapping areas (`alpha=0.5` by default).
- **Syntax / Code Example**:
  ```python
  df.plot.area(stacked=False)  # Overlapping curves
  ```
- **Interview Tip**: Mention that stacked area plots require strictly non-negative values ($y \ge 0$).

##### Q13: How do you display percentage values on a Pandas pie chart?
- **Concept / Definition**: Use the `autopct` parameter with a string format specifier or formatting function.
- **How Pandas & Matplotlib Handle It**: Calculates percentage of each slice relative to total sum and formats the text label.
- **Syntax / Code Example**:
  ```python
  df["market_share"].plot.pie(autopct="%1.1f%%")
  ```
- **Interview Tip**: `%1.1f%%` formats numbers to 1 decimal place followed by a literal `%` sign.

##### Q14: How do you create multiple subplots for each column in a DataFrame with one command?
- **Concept / Definition**: Pass `subplots=True` to the `.plot()` call.
- **How Pandas & Matplotlib Handle It**: Generates an individual `AxesSubplot` for each numeric column, optionally sharing X or Y axes.
- **Syntax / Code Example**:
  ```python
  axes = df.plot(subplots=True, layout=(2, 2), figsize=(10, 8))
  ```
- **Interview Tip**: `layout=(rows, cols)` controls the grid arrangement of the generated subplots.

##### Q15: How do you set the figure size directly within a Pandas plot call?
- **Concept / Definition**: Pass the `figsize=(width, height)` tuple in inches.
- **How Pandas & Matplotlib Handle It**: Forwards the tuple to Matplotlib's figure instantiation backend.
- **Syntax / Code Example**:
  ```python
  df.plot.line(figsize=(12, 6))
  ```
- **Interview Tip**: 12x6 or 10x5 inches are standard presentation aspect ratios for wide time-series charts.

##### Q16: How do you plot onto an existing Matplotlib `Axes` using Pandas?
- **Concept / Definition**: Pass the target `Axes` object to the `ax` parameter.
- **How Pandas & Matplotlib Handle It**: Prevents creation of a new Figure/Axes; renders directly into the provided `ax` container.
- **Syntax / Code Example**:
  ```python
  import matplotlib.pyplot as plt
  fig, ax = plt.subplots(figsize=(8, 4))
  df["sales"].plot.line(ax=ax, color="darkblue")
  ax.set_title("Custom Integrated Plot")
  ```
- **Interview Tip**: This is the universal standard for integrating Pandas plots into multi-panel dashboard layouts.

##### Q17: What does `secondary_y=True` do in a line plot?
- **Concept / Definition**: Creates a twin Y-axis on the right-hand side of the chart sharing the same X-axis.
- **How Pandas & Matplotlib Handle It**: Calls `ax.twinx()` internally and maps the specified columns to the new right-hand axis.
- **Syntax / Code Example**:
  ```python
  df.plot(y=["visitors", "conversion_rate"], secondary_y=["conversion_rate"])
  ```
- **Interview Tip**: Essential when visualizing two variables with vastly different orders of magnitude (e.g. counts vs percentages).

##### Q18: What parameter changes the line style or marker in `df.plot.line()`?
- **Concept / Definition**: The `style` parameter accepts Matplotlib format strings (e.g. `"--"`, `":"`, `"o-"`, `"r--"`).
- **How Pandas & Matplotlib Handle It**: Can be passed as a single string or a dictionary/list mapping columns to distinct styles.
- **Syntax / Code Example**:
  ```python
  df.plot.line(style={"actual": "b-", "forecast": "r--"})
  ```
- **Interview Tip**: Using distinct line styles (solid vs dashed) ensures accessibility for color-blind viewers and black-and-white printouts.

##### Q19: How do you suppress the automatic legend generated by Pandas?
- **Concept / Definition**: Pass `legend=False`.
- **How Pandas & Matplotlib Handle It**: Skips the internal call to `ax.legend()`.
- **Syntax / Code Example**:
  ```python
  df.plot.line(legend=False)
  ```
- **Interview Tip**: Useful when plotting hundreds of series or when a custom external legend is added later.

##### Q20: What happens if a DataFrame contains non-numeric (string) columns when calling `df.plot.line()`?
- **Concept / Definition**: Pandas automatically filters out non-numeric columns and plots only numeric ones.
- **How Pandas & Matplotlib Handle It**: Inspects dtypes; columns with `object`, `string`, or `category` dtypes are silently ignored unless explicitly passed to `x` or `y`.
- **Syntax / Code Example**:
  ```python
  df = pd.DataFrame({"name": ["Alice", "Bob"], "score": [88, 92]})
  df.plot.line()  # Only 'score' is plotted; 'name' is ignored
  ```
- **Interview Tip**: In contrast, calling `df.plot.scatter(x="name", y="score")` will raise a `ValueError` if the X column cannot be coerced to numeric coordinates.

#### B. Intermediate Questions (20 Questions)

##### Q21: How does Pandas handle a `DatetimeIndex` differently from an integer index during plotting?
- **Answer**: When the index is a `DatetimeIndex`, Pandas enables Matplotlib's date plotting engine. It automatically formats tick labels as calendar dates (e.g., "Jan 2024", "Q1 2024"), handles irregular time intervals with appropriate spacing, and supports dynamic zooming where tick resolution updates dynamically. An integer index simply places ticks at numeric offsets.

##### Q22: What happens if you plot a line chart from a DataFrame whose index is unsorted?
- **Answer**: Pandas and Matplotlib connect points in the exact order they appear in the DataFrame rows. If the index is not sorted, the rendered line will jump back and forth across the X-axis, creating a chaotic "spiderweb" or zig-zag artifact. Always call `df.sort_index().plot.line()` prior to plotting time-series.

##### Q23: How do you create stacked bar charts where each category sums to 100%?
- **Answer**: Normalize the DataFrame across rows before plotting:
  ```python
  df_pct = df.div(df.sum(axis=1), axis=0) * 100
  df_pct.plot.bar(stacked=True, rot=0)
  ```
  This creates a 100% stacked bar chart, enabling direct comparison of relative composition regardless of total volume differences.

##### Q24: What is the difference between `df.plot.box()` and `df.boxplot()`?
- **Answer**:
  - `df.plot.box()` is part of the modern `.plot` accessor family and returns a clean `Axes` object.
  - `df.boxplot()` is a legacy top-level DataFrame method that returns a dictionary of Matplotlib line components (whiskers, caps, boxes, medians, fliers) or an `Axes`, and includes default grid lines and a subtitle. `df.boxplot(column="val", by="cat")` is particularly convenient for grouped boxplots.

##### Q25: How do you customize outlier point appearances (fliers) in `df.plot.box()`?
- **Answer**: Pass the `flierprops` dictionary:
  ```python
  flierprops = dict(marker="o", markerfacecolor="red", markersize=6, linestyle="none")
  df.plot.box(flierprops=flierprops)
  ```

##### Q26: How do you plot a kernel density estimation (KDE) curve directly in Pandas?
- **Answer**: Use `df.plot.kde()` or `df.plot.density()`. This uses SciPy's `gaussian_kde` internally to compute a smooth continuous probability density estimate over the data without requiring discrete bins.

##### Q27: How can you control the transparency of overlapping histograms in Pandas?
- **Answer**: Pass the `alpha` parameter between 0.0 (fully transparent) and 1.0 (fully opaque). A value of `alpha=0.5` or `0.6` allows underlying distributions to remain visible:
  ```python
  df[["group_A", "group_B"]].plot.hist(alpha=0.5, bins=30)
  ```

##### Q28: How do you plot multiple DataFrames on the exact same Matplotlib figure?
- **Answer**: Capture the `Axes` object returned by the first plot and pass it via `ax=ax` to the second plot:
  ```python
  ax = df_2023.plot.line(y="revenue", label="2023 Revenue", color="blue")
  df_2024.plot.line(y="revenue", label="2024 Revenue", color="orange", ax=ax)
  ```

##### Q29: What is the `logy=True` parameter used for in Pandas plotting?
- **Answer**: It sets the vertical Y-axis to a logarithmic scale ($\log_{10}$). This is crucial when visualizing exponential growth (e.g. viral infection spread, compounding interest) or distributions with extreme multi-order-of-magnitude skewness.

##### Q30: How do you plot error bars on a Pandas bar chart?
- **Answer**: Pass standard deviations or custom error values to the `yerr` parameter:
  ```python
  means = df.groupby("dept")["salary"].mean()
  stds = df.groupby("dept")["salary"].std()
  means.plot.bar(yerr=stds, capsize=4, rot=0)
  ```

##### Q31: How do you prevent overlapping X-tick labels when plotting high-frequency time-series?
- **Answer**: Call `fig.autofmt_xdate()` on the parent figure, or use Matplotlib's `MaxNLocator` to limit the maximum number of rendered ticks:
  ```python
  ax = df.plot.line()
  ax.figure.autofmt_xdate(rotation=45)
  ```

##### Q32: What is the effect of passing `table=True` to a Pandas plot?
- **Answer**: It renders a formatted data table below the chart containing the exact numerical values plotted. You can also pass a separate DataFrame: `df.plot(table=np.round(df.describe(), 2))`.

##### Q33: How do you plot a cumulative histogram in Pandas?
- **Answer**: Pass `cumulative=True` to `df.plot.hist()`:
  ```python
  df["response_time"].plot.hist(bins=50, cumulative=True, density=True)
  ```
  This creates an empirical Cumulative Distribution Function (CDF).

##### Q34: What causes a `ValueError: pie plot can have only one column` when calling `df.plot.pie()`?
- **Answer**: A pie chart represents a 1D distribution. If `df` has multiple columns, Pandas does not know which column determines the slice sizes. You must specify the column via `y="column_name"` or call `.plot.pie()` on a single `Series`: `df["sales"].plot.pie()`.

##### Q35: How do you explode a specific slice in a Pandas pie chart?
- **Answer**: Pass the `explode` sequence specifying the fractional radial offset for each slice:
  ```python
  s = pd.Series([40, 30, 20, 10], index=["A", "B", "C", "D"])
  s.plot.pie(explode=[0.1, 0, 0, 0])  # Slices 'A' outward by 10%
  ```

##### Q36: How do you customize colors for individual columns using a colormap?
- **Answer**: Pass the `colormap` parameter with any valid Matplotlib colormap name (e.g., `"viridis"`, `"magma"`, `"Set2"`, `"tab10"`):
  ```python
  df.plot.bar(colormap="viridis")
  ```

##### Q37: How do you control the aspect ratio or enforce equal scaling on a scatter plot?
- **Answer**: Retrieve the returned `ax` object and set the aspect ratio via `ax.set_aspect("equal")`. This ensures that one unit on the X-axis visually matches one unit on the Y-axis.

##### Q38: What is the difference between `sharex=True` and `sharex=False` in multi-panel subplots?
- **Answer**: When `subplots=True`, `sharex=True` locks the X-axis limits across all subplots and suppresses tick labels on interior plots to save space. `sharex=False` allows each subplot to scale its X-axis independently based on its own data range.

##### Q39: Why does Matplotlib accumulate memory when calling `df.plot()` inside a loop?
- **Answer**: Every call to `df.plot()` creates a new `Figure` in Matplotlib's global state machine registry (`_pylab_helpers.Gcf`). If figures are not explicitly closed with `plt.close(fig)` or `plt.close("all")`, memory leaks accumulate until the Python process crashes with an OOM error.

##### Q40: How do you render horizontal reference lines or vertical threshold lines on a Pandas plot?
- **Answer**: Use the underlying Matplotlib axes methods on the returned `ax`:
  ```python
  ax = df["metric"].plot.line()
  ax.axhline(y=100, color="red", linestyle="--", label="Target SLA")
  ax.axvline(x="2024-06-01", color="gray", linestyle=":")
  ax.legend()
  ```

##### Q41: Generate a comparative dual-axis time-series plot with customized line styles and legend.
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
dates = pd.date_range("2024-01-01", periods=100)
df = pd.DataFrame({
    "ad_spend": np.random.uniform(1000, 5000, 100).cumsum(),
    "conversion_rate": np.random.uniform(0.01, 0.05, 100)
}, index=dates)

# Plot with dual y-axis
```

### 4. Top Questions to Definitely Prepare

#### 4.1 Must-Know Core Questions (8 Questions)

##### 1. How does the Pandas `.plot` accessor bridge DataFrame structures to Matplotlib?
- **Detailed Technical Answer**:
  Pandas `.plot` is an object-oriented proxy (`pandas.plotting._core.PlotAccessor`) that wraps Matplotlib's procedural state machine. When invoked on a `DataFrame`, it inspects column dtypes, column headers, and the `Index`. It automatically assigns:
  1. The DataFrame `Index` to the X-axis (or Y-axis for horizontal bar charts).
  2. Numerical columns to distinct plotted series, automatically generating colors and line styles.
  3. Column names to the Matplotlib `Legend` entries.
  4. Datetime index objects to Matplotlib date locators and formatters.
  Crucially, it returns the instantiated `matplotlib.axes.Axes` handle, allowing immediate subsequent chaining with native Matplotlib methods without re-extracting data.

##### 2. What are the key differences between `df.plot.bar()` and `df.plot.hist()`?
- **Detailed Technical Answer**:
  Although both render rectangular bars, they represent fundamentally distinct statistical concepts:
  - **Bar Plot (`df.plot.bar()`)**: Operates on **discrete categorical variables**. Each bar corresponds to an explicit row index or categorical level. Bar width has no mathematical meaning; bar height represents a measured or aggregated magnitude. Spacing separates distinct categories.
  - **Histogram (`df.plot.hist()`)**: Operates on a **continuous numerical variable**. The continuous domain is partitioned into adjacent numerical intervals (bins). Bar width represents the interval width $\Delta x$; bar height represents the frequency count or probability density. Bars touch continuously without arbitrary gaps unless frequency in an interval is zero.

##### 3. How do you create dual Y-axes using Pandas plotting and when is it required?
- **Detailed Technical Answer**:
  Dual Y-axes are required when visualizing two series that share a common domain (e.g., time) but exist on drastically different measurement scales (e.g., Server Requests in thousands vs CPU Load percentage from 0 to 100).
  In Pandas, pass `secondary_y=[column_names]` to `df.plot()`. Internally, Pandas calls `ax.twinx()`, generating a secondary `AxesSubplot` overlaying the primary canvas with an independent right-hand Y-axis.
  ```python
  ax = df.plot(y=["requests", "cpu_pct"], secondary_y=["cpu_pct"], figsize=(10, 5))
  ax.set_ylabel("Request Count")
  ax.right_ax.set_ylabel("CPU Load (%)")
  ```

##### 4. How does `subplots=True` work in Pandas and how do you customize the grid layout?
- **Detailed Technical Answer**:
  Passing `subplots=True` instructs Pandas to instantiate an independent `AxesSubplot` for each plotted column instead of overlaying them on a single canvas.
  The layout is controlled via the `layout=(rows, cols)` parameter. For example, `layout=(2, 2)` arranges 4 columns into a 2x2 grid. Pandas returns a 1D or 2D NumPy array of `Axes` handles:
  ```python
  axes = df.plot(subplots=True, layout=(2, 2), figsize=(12, 8), sharex=True)
  # axes is an ndarray of shape (2, 2)
  for ax in axes.flat:
      ax.grid(True, linestyle=":")
  ```

##### 5. How are outliers mathematically calculated and visually rendered in `df.plot.box()`?
- **Detailed Technical Answer**:
  Pandas boxplots adhere to John Tukey's exploratory data analysis formulation:
  1. **Median ($Q_2$)**: Center line inside the box (50th percentile).
  2. **Interquartile Range (IQR)**: Box bounds represent $Q_1$ (25th percentile) and $Q_3$ (75th percentile). Height = $\text{IQR} = Q_3 - Q_1$.
  3. **Whiskers**: Extend to the most extreme data points within $[Q_1 - 1.5 \times \text{IQR}, Q_3 + 1.5 \times \text{IQR}]$.
  4. **Fliers (Outliers)**: Any data point $x_i < Q_1 - 1.5 \text{IQR}$ or $x_i > Q_3 + 1.5 \text{IQR}$ is designated an outlier and plotted as an isolated marker (`+` or `o`).

##### 6. How do you create a 100% normalized stacked bar chart in Pandas?
- **Detailed Technical Answer**:
  By default, `df.plot.bar(stacked=True)` stacks absolute raw values. To create a 100% component bar chart, divide each row by its row-wise sum using `df.div(df.sum(axis=1), axis=0) * 100`:
  ```python
  df_pct = df.div(df.sum(axis=1), axis=0) * 100
  ax = df_pct.plot.bar(stacked=True, rot=0)
  ax.set_ylabel("Composition (%)")
  ```

##### 7. How do you plot onto an existing Matplotlib subplot within a complex `plt.subplot` grid?
- **Detailed Technical Answer**:
  Instantiate the layout via Matplotlib (`plt.subplots()`), and then pass the specific `Axes` reference to the `ax` parameter in Pandas:
  ```python
  fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))
  df["sales"].plot.line(ax=ax1, title="Sales Trend")
  df["margin"].plot.hist(ax=ax2, title="Margin Distribution")
  ```

##### 8. Why do stacked area plots fail when the DataFrame contains negative numbers?
- **Detailed Technical Answer**:
  Stacked area charts (`df.plot.area(stacked=True)`) construct polygons by cumulatively summing series values: $y_{k}(x) = \sum_{j=1}^{k} y_j(x)$. If any $y_j(x) < 0$, the cumulative baseline dips below preceding series, causing intersecting polygons, self-overlapping fills, and rendering inversions. Pandas enforces non-negative data for stacked area plots.

##### 10. How does Pandas format datetime tick labels on time-series line plots?

##### 11. What is the difference between `df.plot(kind="scatter", x="A", y="B")` and `plt.scatter(df["A"], df["B"])`?
- **Detailed Technical Answer**:
  `df.plot.scatter` validates column existence against the DataFrame schema, automatically labels the X and Y axes using column string names, supports mapping third columns directly to color (`c="col_C"`) with an automatic colorbar, and integrates into Pandas layout pipelines. `plt.scatter` operates purely on raw array buffers and requires manual axis labeling, colorbar attachment, and legend configuration.

##### 12. How do you prevent memory leaks when generating thousands of charts in automated scripts?
- **Detailed Technical Answer**:
  Matplotlib maintains internal references to every created figure in a global registry (`Gcf`) until explicitly closed. In a batch loop, calling `df.plot()` without closing figures leaks memory continuously. Always use:
  ```python
  fig, ax = plt.subplots(...)
  df.plot(ax=ax)
  fig.savefig("path.png")
  plt.close(fig)  # Crucial: Releases memory buffer immediately
  ```

  ```python
  import matplotlib.ticker as ticker
  ```

##### 14. What are the advantages of horizontal bar charts (`plot.barh`) over vertical bar charts (`plot.bar`)?
- **Detailed Technical Answer**:
  1. **Label Readability**: Category labels on the Y-axis read naturally from left to right, eliminating the need for 90-degree rotated, illegible text on the X-axis.
  2. **Ranking Presentation**: Vertical sorting allows intuitive top-to-bottom ranking (e.g. descending leaderboard).
  3. **Visual Hierarchy**: Accommodates variable-length strings without altering chart aspect ratios.

##### 15. How do you plot error bars (`yerr`) on Pandas DataFrames with asymmetric confidence bounds?

##### 17. How does Pandas handle sparse matrices or nullable dtypes (`Int64`, `Float64`) during plot generation?
- **Detailed Technical Answer**:
  Matplotlib's core C-extensions expect contiguous NumPy arrays of standard C-types (`float64`, `float32`). When plotting Pandas ExtensionArrays (e.g. nullable integers or categorical arrays):
  1. Pandas calls `.to_numpy(dtype=float, na_value=np.nan)` internally.
  2. Null values (`pd.NA`) are converted to IEEE-754 `np.nan`.
  3. Matplotlib treats `np.nan` as discontinuous gaps in line plots and suppresses rendering for missing slices.

##### 18. How do you architect an automated, thread-safe dashboard reporting microservice using Pandas plotting?
- **Detailed Technical Answer**:
  Matplotlib is inherently not thread-safe when using its default GUI backends. For a production microservice:
  1. Set the headless non-GUI backend before importing pyplot:
     ```python
     import matplotlib
     matplotlib.use("Agg")  # Anti-Grain Geometry headless rasterizer
     import matplotlib.pyplot as plt
     ```
  2. Enforce explicit object-oriented instantiation: avoid `plt.plot()`; always instantiate `fig = Figure(); ax = fig.add_subplot()`.
  3. Ensure every figure is serialized into an in-memory byte buffer (`io.BytesIO()`) and explicitly closed to prevent thread-pool memory accumulation.

##### 19. How do you optimize rendering performance when plotting a DataFrame with 10 million time-series rows?
- **Detailed Technical Answer**:
  Directly passing 10 million rows to Matplotlib causes rendering to hang because it attempts to draw 10 million distinct line segments.
  Optimization strategies:
  1. **Temporal Downsampling**: Use `df.resample("1H").agg({"price": "ohlc"})` or LTTB (Largest Triangle Three Buckets) downsampling to preserve peak visual shape.
  2. **Fast Aggregation**: Render aggregated min/max envelopes rather than individual points.
  3. **Rasterization**: Set `rasterized=True` on vector plot elements so that PDF/SVG outputs render the dense data cloud as a raster bitmap while keeping text axes as vector primitives.

### 6. Section-Adaptive Pandas API Confusions

#### Confusion 1: `df.plot(kind="bar")` vs `df.plot(kind="hist")`
- **Conceptual Divergence**:
  - `bar`: Discrete categorical bins. Input is category keys vs scalar metrics.
  - `hist`: Continuous numeric domain. Input is raw un-aggregated observations; Pandas calculates bin edges and counts dynamically.
- **Side-by-Side Comparison**:
  ```python
  # Bar: expects pre-aggregated counts
  df["grade"].value_counts().plot.bar(rot=0)
  
  # Hist: operates directly on continuous raw values
  df["exam_score"].plot.hist(bins=15)
  ```

#### Confusion 2: `df.plot.scatter()` vs `df.plot.line()`
- **Conceptual Divergence**:
  - `line`: Connects sequential observations with line segments. Assumes natural progression along the X-axis (index).
  - `scatter`: Plots isolated points $(x_i, y_i)$ without connecting segments. Unordered bivariate exploration.
- **Side-by-Side Comparison**:
  ```python
  # Line connects points sequentially:
  df.plot.line(x="time", y="temperature")
  
  # Scatter renders independent point cloud:
  df.plot.scatter(x="height", y="weight", alpha=0.5)
  ```

#### Confusion 3: `df.plot.box()` vs `df.boxplot()`
- **Conceptual Divergence**:
  - `df.plot.box()`: Modern accessor interface, clean default aesthetic, returns `Axes`.
  - `df.boxplot()`: Legacy Matplotlib wrapper. Features built-in `by="col"` parameter for instant multi-category grouping, returns dictionary of line artists or axes.
- **Side-by-Side Comparison**:
  ```python
  # Modern accessor:
  df[["salary", "bonus"]].plot.box()
  
  # Legacy grouped boxplot:
  df.boxplot(column="salary", by="department")
  ```

#### Confusion 4: `df.plot(secondary_y=...)` vs `plt.twinx()`
- **Conceptual Divergence**:
  - `secondary_y`: High-level Pandas declarative syntax; handles automatic axis creation and data routing.
  - `plt.twinx()`: Low-level Matplotlib procedural method; requires explicit manual handle wiring and duplicate plotting calls.
- **Side-by-Side Comparison**:
  ```python
  # Pandas declarative:
  df.plot(y=["A", "B"], secondary_y=["B"])
  
  # Matplotlib manual:
  fig, ax1 = plt.subplots()
  ax1.plot(df["A"], color="b")
  ax2 = ax1.twinx()
  ax2.plot(df["B"], color="r")
  ```

### 7. Interview Traps (10 Traps)

#### Trap 1: The Invisible Scatter Plot Column
- **Trap**: Passing a datetime column to `plot.scatter` on older Pandas versions causes a `TypeError`.
- **Reality**: Historically, Matplotlib's scatter C-backend required pure float coordinates. Datetime objects must be numeric timestamps. Modern Pandas handles datetimes better, but converting via `df["date"].astype("int64")` or using `df.plot.line(marker="o")` avoids version traps.

#### Trap 2: Stacked Bar Chart Legend Inversion
- **Trap**: The order of stacked bar segments on the chart visually reverses the order in the legend.
- **Reality**: In stacked bar charts, Pandas places the first column at the bottom and stacks subsequent columns above it. The legend reads top-to-bottom, which can cause visual confusion. To align them, reverse the legend handles: `ax.legend(reversed(handles), reversed(labels))`.

#### Trap 3: The Missing `plt.show()` in Non-Interactive Scripts
- **Trap**: Running `df.plot.line()` in a standalone Python script does not display anything on the screen.
- **Reality**: In scripts, plotting methods instantiate the canvas in memory but do not open GUI windows. You must explicitly call `import matplotlib.pyplot as plt; plt.show()` to render to screen.

#### Trap 4: Plotting Categorical Columns Directly in Scatter Plots
- **Trap**: `df.plot.scatter(x="department", y="salary")`.
- **Reality**: Raises `ValueError: scatter requires numeric data`. Scatter plots require continuous numerical axes. For categorical vs numerical plots, use `df.boxplot(by=...)` or Seaborn `stripplot`.

#### Trap 5: The Deceptive Default Bins in Histograms
- **Trap**: Assuming `df.plot.hist()` provides an accurate representation of distribution shape without tuning `bins`.
- **Reality**: The default is arbitrary (`bins=10`). For 100,000 records, 10 bins severely underfits the distribution, hiding bimodal peaks. Always specify domain-appropriate bins.

#### Trap 6: Legend Disappearance with `subplots=True`
- **Trap**: Calling `df.plot(subplots=True)` and expecting a shared legend.
- **Reality**: By default, Pandas places individual column legends inside each individual subplot, or suppresses them if column titles match.

#### Trap 7: NaN Gaps in Line Plots
- **Trap**: A line plot unexpectedly renders as disconnected dots or broken line segments.
- **Reality**: Matplotlib breaks line drawing at every `np.nan`. If missing data is scattered, lines never connect. Data must be interpolated first via `df.interpolate()`.

#### Trap 8: Truncated Subplot Labels
- **Trap**: Subplots in a 3x3 grid have X-tick labels overlapping the titles of the row below.
- **Reality**: Pandas does not automatically invoke layout solvers. Always call `plt.tight_layout()` or `plt.subplots_adjust()` before saving or displaying.

#### Trap 9: Unintended Secondary Y-Axis Scaling Distortion
- **Trap**: Using `secondary_y` carelessly can visually mislead viewers by exaggerating tiny fluctuations to look identical to major shifts.
- **Reality**: The secondary axis independently normalizes its limits. A 0.1% change in conversion rate will look as dramatic as a 50% drop in revenue unless axes limits are pinned.

#### Trap 10: Zero-Copy Violation in Pandas Plotting
- **Trap**: Assuming `df.plot()` operates zero-copy on the underlying DataFrame buffer.
- **Reality**: Matplotlib requires contiguous 1D float arrays. Pandas extracts columns and frequently copies data buffers into Matplotlib's internal structures.

### 10. "Explain This Code" Questions (4 Snippets)

#### Snippet 1: Normalized 100% Component Transformation
```python
df.div(df.sum(axis=1), axis=0).mul(100).plot.bar(stacked=True, rot=0)
```
- **Line-by-Line Mechanics**:
  1. `df.sum(axis=1)`: Computes the row-wise sum across all columns, returning a 1D Series of totals for each index row.
  2. `df.div(..., axis=0)`: Divides each element in `df` by its corresponding row sum, broadcasting along rows (`axis=0`). This normalizes each row into fractional shares summing to 1.0.
  3. `.mul(100)`: Scales fractions to percentage values ($[0, 100]$).
  4. `.plot.bar(stacked=True, rot=0)`: Renders vertical stacked bars where each bar reaches exactly 100% height, with horizontal axis labels (`rot=0`).
- **Production Rationale**: Normalizes categorical compositions so teams can compare relative distributions across time periods or cohorts of vastly different absolute sizes.

#### Snippet 2: Overlaid Distribution Density and KDE
```python
ax = df["val"].plot.hist(density=True, bins=30, alpha=0.5)
df["val"].plot.kde(ax=ax, color="black", linewidth=2)
```
- **Line-by-Line Mechanics**:
  1. `df["val"].plot.hist(density=True, bins=30, alpha=0.5)`: Divides `val` into 30 bins, normalizes bin heights so total area equals 1.0, sets opacity to 50%, and returns the `ax` handle.
  2. `df["val"].plot.kde(ax=ax, color="black", linewidth=2)`: Fits a Gaussian Kernel Density Estimate using SciPy, evaluates the continuous density curve, and plots it onto the exact same `ax` canvas with a solid 2pt black line.
- **Production Rationale**: Allows visual comparison of empirical discrete sample bins against a theoretical smoothed continuous density function.

#### Snippet 3: Automated X-Date Auto-Formatting
```python
ax = df.plot.line(figsize=(10, 4))
ax.figure.autofmt_xdate(rotation=30)
```
- **Line-by-Line Mechanics**:
  1. `df.plot.line(...)`: Renders time-series data using `df.index` as the X-axis, returning the `Axes` handle.
  2. `ax.figure`: Navigates from the child `AxesSubplot` to the parent `Figure` container.
  3. `.autofmt_xdate(rotation=30)`: Invokes Matplotlib's date-formatting engine to tilt tick labels by 30° and automatically thin out redundant date labels to prevent collisions.
- **Production Rationale**: Eliminates manual tick locator loops on high-frequency daily or hourly time-series charts.

#### Snippet 4: Headless Figure Clean-up
```python
fig, ax = plt.subplots()
df.plot(ax=ax)
fig.savefig("output.png")
plt.close(fig)
```
- **Line-by-Line Mechanics**:
  1. `plt.subplots()`: Instantiates a dedicated `Figure` and `Axes` pair.
  2. `df.plot(ax=ax)`: Instructs Pandas to render into the explicit `ax` container rather than querying the global state machine.
  3. `fig.savefig(...)`: Serializes the raster pixel buffer to disk.
  4. `plt.close(fig)`: Explicitly dereferences the figure from Matplotlib's internal `Gcf` registry, releasing GPU/RAM canvas buffers immediately.
- **Production Rationale**: Prevents Out-Of-Memory crashes in long-running batch workers generating thousands of charts.

### 16. Questions That Test Understanding (Perturbations)

#### Perturbation 1: Plotting a Datetime Index with Gaps
- **Question**: "You have daily sales data with weekends omitted (only Monday–Friday). What happens when you plot a line chart with `df.plot.line()`?"
- **Expected Insight**: If the index is a plain string index, points appear equidistant, hiding the weekend gaps. If the index is a true `DatetimeIndex`, Matplotlib's date locator renders calendar-proportional spacing, creating visual flat gaps over weekends unless formatted with categorical ordinal indices.

#### Perturbation 2: Scatter Plotting Uncoerced Object Coordinates
- **Question**: "Column `'lat'` contains float values stored as strings, e.g. `'37.77'`. What happens when you call `df.plot.scatter(x='lat', y='lon')`?"
- **Expected Insight**: Matplotlib treats string columns as categorical coordinates, placing every distinct string at integer positions ($0, 1, 2, \dots$) rather than geographic floating-point coordinates, completely corrupting spatial relationships. Columns must be converted via `pd.to_numeric()`.

#### Perturbation 3: Adding Reference Lines to Secondary Y-Axis
- **Question**: "You have a secondary Y-axis for margin percentage. You call `ax.axhline(0.20)`. Does the reference line align with the primary or secondary axis?"
- **Expected Insight**: It aligns with `ax` (the primary axis). To draw a reference line aligned with the secondary axis scale, you must access the secondary axis handle via `ax.right_ax.axhline(0.20)` or capture `ax2`.

#### Perturbation 4: Grouped vs Stacked Bar Total Comparison
- **Question**: "A stakeholder asks whether product A or product B sells more in total across all regions. You show them a stacked bar chart. Is this effective?"
- **Expected Insight**: No. In stacked bar charts, only the bottom-most segment (which shares the common baseline at $y=0$) and the total bar height are easy to compare. Middle and top segments have varying baselines, making human perceptual comparison of individual segments difficult. Grouped bars or separate horizontal bar charts are superior for segment comparison.

### 19. What a Fresher Should Memorize (Section-Specific)

1. **`rot=0` for Bar Charts**: Always pass `rot=0` to `df.plot.bar()` to keep labels horizontal.
2. **Scatter Requires Reset Index**: `df.plot.scatter()` cannot use the index unless reset via `df.reset_index()`.
3. **Pie Chart Requires 1D**: Always specify `y="col_name"` when calling `df.plot.pie()` on a DataFrame.
4. **Stacked Area Requires $y \ge 0$**: Never pass negative values to `df.plot.area(stacked=True)`.
5. **Memory Clean-up Rule**: Always call `plt.close(fig)` inside batch loops to prevent OOM errors.
6. **Secondary Axis Syntax**: `secondary_y=[column_names]` creates a twin right-hand Y-axis.
7. **Return Value is `Axes`**: Pandas `.plot()` returns `matplotlib.axes.Axes` (or ndarray of Axes).

### 20. What a Fresher Should Understand (Computational Mechanics)

1. **The Matplotlib Object Hierarchy**:
   - `Figure` is the top-level window/canvas containing everything.
   - `Axes` is the actual plot area (coordinate space with X-axis, Y-axis, title, and data lines).
   - Pandas returns `Axes`, allowing you to chain native Matplotlib commands (`ax.set_title()`, `ax.grid()`).
2. **Frequency Histograms vs Density Estimates**:
   - Histograms discretize data into intervals; height reflects sample counts.
   - KDE fits a continuous Gaussian kernel $rac{1}{h\sqrt{2\pi}} e^{-rac{(x - x_i)^2}{2h^2}}$ at every observation and sums them to create a smooth curve whose total area equals 1.0.
3. **Tukey's Outlier Mathematics**:
   - Outliers are not arbitrary points; they are rigorously defined as values exceeding $Q_3 + 1.5 	ext{IQR}$ or falling below $Q_1 - 1.5 	ext{IQR}$.

### 24. Final 2-Minute Revision Summary

- **Accessor Architecture**: Pandas `.plot` wraps Matplotlib, mapping DataFrame indices to the X-axis and columns to series, returning `Axes` handles for fine-tuning.
- **Bar Chart Orientation**: Vertical bars default to `rot=90`; pass `rot=0` for horizontal labels or use `df.plot.barh()` for long category names.
- **Dual Y-Axes**: Pass `secondary_y=[cols]` to plot metrics of different scales on the same chart without distortion.
- **Distribution Visualization**: Use `df.plot.hist(density=True)` and chain `df.plot.kde(ax=ax)` to overlay continuous density estimates on empirical histograms.
- **Outlier Mathematics**: Boxplots use Tukey's $1.5 	imes 	ext{IQR}$ fences to isolate outliers as individual flier markers.
- **Compositional Normalization**: Create 100% stacked bars via `df.div(df.sum(axis=1), axis=0).mul(100).plot.bar(stacked=True)`.
- **Memory Safety**: Always call `plt.close(fig)` when generating charts in loops to prevent Out-Of-Memory crashes.
