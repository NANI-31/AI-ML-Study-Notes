### 1. Section Overview

#### What This Section Is About
This section covers statistical and programmatic outlier detection, diagnosis, and remediation using Pandas and NumPy. An outlier is an observation that deviates markedly from the overall distribution of values in a dataset. Outliers can originate from sensor malfunctions, manual data-entry typos (e.g. human age = 999), corrupted telemetry, or genuine real-world heavy-tailed phenomena (e.g. billionaire net worths, high-value corporate fraud, network cyberattacks). This section explores parametric methods (Z-score, Modified Z-score using Median Absolute Deviation), non-parametric methods (Tukey's Interquartile Range fences, percentile capping), removal techniques via boolean filtering, and transformation/capping methods using `Series.clip()` and statistical imputation.

#### Why These Pandas Concepts Matter
1. **Preserving Statistical Reliability:** Parametric statistics such as the sample mean ($\mu$) and standard deviation ($\sigma$) have an unbounded breakdown point ($0\%$ breakdown point); a single massive outlier can drag the sample mean to infinity and inflate standard deviation, rendering downstream calculations useless. Robust statistics (median, IQR) resist extreme perturbations.
2. **Preventing Machine Learning Degradation:** Linear regression, logistic regression, neural networks, and k-means clustering minimize squared error loss functions ($L_2$ norm), which heavily penalize large residuals. Outliers exert disproportionate leverage, tilting regression hyperplanes and destabilizing cluster centroids.
3. **Distinguishing Error from Signal:** Blindly deleting outliers is a dangerous anti-pattern. In fraud detection, cyber threat hunting, and medical diagnostics, the outliers *are* the primary business signal. Senior data professionals understand when to drop, cap (winsorize), or flag outliers for human review.
4. **Data Normalization & Scaling Prep:** Algorithms that rely on Euclidean distances require features scaled within bounded ranges. Removing or capping extreme values prevents standard scalers and min-max scalers from compressing 99% of normal data into a tiny numeric sub-interval.

#### Where They Are Used in Real Projects
- **Credit Card Fraud Detection:** Identifying anomalous spikes in transaction amounts or rapid-fire velocity that deviate from historical customer spend profiles.
- **Predictive Maintenance & IoT Monitoring:** Filtering acoustic and vibration telemetry to catch industrial equipment overheating before mechanical failure.
- **Real Estate & Property Valuation:** Removing data entry typos (e.g. a 2-bedroom condo listed for $100,000,000) while winsorizing legitimate luxury properties.
- **Quantitative Algorithmic Trading:** Detecting Flash Crash exchange artifacts and bid-ask spread glitches to prevent automated algorithmic trade execution.

#### What a Fresher Should Be Able to Do
- Calculate and explain the Interquartile Range (IQR) and Tukey's upper and lower fences ($Q1 - 1.5 \times IQR$, $Q3 + 1.5 \times IQR$).
- Compute Z-scores using Pandas vector operations: `(s - s.mean()) / s.std()`.
- Identify when the Z-score method fails due to non-normal, skewed distribution characteristics.
- Filter out outlier rows cleanly using boolean masking without corrupting DataFrame indexing.
- Cap (winsorize) extreme values at boundary thresholds using `Series.clip()`.
- Replace outliers with `NaN` or median values conditionally based on business domain constraints.

### 2. Topic-Wise Interview Concepts

#### 2.1 Understanding Outliers: Errors vs Natural Extreme Events
Outliers fall into two distinct philosophical categories:
1. **Measurement / Data Entry Errors:** Artifacts of system failure or human mistake (e.g. sensor reporting `-9999` as a sentinel value, human age recorded as `250`, or GPS coordinates in the middle of the ocean). These should be removed, corrected, or imputed as missing (`NaN`).
2. **Genuine Heavy-Tailed Extremes (Black Swans):** Valid observations reflecting natural real-world skew (e.g. customer lifetime value in e-commerce, transaction values on institutional wire transfers, website traffic during viral campaigns). These represent true signals; dropping them introduces catastrophic survivorship bias. They should be handled via non-parametric models, log transforms, or winsorization.

#### 2.2 Sensitivity of Statistics: Mean/Std vs Median/IQR
- **$L_2$ Statistics (Sensitive):** The sample mean and standard deviation are non-robust. If a dataset has values `[10, 12, 11, 13, 1000]`, the mean jumps from `11.5` to `209.2`.
- **$L_1$ Statistics (Robust):** The median and Interquartile Range are robust against extreme values. In the example above, the median remains `12.0`, accurately capturing the central tendency of the typical population.

#### 2.3 The IQR Method (Tukey's Fences)
The IQR method is a non-parametric outlier detection technique that makes zero assumptions about underlying Gaussian distribution:
1. **$Q1$ (25th Percentile):** The value below which 25% of data points fall.
2. **$Q3$ (75th Percentile):** The value below which 75% of data points fall.
3. **$IQR$ (Interquartile Range):** The spread of the middle 50% of data:
   $$IQR = Q3 - Q1$$
4. **Tukey's Inner Fences (Mild Outliers):**
   $$\text{Lower Bound} = Q1 - 1.5 \times IQR$$
   $$\text{Upper Bound} = Q3 + 1.5 \times IQR$$
5. **Tukey's Outer Fences (Extreme Outliers):**
   $$\text{Extreme Lower} = Q1 - 3.0 \times IQR$$
   $$\text{Extreme Upper} = Q3 + 3.0 \times IQR$$

```python
import pandas as pd

s = pd.Series([12, 14, 15, 18, 19, 21, 22, 25, 29, 150])

q1 = s.quantile(0.25)
q3 = s.quantile(0.75)
iqr = q3 - q1

lower_fence = q1 - 1.5 * iqr
upper_fence = q3 + 1.5 * iqr

outlier_mask = (s < lower_fence) | (s > upper_fence)
print("Outliers detected:\n", s[outlier_mask])
# 9    150
```

#### 2.4 The Z-Score Method
The Z-score measures the signed number of standard deviations an observation falls from the mean:
$$Z = \frac{x - \mu}{\sigma}$$
- **Threshold Rule:** In a standard normal (Gaussian) distribution, $99.73\%$ of data falls within $\pm 3\sigma$. An observation with $|Z| > 3$ is traditionally flagged as an outlier.
- **The Critical Limitation:** The Z-score assumes the data is normally distributed! On right-skewed data (e.g. household income or cloud API latency), applying $|Z| > 3$ flags valid business cases while failing to flag anomalies on the short left tail.

```python
# Vectorized Z-score calculation in Pandas
mean = s.mean()
std = s.std()
z_scores = (s - mean) / std

outliers_z = s[z_scores.abs() > 3]
```

#### 2.5 The Modified Z-Score (MAD: Median Absolute Deviation)
Because both $\mu$ and $\sigma$ are distorted by the very outliers being detected, Boris Iglewicz and David Hoaglin introduced the **Modified Z-Score**, which substitutes the median ($\tilde{x}$) and Median Absolute Deviation ($MAD$):
$$MAD = \text{median}(|x_i - \tilde{x}|)$$
$$\text{Modified } Z_i = \frac{0.6745 \times (x_i - \tilde{x})}{MAD}$$
- The constant $0.6745$ makes the estimator consistent with the standard deviation for a normal distribution.
- Observations with $|\text{Modified } Z_i| > 3.5$ are flagged as outliers. This is far more robust than standard Z-scores on contaminated datasets.

```python
median = s.median()
mad = (s - median).abs().median()
modified_z = 0.6745 * (s - median) / mad
outliers_mad = s[modified_z.abs() > 3.5]
```

#### 2.6 Remediating Outliers: Dropping vs Capping (Winsorization)
Once outliers are detected, the data engineer must choose a remediation strategy:
1. **Removal (Boolean Masking):** Drops rows from the DataFrame. Acceptable when rows are corrupted data entry errors.
   ```python
   clean_df = df[(df['amount'] >= lower_fence) & (df['amount'] <= upper_fence)]
```
2. **Capping / Winsorization (`Series.clip()`):** Replaces extreme values outside the threshold with the boundary values themselves, preserving sample size without distorting scale.
   ```python
   df['amount_capped'] = df['amount'].clip(
       lower=lower_fence, upper=upper_fence
   )
```
3. **Quantile Capping (Percentile Winsorization):** Clamps values at fixed percentiles (e.g. 1st and 99th percentiles):
   ```python
   low_pct = df['amount'].quantile(0.01)
   high_pct = df['amount'].quantile(0.99)
   df['amount_winsorized'] = df['amount'].clip(lower=low_pct, upper=high_pct)
```
4. **Masking with `NaN`:** Converts outlier values to `np.nan` so they can be imputed using domain-appropriate techniques (e.g. forward-fill for time series, or median imputation).
   ```python
   df.loc[outlier_mask, 'amount'] = np.nan
```

### 3. Fresher Interview Questions

#### 3.1 20 Basic Interview Questions (4-Part Structure)

##### Q1: What is an outlier in a statistical dataset?
- **Concept:** Outlier definition and taxonomy.
- **Direct Answer:** An outlier is an observation that lies an abnormal distance from other values in a random sample of a population. It can arise from measurement or data-entry errors, or represent genuine heavy-tailed real-world events.
- **Code Example:**
  ```python
  import pandas as pd

  s = pd.Series([20, 22, 21, 23, 20, 999])  # 999 is a clear outlier
```
- **Pitfall / Note:** Not all outliers are errors; deleting genuine extreme events (like fraud) destroys the exact signal models are built to predict.

---

##### Q2: Why is the sample mean sensitive to outliers, while the sample median is robust?
- **Concept:** Statistical breakdown point.
- **Direct Answer:** The mean sums all values and divides by $N$; changing a single point to an arbitrarily large number pulls the mean to infinity ($0\%$ breakdown point). The median only depends on rank order; up to $50\%$ of data points can be corrupted before the median breaks down ($50\%$ breakdown point).
- **Code Example:**
  ```python
  s1 = pd.Series([10, 11, 12, 13, 14])
  s2 = pd.Series([10, 11, 12, 13, 10000])
  print("Mean change:", s1.mean(), "->", s2.mean())  # 12.0 -> 2009.2
  print("Median change:", s1.median(), "->", s2.median())  # 12.0 -> 12.0
```
- **Pitfall / Note:** Relying on the mean to describe central tendency in skewed or outlier-contaminated datasets produces misleading summaries.

---

##### Q3: How do you compute the Interquartile Range (IQR) in Pandas?
- **Concept:** Non-parametric spread measurement.
- **Direct Answer:** Calculate the 75th percentile ($Q3$) and 25th percentile ($Q1$) using `Series.quantile()`, then subtract: `iqr = s.quantile(0.75) - s.quantile(0.25)`.
- **Code Example:**
  ```python
  q1 = df["income"].quantile(0.25)
  q3 = df["income"].quantile(0.75)
  iqr = q3 - q1
```
- **Pitfall / Note:** In standard boxplots, the IQR represents the height of the central box containing the middle 50% of the distribution.

---

##### Q4: What are Tukey's upper and lower fences for outlier detection?
- **Concept:** Tukey's Fences formula.
- **Direct Answer:** Tukey's fences define boundaries beyond which points are flagged as outliers:
  - $\text{Lower Fence} = Q1 - 1.5 \times IQR$
  - $\text{Upper Fence} = Q3 + 1.5 \times IQR$
- **Code Example:**
  ```python
  lower = q1 - 1.5 * iqr
  upper = q3 + 1.5 * iqr
  outliers = df[(df["income"] < lower) | (df["income"] > upper)]
```
- **Pitfall / Note:** Points between $1.5 \times IQR$ and $3.0 \times IQR$ are termed "mild outliers"; points beyond $3.0 \times IQR$ are "extreme outliers".

---

##### Q5: Why is the multiplier $1.5$ used in Tukey's IQR rule?
- **Concept:** Theoretical grounding of Tukey's Fences.
- **Direct Answer:** For a Gaussian (normal) distribution, the IQR equals approximately $1.349 \times \sigma$. Setting the fences at $\pm 1.5 \times IQR$ spans approximately $\pm 2.7\sigma$, capturing $99.3\%$ of values and leaving only $0.7\%$ in the tails as potential outliers.
- **Code Example:**
  ```python
  # In normal data, 1.5 * IQR leaves ~0.7% in tails
  # 3.0 * IQR spans ~4.7 sigma, leaving ~0.0002% in tails
```
- **Pitfall / Note:** If your data is heavily skewed or log-normal, $1.5 \times IQR$ will flag far more than $0.7\%$ of points.

---

##### Q6: How do you calculate a Z-score for a Pandas Series?
- **Concept:** Parametric standardization.
- **Direct Answer:** Subtract the mean and divide by standard deviation: `z = (s - s.mean()) / s.std()`.
- **Code Example:**
  ```python
  s = pd.Series([10, 20, 30, 40, 50, 200])
  z_scores = (s - s.mean()) / s.std()
  outliers = s[z_scores.abs() > 3]
```
- **Pitfall / Note:** `s.std()` in Pandas uses Bessel's correction by default (`ddof=1`), whereas NumPy's `np.std()` uses `ddof=0`.

##### Q7: What is the primary operational assumption of the Z-score outlier method?
- **Concept:** Distributional assumptions.
- **Direct Answer:** The Z-score method assumes that the underlying population is **normally (Gaussian) distributed**.
- **Code Example:**
  ```python
  # On exponential/lognormal distributions, Z-score produces biased outliers
```
- **Pitfall / Note:** Applying Z-score filtering to power-law distributions (like wealth, web page views, or call durations) erroneously deletes legitimate long-tail observations.

##### Q8: What threshold is typically used to classify an observation as an outlier using Z-scores?
- **Concept:** Standard Z-score cutoff.
- **Direct Answer:** An absolute Z-score threshold of $|Z| > 3$ (or occasionally $|Z| > 2.5$) is standard practice, indicating points falling outside the $99.73\%$ confidence region of a normal curve.
- **Code Example:**
  ```python
  outlier_mask = z_scores.abs() > 3.0
```
- **Pitfall / Note:** A rigid cutoff of $3.0$ will falsely flag points in large datasets ($N > 1,000,000$) where hundreds of points naturally exceed $3\sigma$.

##### Q9: What is "Winsorization" or "Capping", and how is it implemented in Pandas?
- **Concept:** Retaining sample size via value clamping.
- **Direct Answer:** Winsorization replaces extreme values that exceed thresholds with the threshold values themselves rather than dropping rows. In Pandas, this is accomplished via `Series.clip()`.
- **Code Example:**
  ```python
  df["capped_val"] = df["val"].clip(lower=lower_fence, upper=upper_fence)
```
- **Pitfall / Note:** Capping changes the distribution shape by creating artificial spikes at the boundary fences.

##### Q10: How do you drop outlier rows from a DataFrame using boolean indexing?
- **Concept:** Row removal via inverted masks.
- **Direct Answer:** Filter the DataFrame using the negation of the outlier condition: `df[(df['col'] >= lower) & (df['col'] <= upper)]`.
- **Code Example:**
  ```python
  clean_df = df[(df["speed"] >= 0) & (df["speed"] <= 120)].reset_index(drop=True)
```
- **Pitfall / Note:** Always chain `.reset_index(drop=True)` after dropping rows to prevent discontinuous index gaps.

##### Q11: How do you replace detected outliers with `NaN` in Pandas?
- **Concept:** Masking outliers for downstream imputation.
- **Direct Answer:** Use `df.loc[mask, 'col'] = np.nan` or `s.mask(mask, np.nan)`.
- **Code Example:**
  ```python
  import numpy as np

  outliers = df["temp"] > 100
  df.loc[outliers, "temp"] = np.nan
```
- **Pitfall / Note:** Do not use chained indexing like `df['temp'][outliers] = np.nan`, which triggers a `SettingWithCopyWarning`.

##### Q12: How do you perform percentile-based capping (e.g. 1st and 99th percentiles)?
- **Concept:** Percentile Winsorization.
- **Direct Answer:** Compute boundaries using `df['col'].quantile(0.01)` and `df['col'].quantile(0.99)`, then apply `.clip()`.
- **Code Example:**
  ```python
  p01 = df["price"].quantile(0.01)
  p99 = df["price"].quantile(0.99)
  df["price_clean"] = df["price"].clip(lower=p01, upper=p99)
```
- **Pitfall / Note:** Percentile capping guarantees that exactly 2% of the dataset will be clamped to the boundaries.

##### Q13: What is the Median Absolute Deviation (MAD), and why is it preferred over standard deviation?
- **Concept:** Robust dispersion metric.
- **Direct Answer:** $MAD = \text{median}(|x_i - \text{median}(x)|)$. Unlike standard deviation, which squares deviations and is heavily distorted by outliers, MAD uses absolute deviations from the median, making it robust against extreme values.
- **Code Example:**
  ```python
  med = s.median()
  mad = (s - med).abs().median()
```
- **Pitfall / Note:** In older versions of Pandas, `Series.mad()` computed the Mean Absolute Deviation. In modern Pandas, compute it explicitly via median of absolute deviations.

##### Q14: What is the formula for the Modified Z-Score?
- **Concept:** Robust Z-score calculation.
- **Direct Answer:**
  $$\text{Modified } Z_i = \frac{0.6745 \times (x_i - \text{median}(x))}{MAD}$$
  Observations with $|\text{Modified } Z_i| > 3.5$ are considered outliers.
- **Code Example:**
  ```python
  mod_z = 0.6745 * (s - s.median()) / ((s - s.median()).abs().median())
  outliers = s[mod_z.abs() > 3.5]
```
- **Pitfall / Note:** If more than 50% of the dataset has identical values, $MAD = 0$, causing a division-by-zero error.

##### Q16: How do you replace outliers with the column median?

- **Code Example:**

- **Pitfall / Note:** Tree-based models (Random Forest, XGBoost) split on rank order and are naturally robust to monotonic feature outliers.

##### Q19: How do you apply IQR outlier filtering across multiple numeric columns simultaneously?
- **Concept:** Multi-column outlier purge.
- **Direct Answer:** Loop over numeric columns, compute upper and lower fences per column, and combine boolean conditions using bitwise AND (`&`).
- **Code Example:**
  ```python
  clean_df = df.copy()
  for col in df.select_dtypes("number").columns:
    q1 = df[col].quantile(0.25)
    q3 = df[col].quantile(0.75)
    iqr = q3 - q1
    clean_df = clean_df[
        (clean_df[col] >= q1 - 1.5 * iqr) & (clean_df[col] <= q3 + 1.5 * iqr)
    ]
```
- **Pitfall / Note:** Filtering iteratively across 20 columns can drop 80% of data if outliers occur in different rows across columns.

##### Q20: When should you transform data (e.g. log transform) instead of removing outliers?
- **Concept:** Transformation versus deletion.
- **Direct Answer:** When data is naturally right-skewed and heavy-tailed (e.g. income, file sizes, transaction volume), applying a logarithmic transform (`np.log1p(df['col'])`) compresses the tail and normalizes the distribution, allowing extreme values to be retained without distorting linear models.
- **Code Example:**
  ```python
  import numpy as np

  df["log_income"] = np.log1p(df["income"])
```
- **Pitfall / Note:** `np.log1p(x)` computes $\ln(1 + x)$, safely handling zero values without generating `-inf`.

#### 3.2 20 Intermediate Interview Questions

1. **Why does applying Tukey's IQR rule on skewed distributions falsely flag legitimate high values?**  
   Tukey's fences assume symmetrical dispersion around the quartiles. In heavily right-skewed data, the distance from $Q1$ to the minimum is short, while $Q3$ to the maximum is long. The fixed $1.5 \times IQR$ fence cuts off legitimate tail observations while failing to detect anomalies on the lower side.
2. **What is the Medcouple, and how does the Adjusted Boxplot handle skewed distributions?**  
   The Medcouple ($MC$) is a robust statistic measuring skewness. The adjusted boxplot modifies Tukey's fences: for $MC \ge 0$, fences become $[Q1 - 1.5 e^{-4 MC} IQR, Q3 + 1.5 e^{3 MC} IQR]$, expanding the upper fence to accommodate the natural skew.
3. **What happens to the Z-score calculation if a column contains zero variance (all identical values)?**  
   The standard deviation $\sigma = 0$. Dividing by zero produces `NaN` or `inf` across the entire column. Production pipelines must assert `df[col].std() > 0` before calculating Z-scores.
4. **How do you calculate Mahalanobis distance in Python for multivariate outlier detection?**  
   Mahalanobis distance measures the distance of a point from the multidimensional distribution mean, scaled by the covariance matrix: $D_M(x) = \sqrt{(x - \mu)^T \Sigma^{-1} (x - \mu)}$. It is calculated using `scipy.spatial.distance.mahalanobis`.
5. **How does `Series.clip()` differ from `np.clip()` in Pandas workflows?**  
   `Series.clip()` preserves the Pandas index, handles missing values (`NaN`) safely without propagating errors, and accepts scalar boundaries or Series/dict alignments.
6. **Why does removing outliers *reduce* the generalizability of a fraud detection model?**  
   Fraudulent transactions are, by definition, anomalous outliers. Removing them purges the minority positive class, ensuring the trained classifier will never learn how to identify actual fraud in production.
7. **How can you detect outliers in time series data with strong seasonality?**  
   Direct Z-score or IQR fails because seasonal peaks appear as outliers. Decompose the time series into trend, seasonal, and residual components (e.g. via `statsmodels.tsa.seasonal_decompose`), and apply outlier detection strictly to the **residual (noise)** component.
8. **What is the masking effect in outlier detection?**  
   The masking effect occurs when a cluster of multiple extreme outliers inflates the mean and standard deviation so much that other genuine outliers are erroneously classified as normal.
9. **What is the swamping effect in outlier detection?**  
   The swamping effect occurs when an extreme outlier inflates the variance so severely that normal observations on the opposite side of the distribution are falsely flagged as outliers.
10. **How does an Isolation Forest detect outliers compared to IQR and Z-scores?**  
    An Isolation Forest isolates anomalies by randomly partitioning feature space with decision trees. Because outliers are rare and have distinct feature values, they require fewer random splits to isolate, resulting in shorter average path lengths in the trees.
11. **How do you safely replace outliers in a pipeline without causing data leakage between train and test sets?**  
    Calculate the threshold statistics ($Q1$, $Q3$, $\mu$, $\sigma$, or median) strictly on the **training set**. Apply these fixed numeric bounds to cap or filter both the training set and the test set.
12. **What is the breakdown point of an estimator?**  
    The breakdown point is the maximum proportion of arbitrarily corrupted observations an estimator can tolerate before yielding an arbitrarily large incorrect result. The mean has a breakdown point of $0$ ($1/N$); the median has a breakdown point of $0.5$ ($50\%$).
13. **Why is log transformation (`np.log1p`) effective for handling right-skewed outliers?**  
    Logarithmic functions have a decelerating rate of growth; as $x$ increases, $\ln(x)$ grows slowly. A value of $1,000,000$ becomes $\approx 13.8$, pulling long-tail extremes into a compact, near-Gaussian bell shape.
14. **How does boxplot notch visualization reflect statistical confidence?**  
    Notches in a boxplot represent the $95\%$ confidence interval around the median ($\text{median} \pm 1.57 \times IQR / \sqrt{N}$). If notches of two groups do not overlap, their medians differ with $95\%$ statistical confidence.
15. **Can you detect outliers in categorical data?**  
    Yes. Rare category detection identifies infrequent labels that appear below a frequency threshold (e.g. $< 1\%$ of rows). Rare categories can be grouped into an `'Other'` bucket using `df['cat'].value_counts()`.
16. **How does `df.describe()` help you quickly spot outliers?**  
    Compare the `mean` to the `50%` (median): a large divergence indicates skew. Compare `75%` to `max`: if `max` is orders of magnitude larger than `75%`, severe upper-tail outliers exist.
17. **What is the difference between hard thresholding and soft thresholding?**  
    Hard thresholding sets values outside bounds to `NaN` or drops them completely. Soft thresholding (like Winsorization or shrinkage) contracts values toward the boundary or applies a smooth sigmoid penalty.
18. **Why should you never remove outliers from a feature when training tree-based models like XGBoost?**  
    Gradient boosted trees split data based on ordering (rank) rather than distance. An outlier value of $1,000,000$ produces the exact same tree split as $500$ if there are no intermediate points. Removing it discards training rows without improving the tree split.
19. **How do you detect outliers in grouping subsets (e.g. salary outliers per department)?**  
    Compute group-wise statistics using `.transform()`: `upper = df.groupby('dept')['salary'].transform(lambda x: x.quantile(0.75) + 1.5 * (x.quantile(0.75) - x.quantile(0.25)))`.
20. **What is the impact of outlier removal on linear regression $R^2$?**  
    Removing legitimate high-leverage points can artificially inflate or deflate $R^2$. If the points follow the true linear trend, dropping them reduces $R^2$; if they deviate from the line, dropping them inflates $R^2$.

##### Code Q1: Clean Outliers via Tukey's IQR Fences
```python
import pandas as pd


def remove_outliers_iqr(df: pd.DataFrame, col: str) -> pd.DataFrame:
  q1 = df[col].quantile(0.25)
  q3 = df[col].quantile(0.75)
  iqr = q3 - q1
  lower = q1 - 1.5 * iqr
  upper = q3 + 1.5 * iqr
  return df[(df[col] >= lower) & (df[col] <= upper)].reset_index(drop=True)
```

##### Code Q3: Detect Outliers Using Vectorized Z-Score
```python
import pandas as pd


def flag_zscore_outliers(
    df: pd.DataFrame, col: str, threshold: float = 3.0
```

##### Scenario 4: Leakage-Free Preprocessing in Scikit-Learn Pipelines
- **Problem:** You are deploying an XGBoost regression model. You need an automated transformer that learns the lower and upper capping thresholds from the training data and applies them identically to incoming inference requests without data leakage.
- **Solution:**

  ```python
  from sklearn.base import BaseEstimator, TransformerMixin
  import pandas as pd


  class IQRCapper(BaseEstimator, TransformerMixin):

    def __init__(self, factor=1.5):
      self.factor = factor
      self.bounds_ = {}

    def fit(self, X, y=None):
      X_df = pd.DataFrame(X)
      for col in X_df.columns:
        q1 = X_df[col].quantile(0.25)
        q3 = X_df[col].quantile(0.75)
        iqr = q3 - q1
        self.bounds_[col] = (q1 - self.factor * iqr, q3 + self.factor * iqr)
      return self

    def transform(self, X):
      X_df = pd.DataFrame(X).copy()
      for col, (lower, upper) in self.bounds_.items():
        if col in X_df.columns:
          X_df[col] = X_df[col].clip(lower=lower, upper=upper)
      return X_df
```

## Phase 2: High-Yield Concepts, Pitfalls & Production Drills

### 4. Top Questions to Definitely Prepare

#### 4.1 Must-Know Core Questions

1. **How do you calculate Tukey's Interquartile Range (IQR) fences in Pandas?**  
   - Compute the 25th percentile ($Q1$) and 75th percentile ($Q3$) using `s.quantile(0.25)` and `s.quantile(0.75)`. Calculate $IQR = Q3 - Q1$. The lower fence is $Q1 - 1.5 \times IQR$, and the upper fence is $Q3 + 1.5 \times IQR$.
2. **What is the difference between removing outliers and capping (winsorizing) them?**  
   - Removing outliers deletes entire rows from the DataFrame, which reduces sample size and risks deleting valuable data. Capping (via `Series.clip(lower=..., upper=...)`) replaces extreme values exceeding thresholds with the boundary values themselves, preserving sample size while restricting extreme leverage.
3. **Why does the standard Z-score method fail on skewed distributions?**  
   - The Z-score assumes a symmetrical, normal (Gaussian) distribution. In heavily right-skewed data (such as income, web traffic, or transaction amounts), the sample mean is inflated by the tail, causing the standard Z-score to misidentify valid tail events while failing to flag anomalies on the lower side.
4. **How do you replace detected outliers with `NaN` for subsequent imputation?**  
   - Use boolean indexing with `.loc[]`: `df.loc[outlier_mask, 'col'] = np.nan`, or use `s.mask(outlier_mask, np.nan)`.
5. **How does `Series.clip()` work when winsorizing data?**  
   - `s.clip(lower=lower_bound, upper=upper_bound)` clamps all values below `lower_bound` to `lower_bound` and all values above `upper_bound` to `upper_bound`, while leaving intermediate values unchanged.

#### 4.2 Good-to-Know Differentiating Questions

6. **What is the Modified Z-Score and why is it preferred over the standard Z-Score?**  
   - Standard Z-score uses the sample mean and standard deviation, which are themselves distorted by outliers. The Modified Z-Score uses the median ($\tilde{x}$) and Median Absolute Deviation ($MAD$): $\text{Modified } Z = 0.6745 \times (x - \tilde{x}) / MAD$. Because median and MAD have a 50% breakdown point, the Modified Z-Score detects outliers robustly without being masked by them.
7. **What is the difference between Tukey's mild outliers ($1.5 \times IQR$) and extreme outliers ($3.0 \times IQR$)?**  
   - Mild outliers lie between $1.5 \times IQR$ and $3.0 \times IQR$ beyond the quartiles. Extreme outliers lie beyond $3.0 \times IQR$. In production, mild outliers are often capped, whereas extreme outliers are typically audited for system corruption or flagged for fraud.
8. **How do you perform percentile-based Winsorization (e.g. 1st and 99th percentiles)?**  
   - Compute boundaries using `df['col'].quantile(0.01)` and `df['col'].quantile(0.99)`, then apply `.clip(lower=p01, upper=p99)`.
9. **How do you detect group-specific outliers (e.g. salary outliers per job department)?**  
   - Calculate group-level bounds using `groupby()` with `.transform()`:  
     `lower = df.groupby('dept')['salary'].transform(lambda s: s.quantile(0.25) - 1.5 * (s.quantile(0.75) - s.quantile(0.25)))`.
10. **Why are tree-based machine learning algorithms (Random Forest, XGBoost) naturally robust to outliers?**  
    - Tree-based models partition feature space based on rank ordering rather than linear distances or squared errors. An outlier value of $1,000,000$ produces the exact same decision split as a value of $500$ if there are no data points between them.

#### 4.3 Advanced / Senior / Architect-Level Questions

11. **Explain the masking and swamping phenomena in multi-point outlier detection.**  
    - **Masking:** Occurs when a cluster of multiple extreme outliers inflates the mean and standard deviation so drastically that other true outliers fall within the acceptance region.  
    - **Swamping:** Occurs when a single massive outlier inflates the standard deviation so much that normal observations on the opposite side of the distribution are falsely flagged as outliers.
12. **How do you architect a data leakage-free outlier preprocessing step in a production Scikit-Learn pipeline?**  
    - Build a custom transformer implementing `fit()` and `transform()`. In `fit(X_train)`, compute and store the quantile boundaries ($Q1, Q3, IQR$) in instance attributes (`self.lower_`, `self.upper_`). In `transform(X)`, apply `.clip(lower=self.lower_, upper=self.upper_)` using the stored training parameters across both train and test splits.
13. **What is the Medcouple ($MC$), and how does the Adjusted Boxplot prevent false outlier flagging on skewed distributions?**  
    - The Medcouple is a robust kernel-based statistic measuring skewness. The adjusted boxplot scales Tukey's fences exponentially: $[Q1 - 1.5 e^{-4 MC} IQR, Q3 + 1.5 e^{3 MC} IQR]$ for positive skew, extending the upper fence into the long tail to avoid falsely flagging legitimate values.
14. **How do you detect multivariate outliers that are normal in every single individual feature dimension?**  
    - Use distance metrics that account for feature correlation (e.g. Mahalanobis distance: $D_M(x) = \sqrt{(x - \mu)^T \Sigma^{-1} (x - \mu)}$) or machine learning anomaly algorithms (e.g. Scikit-Learn's `IsolationForest` or `LocalOutlierFactor`).
15. **What are the architectural trade-offs between log transformation, square root transformation, and Box-Cox / Yeo-Johnson transformations?**  
    - Log transform (`np.log1p`) handles strictly non-negative data with exponential skew. Square root is milder and handles exact zeros naturally. Box-Cox optimizes a power parameter $\lambda$ via maximum likelihood but requires strictly positive data ($x > 0$). Yeo-Johnson extends Box-Cox to support negative, zero, and positive values.

### 5. Common Beginner Mistakes (10 Mistakes)

#### Mistake 1: Computing Outlier Fences on the Test Set (Data Leakage)
- **The Mistake:** Computing $Q1$ and $Q3$ independently on `X_test`.
- **Bad Code:**
  ```python
  # Testing set leakage!
  q1_test = X_test["price"].quantile(0.25)
  q3_test = X_test["price"].quantile(0.75)
  X_test["price"] = X_test["price"].clip(
      lower=q1_test - 1.5 * (q3_test - q1_test)
  )
```
- **Why It's Wrong:** Test set evaluation must simulate unobserved real-world inference. Calculating statistics on `X_test` leaks test distribution properties into the pipeline.
- **Good Code:**
  ```python
  q1_train = X_train["price"].quantile(0.25)
  q3_train = X_train["price"].quantile(0.75)
  lower_fence = q1_train - 1.5 * (q3_train - q1_train)
  upper_fence = q3_train + 1.5 * (q3_train - q1_train)

  X_train["price"] = X_train["price"].clip(lower=lower_fence, upper=upper_fence)
  X_test["price"] = X_test["price"].clip(lower=lower_fence, upper=upper_fence)
```
- **Production Impact:** Optimistically biased test evaluations that degrade upon real-world deployment.

#### Mistake 2: Applying Z-Score Filtering to Severely Skewed Data
- **The Mistake:** Using $|Z| > 3$ on right-skewed variables like customer spending.
- **Bad Code:**
  ```python
  z = (df["spend"] - df["spend"].mean()) / df["spend"].std()
  clean_df = df[z.abs() <= 3.0]
```
- **Why It's Wrong:** The extreme right tail inflates $\mu$ and $\sigma$. The cutoff deletes high-value legitimate customers while failing to detect anomalous zero or negative spend values.
- **Good Code:**

  ```python
  # Use log transformation or IQR
  q1 = df["spend"].quantile(0.25)
  q3 = df["spend"].quantile(0.75)
  clean_df = df[(df["spend"] >= 0) & (df["spend"] <= q3 + 3.0 * (q3 - q1))]
```

- **Production Impact:** Wholesale deletion of the most profitable customer segment from marketing models.

#### Mistake 3: Triggering `SettingWithCopyWarning` During Outlier Replacement

#### Mistake 4: Division by Zero in Z-Score Calculation on Invariant Features

### 6. Section-Adaptive Pandas API Confusions

#### Confusion 1: IQR Tukey Fences vs Z-Score Method

| Dimension | Tukey's IQR Method | Z-Score Method |
|:---|:---|:---|
| **Underlying Assumption** | **Non-parametric** (No distribution assumed). | **Parametric** (Assumes normal/Gaussian distribution). |
| **Robustness to Contamination**| **High** ($50\%$ breakdown point; median & quartiles). | **Low** ($0\%$ breakdown point; mean & std inflated). |
| **Primary Formula** | $[Q1 - 1.5 \times IQR, Q3 + 1.5 \times IQR]$ | $[\mu - 3\sigma, \mu + 3\sigma]$ |
| **Performance on Skewed Data** | Moderate (may still flag long tails). | **Fails completely** (tail inflates $\sigma$, shifting $\mu$). |
| **Best Used For** | General tabular data, exploratory data analysis. | Symmetrical, bell-shaped scientific sensor data. |

```python
import pandas as pd

# IQR: Non-parametric
q1 = s.quantile(0.25)
q3 = s.quantile(0.75)
iqr_mask = (s < q1 - 1.5 * (q3 - q1)) | (s > q3 + 1.5 * (q3 - q1))

# Z-score: Parametric
z_mask = ((s - s.mean()) / s.std()).abs() > 3.0
```

---

#### Confusion 2: Outlier Dropping vs Outlier Capping (Winsorization via `Series.clip()`)

| Dimension | Outlier Dropping (Row Filtering) | Outlier Capping (`Series.clip()`) |
|:---|:---|:---|
| **Sample Size** | **Reduces $N$** (deletes rows). | **Preserves $N$** (zero rows deleted). |
| **Information Loss** | High (deletes entire record, including other columns). | Minimal (contracts extreme values to boundaries). |
| **Distribution Impact** | Truncates distribution abruptly. | Creates point masses (spikes) at boundary fences. |
| **When to Use** | System errors, corrupted data entry, sensor glitch. | Legitimate heavy tails, training linear models/neural nets. |

```python
# Dropping rows
clean_df = df[(df["val"] >= lower) & (df["val"] <= upper)]

# Capping (Winsorizing)
df["val_capped"] = df["val"].clip(lower=lower, upper=upper)
```

#### Confusion 3: `s.quantile()` vs `s.describe()` vs `scipy.stats.scoreatpercentile`

| Dimension | `s.quantile(q)` | `s.describe()` | `scipy.stats.scoreatpercentile` |
|:---|:---|:---|:---|
| **Input Arguments** | Float between 0.0 and 1.0 (e.g. `0.25`). | None (computes fixed summary). | Float between 0 and 100 (e.g. `25`). |
| **Return Type** | Scalar float or Series if list of $q$ passed. | Series of 8 summary statistics. | Scalar float. |
| **Interpolation Options** | Supports `'linear'`, `'lower'`, `'higher'`, `'midpoint'`, `'nearest'`. | Uses default linear interpolation. | Supports fractional rank methods. |

---

#### Confusion 4: Standard Z-Score vs Modified Z-Score (MAD)

| Dimension | Standard Z-Score | Modified Z-Score (Iglewicz & Hoaglin) |
|:---|:---|:---|
| **Center Metric** | Sample Mean ($\mu$). | Sample Median ($\tilde{x}$). |
| **Spread Metric** | Sample Standard Deviation ($\sigma$). | Median Absolute Deviation ($MAD$). |
| **Breakdown Point** | $0\%$ (1 outlier ruins it). | **$50\%$** (resists up to half outliers). |
| **Standard Threshold** | $|Z| > 3.0$ | $|\text{Mod } Z| > 3.5$ |

```python
# Standard Z-Score
z = (s - s.mean()) / s.std()

# Modified Z-Score
med = s.median()
mad = (s - med).abs().median()
mod_z = 0.6745 * (s - med) / mad
```

#### Confusion 5: Univariate Outliers vs Multivariate Outliers

| Dimension | Univariate Outlier | Multivariate Outlier |
|:---|:---|:---|
| **Dimensions Evaluated**| 1 single column in isolation. | 2 or more columns simultaneously. |
| **Example** | Height = 7 feet 8 inches. | Height = 5 feet 0 inches AND Weight = 300 lbs. |
| **Detection Tools** | IQR fences, Z-score, histogram. | Mahalanobis distance, Isolation Forest, Local Outlier Factor. |
| **Limitation of 1D** | N/A | **Completely invisible** to 1D IQR or Z-score checks! |

### 7. Interview Traps (10 Traps)

#### Trap 1: The Test Set Quantile Leakage
- **The Trap:** An interviewer asks: "In your preprocessing script, how do you handle outliers on the test set?" A candidate responds: "I compute the IQR on the test set and drop values outside the fences."
- **Why It Catches Candidates:** Candidates assume each dataset should clean itself.
- **The Reality / Mechanics:** Calculating fences on test data leaks test set distribution statistics. Furthermore, dropping rows from the test set changes the evaluation distribution and makes comparing models invalid.
- **How to Avoid:** Compute fences strictly on the training set, and use the training fences to cap (never drop) the test set.

---

#### Trap 2: The Masking Effect on Multiple Outliers
- **The Trap:** An interviewer presents a dataset with 5 massive outliers and asks why the Z-score method fails to flag them.
- **Why It Catches Candidates:** Candidates assume larger outliers are always easier to catch with Z-scores.
- **The Reality / Mechanics:** Multiple extreme outliers inflate the standard deviation $\sigma$ quadratically. Because $\sigma$ balloons, the denominator in $Z = (x - \mu)/\sigma$ becomes huge, pulling all Z-scores below 3.0.
- **How to Avoid:** Use the Modified Z-Score (MAD) or Tukey's IQR fences.

---

#### Trap 3: The Constant Series ZeroDivisionError
- **The Trap:** An interviewer asks what happens when you compute Z-scores on a column where all sensor values are identical (`10.0`).
- **Why It Catches Candidates:** Candidates assume Z-scores evaluate to 0.
- **The Reality / Mechanics:** $\sigma = 0$. Dividing $0 / 0$ yields `NaN` across the entire column.
- **How to Avoid:** Assert `s.std() > 0` before computing Z-scores.

---

#### Trap 4: Deleting True Positive Signals in Fraud Detection
- **The Trap:** An interviewer asks: "We want to improve our credit card fraud detection model. Should we run `remove_outliers_iqr()` on transaction amount?"
- **Why It Catches Candidates:** Candidates assume cleaning outliers is always beneficial.
- **The Reality / Mechanics:** Fraudulent charges are heavy-tailed outliers. Removing them eliminates the minority positive class that the model is being built to detect!
- **How to Avoid:** Clarify business context: never delete outliers when the outlier is the target class.

---

#### Trap 5: Truncating Skewed Target Variables
- **The Trap:** A candidate drops house prices $> Q3 + 1.5 \times IQR$ when training a house price prediction model.
- **Why It Catches Candidates:** Candidates assume house prices should follow a normal distribution.
- **The Reality / Mechanics:** Real estate prices are naturally log-normal. Dropping high-value homes makes the model incapable of predicting prices of luxury properties.
- **How to Avoid:** Apply a logarithmic transform (`np.log1p(df['price'])`) rather than dropping rows.

---

#### Trap 6: Multi-Column Compound Data Destruction
- **The Trap:** A candidate writes a loop to drop IQR outliers across all 30 features in a DataFrame. The original DataFrame had 10,000 rows; the clean DataFrame has only 400 rows!
- **Why It Catches Candidates:** Candidates don't realize that outlier rows across independent features compound.
- **The Reality / Mechanics:** If each feature drops 5% of rows independently, 30 features can easily eliminate $(1 - 0.05)^{30} \approx 78\%$ of data.
- **How to Avoid:** Cap values with `.clip()` or use multidimensional Isolation Forests.

---

#### Trap 7: The Unbounded Breakdown Point of the Sample Mean
- **The Trap:** An interviewer asks: "How many corrupted outlier points does it take to make the sample mean arbitrarily wrong?"
- **Why It Catches Candidates:** Candidates guess percentages like 5% or 10%.
- **The Reality / Mechanics:** Exactly **one single point** ($1/N$, 0% breakdown point). A single value of $10^{15}$ will drag the sample mean of 1,000,000 numbers to over a billion.
- **How to Avoid:** State that the mean has a breakdown point of 0%, while the median has a breakdown point of 50%.

---

#### Trap 8: Quantile Return Type Confusion
- **The Trap:** Writing `q1, q3 = s.quantile([0.25, 0.75])` and expecting two scalar floats.
- **Why It Catches Candidates:** Candidates assume passing two quantiles returns a tuple.
- **The Reality / Mechanics:** It returns a Pandas `Series` indexed by `0.25` and `0.75`. Attempting direct unpacking can raise `ValueError: too many values to unpack` in older Pandas versions.
- **How to Avoid:** Extract as list: `q1, q3 = s.quantile([0.25, 0.75]).tolist()`.

---

#### Trap 9: Single-Tick Sensor Spikes vs Genuine Trend Shifts
- **The Trap:** A sensor blips from 20°C to 120°C for 1 second, then returns to 20°C. Standard rolling average smooths it across 10 seconds, spreading the error.
- **Why It Catches Candidates:** Candidates apply rolling filters rather than isolated tick outlier detection.
- **The Reality / Mechanics:** A single-tick glitch should be identified by comparing the value to both its immediate predecessor and successor (`shift(1)` and `shift(-1)`).
- **How to Avoid:** Use isolated spike detection: `(s - (s.shift(1) + s.shift(-1))/2).abs()`.

---

#### Trap 10: In-Place `clip()` Mutability Illusion
- **The Trap:** An engineer writes `df['amount'].clip(lower=0, upper=1000)` and expects `df['amount']` to be updated.
- **Why It Catches Candidates:** Candidates assume `.clip()` modifies in place like `.dropna(inplace=True)`.
- **The Reality / Mechanics:** `clip()` returns a new Series by default. The original column remains unchanged.
- **How to Avoid:** Assign back: `df['amount'] = df['amount'].clip(lower=0, upper=1000)`.

#### Question 1: Robust Feature Engineering for Skewed Financial Data
- **Scenario:** You are training a credit scoring model on loan applicants. The feature `annual_income` spans from $5,000 to $50,000,000. Applying standard scaling ($(x - \mu)/\sigma$) compresses 98% of applicants into a tiny interval between -0.2 and 0.1, preventing gradient descent from learning feature weights. Design a production feature engineering pipeline that handles extreme income outliers cleanly without deleting applicants.
- **Solution:**
  ```python
  import numpy as np
  import pandas as pd


  def process_annual_income_feature(df_loans: pd.DataFrame) -> pd.DataFrame:
    df = df_loans.copy()

    # 1. Physical sanity guard: Replace negative/zero income with NaN
    df.loc[df["annual_income"] <= 0, "annual_income"] = np.nan

    # 2. Impute missing income with median
    income_median = df["annual_income"].median()
    df["annual_income"] = df["annual_income"].fillna(income_median)

    # 3. Winsorize extreme 99.5th percentile to handle billionaires
    p995 = df["annual_income"].quantile(0.995)
    df["income_capped"] = df["annual_income"].clip(upper=p995)

    # 4. Apply logarithmic transform to normalize the right skew
    df["log_annual_income"] = np.log1p(df["income_capped"])

    # 5. Add a binary flag indicating high-net-worth VIP applicant
    df["is_high_income_tail"] = (df["annual_income"] >= p995).astype(int)

    return df
```

#### Question 2: Group-Aware Outlier Detection for Multi-Store Retail
- **Scenario:** A nationwide retailer tracks daily store revenue across 500 stores. Flagging stores where daily revenue is an outlier requires comparing each store against its own store tier (`FLAGSHIP`, `URBAN_STANDARD`, `RURAL_KIOSK`). A revenue of $10,000 is an extreme low for a Flagship store, but an extreme high for a Rural Kiosk. Write a vectorized, group-aware outlier detector that flags performance anomalies per tier.
- **Solution:**
  ```python
  import pandas as pd


  def flag_tier_revenue_anomalies(df_sales: pd.DataFrame) -> pd.DataFrame:
    df = df_sales.copy()

    # Define function to calculate Tukey fences per group
    def compute_group_fences(group_series):
      q1 = group_series.quantile(0.25)
      q3 = group_series.quantile(0.75)
      iqr = q3 - q1
      return pd.Series({
          "lower_fence": q1 - 1.5 * iqr,
          "upper_fence": q3 + 1.5 * iqr,
      })

    # Groupby store tier and compute fences
    fences = (
        df.groupby("store_tier")["daily_revenue"]
        .apply(compute_group_fences)
        .unstack()
    )

    # Merge fences back to individual records
    df = df.merge(fences, left_on="store_tier", right_index=True)

    # Flag low and high anomalies
    df["is_underperforming"] = df["daily_revenue"] < df["lower_fence"]
    df["is_breakout_high"] = df["daily_revenue"] > df["upper_fence"]

    return df.drop(columns=["lower_fence", "upper_fence"])
```

#### Question 3: Real-Time Acoustic IoT Telemetry Anomaly Cleaner
- **Scenario:** Acoustic monitoring sensors on wind turbines sample sound decibels every 100 milliseconds. Sensor hardware occasionally drops voltage, producing burst anomalies of `0.0 dB` or `999.9 dB` lasting exactly 1 to 3 ticks. Clean these hardware burst dropouts and replace them using linear interpolation, while keeping genuine mechanical degradation trends intact.
- **Solution:**
  ```python
  import numpy as np
  import pandas as pd


  def clean_acoustic_telemetry_bursts(df_sensor: pd.DataFrame) -> pd.DataFrame:
    df = df_sensor.sort_values(by=["turbine_id", "timestamp"]).copy()

    # 1. Identify hardware sentinel errors
    is_hardware_fault = (df["decibels"] <= 0.0) | (df["decibels"] >= 999.0)

    df.loc[is_hardware_fault, "decibels"] = np.nan
```

#### Question 4: Scikit-Learn Compatible Leakage-Free Robust Scaler
- **Scenario:** Build an end-to-end custom Scikit-Learn transformer that performs robust outlier capping using Tukey's fences, calculates median and IQR on the training set, and applies them to transform unseen test data during real-time model inference.
- **Solution:**
  ```python
  from sklearn.base import BaseEstimator, TransformerMixin
  import pandas as pd


  class RobustOutlierCapper(BaseEstimator, TransformerMixin):

    def __init__(self, factor=1.5):
      self.factor = factor
      self.fences_ = {}

    def fit(self, X, y=None):
      X_df = pd.DataFrame(X)
      self.fences_ = {}
      for col in X_df.select_dtypes("number").columns:
        q1 = X_df[col].quantile(0.25)
        q3 = X_df[col].quantile(0.75)
        iqr = q3 - q1
        lower = q1 - self.factor * iqr
        upper = q3 + self.factor * iqr
        self.fences_[col] = (lower, upper)
      return self

    def transform(self, X):
      X_df = pd.DataFrame(X).copy()
      for col, (lower, upper) in self.fences_.items():
        if col in X_df.columns:
          X_df[col] = X_df[col].clip(lower=lower, upper=upper)
      return X_df
```

```python
from scipy.spatial.distance import mahalanobis


def compute_bivariate_mahalanobis(
    df: pd.DataFrame, col1: str, col2: str
```

### 13. Flashcard Section (16 Flashcards)

#### Card 1
- **Front:** What is the mathematical definition of Tukey's IQR Fences?
- **Back:** $IQR = Q3 - Q1$. The lower fence is $Q1 - 1.5 \times IQR$, and the upper fence is $Q3 + 1.5 \times IQR$. Values outside these fences are classified as Tukey outliers.

#### Card 2
- **Front:** What is the primary difference between outlier removal and Winsorization (capping)?
- **Back:** Outlier removal drops entire rows from the dataset, reducing sample size $N$ and discarding valid data in other columns. Winsorization (via `Series.clip()`) clamps extreme values to boundary thresholds, preserving sample size without distorting scale.

#### Card 3
- **Front:** Why is the Z-score method considered non-robust compared to the IQR method?
- **Back:** Z-scores rely on the sample mean and standard deviation ($L_2$ norm), which have a 0% breakdown point and are inflated by the very outliers being detected. IQR relies on quartiles ($L_1$ norm), which resist extreme values up to a 25% breakdown point.

#### Card 4
- **Front:** What is the Modified Z-Score and how is it calculated?
- **Back:** Developed by Iglewicz and Hoaglin, it uses the median ($\tilde{x}$) and Median Absolute Deviation ($MAD$): $\text{Mod } Z = 0.6745 \times (x - \tilde{x}) / MAD$. Points with $|\text{Mod } Z| > 3.5$ are flagged as outliers.

#### Card 5
- **Front:** Why must you never fit outlier thresholds on the test set in machine learning?
- **Back:** Calculating quantile fences or Z-score parameters on test data causes data leakage. All preprocessing parameters must be learned strictly from `X_train` and applied immutably to `X_test`.

#### Card 6
- **Front:** What causes division by zero when calculating Z-scores in Pandas?
- **Back:** If all values in a feature column are identical (zero variance), `s.std() == 0.0`. Dividing by zero produces `NaN` across the entire column. Guard with `if s.std() > 0:`.

#### Card 7
- **Front:** Why is `np.log1p(x)` preferred over `np.log(x)` when transforming skewed features?
- **Back:** `np.log1p(x)` computes $\ln(1 + x)$. For $x = 0$, $\ln(1) = 0$. In contrast, `np.log(0)` returns $-\infty$, corrupting downstream matrix calculations.

#### Card 8
- **Front:** What is the difference between mild outliers and extreme outliers in boxplot terminology?
- **Back:** Mild outliers lie between $1.5 \times IQR$ and $3.0 \times IQR$ beyond the quartiles. Extreme outliers lie beyond $3.0 \times IQR$.

#### Card 9
- **Front:** Why should you avoid dropping outliers in fraud detection pipelines?
- **Back:** Fraudulent transactions are naturally extreme outliers. Dropping them removes the positive class, ensuring the machine learning classifier will never learn how to catch fraud.

#### Card 10
- **Front:** What is the breakdown point of an estimator?
- **Back:** The breakdown point is the proportion of arbitrarily corrupted observations an estimator can handle before giving an arbitrarily large incorrect result. Mean has a 0% breakdown point; median has a 50% breakdown point.

#### Card 11
- **Front:** How do you detect multivariate outliers that are invisible to 1D IQR checks?
- **Back:** Use distance metrics that account for feature correlations (such as Mahalanobis distance) or multi-dimensional unsupervised algorithms like Isolation Forests.

#### Card 12
- **Front:** What happens if you drop outliers iteratively across 30 numeric columns?
- **Back:** Compounding row loss: if each feature drops 5% of rows independently, dropping across 30 columns can purge over 78% of the entire dataset. Cap values with `.clip()` instead.

#### Card 13
- **Front:** What does `Series.clip(lower=p01, upper=p99)` accomplish?
- **Back:** It performs percentile Winsorization, clamping values below the 1st percentile to $P_{01}$ and values above the 99th percentile to $P_{99}$, eliminating extreme tails while keeping 100% of rows.

#### Card 14
- **Front:** How do you detect group-specific outliers (e.g. salary outliers per department)?
- **Back:** Use `groupby()` with `.transform()` to evaluate quartiles and fences independently within each categorical group, preventing regional or departmental bias.

#### Card 15
- **Front:** How do you clean single-tick telemetry glitch spikes in time series data?
- **Back:** Compare the suspicious tick to its immediate predecessor and successor using `s.shift(1)` and `s.shift(-1)`. If both neighbors are consistent with each other but the target tick deviates sharply, replace it with their average.

#### Card 16
- **Front:** Why does linear regression tilt significantly in the presence of a single outlier?
- **Back:** Ordinary Least Squares minimizes the sum of squared residuals ($\sum (y - \hat{y})^2$). An outlier with a large residual exerts quadratic leverage, pulling the regression slope toward itself.

If consumed, automated execution models trigger market orders resulting in catastrophic financial loss.
- **Root Cause & Bottleneck:** Bad tick market data artifacts corrupting real-time VWAP execution algorithms.
- **Engineered Solution:**
  ```python
  import pandas as pd


  def sanitize_market_feed(df_ticks: pd.DataFrame) -> pd.DataFrame:
    df = df_ticks.sort_values(by=["symbol", "timestamp"]).copy()

    # Compute rolling median bid and ask over 20 ticks per symbol
    roll_med_bid = df.groupby("symbol")["bid"].transform(
        lambda s: s.rolling(20, min_periods=3).median()
    )
    roll_med_ask = df.groupby("symbol")["ask"].transform(
        lambda s: s.rolling(20, min_periods=3).median()
    )

    # Relative deviation from rolling median
    bid_dev = (df["bid"] - roll_med_bid).abs() / roll_med_bid
    ask_dev = (df["ask"] - roll_med_ask).abs() / roll_med_ask

    # Glitch conditions: > 10% sudden deviation from local rolling median
    is_glitch = (
        (bid_dev > 0.10)
        | (ask_dev > 0.10)
        | (df["bid"] <= 0)
        | (df["bid"] >= df["ask"])
    )

    clean_feed = df[~is_glitch].reset_index(drop=True)
    quarantine = df[is_glitch].reset_index(drop=True)

    print(
        f"Protected execution: Purged {len(quarantine):,} corrupted market ticks."
    )
    return clean_feed
```

#### Scenario 2: Housing Valuation Pipeline with Multi-City Winsorization
- **Context:** An online real estate valuation platform ingests property listings across 50 Metropolitan Statistical Areas (MSAs). Listings in San Francisco have a median price of $1,400,000, while listings in Cleveland have a median price of $180,000. Applying a single national IQR filter deletes 40% of San Francisco homes while failing to catch corrupted $500,000 condos in Cleveland.
- **Root Cause & Bottleneck:** Multimodal distribution where regional variance invalidates global outlier boundaries.
- **Engineered Solution:**
  ```python
  import pandas as pd


  def regional_property_winsorization(
      df_properties: pd.DataFrame,
  ) -> pd.DataFrame:
    df = df_properties.copy()

    # Define robust capping per MSA group
    def cap_by_msa(s):
      q1 = s.quantile(0.25)
      q3 = s.quantile(0.75)
      iqr = q3 - q1
      lower_fence = max(q1 - 1.5 * iqr, 10_000.0)  # Physical minimum
      upper_fence = q3 + 3.0 * iqr  # Allow legitimate local luxury
      return s.clip(lower=lower_fence, upper=upper_fence)

    # Apply per-region capping
    df["price_winsorized"] = df.groupby("msa_code")["list_price"].transform(
        cap_by_msa
    )

    # Flag records capped for luxury audit
    df["is_luxury_capped"] = df["list_price"] > df["price_winsorized"]
    return df
```

#### Scenario 3: Leakage-Free Preprocessing in Automated Cross-Validation
- **Context:** A credit risk model undergoes 5-fold cross validation. An engineer mistakenly writes `df['income'] = df['income'].clip(upper=df['income'].quantile(0.99))` before passing data to `cross_val_score`. The audit team flags the submission for regulatory compliance violations due to data leakage.
- **Root Cause & Bottleneck:** Preprocessing calculated globally across both train and validation folds prior to cross-validation splitting.
- **Engineered Solution:**
  ```python
  from sklearn.base import BaseEstimator, TransformerMixin
  from sklearn.pipeline import Pipeline
  from sklearn.ensemble import HistGradientBoostingRegressor
  import pandas as pd


  class TrainBoundCapper(BaseEstimator, TransformerMixin):

    def __init__(self, low_pct=0.01, high_pct=0.99):
      self.low_pct = low_pct
      self.high_pct = high_pct
      self.bounds_ = {}

    def fit(self, X, y=None):
      X_df = pd.DataFrame(X)
      self.bounds_ = {}
      for col in X_df.select_dtypes("number").columns:
        lo = X_df[col].quantile(self.low_pct)
        hi = X_df[col].quantile(self.high_pct)
        self.bounds_[col] = (lo, hi)
      return self

    def transform(self, X):
      X_df = pd.DataFrame(X).copy()
      for col, (lo, hi) in self.bounds_.items():
        if col in X_df.columns:
          X_df[col] = X_df[col].clip(lower=lo, upper=hi)
      return X_df


  # Verified leak-free pipeline
  model_pipeline = Pipeline([
      ("outlier_capper", TrainBoundCapper(0.01, 0.99)),
      ("regressor", HistGradientBoostingRegressor()),
  ])
```

#### Scenario 4: IoT Wind Turbine Temperature Burst Interpolator
- **Context:** Bearing temperature sensors on offshore wind turbines stream telemetry every second. Lightning strikes and EMF noise cause burst dropouts where readings jump to `999°C` for 1–5 seconds before returning to normal 65°C operating levels. Dropping rows creates time gaps that break downstream Fast Fourier Transform (FFT) vibration models.
- **Root Cause & Bottleneck:** Discontinuous time grids caused by row deletion in frequency-domain vibration analysis.
- **Engineered Solution:**
  ```python
  import numpy as np
  import pandas as pd


  def repair_sensor_dropouts(df_sensor: pd.DataFrame) -> pd.DataFrame:
    df = df_sensor.sort_values(by=["turbine_id", "timestamp"]).copy()

    # Mark physical impossibilities as NaN
    is_fault = (df["temp_celsius"] < -40.0) | (df["temp_celsius"] > 150.0)
    df.loc[is_fault, "temp_celsius"] = np.nan

    # Time-aware interpolation per turbine up to 10 seconds gap
    df["temp_celsius"] = df.groupby("turbine_id")["temp_celsius"].transform(
        lambda s: s.interpolate(method="time", limit=10)
    )

    # Any remaining nulls filled with rolling median
    df["temp_celsius"] = df.groupby("turbine_id")["temp_celsius"].transform(
        lambda s: s.fillna(s.rolling(60, min_periods=1).median())
    )

    return df
```

### 24. Final 2-Minute Revision Summary

- **Tukey's IQR Fences:** Non-parametric; $IQR = Q3 - Q1$. Bounds are $[Q1 - 1.5 \times IQR, Q3 + 1.5 \times IQR]$.
- **Z-Score Method:** Parametric; $Z = (x - \mu)/\sigma$. Cutoff $|Z| > 3.0$. Assumes normal distribution; fails on skewed data.
- **Modified Z-Score (MAD):** $\text{Mod } Z = 0.6745 \times (x - \text{median}) / MAD$. Robust against multiple extreme outliers.
- **Winsorization via `clip()`:** Cap extreme values at bounds without deleting rows: `df['col'] = df['col'].clip(lower, upper)`.
- **Percentile Capping:** Clamps extreme tails at fixed percentiles: `df['col'] = df['col'].clip(df['col'].quantile(0.01), df['col'].quantile(0.99))`.
- **Data Leakage Guard:** Always compute outlier thresholds strictly on `X_train` and apply them immutably to `X_test`.
- **Domain Context:** Never delete outliers when the outlier is the positive target signal (e.g. fraud, cyberattacks, equipment failure).
