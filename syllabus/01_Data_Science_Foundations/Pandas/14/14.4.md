### 1. Section Overview

#### What This Section Is About
Section 14.4 covers the foundational and advanced techniques for analyzing time series data in Pandas. It focuses on temporal frequency conversion via `DataFrame.resample()`; downsampling high-frequency observations (e.g. seconds, minutes, hours) into lower-frequency aggregates across daily (`'D'`, `'B'`), monthly (`'ME'`, `'MS'`, `'BME'`), and yearly (`'YE'`, `'YS'`) boundaries; upsampling low-frequency data with forward-fill, backward-fill, and linear interpolation; navigating interval boundary semantics via `closed` and `label`; and evaluating time-aware rolling statistical windows (`rolling('30D')`) over irregular, asynchronous time grids.

#### Why These Pandas Concepts Matter
Financial trading desks, IoT sensor meshes, e-commerce platforms, and server monitoring infrastructures produce massive streams of timestamped events. However, raw events arrive asynchronously with irregular gaps, missing periods, and bursty intervals. Standard tabular aggregations like `groupby()` cannot bucket by calendar-aware intervals (e.g. months with varying days, business weeks skipping holidays), and row-count rolling windows (`rolling(30)`) produce catastrophic calculation errors when rows represent non-uniform time intervals. Technical interviewers place heavy emphasis on time series because an engineer's ability to configure `closed` and `label` boundaries, avoid forward-looking data leakage in upsampling, and correctly choose between time-based vs row-based rolling windows is an immediate indicator of senior-level data engineering competence.

#### Where They Are Used in Real Projects
1. **Financial Algorithmic Trading**: Downsampling millisecond tick feeds into 1-minute, 5-minute, and daily Open-High-Low-Close (OHLC) candlestick bars via `df.resample('1min').ohlc()`.
2. **IoT Telemetry & Industrial SCADA**: Resampling asynchronous sensor temperatures and pressures into uniform 10-second grids using linear interpolation to detect equipment strain.
3. **E-Commerce & Digital Advertising**: Calculating 7-day and 30-day moving average revenues via `df.rolling('30D').mean()` to smooth out day-of-week demand seasonality.
4. **Energy Grid & Smart Meter Operations**: Aggregating 15-minute smart meter electricity consumptions into daily and monthly peak billing totals via `df.resample('ME').sum()`.
5. **Macro-Economic Forecasting**: Aligning quarterly GDP and annual unemployment data with monthly inflation indicators using upsampling and forward filling.

- Differentiate between Downsampling (aggregation) and Upsampling (interpolation / filling).

### 2. Topic-Wise Interview Concepts

#### 2.1 The Resample Architecture: Time-Aware Grouping
`DataFrame.resample()` is conceptually analogous to `DataFrame.groupby()`, but specifically designed for regular frequency transformations over temporal axes:

```
                  Raw Asynchronous Time Series
   ┌─────────────────────────────────────────────────────────┐
   │ 10:01:15 │ 10:01:42 │ 10:02:05 │ 10:03:12 │ 10:03:55    │
   └─────────────────────────────────────────────────────────┘
                                │
                    df.resample('1min')
                                │
         ┌──────────────────────┴──────────────────────┐
         ▼                                             ▼
Downsampling (High -> Low)                    Upsampling (Low -> High)
Aggregation over time bins:                   Interpolation across missing steps:
.mean(), .sum(), .ohlc()                      .ffill(), .bfill(), .interpolate()
```

Under the hood:
- `resample()` requires a `DatetimeIndex`, `TimedeltaIndex`, or `PeriodIndex` (or an explicit column passed to `on='col_name'`).
- It constructs uniform interval bins of width $\Delta t$ spanning from the minimum timestamp to the maximum timestamp.
- Unlike `groupby()`, `resample()` can generate empty intervals if no events occurred within a bin, allowing analysts to detect missing data periods.

#### 2.2 The Critical Interval Boundary Parameters: `closed` and `label`
Understanding `closed` and `label` is the single most tested concept in time series interviews:
- `closed`: Determines which end of the interval bin is **closed** (inclusive):
  - `'left'`: $[T_{\text{start}}, T_{\text{end}})$ — includes start, excludes end.
  - `'right'`: $(T_{\text{start}}, T_{\text{end}}]$ — excludes start, includes end.
- `label`: Determines which boundary timestamp is assigned as the **index label** of the aggregated result:
  - `'left'`: The output label is $T_{\text{start}}$.
  - `'right'`: The output label is $T_{\text{end}}$.

```
Interval: 10:00:00 to 11:00:00 (Hourly Resample)

closed='left':   [10:00:00, 11:00:00)  <-- 10:00:00 included, 11:00:00 belongs to next bin
closed='right':  (10:00:00, 11:00:00]  <-- 10:00:00 belongs to prior bin, 11:00:00 included

label='left':    Output index row is labeled '10:00:00'
label='right':   Output index row is labeled '11:00:00'
```

##### Default Rules by Frequency:
- For sub-daily frequencies (`'s'`, `'min'`, `'h'`), defaults are: `closed='left'`, `label='left'`.
- For daily and calendar frequencies (`'D'`, `'ME'`, `'YE'`), defaults are: `closed='right'`, `label='right'`.

#### 2.3 Modern Frequency Aliases (Pandas 2.2+ Standard)
Legacy aliases like `'M'`, `'BM'`, `'A'`, `'Q'` have been deprecated in modern Pandas in favor of explicit, unambiguous codes:

| Frequency | Modern Code | Legacy (Deprecated) | Behavior / Definition |
| :--- | :--- | :--- | :--- |
| **Calendar Day** | `'D'` | `'D'` | Exactly 24-hour intervals |
| **Business Day** | `'B'` | `'B'` | Monday through Friday |
| **Hour** | `'h'` | `'H'` | 1-hour interval |
| **Minute** | `'min'` | `'T'` | 1-minute interval |
| **Second** | `'s'` | `'S'` | 1-second interval |
| **Month End** | `'ME'` | `'M'` | Last calendar day of month |
| **Month Start** | `'MS'` | `'MS'` | First calendar day of month |
| **Business Month End**| `'BME'` | `'BM'` | Last business day of month |
| **Quarter End** | `'QE'` | `'Q'` | Last calendar day of quarter |
| **Quarter Start** | `'QS'` | `'QS'` | First calendar day of quarter |
| **Year End** | `'YE'` | `'Y'`, `'A'` | Last calendar day of year (Dec 31) |
| **Year Start** | `'YS'` | `'YS'`, `'AS'` | First calendar day of year (Jan 1) |

#### 2.4 Downsampling vs Upsampling Mechanics
1. **Downsampling**:
   - Reduces frequency (e.g. 100,000 tick events down to daily summaries).
   - Requires an aggregation function: `.mean()`, `.sum()`, `.std()`, `.min()`, `.max()`, or `.ohlc()`.
   - `.ohlc()` computes four essential financial series simultaneously: `open` (first value), `high` (max), `low` (min), and `close` (last value).
2. **Upsampling**:
   - Increases frequency (e.g. daily sales upsampled to hourly slots).
   - Creates new, unpopulated timestamps.
   - Handled via:
     - `.asfreq()`: Leaves new timestamps as `NaN`.
     - `.ffill()` (Forward fill): Propagates the last known valid observation forward.
     - `.bfill()` (Backward fill): Propagates future observations backward (Caution: causes data leakage in ML!).
     - `.interpolate(method='linear')`: Computes intermediate values along a linear gradient.

#### 2.5 Rolling Time Windows: `rolling('30D')` vs `rolling(30)`
Standard row-count rolling (`df.rolling(30)`) counts exactly 30 consecutive **rows**.
Time-based rolling (`df.rolling('30D')`) aggregates all rows falling within a **30-day time duration window** relative to the current row's timestamp.

```
Row-Based:  df.rolling(window=3)
Index:    [Mon,  Tue,  [Weekend],  Mon]
Window:   (Mon, Tue, Mon) -> Always exactly 3 rows, ignoring the 2-day gap!

Time-Based: df.rolling(window='3D')
Index:    [Mon,  Tue,  [Weekend],  Mon]
Window on 2nd Mon: Only looks back 3 calendar days (Fri, Sat, Sun) -> Prior Mon/Tue excluded!
```

##### Strict Rules for Time-Based Rolling:
1. The DataFrame index **must be a `DatetimeIndex`**.
2. The `DatetimeIndex` **must be monotonic increasing** (sorted).
3. The window specification must be a frequency string (e.g. `'7D'`, `'12h'`), not an integer.
4. Unlike row-based rolling, time-based rolling windows never produce `NaN` rows at the start if `min_periods=1` is satisfied.

### 3. Fresher Interview Questions

#### 3.1 20 Basic Interview Questions (4-Part Structure)

##### Q1: What is time series resampling in Pandas?
- **Concept**: Changing the frequency of time series observations using `DataFrame.resample()`.
- **Why It Matters**: Standardizes irregular timestamps into uniform temporal intervals for modeling and visualization.
- **Code**:
  ```python
  import pandas as pd
  idx = pd.date_range('2026-01-01', periods=10, freq='h')
  df = pd.DataFrame({'temp': range(10)}, index=idx)
  daily = df.resample('D').mean()
  print(daily)
  ```
- **Interview Trap**: `resample()` is lazy (like `groupby()`). Calling `df.resample('D')` returns a `DatetimeIndexResampler` object; you must follow it with an aggregation function (e.g., `.mean()`, `.sum()`).

##### Q2: What is the difference between Downsampling and Upsampling?
- **Concept**: Downsampling reduces frequency (e.g. hourly to daily); Upsampling increases frequency (e.g. daily to hourly).
- **Why It Matters**: Downsampling requires aggregation to summarize multiple points into one; upsampling requires filling or interpolation to populate empty bins.
- **Code**:
  ```python
  # Downsampling:
  down = df.resample('D').mean()
  # Upsampling:
  up = daily.resample('h').ffill()
  ```
- **Interview Trap**: Forgetting to supply a fill method when upsampling leaves all newly created rows as `NaN`.

##### Q3: What is the modern frequency alias for Month-End in Pandas 2.2+?
- **Concept**: `'ME'` (Month End).
- **Why It Matters**: The legacy alias `'M'` is deprecated and raises a `FutureWarning` in modern Pandas.
- **Code**:
  ```python
  monthly = df.resample('ME').sum()
  ```
- **Interview Trap**: Do not use `'M'`. Use `'ME'` for Month End, and `'MS'` for Month Start.

##### Q4: What does `closed='left'` vs `closed='right'` specify in `resample()`?
- **Concept**: Which boundary of the time bin interval is inclusive.
- **Why It Matters**: Dictates whether an event occurring exactly on the hour belongs to the current bin or the previous bin.
- **Code**:
  ```python
  # [10:00, 11:00) vs (10:00, 11:00]
  res_left = df.resample('h', closed='left').sum()
  res_right = df.resample('h', closed='right').sum()
  ```
- **Interview Trap**: For sub-daily data (`'min'`, `'h'`), `closed` defaults to `'left'`. For daily/monthly data (`'D'`, `'ME'`), `closed` defaults to `'right'`.

##### Q5: What does `label='left'` vs `label='right'` specify in `resample()`?
- **Concept**: Which boundary timestamp is used to label the output row in the resulting index.
- **Why It Matters**: Critical for reporting: does `'10:00'` represent the window from 10:00 to 11:00, or from 09:00 to 10:00?
- **Code**:
  ```python
  res = df.resample('h', closed='left', label='left').sum()
  ```
- **Interview Trap**: Mismatched `closed` and `label` configurations can cause 1-bin temporal shifts in financial charts.

##### Q6: What does the `.ohlc()` method do in `resample()`?
- **Concept**: Computes Open, High, Low, and Close aggregations in a single operation.
- **Why It Matters**: Industry standard for converting high-frequency transaction ticks into financial candlestick charts.
- **Code**:
  ```python
  ticks = pd.Series([100, 102, 99, 105, 103], index=pd.date_range('2026-01-01 09:30', periods=5, freq='min'))
  candlestick = ticks.resample('5min').ohlc()
  print(candlestick)
  ```
- **Interview Trap**: Returns a DataFrame with 4 columns: `open`, `high`, `low`, `close`.

##### Q7: What is the modern alias for Year-End frequency in Pandas?
- **Concept**: `'YE'` (Year End).
- **Why It Matters**: Replaces legacy aliases `'Y'` and `'A'`.
- **Code**:
  ```python
  annual = df.resample('YE').sum()
  ```
- **Interview Trap**: `'YS'` is Year Start (Jan 1); `'YE'` is Year End (Dec 31).

##### Q8: What is the difference between `df.rolling(30)` and `df.rolling('30D')`?
- **Concept**: Row-count rolling vs calendar time-based rolling.
- **Why It Matters**: `df.rolling(30)` assumes uniformly spaced rows. On irregular or weekend-skipping data, 30 rows can span 42 calendar days, invalidating moving averages.
- **Code**:
  ```python
  # 30 consecutive rows:
  mavg_rows = df['price'].rolling(30).mean()
  # 30 calendar days window:
  mavg_time = df['price'].rolling('30D').mean()
  ```
- **Interview Trap**: `df.rolling('30D')` requires a sorted `DatetimeIndex`.

##### Q9: What happens if you call `resample()` on a DataFrame without a DatetimeIndex?
- **Concept**: Index prerequisite for `resample()`.
- **Why It Matters**: Prevents runtime errors when datetime is a standard column.
- **Code**:
  ```python
  df_non_idx = pd.DataFrame({'date': pd.date_range('2026-01-01', periods=5), 'val': range(5)})
  # Specify the column via 'on':
  daily = df_non_idx.resample('2D', on='date')['val'].sum()
  ```
- **Interview Trap**: Calling `df.resample('D')` directly on an integer-indexed DataFrame raises `TypeError: Only valid with DatetimeIndex, TimedeltaIndex or PeriodIndex`.

##### Q10: How do you forward-fill missing values during upsampling?
- **Concept**: `resample().ffill()`.
- **Why It Matters**: Propagates known historical values forward in time without looking into the future.
- **Code**:
  ```python
  s = pd.Series([10, 20], index=pd.to_datetime(['2026-01-01', '2026-01-03']))
  up_filled = s.resample('D').ffill()
  print(up_filled.tolist())  # [10, 10, 20]
  ```
- **Interview Trap**: Using `.bfill()` (backward fill) causes target leakage in predictive ML models because it leaks future values into past timestamps.

##### Q11: What is the modern frequency alias for Business Month End?
- **Concept**: `'BME'`.
- **Why It Matters**: Replaces legacy `'BM'`. Snaps to the last weekday (Monday–Friday) of the month.
- **Code**:
  ```python
  bme_series = df.resample('BME').sum()
  ```
- **Interview Trap**: For January 2026 (Jan 31 is Saturday), `'BME'` snaps to Friday, Jan 30.

##### Q12: How do you perform linear interpolation during upsampling?
- **Concept**: `resample().interpolate(method='linear')`.
- **Why It Matters**: Generates smooth continuous transitions between sparse physical readings (e.g. sensor telemetry).
- **Code**:
  ```python
  s = pd.Series([0.0, 10.0], index=pd.to_datetime(['2026-01-01 10:00', '2026-01-01 10:10']))
  smooth = s.resample('min').interpolate(method='linear')
  print(smooth.iloc[5])  # 5.0
  ```
- **Interview Trap**: Linear interpolation looks both backward and forward, making it unsuitable for real-time online streaming features.

##### Q13: What does `asfreq()` do on a time series DataFrame?
- **Concept**: Changes frequency without aggregation, re-indexing against a new regular grid.
- **Why It Matters**: Quick frequency conversion when values at exact interval points are desired.
- **Code**:
  ```python
  s = pd.Series([1, 2], index=pd.to_datetime(['2026-01-01', '2026-01-03']))
  grid = s.asfreq('D')
  print(grid.tolist())  # [1.0, nan, 2.0]
  ```
- **Interview Trap**: Any newly added timestamps receive `NaN` unless `fill_value` is provided.

##### Q14: How do you calculate a 7-day rolling sum using a time window?
- **Concept**: `df.rolling('7D').sum()`.
- **Why It Matters**: Evaluates trailing 7-day revenue, volume, or error rates.
- **Code**:
  ```python
  rev_7d = df['revenue'].rolling('7D').sum()
  ```
- **Interview Trap**: The window covers $[T - 7\text{ days}, T]$ inclusive of the current timestamp.

##### Q15: What does `min_periods` control in a rolling time window?
- **Concept**: Minimum number of valid observations required in the window to generate a non-null result.
- **Why It Matters**: Prevents calculating statistics on insufficient sample sizes.
- **Code**:
  ```python
  mavg = df['price'].rolling('7D', min_periods=3).mean()
  ```
- **Interview Trap**: For time-based rolling windows, `min_periods` defaults to `1`. For integer row-based rolling, `min_periods` defaults to the window size $N$.

##### Q16: How do you resample to Business Daily frequency (`'B'`)?
- **Concept**: `df.resample('B')`.
- **Why It Matters**: Standard for financial equities and bond data that only trade Monday through Friday.
- **Code**:
  ```python
  b_daily = df.resample('B').mean()
  ```
- **Interview Trap**: `'B'` skips Saturdays and Sundays completely; it does not generate empty weekend rows.

##### Q17: What does `origin='start'` do in `resample()`?
- **Concept**: Controls the timestamp anchor for bin boundaries.
- **Why It Matters**: By default, bins align to calendar epoch boundaries (midnight, start of hour). `origin='start'` aligns bins relative to the first timestamp in the dataset.
- **Code**:
  ```python
  res = df.resample('10min', origin='start').mean()
  ```
- **Interview Trap**: If the dataset starts at `10:03:00`, bins become `[10:03, 10:13)`, `[10:13, 10:23)` instead of standard clock boundaries `[10:00, 10:10)`.

##### Q18: Can you apply multiple aggregations simultaneously to a resampled object?
- **Concept**: `resample().agg(['mean', 'std', 'max'])` or dictionary mapping.
- **Why It Matters**: Summarizes central tendency and volatility in a single pass.
- **Code**:
  ```python
  summary = df.resample('D').agg({'price': ['mean', 'std'], 'volume': 'sum'})
  ```
- **Interview Trap**: Produces a MultiIndex column structure when lists of functions are passed.

##### Q19: How do you compute an Exponentially Weighted Moving Average (EWMA)?
- **Concept**: `DataFrame.ewm(span=N).mean()` or `DataFrame.ewm(halflife='7D', times=df.index).mean()`.
- **Why It Matters**: Weights recent observations more heavily than older observations, reacting faster to market trends.
- **Code**:
  ```python
  ewma = df['price'].ewm(span=20).mean()
  ```
- **Interview Trap**: When timestamps are non-uniformly spaced, pass `halflife='7D'` and `times=df.index` for time-aware exponential decay.

##### Q20: How do you resample to Custom Business Quarters?
- **Concept**: Anchored frequency strings like `'QE-DEC'`, `'QE-MAR'`, `'QE-JUN'`.
- **Why It Matters**: Accommodates corporate fiscal years ending in months other than December.
- **Code**:
  ```python
  fiscal_q = df.resample('QE-MAR').sum()
  ```
- **Interview Trap**: `'QE-MAR'` generates quarters ending in March, June, September, and December.

#### 3.2 20 Intermediate Interview Questions

##### Q21: What is the exact difference between `df.resample('D').mean()` and `df.groupby(df.index.date).mean()`?
- **Answer**: `groupby(df.index.date)` groups strictly by existing dates in the dataset; if no records exist for Tuesday, Tuesday is absent from the output index, and the index dtype becomes Python `object` (`datetime.date`). `df.resample('D').mean()` generates a continuous, regular `DatetimeIndex` including Tuesday (with `NaN` values), preserving temporal continuity and frequency metadata (`freq='D'`).

##### Q22: How does `label='right'` vs `label='left'` impact daily data aggregated from hourly readings?
- **Answer**: If hourly readings from `2026-05-14 00:00` to `2026-05-14 23:00` are aggregated:
  - `label='left'` labels the aggregated day as `2026-05-14`.
  - `label='right'` labels the aggregated day as `2026-05-15`.
  In daily data, misconfiguring `label='right'` mistakenly dates Thursday's metrics as Friday!

##### Q23: Why does `df.rolling('30D')` work on irregular time series while `df.rolling(30)` causes bias?
- **Answer**: An irregular series might have 25 pings on Monday and 5 pings spread across the rest of the month. `rolling(30)` aggregates 30 consecutive rows, meaning Monday's burst dominates the calculation and the window spans only a few days. `rolling('30D')` aggregates all points within a true 30-day time window, correctly capturing temporal moving averages regardless of ping density.

##### Q24: What is the difference between `resample('ME')` and `resample('MS')`?
- **Answer**: `resample('ME')` (Month End) groups records into calendar months and labels the output with the last day of each month (e.g. `2026-01-31`). `resample('MS')` (Month Start) groups records into calendar months and labels the output with the first day of each month (e.g. `2026-01-01`).

##### Q25: How do you resample multi-column DataFrames where different columns require different aggregation functions?
- **Answer**: Pass a dictionary to `.agg()`:
  ```python
  res = df.resample('D').agg({
      'open_price': 'first',
      'close_price': 'last',
      'high_price': 'max',
      'low_price': 'min',
      'volume': 'sum'
  })
  ```

##### Q26: What happens if `df.index` is unsorted when calling `df.rolling('7D')`?
- **Answer**: It raises `ValueError: index values must be monotonic increasing`. Time-based rolling windows rely on binary search to identify temporal window boundaries, which strictly requires sorted timestamps.

##### Q27: How does `closed` parameter work in `df.rolling('7D')`?
- **Answer**: In `rolling()`, `closed` determines interval inclusivity relative to the current timestamp $T$:
  - `'right'` (default): $(T - 7\text{D}, T]$ — excludes past boundary, includes current row.
  - `'left'`: $[T - 7\text{D}, T)$ — includes past boundary, excludes current row (useful to prevent target leakage in ML!).
  - `'both'`: $[T - 7\text{D}, T]$ — includes both.
  - `'neither'`: $(T - 7\text{D}, T)$ — excludes both.

##### Q28: How do you detect missing time series intervals after resampling?
- **Answer**: Resample to the target frequency, then filter for rows where all metrics are null:
  ```python
  resampled = df.resample('h').mean()
  missing_periods = resampled[resampled['val'].isna()]
  ```

##### Q29: What is `offset` parameter in `df.resample()`?
- **Answer**: `offset` shifts the start and end of resampled bins by a fixed duration timedelta. For example, `df.resample('D', offset='6h')` shifts daily bins to run from 6:00 AM to 6:00 AM the following day (ideal for broadcast television or industrial shifts).

##### Q30: How do you compute trailing 30-day rolling statistics partitioned by group (e.g. per customer)?
- **Answer**: Set the datetime as index, group by customer, and apply time-based rolling:
  ```python
  df['rolling_30d_rev'] = (
      df.set_index('ts')
        .groupby('customer_id')['amount']
        .rolling('30D')
        .sum()
        .reset_index(level=0, drop=True)
  )
  ```

##### Q31: How do you resample to weekly frequency anchored on a specific day of the week?
- **Answer**: Use weekly anchor codes: `'W-MON'`, `'W-TUE'`, `'W-WED'`, `'W-THU'`, `'W-FRI'`, `'W-SAT'`, `'W-SUN'` (default).
  ```python
  # Resample to weeks ending on Friday:
  weekly_fri = df.resample('W-FRI').sum()
  ```

##### Q32: What is the computational complexity of downsampling via `resample()`?
- **Answer**: $O(N)$ linear time complexity. Because the `DatetimeIndex` is sorted, Pandas computes integer bin assignments via fast C-level integer division on the 64-bit nanosecond buffer, grouping contiguous memory chunks with SIMD vectorization.

##### Q33: How do you compute forward-looking rolling windows (e.g. next 7 days) without data leakage?
- **Answer**: Reverse the time series, calculate trailing rolling window, and reverse back, or use offset indexing:
  ```python
  # Forward-looking 7 days:
  indexer = pd.api.indexers.FixedForwardWindowIndexer(window_size=7)
  df['next_7_mean'] = df['val'].rolling(window=indexer).mean()
  ```

##### Q34: What is the difference between `df.resample('D').first()` and `df.resample('D').asfreq()`?
- **Answer**: `first()` finds the *first actual recorded observation* within that calendar day, regardless of what hour it occurred. `asfreq()` checks for an observation occurring *exactly at midnight (`00:00:00`)*; if no observation exists at midnight, `asfreq()` yields `NaN`.

##### Q35: How do you resample quarterly data into annual data for a company with a September fiscal year end?
- **Answer**: Use `'YE-SEP'`:
  ```python
  annual_fiscal = df.resample('YE-SEP').sum()
  ```

##### Q36: How does `.resample().nearest()` work during upsampling?
- **Answer**: It populates newly created timestamps with the value of the nearest chronological observation, minimizing Euclidean temporal distance.

##### Q37: Can you resample by two frequencies simultaneously (e.g. 1 day and 12 hours)?
- **Answer**: Yes, compound frequency strings are valid: `df.resample('1D12h').mean()` creates 36-hour bins.

##### Q38: How do you prevent upsampling from forward-filling infinitely across massive gaps?
- **Answer**: Pass the `limit` parameter to `.ffill()`:
  ```python
  # Only forward fill up to 3 consecutive missing steps:
  df.resample('h').ffill(limit=3)
  ```

##### Q39: What is the effect of `center=True` in a rolling window?
- **Answer**: It centers the window around the current observation (e.g. for a 5-day window, 2 days before, current day, 2 days after). Caution: `center=True` uses future information and is strictly prohibited in predictive causal pipelines.

##### Q40: How do you downsample a DataFrame while retaining original row metadata from the peak value?
- **Answer**: Use `.idxmax()` to extract timestamps of maximum values, then index back into the DataFrame:
  ```python
  idx_peaks = df.resample('D')['val'].idxmax()
  peak_rows = df.loc[idx_peaks.dropna()]
  ```

##### Q41: Code Snippet — Financial Candlestick (OHLC) Generator
```python
import pandas as pd

def generate_candlesticks(ticks: pd.Series, freq: str = '5min') -> pd.DataFrame:
    # Ensure DatetimeIndex
```

## Phase 2: High-Yield Concepts, Pitfalls & Production Drills

### 4. Top Questions to Definitely Prepare

#### 4.1 Must-Know Core Questions

##### Q4.1.1: What is the primary operational difference between `DataFrame.resample()` and `DataFrame.groupby()`?
- **Answer**: `groupby()` aggregates strictly over existing unique values present in the data. If no rows exist for a date, `groupby()` omits that date entirely, destroying regularity. `resample()` is temporal-frequency aware: it enforces a continuous time grid spanning the full range of the data, populating empty intervals with `NaN` (or filled values) and attaching frequency metadata (`freq=`) to the resulting index.

##### Q4.1.2: How do `closed` and `label` interact in `DataFrame.resample()`?
- **Answer**: `closed` controls the mathematical interval boundary: `closed='left'` means $[T_{\text{start}}, T_{\text{end}})$ (start inclusive, end exclusive), whereas `closed='right'` means $(T_{\text{start}}, T_{\text{end}}]$. `label` dictates which timestamp is assigned to the output row: `label='left'` uses $T_{\text{start}}$, while `label='right'` uses $T_{\text{end}}$. Misaligning them can shift aggregated metrics by one full time bucket.

##### Q4.1.3: What are the modern replacements for legacy frequency codes `'M'`, `'A'`, and `'Q'`?
- **Answer**: 
  - Month End: `'ME'` (replaces `'M'`).
  - Month Start: `'MS'`.
  - Business Month End: `'BME'` (replaces `'BM'`).
  - Quarter End: `'QE'` (replaces `'Q'`).
  - Year End: `'YE'` (replaces `'A'`, `'Y'`).
  - Year Start: `'YS'` (replaces `'AS'`).

##### Q4.1.4: Why does `df.rolling('30D')` require a monotonic increasing `DatetimeIndex`?
- **Answer**: Time-based rolling windows do not count rows; they compute continuous time spans $[T - 30\text{D}, T]$ dynamically. To locate boundary rows in $O(\log N)$ time without scanning the entire DataFrame on every step, Pandas relies on binary search algorithms (`searchsorted`), which mathematically require sorted timestamps.

##### Q4.1.5: How does `df.resample('D').ohlc()` construct Open, High, Low, and Close columns?
- **Answer**: It partitions each daily bin and extracts:
  - `open`: The value of the first recorded chronological observation in the bin.
  - `high`: The maximum value recorded in the bin.
  - `low`: The minimum value recorded in the bin.
  - `close`: The value of the last recorded chronological observation in the bin.

##### Q4.1.6: Why is backward filling (`.bfill()`) dangerous when upsampling time series for machine learning?
- **Answer**: Backward filling propagates future observations into past timestamps. If an hourly model uses backward-filled daily CPI or revenue data, it peeks into the future (target leakage), yielding artificially high backtest scores that catastrophically fail in real-world deployment. Always use `.ffill()`.

##### Q4.1.7: What does `min_periods` do in `rolling('7D')`?
- **Answer**: It dictates the minimum number of valid observations required within the 7-day window to calculate a statistic. In time-based rolling windows, `min_periods` defaults to 1 (meaning the very first row returns its own value rather than `NaN`).

##### Q4.1.8: How do you resample a DataFrame when the datetime is stored in a column rather than the index?
- **Answer**: Pass the column name to the `on` parameter:
  ```python
  df_resampled = df.resample('D', on='event_time').mean()
  ```

##### Q4.1.9: What is the difference between `s.resample('D').asfreq()` and `s.resample('D').first()`?
- **Answer**: `asfreq()` samples the exact instantaneous value at midnight (`00:00:00`), returning `NaN` if no reading occurred at midnight. `first()` searches the 24-hour bin and returns the first observation that actually occurred, regardless of whether it happened at 00:00 or 14:30.

##### Q4.1.10: What does `offset` do in `DataFrame.resample()`?
- **Answer**: `offset` shifts the bin boundaries by a fixed duration timedelta. For example, `df.resample('D', offset='6h')` shifts daily bins to run from 06:00:00 to 06:00:00 the following day, aligning data to commercial shifts.

#### 4.2 Good-to-Know Differentiating Questions

##### Q4.2.1: How do you resample a time series anchored to the dataset's initial timestamp rather than calendar boundaries?
- **Answer**: Use `origin='start'`. By default, `origin='start_day'` aligns to midnight. Setting `origin='start'` forces interval bins to start exactly at the first recorded timestamp (e.g. `10:14:22`).

##### Q4.2.2: What is the difference between `df.rolling('7D', closed='right')` and `df.rolling('7D', closed='left')`?
- **Answer**: `closed='right'` (default) defines the window as $(T - 7\text{D}, T]$, including the current row's observation. `closed='left'` defines the window as $[T - 7\text{D}, T)$, strictly excluding the current row. `closed='left'` is essential in streaming feature engineering to prevent label leakage.

##### Q4.2.3: How does `df.resample('B')` handle public holidays?
- **Answer**: Frequency `'B'` (Business Day) strictly filters out Saturdays and Sundays. It does **not** filter statutory public holidays (e.g. Christmas, New Year's Day). To filter holidays, use a `CustomBusinessDay` offset.

##### Q4.2.4: Can you apply a rolling time window on an upsampled time series?
- **Answer**: Yes. A common production pattern is to upsample sparse event data to a regular 1-minute grid using `.ffill()`, and then apply a rolling time window (`rolling('60min')`) to maintain smooth rolling aggregates over a uniform axis.

##### Q4.2.5: How do you calculate Exponentially Weighted Moving Statistics over irregular time intervals?
- **Answer**: Pass `times=df.index` and a duration `halflife='7D'` to `.ewm()`:
  ```python
  df['ewma'] = df['val'].ewm(halflife='7D', times=df.index).mean()
  ```
  This applies continuous exponential decay based on actual elapsed time rather than discrete row steps.

##### Q4.2.6: How do you handle MultiIndex columns produced by `resample().agg()`?
- **Answer**: Flatten them by joining column levels:
  ```python
  res = df.resample('D').agg({'price': ['mean', 'max'], 'volume': 'sum'})
  res.columns = ['_'.join(c).strip('_') for c in res.columns]
  ```

##### Q4.2.7: What is the difference between `resample('QE')` and `resample('QE-DEC')`?
- **Answer**: They are identical. `'QE'` defaults to December year-end quarters (March, June, September, December). Non-standard fiscal quarters must specify anchors explicitly: `'QE-MAR'` (quarters ending in March, June, September, December), `'QE-JAN'` (quarters ending in January, April, July, October).

##### Q4.2.8: How do you limit forward-fill during upsampling to prevent propagating stale data indefinitely?
- **Answer**: Pass the `limit=N` argument to `.ffill()`:
  ```python
  df_hourly = df_daily.resample('h').ffill(limit=48)
  ```
  This caps forward filling at 48 consecutive hours.

##### Q4.2.9: What happens when calling `df.resample('D').sum()` on an empty DataFrame?
- **Answer**: It returns an empty DataFrame with an empty `DatetimeIndex` having `freq='D'` and the same column schema, without raising an exception.

##### Q4.2.10: How do you perform rolling aggregations on a Series grouped by an entity (e.g., store ID)?

#### 4.3 Advanced / Senior / Architect-Level Questions

##### Q4.3.1: How does Pandas optimize `resample()` downsampling under the hood?
- **Answer**: Because the `DatetimeIndex` is monotonic, Pandas computes bin boundaries by dividing integer nanosecond timestamps by the frequency step size in C. This generates an array of integer group codes in $O(N)$ time. Aggregations then execute via Cython group-reduction kernels without hash table allocations or Python function call overhead.

##### Q4.3.2: Explain how `FixedForwardWindowIndexer` enables leakage-free target generation for time-series forecasting.
- **Answer**: In time-series forecasting, models predict target outcomes over future horizons (e.g. next 7-day revenue). Standard `.rolling()` is trailing. `FixedForwardWindowIndexer` constructs a forward-looking window spanning $[T+1, T+N]$:
  ```python
  from pandas.api.indexers import FixedForwardWindowIndexer
  indexer = FixedForwardWindowIndexer(window_size=7)
  df['target_next_7d'] = df['revenue'].rolling(window=indexer).sum().shift(-1)
  ```
  This aligns future outcomes to the current row without manual shifting loops.

##### Q4.3.3: How do you architect a real-time streaming feature pipeline using Pandas time-series primitives?
- **Answer**: Maintain an in-memory sliding buffer of the last $N$ days of sorted data. When a micro-batch arrives:
  1. Concat and sort index: `buffer = pd.concat([buffer, new_batch]).sort_index()`.
  2. Prune data older than cutoff: `buffer = buffer.loc[cutoff:]`.
  3. Compute time-based rolling features with `closed='left'` to ensure strictly causal features: `buffer.rolling('24h', closed='left').mean()`.
  4. Emit latest row features to the inference model.

##### Q4.3.4: What are the memory and cache locality implications of `df.resample()` vs `df.groupby()`?
- **Answer**: `groupby()` requires building an arbitrary hash table of group keys and pointers, leading to scattered memory reads and L1/L2 CPU cache misses. `resample()` operates on contiguous sorted temporal blocks, enabling sequential SIMD memory access, hardware prefetching, and minimal heap allocation.

##### Q4.3.5: How do you handle non-standard trading holidays when resampling financial data to business days?
- **Answer**: Construct a `CustomBusinessDay` offset using an exchange holiday calendar (e.g. `USFederalHolidayCalendar` or NYSE calendar) and pass it directly to `resample()`:
  ```python
  from pandas.tseries.holiday import USFederalHolidayCalendar
  from pandas.tseries.offsets import CustomBusinessDay
  cbd = CustomBusinessDay(calendar=USFederalHolidayCalendar())
  df_resampled = df.resample(cbd).mean()
  ```

### 6. Section-Adaptive Pandas API Confusions

#### Confusion 1: `df.resample()` vs `df.groupby()`
| Dimension | `df.resample()` | `df.groupby()` |
| :--- | :--- | :--- |
| **Index Type** | Must be DatetimeIndex (or `on=`) | Any index or column dtype |
| **Grid Continuity** | Generates continuous, regular time grid | Only aggregates existing observed keys|
| **Missing Bins** | Populated with `NaN` (allows detecting gaps)| Missing keys are omitted entirely |
| **Frequency Metadata**| Attaches `freq=` attribute to output | No temporal frequency metadata |
| **Primary Use Case** | Regular time series aggregation / resampling| Relational and categorical grouping |

---

#### Confusion 2: `df.rolling('30D')` vs `df.rolling(30)`
| Dimension | `df.rolling('30D')` (Time-Based) | `df.rolling(30)` (Row-Based) |
| :--- | :--- | :--- |
| **Window Boundary** | Continuous elapsed calendar time ($30$ days)| Fixed count of consecutive rows ($30$ rows)|
| **Prerequisite** | Sorted `DatetimeIndex` mandatory | Any index type |
| **Irregular Gaps** | Dynamically adapts to temporal spacing | Distorts time windows across gaps |
| **Default `min_periods`**| Defaults to `1` | Defaults to $N$ ($30$) |
| **Initial NaNs** | None (if `min_periods=1`) | First 29 rows return `NaN` |

---

#### Confusion 3: `closed='left'` vs `label='left'`
| Parameter | Definition | Impact of Changing |
| :--- | :--- | :--- |
| **`closed`** | Mathematical interval boundary rule: $[T_1, T_2)$ vs $(T_1, T_2]$| Determines which bin an exact boundary event enters |
| **`label`** | Output index naming rule: $T_{\text{start}}$ vs $T_{\text{end}}$| Changes the timestamp label of the output row |

---

#### Confusion 4: `.asfreq()` vs `.resample().ffill()`
| Method | Behavior on Missing Bins | Primary Use Case |
| :--- | :--- | :--- |
| **`.asfreq('D')`** | Re-indexes to regular grid; leaves empty bins as `NaN`| Detecting missing time points / gap audit |
| **`.resample('D').ffill()`**| Re-indexes to regular grid; forward-fills last valid value| Causal signal alignment for ML models |

---

#### Confusion 5: `'ME'` vs `'MS'` vs `'BME'`
| Frequency Code | Name | Example Label (Jan 2026) |
| :--- | :--- | :--- |
| **`'ME'`** | Month End (Calendar) | `2026-01-31` (Saturday) |
| **`'MS'`** | Month Start (Calendar) | `2026-01-01` (Thursday) |
| **`'BME'`** | Business Month End | `2026-01-30` (Friday) |

- **Context**: A quantitative hedge fund deployed an intraday equity model that incorporated daily macroeconomic updates. In backtesting, the strategy achieved an impossible Sharpe ratio of 4.5. In live trading, it suffered severe capital drawdowns.
- **Root Cause**: The developer upsampled daily macro signals to 1-minute intervals using `.resample('min').bfill()`. This allowed the model to trade at 09:30 AM based on macro numbers announced at 02:00 PM that afternoon!
- **Diagnostic Code**:
  ```python

  print("Leaked signal at 2026-05-01 12:00:\n", leaked) # Shows 20! Future data!
  ```
- **Architectural Fix**:
  ```python
  # Strictly forward fill to preserve historical causality:
  causal = daily.resample('12h').ffill()
  print("Causal signal at 2026-05-01 12:00:\n", causal) # Shows 10 (Past data)
  ```

### 10. "Explain This Code" Questions

#### Challenge 1: The Gapped Rolling Discrepancy
```python
import pandas as pd
idx = pd.to_datetime(['2026-01-01', '2026-01-02', '2026-01-10'])
df = pd.DataFrame({'x': [10, 20, 30]}, index=idx)
res_row = df['x'].rolling(2).mean()
res_time = df['x'].rolling('2D').mean()
print("Row:", res_row.iloc[-1], "| Time:", res_time.iloc[-1])
```
- **Line-by-Line Mechanics**:
  1. `df['x'].rolling(2).mean()` counts the last 2 consecutive rows: Row 1 (`20`) and Row 2 (`30`). The average is $(20 + 30) / 2 = 25.0$. The 8-day calendar gap is completely ignored.
  2. `df['x'].rolling('2D').mean()` constructs a continuous 2-day temporal window relative to the current row's timestamp: $[2026-01-08\ 00:00:00, 2026-01-10\ 00:00:00]$.
  3. Row 1 (`2026-01-02`) falls outside this 2-day window!
  4. Only Row 2 (`30`) falls inside the window. The average is $30.0 / 1 = 30.0$.
- **Output**: `Row: 25.0 | Time: 30.0`
- **Perturbation**: If Row 2 had timestamp `'2026-01-03'`, it would fall inside the 2-day window, yielding $25.0$ for both.

#### Challenge 2: Closed Boundary Interval Shift
```python
import pandas as pd
idx = pd.to_datetime(['2026-01-01 10:00:00', '2026-01-01 11:00:00'])
df = pd.DataFrame({'x': [10, 20]}, index=idx)
print("Left:\n", df.resample('1h', closed='left').sum())
print("Right:\n", df.resample('1h', closed='right').sum())
```
- **Line-by-Line Mechanics**:
  1. `closed='left'` defines bins as $[T_1, T_2)$. The first bin is $[10:00, 11:00)$; it captures `10:00:00` (`10`). `11:00:00` is excluded and belongs to the second bin $[11:00, 12:00)$ (`20`). Total 2 bins.
  2. `closed='right'` defines bins as $(T_1, T_2]$. The first bin is $(09:00, 10:00]$, which captures `10:00:00` (`10`). The second bin is $(10:00, 11:00]$, which captures `11:00:00` (`20`).
  3. The resulting labels differ based on default labeling convention.
- **Output**: Shows how timestamps partition across intervals depending on boundary rules.

#### Challenge 3: Time-Based Rolling Default `min_periods`
```python
import pandas as pd
idx = pd.date_range('2026-01-01', periods=3, freq='D')
s = pd.Series([10.0, 20.0, 30.0], index=idx)
print("Row min_periods:\n", s.rolling(3).mean().tolist())
print("Time min_periods:\n", s.rolling('3D').mean().tolist())
```
- **Line-by-Line Mechanics**:
  1. `s.rolling(3)` defaults `min_periods=3`. Rows 0 and 1 have fewer than 3 observations, so they evaluate to `NaN`. Only Row 2 evaluates to a number (`20.0`).
  2. `s.rolling('3D')` defaults `min_periods=1`! Row 0 has 1 observation, evaluating to `10.0`. Row 1 has 2 observations, evaluating to `15.0`. Row 2 has 3 observations, evaluating to `20.0`.
- **Output**:
  ```text
  Row min_periods:  [nan, nan, 20.0]
  Time min_periods: [10.0, 15.0, 20.0]
  ```
- **Perturbation**: Passing `min_periods=3` to `s.rolling('3D', min_periods=3)` restores `[nan, nan, 20.0]`.

#### Challenge 4: Upsampling Forward Fill vs Interpolate
```python
import pandas as pd
idx = pd.to_datetime(['2026-01-01 10:00', '2026-01-01 10:02'])
s = pd.Series([0.0, 10.0], index=idx)
print("FFILL:\n", s.resample('1min').ffill().tolist())
print("INTERPOLATE:\n", s.resample('1min').interpolate(method='linear').tolist())
```
- **Line-by-Line Mechanics**:
  1. Minute 10:01 is generated by upsampling.
  2. `.ffill()` carries the last known value forward: Minute 10:01 becomes `0.0`. Step-function progression: `[0.0, 0.0, 10.0]`.
  3. `.interpolate(method='linear')` evaluates the slope: $(10.0 - 0.0) / 2 = 5.0$. Minute 10:01 becomes `5.0`. Linear gradient progression: `[0.0, 5.0, 10.0]`.
- **Output**:
  ```text
  FFILL:       [0.0, 0.0, 10.0]
  INTERPOLATE: [0.0, 5.0, 10.0]
  ```
- **Perturbation**: If Minute 10:02 was missing, `.ffill()` would continue forward, while `.interpolate()` would leave it `NaN`.

### 15. Fresher Answer Evolution Patterns

#### Pattern 1: "How do you calculate a 30-day moving average in Pandas?"
- **Freshman Answer**: "You just call `df['price'].rolling(30).mean()`."
- **Junior Answer**: "If the data has missing days or weekends, `rolling(30)` takes 30 rows instead of 30 days. You should use `df['price'].rolling('30D').mean()`, which requires setting the date as the index."
- **Senior Answer**: "`df['price'].rolling(30)` is an integer row-count window that assumes uniformly sampled data. In real-world data with irregular arrivals, holidays, and weekends, 30 rows can span 40+ calendar days, introducing severe bias. The production standard is `df['price'].rolling('30D').mean()`. This requires a `DatetimeIndex` that is monotonically increasing (`df.index.is_monotonic_increasing`). In predictive ML feature pipelines, also set `closed='left'` to ensure the current row's observation is excluded, preventing label leakage."

---

#### Pattern 2: "How do you convert hourly data to daily data?"
- **Freshman Answer**: "You use `groupby` on the date part of the timestamp: `df.groupby(df['date'].dt.date).mean()`."
- **Junior Answer**: "You set the date as index and use `df.resample('D').mean()`. This is faster and produces a datetime index."
- **Senior Answer**: "Using `groupby(df.index.date)` is an anti-pattern: it destroys frequency metadata, casts the index to a slow Python `object` array of `datetime.date` scalars, and omits dates with zero observations. In contrast, `df.resample('D').mean()` enforces a continuous, regular time grid, surfaces missing blackout periods as `NaN`, and operates via optimized C-level integer division over contiguous memory buffers. Always explicitly specify `label='left'` to avoid 1-day labeling shifts."

#### Pattern 3: "How do you upsample monthly data to daily data for machine learning?"
- **Freshman Answer**: "You use `df.resample('D')` and fill missing values with `.bfill()` or `.ffill()`."
- **Junior Answer**: "You use `df.resample('D').ffill()` because `.bfill()` causes data leakage by looking into the future."
- **Senior Answer**: "Upsampling monthly data to daily requires strict causal protection. Using `.bfill()` leaks future monthly announcements into historical days, completely invalidating backtests. You must use `df.resample('D').ffill()`. Furthermore, in production ingestion pipelines, you should always set a safety limit like `ffill(limit=45)` so that if upstream ingestion halts, stale data is not propagated indefinitely into the feature store."

### 18. Cross-Concept Bridges

#### Bridge 1: NumPy (`np.convolve`, Sliding Strides)
- **Mechanics**: Pandas `.rolling()` replaces low-level NumPy stride manipulation (`np.lib.stride_tricks.sliding_window_view`).
- **Advantage**: NumPy sliding windows require uniform arrays and cannot evaluate time-based duration windows (`'30D'`). Pandas handles non-uniform intervals natively.

#### Bridge 2: SQL (`OVER (ORDER BY ts RANGE BETWEEN ... )`)
- **Equivalence Table**:
  | Pandas Operation | ANSI SQL Equivalent |
  | :--- | :--- |
  | `df.rolling(30).mean()` | `AVG(val) OVER (ORDER BY ts ROWS 29 PRECEDING)` |
  | `df.rolling('30D').mean()`| `AVG(val) OVER (ORDER BY ts RANGE BETWEEN INTERVAL '30 days' PRECEDING AND CURRENT ROW)` |
  | `df.resample('D').sum()` | `SUM(val) ... GROUP BY DATE_TRUNC('day', ts)` |

#### Bridge 3: Scikit-learn (Time Series Split & Rolling Features)

### 24. Final 2-Minute Revision Summary

#### Core Concepts
- `df.resample()` enforces continuous regular time grids, supporting Downsampling (`.mean()`, `.sum()`, `.ohlc()`) and Upsampling (`.ffill()`, `.interpolate()`).
- Modern aliases: Use `'ME'` (Month End), `'MS'` (Month Start), `'BME'` (Business Month End), `'YE'` (Year End), `'QE'` (Quarter End), `'h'`, `'s'`. Avoid deprecated `'M'`, `'BM'`, `'A'`.
- Boundaries: `closed` controls bin inclusivity ($[A, B)$ vs $(A, B]$); `label` controls the output row's timestamp name.
- Time-based rolling: `df.rolling('30D')` calculates true elapsed time windows; strictly requires a monotonic increasing `DatetimeIndex`.
- Causality: Never use `.bfill()` or `center=True` in predictive ML feature stores. Use `closed='left'` to strictly exclude current row values.

#### Top 5 Traps to Dodge
1. **Unsorted Index in Rolling**: Calling `rolling('7D')` on unsorted data raises `ValueError`. Call `df.sort_index()` first.
2. **Deprecated Frequency Aliases**: Using `'M'` or `'A'` raises `FutureWarning`. Use `'ME'` and `'YE'`.
3. **Target Leakage via `.bfill()`**: Peeks into the future. Always use `.ffill()` in causal pipelines.
4. **Row-Count Rolling on Gapped Data**: `rolling(30)` counts rows, not days. Use `rolling('30D')`.
5. **1-Day Shift via `label='right'`**: In daily data, `label='right'` labels Friday as Saturday. Use `label='left'`.
