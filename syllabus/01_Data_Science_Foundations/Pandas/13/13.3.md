### 1. Section Overview

#### What This Section Is About
Section 13.3 explores advanced hierarchical reshaping techniques in Pandas, focusing on `DataFrame.stack()`, `Series.unstack()` / `DataFrame.unstack()`, matrix transposition (`DataFrame.transpose()` / `df.T`), multi-level index manipulation, and production-grade reshaping of complex real-world datasets. Unlike basic column-oriented methods, these techniques operate directly on the hierarchical structure of Pandas `Index` and `MultiIndex` objects, allowing arbitrary rotations of dimensional axes between rows and columns.

#### Why These Pandas Concepts Matter
In complex data pipelines, analytical tables frequently evolve into multi-level hierarchical representations (e.g., outputs of grouped multi-metric aggregations, multi-period financial statements, or multi-sensor time-series cubes). While beginners often resort to flattening tables via awkward string manipulations or manual Python dictionary loops, seasoned data engineers and scientists use `stack()` and `unstack()` to fluidly navigate multidimensional coordinate spaces. Technical interviewers probe these methods to test a candidate's mastery of Pandas index architecture, understanding of sparse Cartesian products, and ability to reshape data without compromising performance or causing dtype upcasting.

#### Where They Are Used in Real Projects
1. **Financial Balance Sheet & P&L Analysis**: Transposing financial line items into column metrics for chronological ratio and margin calculations over time.
2. **Multi-Metric Groupby Pipelines**: Reshaping the output of `df.groupby(['store', 'dept'])[['sales', 'profit']].agg(['mean', 'sum'])` using targeted `.unstack()` calls to build feature vectors.
3. **Econometric & Longitudinal Panel Modeling**: Stacking wide cross-sectional panels into balanced long-format multi-indexed panels for regression analysis.
4. **Machine Learning Model Evaluation**: Transposing classification reports (`precision`, `recall`, `f1-score` across classes) for visualization heatmaps and model card documentation.
5. **IoT & Industrial Telemetry Harmonization**: Rotating nested MultiIndex sensor-timestamp hierarchies to align asynchronous readings.

#### What a Fresher Should Be Able to Do

- Control the targeted level of rotation using integer level indices (e.g., `level=-1`, `level=0`) or explicit level names.
- Manage missing values during unstacking using `fill_value` and understand `stack()`'s default `dropna=True` behavior.
- Understand the computational and memory implications of matrix transposition (`.T`), specifically why transposing mixed-dtype DataFrames forces upcasting to `object`.
- Reorder, swap, and sort multi-level indices using `swaplevel()`, `reorder_levels()`, and `sort_index()`.
- Clean and normalize messy hierarchical datasets into production-grade flat schemas ready for SQL and parquet serialization.

### 2. Topic-Wise Interview Concepts

#### Topic 1: `stack()`
- **Concept**: `DataFrame.stack(level=-1, dropna=True, sort=True, future_stack=False)` rotates specified column headers into the innermost row index level, transforming a 2D DataFrame into a multi-indexed Series (or a multi-indexed DataFrame if columns had multiple levels).
- **Why It Matters**: Interviewers test `stack()` to verify whether candidates know how to compress horizontal column structures into vertical index hierarchies without manual unpivoting.
- **Technical / Algorithmic Intuition**: For each row in the DataFrame, `stack()` iterates across the specified column level, pairing the row's existing index with each column label to form a composite `MultiIndex` row coordinate. If `dropna=True` (default), cells containing `NaN` are dropped during construction, yielding a compact, sparse Series.
- **Syntax / Pandas API**:
  ```python
  s = df.stack(level=-1, dropna=True)
  ```
- **Minimal Working Example**:
  ```python
  import pandas as pd

  df = pd.DataFrame({
      'Jan': [100, 200],
      'Feb': [150, 250]
  }, index=['Store_A', 'Store_B'])

  stacked = df.stack()
  print(stacked)
  ```
- **Expected Output / Interpretation**:
  ```text
  Store_A  Jan    100
           Feb    150
  Store_B  Jan    200
           Feb    250
  dtype: int64
  ```
  The 2-column DataFrame was rotated into a multi-indexed Series where Level 0 is the store and Level 1 is the month.
- **Important Parameters & Options**:
  - `level`: Level(s) to stack from column axis to index axis (default `-1`, innermost level). Can be int, str, or list.
  - `dropna`: Boolean (default `True`). Whether to drop rows in the resulting index with missing values.
  - `sort`: Boolean (default `True`). Whether to sort the resulting MultiIndex levels.
- **Common Interview Confusion**: Candidates frequently confuse `stack()` with `melt()`. `melt()` operates on columns by name, always returning a flat DataFrame with customizable variable/value columns. `stack()` operates strictly on index/column levels, returning a `Series` (or multi-indexed DataFrame) with index hierarchies.

#### Topic 2: `unstack()`
- **Concept**: `Series.unstack(level=-1, fill_value=None, sort=True)` or `DataFrame.unstack(level=-1, fill_value=None, sort=True)` is the exact inverse of `stack()`. It rotates a specified level of the row `MultiIndex` into horizontal column headers.
- **Why It Matters**: This is one of the most frequently used methods following a `.groupby()` aggregation. Interviewers test it to see if candidates can reshape multi-indexed summaries into wide matrices.
- **Technical / Algorithmic Intuition**: Pandas extracts the unique labels of the specified row index level, removes that level from the row MultiIndex, and attaches it as the new innermost (or outermost) level of `df.columns`. Any Cartesian coordinate gaps resulting from the rotation are filled with `NaN` (or `fill_value`).
- **Syntax / Pandas API**:
  ```python
  wide_df = multi_index_series.unstack(level=-1, fill_value=0)
  ```
- **Minimal Working Example**:
  ```python
  import pandas as pd

  # Multi-indexed Series (e.g. output from groupby)
  idx = pd.MultiIndex.from_tuples([('East', 'Q1'), ('East', 'Q2'), ('West', 'Q1'), ('West', 'Q2')], names=['region', 'quarter'])
  s = pd.Series([100, 150, 200, 250], index=idx)

  # Unstack quarter into columns
  unstacked = s.unstack(level='quarter')
  print(unstacked)
  ```
- **Expected Output / Interpretation**:
  ```text
  quarter   Q1   Q2
  region          
  East     100  150
  West     200  250
  ```
  The row index level `'quarter'` was rotated into horizontal column headers, leaving `'region'` as the row index.
- **Important Parameters & Options**:
  - `level`: Level of the row index to unstack (default `-1`, innermost). Can be int or string name.
  - `fill_value`: Scalar replacement value for missing combinations (e.g., `fill_value=0`).
  - `sort`: Boolean (default `True`). Sorts column levels.
- **Common Interview Confusion**: Unstacking a level when combinations are missing can create massive sparse matrices filled with `NaN`. Candidates must remember to supply `fill_value=0` when appropriate.

#### Topic 3: `transpose()` / `.T`
- **Concept**: `DataFrame.transpose(*args, copy=False)` (conveniently accessed via property `df.T`) reflects the DataFrame over its main diagonal: row index labels become column headers, and column headers become row index labels.
- **Why It Matters**: Interviewers test transposition to assess whether candidates understand matrix orientation, row-vs-column memory layout, and the severe dtype penalties of transposing heterogeneous DataFrames.
- **Technical / Algorithmic Intuition**: Transposition swaps the axis metadata: `df.index` becomes `df.columns`, and `df.columns` becomes `df.index`. If the DataFrame has homogeneous dtypes (e.g., all `float64`), this operation can be performed as a fast, zero-copy strided view over the underlying 2D NumPy array. However, if columns have differing dtypes (e.g., integers, floats, strings), Pandas must consolidate all columns into a single 2D array, forcing all data to upcast to `object`.
- **Syntax / Pandas API**:
  ```python
  df_transposed = df.T
  # Or explicitly:
  df_transposed = df.transpose()
  ```
- **Minimal Working Example**:
  ```python
  import pandas as pd

  metrics = pd.DataFrame({
      'revenue': [1000, 1500],
      'margin': [0.25, 0.30]
  }, index=['Q1', 'Q2'])

  print(metrics.T)
  ```
- **Expected Output / Interpretation**:
  ```text
                Q1      Q2
  revenue  1000.00  1500.0
  margin      0.25     0.3
  ```
  Quarters are now column headers; metrics are row labels.
- **Important Parameters & Options**:
  - `copy`: Default `False` (in older versions) or depends on backend. In Pandas 2.0+, Copy-on-Write rules govern transposition.
- **Common Interview Confusion**: Beginners often call `.T` on heterogeneous DataFrames (e.g. `['name', 'age', 'salary']`) to "view data vertically", unaware that converting numbers into rows beneath string headers degrades all numeric columns into slow Python `object` types.

#### Topic 4: Multi-Level Reshaping
- **Concept**: Multi-level reshaping encompasses operations on DataFrames possessing multi-indexed rows, multi-indexed columns, or both. It includes targeted stacking/unstacking across arbitrary levels, swapping index levels (`df.swaplevel()`), reordering hierarchies (`df.reorder_levels()`), and sorting multi-level axes (`df.sort_index()`).
- **Why It Matters**: Proves that a candidate can navigate OLAP data cubes and manipulate multi-dimensional hierarchies without flattening and reconstructing data structures from scratch.
- **Technical / Algorithmic Intuition**: A `MultiIndex` is a sequence of tuples backed by internal integer codes and category levels. Methods like `swaplevel(i, j)` simply swap the positions of level $i$ and level $j$ in the tuple hierarchy, updating the code pointers. Calling `sort_index()` after level reordering is mandatory to ensure lexicographical ordering for fast binary search indexing.
- **Syntax / Pandas API**:
  ```python
  df.swaplevel(0, 1, axis=0)
  df.reorder_levels(['country', 'state', 'city'], axis=0)
  df.sort_index(level=0)
  ```
- **Minimal Working Example**:
  ```python
  import pandas as pd

  idx = pd.MultiIndex.from_tuples([('USA', 'NY'), ('USA', 'CA'), ('CAN', 'ON')], names=['country', 'state'])
  df = pd.DataFrame({'population': [8.5, 39.0, 14.5]}, index=idx)

  # Swap levels so state is outer, country is inner
  swapped = df.swaplevel('country', 'state').sort_index()
  print(swapped)
  ```
- **Expected Output / Interpretation**:
  ```text
                 population
  state country            
  CA    USA            39.0
  NY    USA             8.5
  ON    CAN            14.5
  ```
  The level hierarchy was inverted and sorted lexicographically.
- **Important Parameters & Options**:
  - `i, j`: Integer or name of levels to swap.
  - `axis`: 0 for rows, 1 for columns.
  - `sort_index()`: Essential companion method after swapping levels to restore performance.
- **Common Interview Confusion**: Attempting to index a swapped MultiIndex with `.loc[]` without calling `.sort_index()` can raise a `PerformanceWarning` or `UnsortedIndexError`.

#### Topic 5: Reshaping Real-World Datasets
- **Concept**: In production, raw data rarely conforms to textbook schemas. Real-world reshaping involves orchestrating `stack()`, `unstack()`, and `transpose()` to normalize messy multi-header spreadsheets, parse nested JSON hierarchies, and transform multi-metric group summaries into clean tabular feature vectors.
- **Why It Matters**: Hiring managers want to see if a candidate can handle dirty, nested, non-uniform schemas, prevent Cartesian product bloat, and produce database-ready flat tables.
- **Technical / Algorithmic Intuition**:
  1. *Hierarchical Aggregations*: Aggregating multiple metrics across multiple dimensions (`df.groupby(['A', 'B'])[['X', 'Y']].agg(['mean', 'sum'])`) generates a MultiIndex column header. Unstacking level `'B'` creates a 2-level row index and a 2-level column index.
  2. *Flattening & Export*: Converting composite tuple headers into clean single-level strings (`['_'.join(c) for c in df.columns]`) ensures compatibility with parquet, CSV, and SQL warehouses.
  3. *Sparsity & Memory*: Real-world unstacking introduces structural sparsity; using `fill_value=0` and downcasting numeric types avoids out-of-memory errors.
- **Syntax / Pandas API**:
  ```python
  summary = df.groupby(['store', 'dept'])['sales'].sum().unstack('dept', fill_value=0)
  summary.columns.name = None
  clean_table = summary.reset_index()
  ```
- **Minimal Working Example**:
  ```python
  import pandas as pd

  txns = pd.DataFrame({
      'region': ['North', 'North', 'South'],
      'channel': ['Web', 'Store', 'Web'],
      'revenue': [1000, 500, 1200],
      'margin': [0.3, 0.2, 0.35]
  })

  # Groupby multi-metric, unstack channel, and flatten
  summary = txns.groupby(['region', 'channel'])[['revenue', 'margin']].mean().unstack('channel')
  summary.columns = [f"{metric}_{channel}" for metric, channel in summary.columns]
  print(summary)
  ```
- **Expected Output / Interpretation**:
  ```text
          revenue_Store  revenue_Web  margin_Store  margin_Web
  region                                                      
  North           500.0       1000.0           0.2        0.30
  South             NaN       1200.0           NaN        0.35
  ```
  Produces a clean, single-level wide feature table per region.
- **Important Parameters & Options**:
  - `fill_value`: Essential for unstacking sparse multi-group tables.
  - Column flattening list comprehensions.
- **Common Interview Confusion**: Candidates often get stuck when downstream visualization or database export tools reject MultiIndex columns. Knowing how to systematically collapse hierarchies using list comprehensions is a required engineering skill.

### 3. Fresher Interview Questions

#### A. Basic Questions (20 Questions)

### Q1: What does `DataFrame.stack()` do in Pandas?
- **Direct Answer & Definition**: `DataFrame.stack()` rotates the innermost (or specified) level of column headers into the innermost row index level, transforming horizontal column attributes into vertical index rows.
- **Technical & Computational Reasoning**: It takes column headers and appends them to the DataFrame's row index hierarchy as a new inner level, converting a 2D tabular block into a multi-indexed Series (or a DataFrame with fewer column levels).
- **Practical Application / Syntax**: `stacked_series = df.stack(level=-1, dropna=True)`.
- **Nuances, Defaults & Pitfalls**: By default, `stack()` drops all `NaN` values resulting from the rotation (`dropna=True`), which can silently change the total count of observations unless `dropna=False` is explicitly set.

### Q2: What does `Series.unstack()` do in Pandas?
- **Direct Answer & Definition**: `Series.unstack()` rotates a specified level of a multi-indexed row index into horizontal column headers, transforming a hierarchical 1D Series into a wide 2D DataFrame.
- **Technical & Computational Reasoning**: It extracts the unique labels of the target row index level, removes that level from the row MultiIndex, and sets them as new column labels, populating cells with the corresponding Series values.
- **Practical Application / Syntax**: Commonly chained after groupby operations: `df.groupby(['region', 'year'])['sales'].sum().unstack('year')`.
- **Nuances, Defaults & Pitfalls**: If specific combinations of index levels had no data in the Series, `unstack()` populates those intersection cells with `NaN` unless `fill_value` is specified.

### Q3: What is the default level operated upon by `stack()` and `unstack()`?
- **Direct Answer & Definition**: Both `stack()` and `unstack()` default to `level=-1`, which corresponds to the innermost (deepest) level of the column or row hierarchy.
- **Technical & Computational Reasoning**: Negative indexing in Pandas follows Python standard conventions: `-1` refers to the last level, allowing intuitive rotation of the most granular sub-dimension without hardcoding level numbers or names.
- **Practical Application / Syntax**: Calling `df.stack()` or `s.unstack()` without arguments rotates the innermost level automatically.
- **Nuances, Defaults & Pitfalls**: In a single-level column DataFrame, `level=-1` is level 0 (the only level available).

### Q4: How does `DataFrame.transpose()` / `df.T` differ from `DataFrame.unstack()`?
- **Direct Answer & Definition**: `df.T` reflects the entire DataFrame across its diagonal—swapping the entire row index with the entire column index—whereas `unstack()` moves only a single specified level of the row MultiIndex into the column axis.
- **Technical & Computational Reasoning**: Transposition changes the shape from $(M, N)$ to $(N, M)$ without reshaping hierarchies, whereas `unstack()` alters dimensionality and hierarchy, transforming a MultiIndex into a multi-column structure.
- **Practical Application / Syntax**: Use `df.T` when comparing summary statistics across rows; use `s.unstack()` when pivoting a grouped category dimension into wide format.
- **Nuances, Defaults & Pitfalls**: Transposing a DataFrame with mixed dtypes (e.g. floats and strings) forces all data into the `object` dtype, causing performance degradation.

### Q5: What does the `dropna` parameter in `DataFrame.stack()` control?
- **Direct Answer & Definition**: The `dropna` parameter controls whether missing values (`NaN`) in the resulting stacked rows are automatically dropped (`True`, default) or retained (`False`).
- **Technical & Computational Reasoning**: If a wide DataFrame contains `NaN` at row `r` and column `c`, setting `dropna=True` excludes the tuple `(r, c)` from the resulting Series, keeping the Series sparse and compact.
- **Practical Application / Syntax**: Use `df.stack(dropna=False)` when every entity must maintain an explicit record for all categories, even if unobserved.
- **Nuances, Defaults & Pitfalls**: Setting `dropna=False` can drastically increase the length of the stacked Series if the original wide table was sparse.

### Q6: What does the `fill_value` parameter in `Series.unstack()` do?
- **Direct Answer & Definition**: `fill_value` specifies a replacement scalar to impute into cells where no observation existed for that specific row-column index combination in the original multi-indexed Series.
- **Technical & Computational Reasoning**: When unstacking, Pandas constructs the full Cartesian product of the remaining row levels and the unstacked column level. Gaps in the product evaluate to `NaN`; `fill_value` replaces those NaNs prior to array construction.
- **Practical Application / Syntax**: In financial totals where missing records represent zero revenue: `s.unstack(fill_value=0)`.
- **Nuances, Defaults & Pitfalls**: `fill_value` only applies to missing Cartesian intersections; it does not replace pre-existing NaNs that were explicitly stored in the Series.

### Q7: What type of object does `df.stack()` return when called on a standard DataFrame with single-level columns?
- **Direct Answer & Definition**: Calling `df.stack()` on a DataFrame with single-level columns returns a Pandas `Series` with a 2-level `MultiIndex`.
- **Technical & Computational Reasoning**: Because all column labels are consumed and rotated into the row index, only a single 1D array of values remains, which Pandas formats as a `Series` indexed by `(row_label, col_label)`.
- **Practical Application / Syntax**: To convert the resulting Series back into a standard 3-column flat DataFrame, call `.reset_index()`: `df.stack().reset_index(name='value')`.
- **Nuances, Defaults & Pitfalls**: Candidates often expect `stack()` to always return a DataFrame; it returns a DataFrame ONLY if the source columns had a MultiIndex and fewer than all levels were stacked.

### Q8: What type of object does `df.stack()` return when called on a DataFrame with a MultiIndex on columns?
- **Direct Answer & Definition**: It returns a `DataFrame` whose row index has an additional level and whose column index has one fewer level (unless all column levels were stacked simultaneously).
- **Technical & Computational Reasoning**: Since only one level of the column MultiIndex was rotated into rows, remaining column levels still form a horizontal dimension, preserving the 2D `DataFrame` structure.
- **Practical Application / Syntax**: Used when rotating one metric or period level into rows while keeping other attributes as columns: `multi_col_df.stack(level='quarter')`.
- **Nuances, Defaults & Pitfalls**: If you pass `level=[0, 1]` (stacking all column levels), it collapses completely into a `Series`.

### Q9: Can you stack or unstack by column/index level names instead of integer positions?
- **Direct Answer & Definition**: Yes, if the index or column levels are assigned names (e.g. `names=['country', 'city']`), you can pass the string name directly to `level`.
- **Technical & Computational Reasoning**: Pandas searches `index.names` or `columns.names` and resolves the string to its corresponding integer level index.
- **Practical Application / Syntax**: `s.unstack(level='year')` is vastly superior to `s.unstack(level=1)` because it is immune to index level reordering bugs.
- **Nuances, Defaults & Pitfalls**: If level names are `None` (un-named), passing a string raises a `KeyError`; you must reference by integer position (`level=0`, `level=1`) or name the index first via `df.index.names = [...]`.

### Q10: What does `DataFrame.swaplevel(i, j, axis=0)` do?
- **Direct Answer & Definition**: `DataFrame.swaplevel()` interchanges the positions of two levels in a MultiIndex without altering the underlying data.
- **Technical & Computational Reasoning**: It swaps level $i$ and level $j$ in the index tuple metadata, modifying the hierarchical ordering (e.g. converting `(country, state)` to `(state, country)`).
- **Practical Application / Syntax**: `df.swaplevel('year', 'quarter', axis=0)`.
- **Nuances, Defaults & Pitfalls**: After swapping levels, the MultiIndex is often non-lexicographically sorted; you must call `.sort_index()` immediately afterward to maintain optimal indexing performance.

### Q11: What does `DataFrame.reorder_levels(order, axis=0)` do?
- **Direct Answer & Definition**: `DataFrame.reorder_levels()` rearranges all levels of a MultiIndex to match a specified sequence of level names or integer positions.
- **Technical & Computational Reasoning**: While `swaplevel()` swaps exactly two levels, `reorder_levels()` allows arbitrary reordering of 3 or more levels in a single operation.
- **Practical Application / Syntax**: `df.reorder_levels(['year', 'country', 'city'], axis=0)`.
- **Nuances, Defaults & Pitfalls**: The `order` list must contain all existing levels exactly once; omitting or duplicating a level raises a `ValueError`.

### Q12: Why is calling `.sort_index()` recommended after `swaplevel()` or `reorder_levels()`?
- **Direct Answer & Definition**: Calling `.sort_index()` ensures the MultiIndex is lexicographically sorted, enabling fast binary search lookups and preventing `PerformanceWarning` or `UnsortedIndexError` during slicing.
- **Technical & Computational Reasoning**: Pandas uses binary search algorithms on sorted MultiIndex buffers to achieve $O(\log N)$ slicing speed. If the index is unsorted, Pandas must fall back to slow linear scans ($O(N)$) or raise exceptions on partial string slices.
- **Practical Application / Syntax**: `df_swapped = df.swaplevel(0, 1).sort_index()`.
- **Nuances, Defaults & Pitfalls**: Slicing an unsorted MultiIndex using `.loc[('USA', 'CA'):('USA', 'NY')]` will fail with `UnsortedIndexError`.

### Q13: Can you unstack multiple levels simultaneously?
- **Direct Answer & Definition**: Yes, passing a list of level names or integers to `unstack(level=[...])` unpivots multiple row levels into a MultiIndex column header.
- **Technical & Computational Reasoning**: Pandas extracts all specified levels from the row MultiIndex and constructs a MultiIndex on columns representing the Cartesian product of those levels.
- **Practical Application / Syntax**: `s.unstack(level=['year', 'quarter'])`.
- **Nuances, Defaults & Pitfalls**: Unstacking multiple high-cardinality levels can produce thousands of columns, dramatically inflating memory usage.

### Q14: How does `stack()` differ fundamentally from `melt()`?
- **Direct Answer & Definition**: `stack()` rotates existing column headers into the row index hierarchy based on level position, returning a multi-indexed Series/DataFrame. `melt()` unpivots columns into flat tabular rows, creating explicit user-named `variable` and `value` columns while dropping or repeating the index.
- **Technical & Computational Reasoning**: `stack()` is an index/column level transformation that preserves row-column coordinate identities in index metadata; `melt()` is a 2D table transformation that projects data into a flat First Normal Form schema.
- **Practical Application / Syntax**: Use `stack()` when manipulating multi-level statistical summaries; use `melt()` when normalizing raw spreadsheets for database loading.
- **Nuances, Defaults & Pitfalls**: `stack()` drops `NaN`s by default; `melt()` keeps `NaN`s by default.

### Q15: How does `unstack()` differ fundamentally from `pivot()`?
- **Direct Answer & Definition**: `unstack()` operates strictly on row `MultiIndex` levels, moving a level into columns. `pivot()` operates on ordinary DataFrame columns specified by name (`index='A'`, `columns='B'`, `values='C'`).
- **Technical & Computational Reasoning**: `unstack()` assumes the data is already structured with a MultiIndex row and directly manipulates the axis layout; `pivot()` extracts data from regular columns, sets up hash tables, and reorganizes the grid.
- **Practical Application / Syntax**: `df.set_index(['A', 'B'])['C'].unstack()` is functionally identical to `df.pivot(index='A', columns='B', values='C')`.
- **Nuances, Defaults & Pitfalls**: If duplicate coordinates exist, `unstack()` raises `ValueError: Index contains duplicate entries, cannot reshape` just like `pivot()`.

### Q16: What happens if you call `unstack()` on a Series that does NOT have a MultiIndex?
- **Direct Answer & Definition**: Calling `unstack()` on a single-level indexed Series raises a `ValueError: Index must be a MultiIndex to unstack`.
- **Technical & Computational Reasoning**: A single-level Series has only one dimension (rows). Unstacking requires moving one level to columns while leaving at least one level on rows; with only one level, there is no remaining row dimension.
- **Practical Application / Syntax**: To reshape a single-level Series into a horizontal DataFrame, use `.to_frame().T`.
- **Nuances, Defaults & Pitfalls**: Beginners often attempt to call `.unstack()` on simple groupby outputs where only a single grouping column was used.

### Q17: What is the performance impact of matrix transposition (`.T`) on a DataFrame with mixed data types?
- **Direct Answer & Definition**: Transposing a DataFrame with mixed dtypes forces Pandas to consolidate all data into a single 2D NumPy array of `object` dtype, causing high memory overhead and destroying numeric vectorization.
- **Technical & Computational Reasoning**: In Pandas, columns can have different dtypes because each column is a separate array buffer in the BlockManager. Rows, however, do not have independent dtypes. When transposed, former rows become columns; because former columns had mixed types, all cells must share a single common dtype, which forces Python `object`.
- **Practical Application / Syntax**: Avoid transposing DataFrames containing mixed string and numeric columns unless performing quick terminal inspection.
- **Nuances, Defaults & Pitfalls**: Subsequent math operations on the transposed DataFrame will execute via slow Python interpreter loops rather than SIMD vector instructions.

### Q18: How do you flatten a multi-indexed DataFrame created by `unstack()` into a standard flat table?
- **Direct Answer & Definition**: Flatten the MultiIndex columns using a list comprehension: `df.columns = ['_'.join(map(str, c)) for c in df.columns]`, clear the column name `df.columns.name = None`, and call `.reset_index()`.
- **Technical & Computational Reasoning**: `unstack()` often creates MultiIndex column tuples; flattening them converts the column index into a standard single-level string index, while `.reset_index()` moves the row MultiIndex into standard columns.
- **Practical Application / Syntax**:
  ```python
  wide = s.unstack('year')
  wide.columns = [f"val_{col}" for col in wide.columns]
  wide = wide.reset_index()
  ```
- **Nuances, Defaults & Pitfalls**: If column tuples contain empty strings, clean them with `.strip('_')`.

### Q19: What does `DataFrame.unstack()` do when called on a DataFrame (not a Series)?
- **Direct Answer & Definition**: When called on a DataFrame with a MultiIndex row, `df.unstack()` moves the specified row level into columns, creating a 2-level MultiIndex on columns where Level 0 contains the original DataFrame column names and Level 1 contains the unstacked row labels.
- **Technical & Computational Reasoning**: Because the DataFrame already possessed horizontal columns, rotating an additional level from rows to columns pushes that level underneath (or above) the existing column headers, forming a hierarchical column structure.
- **Practical Application / Syntax**: `df.unstack(level='quarter')`.
- **Nuances, Defaults & Pitfalls**: This multiplies the number of columns by the number of unique labels in the unstacked level.

### Q20: Can you reverse a `stack()` operation with `unstack()`?
- **Direct Answer & Definition**: Yes, `stack()` and `unstack()` are exact inverse mathematical operations; calling `df.stack().unstack()` recovers the original DataFrame (provided `dropna=False` was used, or missing cells are restored).
- **Technical & Computational Reasoning**: `stack()` moves columns to rows; `unstack()` moves rows to columns. If `dropna=True` was used during `stack()`, cells that were originally `NaN` will remain `NaN` or be populated with `fill_value`.
- **Practical Application / Syntax**: `assert df.equals(df.stack(dropna=False).unstack())`.
- **Nuances, Defaults & Pitfalls**: If column names or index level names were modified between calls, exact metadata equality may require renaming.

### Q21: How do you choose between `unstack(0)` and `unstack(1)` on a 2-level MultiIndex Series?

### Q22: What happens if duplicate index entries exist when calling `.unstack()`?

## Phase 2: High-Yield Concepts, Pitfalls & Production Drills

### 4. Top Questions to Definitely Prepare

#### Must Know
1. **What is the inverse relationship between `DataFrame.stack()` and `Series.unstack()`?**
   - *Answer*: `stack()` rotates the innermost (or specified) column level into the innermost row index level, transforming a 2D DataFrame into a multi-indexed Series. `unstack()` is its exact mathematical inverse: it rotates a level of the row MultiIndex into horizontal column headers, expanding a multi-indexed Series back into a wide 2D DataFrame.

2. **Why does `stack()` default to `dropna=True`, and what are the consequences?**
   - *Answer*: By default, `stack()` discards all cells containing `NaN` during the rotation to keep the resulting stacked Series compact. In production, this can silently drop unobserved category combinations, changing the number of observations and potentially breaking balance in panel data unless `dropna=False` is explicitly set.

3. **What happens when you call `transpose()` (`.T`) on a DataFrame with heterogeneous data types?**
   - *Answer*: Transposing a DataFrame with mixed column types (e.g. integers, floats, and strings) forces Pandas to consolidate all data into a single 2D NumPy array of `object` dtype. This eliminates numeric vectorization, inflates memory consumption, and slows downstream computations by up to $100	imes$.

4. **Why is calling `.sort_index()` mandatory after `swaplevel()` or `reorder_levels()`?**
   - *Answer*: Swapping or reordering index levels disrupts the lexicographical sorting of the MultiIndex. Unsorted MultiIndexes cannot perform fast binary search lookups, causing Pandas to raise an `UnsortedIndexError` or emit a `PerformanceWarning` when slicing rows via `.loc[]`.

5. **How do you handle duplicate coordinates when calling `unstack()`?**
   - *Answer*: `unstack()` raises `ValueError: Index contains duplicate entries, cannot reshape` if any combination of the remaining row levels and the unstacked level appears more than once. To fix this, you must aggregate the duplicate entries (e.g. using `.groupby().sum()` or `.groupby().mean()`) prior to unstacking.

6. **How do you flatten a multi-indexed DataFrame created by unstacking for SQL or Parquet export?**
   - *Answer*: MultiIndex columns cannot be written cleanly to flat relational databases. Flatten them using a list comprehension: `df.columns = ['_'.join(map(str, c)).strip('_') for c in df.columns]`, followed by `df.columns.name = None` and `df = df.reset_index()`.

#### Good to Know
1. **What is the difference between `df.stack()` and `df.melt()`?**
   - *Answer*: `stack()` is an index/column level transformation that operates on the structural hierarchy of the DataFrame, returning a multi-indexed Series. `melt()` is a 2D table transformation that projects columns into flat rows with explicit `variable` and `value` columns while ignoring or repeating the index.

2. **How does `fill_value` in `Series.unstack()` prevent unwanted float upcasting?**
   - *Answer*: When unstacking integer data with missing Cartesian combinations, missing cells naturally default to `NaN`, which forces integer columns to upcast to `float64`. Supplying `fill_value=0` populates the gaps with integer zeros during array construction, preserving integer dtypes.

3. **What is the difference between `s.unstack(0)` and `s.unstack(1)` on a 2-level MultiIndex Series?**
   - *Answer*: `s.unstack(0)` rotates the outermost row level (level 0) into columns, leaving level 1 as rows. `s.unstack(1)` (or `level=-1`) rotates the innermost level (level 1) into columns, leaving level 0 as rows.

4. **Can you call `.T` on a Pandas `Series` to rotate it horizontally?**
   - *Answer*: No. Calling `.T` on a 1D `Series` returns the exact same Series unmodified because a Series has only one dimension. To transpose a Series into a horizontal 1-row DataFrame, you must convert it to a 2D DataFrame first: `s.to_frame().T`.

5. **How does `future_stack=True` alter `DataFrame.stack()` in modern Pandas?**
   - *Answer*: Introduced in Pandas 2.1+, `future_stack=True` enables the new PyArrow-compatible stacking engine. It provides consistent null preservation, avoids unwanted dtype downcasting, and standardizes stacking behavior in preparation for Pandas 3.0.

6. **How do you query an inner level of a stacked MultiIndex Series without unstacking?**
   - *Answer*: Use `.xs(key, level='level_name')` or index slicing: `s.loc[(slice(None), key)]`. Cross-sectional selection (`.xs()`) extracts data across the inner level without expanding the Series into a full wide matrix.

#### Bonus
1. **What is the internal memory representation of a `MultiIndex` in Pandas?**
   - *Answer*: A `MultiIndex` is stored as an array of unique level values (`levels`) and an array of integer code pointers (`codes`). When levels are swapped via `swaplevel()`, Pandas does not copy the string labels; it merely swaps the internal integer code arrays, executing in $O(1)$ time metadata manipulation.

2. **Why does `s.unstack().stack()` not always equal the original Series `s`?**
   - *Answer*: If `s` originally contained explicit `NaN` values, `unstack()` generates a matrix where missing Cartesian combinations are also `NaN`. Subsequent `.stack()` with default `dropna=True` drops all `NaN`s—including the explicit `NaN`s that were present in `s` before unstacking. Exact round-trip equality is only guaranteed if `s` had no nulls and `dropna=False` is used.

3. **How does matrix transposition (`.T`) interact with NumPy array memory strides?**
   - *Answer*: In a homogeneous 2D NumPy array, transposition simply reverses the stride tuple: $(s_{	ext{row}}, s_{	ext{col}}) ightarrow (s_{	ext{col}}, s_{	ext{row}})$, creating a zero-copy C-contiguous to Fortran-contiguous view. In Pandas 2.0+ with Copy-on-Write, this view is maintained safely until an in-place mutation triggers an atomic buffer copy.

4. **How do you optimize memory when unstacking high-cardinality grouped objects?**
   - *Answer*: Unstacking high-cardinality levels produces a massive Cartesian matrix that can exhaust memory. To optimize: (1) unstack only low-cardinality dimensions, (2) filter out zero-volume categories before unstacking, (3) downcast numeric values to `float32` or `uint16`, and (4) use SciPy sparse matrices if sparsity exceeds 95%.

### 5. Common Beginner Mistakes (10 Mistakes)

#### Mistake 1: Calling `.unstack()` on a Single-Level Series
- **Why It Happens**: Grouping by a single column and attempting to unstack, expecting it to convert to a DataFrame.
- **Correct Approach**: `unstack()` requires at least 2 index levels. For a 1-level Series, use `.to_frame().T`.
- **Example**:
  ```python
  s = pd.Series([10, 20], index=['HR', 'IT'])

  # WRONG: Raises ValueError: Index must be a MultiIndex to unstack
  # bad = s.unstack()

  # RIGHT: Convert to DataFrame and transpose
  good = s.to_frame().T
  ```

#### Mistake 2: Forgetting to Call `.sort_index()` After `swaplevel()`
- **Why It Happens**: Assuming `swaplevel()` automatically sorts the resulting index.
- **Correct Approach**: Always chain `.sort_index()` after swapping or reordering levels.
- **Example**:
  ```python
  idx = pd.MultiIndex.from_tuples([('US', 'NY'), ('US', 'CA')])
  df = pd.DataFrame({'val': [1, 2]}, index=idx)

  # WRONG: Index is unsorted! Slicing raises UnsortedIndexError
  swapped_bad = df.swaplevel(0, 1)

  # RIGHT: Chain sort_index()
  swapped_good = df.swaplevel(0, 1).sort_index()
  ```

#### Mistake 3: Unstacking with Duplicate Coordinate Entries
- **Why It Happens**: Attempting to unstack a multi-indexed DataFrame that contains duplicate index keys.
- **Correct Approach**: Aggregate duplicates using `.groupby().sum()` before unstacking.
- **Example**:
  ```python
  idx = pd.MultiIndex.from_tuples([('A', 1), ('A', 1)])
  s = pd.Series([10, 20], index=idx)

  # WRONG: ValueError: Index contains duplicate entries, cannot reshape
  # bad = s.unstack()

  # RIGHT: Group and aggregate first
  good = s.groupby(level=[0, 1]).sum().unstack()
  ```

#### Mistake 4: Calling `.T` on a Series Expecting a Horizontal DataFrame
- **Why It Happens**: Forgetting that transposing a 1D Series is a no-op that returns the Series itself.
- **Correct Approach**: Convert to DataFrame first: `s.to_frame().T`.
- **Example**:
  ```python
  s = pd.Series([1, 2, 3])

  # WRONG: Still a 1D Series!
  bad = s.T

  # RIGHT: 1x3 horizontal DataFrame
  good = s.to_frame().T
  ```

#### Mistake 5: Transposing a Heterogeneous Table and Destroying Numeric Types
- **Why It Happens**: Transposing a table with names, dates, and numbers for display, unaware that all numbers become `object` strings.
- **Correct Approach**: Do not transpose mixed-type tables for numerical processing. Use `.melt()` instead.
- **Example**:
  ```python
  df = pd.DataFrame({'name': ['Alice'], 'score': [95.5]})

  # WRONG: score is now object dtype!
  transposed = df.T
  print(transposed.dtypes[0])  # object!
  ```

#### Mistake 6: Unnoticed Row Loss from `stack()`'s Default `dropna=True`
- **Why It Happens**: Forgetting that `stack()` silently drops all `NaN` cells by default.
- **Correct Approach**: Pass `dropna=False` if you need to retain all combinations in the index.
- **Example**:
  ```python
  df = pd.DataFrame({'A': [10, None], 'B': [None, 20]}, index=['r1', 'r2'])

  # WRONG: Silently drops half the grid cells!
  bad = df.stack()  # length 2

  # RIGHT: Preserves complete grid
  good = df.stack(dropna=False)  # length 4
  ```

#### Mistake 7: Unstacking High-Cardinality Dimensions Causing Memory Crashes
- **Why It Happens**: Calling `.unstack('timestamp')` or `.unstack('user_id')`, creating hundreds of thousands of columns.
- **Correct Approach**: Only unstack low-cardinality categorical dimensions (e.g. quarters, categories, segments).
- **Example**:
  ```python
  # WRONG: 50,000 users create 50,000 columns -> OutOfMemoryError!
  # s.unstack('user_id')

  # RIGHT: Keep high cardinality on rows, unstack low cardinality
  s.unstack('quarter')
  ```

#### Mistake 8: Hardcoding Positional Levels (`level=1`) Instead of Level Names
- **Why It Happens**: Using integer index positions (`level=1`) that break when upstream groupby keys are modified.
- **Correct Approach**: Always reference index levels by explicit string names.
- **Example**:
  ```python
  # WRONG: Fragile to schema changes
  # s.unstack(1)

  # RIGHT: Robust and self-documenting
  s.unstack('year')
  ```

#### Mistake 9: Forgetting `fill_value=0` and Generating Unwanted NaNs During Unstack
- **Why It Happens**: Forgetting that missing Cartesian combinations in `unstack()` default to `NaN`.
- **Correct Approach**: Supply `fill_value=0` when missing combinations represent zero counts or zero spend.
- **Example**:
  ```python
  # RIGHT: Missing combinations are 0 instead of NaN
  wide = s.unstack(fill_value=0)
  ```

#### Mistake 10: Exporting MultiIndex Columns Directly to CSV/SQL Without Flattening
- **Why It Happens**: Exporting the output of `unstack()` directly to CSV, producing mangled multi-line headers.
- **Correct Approach**: Flatten column tuples with a list comprehension before export.
- **Example**:
  ```python
  unstacked = df.unstack()

  # RIGHT: Flatten headers
  unstacked.columns = ['_'.join(map(str, c)) for c in unstacked.columns]
  unstacked.columns.name = None
  unstacked = unstacked.reset_index()
  ```

### 6. Section-Adaptive Pandas API Confusions

#### Confusion 1: `DataFrame.stack()` vs `DataFrame.melt()`
| Dimension | `DataFrame.stack()` | `DataFrame.melt()` |
| :--- | :--- | :--- |
| **Operational Basis** | Column Index levels (hierarchical rotation) | Column names (2D projection) |
| **Output Type** | MultiIndex `Series` (or multi-level DataFrame) | Flat `DataFrame` with `[variable, value]` |
| **Index Handling** | Replaces/modifies row index hierarchy | Drops or duplicates original index |
| **Missing Values** | Drops `NaN`s by default (`dropna=True`) | Keeps `NaN`s by default |
| **Primary Use Case** | OLAP multi-level data cubes & statistical outputs | Tidy 1NF normalization for SQL/BI databases |

```python
import pandas as pd

df = pd.DataFrame({'Q1': [100], 'Q2': [200]}, index=['StoreA'])

# stack(): Returns MultiIndex Series
print(df.stack())
# StoreA  Q1    100
#         Q2    200
# dtype: int64

# melt(): Returns flat DataFrame
print(df.reset_index().melt(id_vars='index'))
#     index variable  value
# 0  StoreA       Q1    100
# 1  StoreA       Q2    200
```

#### Confusion 2: `DataFrame.unstack()` vs `DataFrame.pivot()`
| Dimension | `Series.unstack()` | `DataFrame.pivot()` |
| :--- | :--- | :--- |
| **Input Structure** | Requires a `MultiIndex` row index | Requires regular flat DataFrame columns |
| **Invocation** | Method on multi-indexed Series/DataFrame | Method on flat DataFrame with column arguments |
| **Missing Intersections** | Supported via `fill_value` | No `fill_value` parameter |
| **Duplicate Keys** | Raises `ValueError: duplicate entries` | Raises `ValueError: duplicate entries` |
| **Primary Use Case** | Reshaping after `.groupby()` aggregations | Pivoting flat tabular extracts |

```python
import pandas as pd

# unstack on MultiIndex
idx = pd.MultiIndex.from_tuples([('A', 'x'), ('B', 'y')])
s = pd.Series([10, 20], index=idx)
print(s.unstack(fill_value=0))

# pivot on flat table
flat = s.reset_index(name='val')
print(flat.pivot(index='level_0', columns='level_1', values='val').fillna(0))
# Both produce identical wide grids!
```

#### Confusion 3: `DataFrame.transpose()` (`.T`) vs `DataFrame.unstack()`
| Dimension | `DataFrame.transpose()` (`.T`) | `DataFrame.unstack()` |
| :--- | :--- | :--- |
| **Axis Transformation** | Swaps entire row index with entire column index | Moves only 1 specified level from rows to columns |
| **Shape Modification** | $(M, N) ightarrow (N, M)$ | $(M, K) ightarrow (M / U, K 	imes U)$ |
| **Dtype Impact** | Forces upcast to `object` if columns had mixed types | Preserves column dtypes per unstacked variable |
| **MultiIndex Requirement** | Works on standard flat or MultiIndex tables | Requires row `MultiIndex` |
| **Primary Use Case** | Rotating metric tables or quick inspection | Dimensional rotation in OLAP cubes |

```python
import pandas as pd

idx = pd.MultiIndex.from_tuples([('A', 1), ('A', 2)])
df = pd.DataFrame({'val': [10, 20]}, index=idx)

# unstack: rotates level 1 into columns
print(df.unstack())
#     val    
#       1   2
# A    10  20

# transpose: swaps index and columns entirely
print(df.T)
#      A    
#      1   2
# val 10  20
```

#### Confusion 4: `stack(dropna=True)` vs `stack(dropna=False)`
| Dimension | `stack(dropna=True)` (Default) | `stack(dropna=False)` |
| :--- | :--- | :--- |
| **Missing Values** | Dropped automatically | Retained as explicit `NaN`s in the Series |
| **Output Length** | Equal to count of non-null cells | Equal to full Cartesian grid ($N_{	ext{rows}} 	imes K_{	ext{cols}}$) |
| **Memory Efficiency** | High (sparse representation) | Lower (materializes empty combinations) |
| **Panel Balance** | Unbalanced panel | Balanced panel across all categories |
| **Round-Trip Fidelity** | Loses original `NaN` records | Lossless round-trip with `unstack()` |

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({'A': [1.0, np.nan], 'B': [np.nan, 2.0]})

# dropna=True: length 2
print(len(df.stack(dropna=True)))  # 2

# dropna=False: length 4
print(len(df.stack(dropna=False))) # 4
```

### 7. Interview Traps (10 Traps)

#### Trap 1: The "Series Transposition No-Op" Trap
- **Trap Question**: "You have a Series `s` of length 5. You call `s.T`. What is the shape of the output?"
- **Naive Answer**: "`(1, 5)` because transposing a column vector creates a row vector."
- **Trap Unveiled**: A Pandas `Series` is strictly 1-dimensional with shape `(5,)`. Transposing a 1D array does not alter its shape; `s.T` returns `s` unchanged.
- **Winning Staff-Level Response**: "In Pandas, a Series is a 1-dimensional data structure with shape `(5,)`. Unlike 2D matrices, transposing a 1D array is a no-op that returns the identical Series object. To transform a Series into a 2D horizontal row vector with shape `(1, 5)`, you must first expand its dimensions via `s.to_frame().T`."

#### Trap 2: The "Heterogeneous Transpose Object Degradation" Trap
- **Trap Question**: "You transpose a DataFrame containing customer `id` (int), `name` (string), and `balance` (float). Why did all numerical operations on the transposed table suddenly become 100x slower?"
- **Naive Answer**: "Transposition causes memory fragmentation in Pandas."
- **Trap Unveiled**: Pandas columns are stored in independent homogeneous memory blocks. Transposing mixes the three distinct types across rows; because former rows become columns, all cells in the transposed DataFrame must be upcast to a single common supertype: Python `object`.
- **Winning Staff-Level Response**: "In Pandas, data type homogeneity is enforced along columns, not rows. When you transpose a DataFrame with mixed dtypes, former rows become columns. Because each new column now contains a string, an integer, and a float, Pandas must coerce the entire DataFrame into a single 2D NumPy array of `object` dtype. All subsequent calculations run via un-vectorized Python interpreter loops rather than compiled SIMD C routines."

#### Trap 3: The "Unsorted MultiIndex Slicing Crash" Trap
- **Trap Question**: "You call `df.swaplevel(0, 1)` to invert your index hierarchy. Then you call `df.loc['CA':'NY']` and get an `UnsortedIndexError`. Why did it crash?"
- **Naive Answer**: "There is a bug in `swaplevel()` that corrupts index pointers."
- **Trap Unveiled**: `swaplevel()` inverts index level positions in metadata without sorting the values. Range slicing with `.loc[]` requires the MultiIndex to be lexicographically sorted.
- **Winning Staff-Level Response**: "`swaplevel()` merely alters level order in the index tuple metadata without rearranging the rows into sorted order. Slicing an index range via `.loc[]` relies on binary search algorithms that strictly require lexicographical sortedness. #### Trap 5: The "Duplicate Index Crash in `unstack()`" Trap

- **Winning Staff-Level Response**: "`unstack()` requires that every combination of the remaining index levels and the unstacked level uniquely maps to a single scalar value. #### Trap 8: The "Unstack Fill Value Type Invariant" Trap

- **Winning Staff-Level Response**: "Yes, it is guaranteed to remain integer. In Pandas, integer columns upcast to `float64` strictly because standard NumPy integers cannot represent `NaN`. #### Trap 9: The "Positional Level Fragility" Trap
- **Trap Question**: "Why is `df.unstack(level=1)` considered an anti-pattern in production data engineering pipelines?"

#### Trap 10: The "Round-Trip Identity Loss" Trap

- **Winning Staff-Level Response**: "`stack()` drops missing cells by default (`dropna=True`). #### Question 2
- **Problem Statement**: Slicing an index range on a swapped MultiIndex crashes with `UnsortedIndexError`.
- **Incorrect / Buggy Code**:
  ```python
  import pandas as pd

  idx = pd.MultiIndex.from_tuples([('US', 'NY'), ('US', 'CA'), ('UK', 'LON')], names=['country', 'city'])
  df = pd.DataFrame({'val': [1, 2, 3]}, index=idx)

  # Swapped but unsorted!
  swapped = df.swaplevel('country', 'city')
  # Crashes with UnsortedIndexError!
  sub = swapped.loc['CA':'NY']
  ```
- **Expected Behavior**: Clean selection of cities from `'CA'` to `'NY'`.
- **Corrected Code**:
  ```python
  swapped = df.swaplevel('country', 'city').sort_index()
  sub = swapped.loc['CA':'NY']
  ```
- **Root Cause Analysis**: `swaplevel()` inverts level order in metadata without sorting rows. Range slicing with `.loc[]` requires lexicographical sortedness. Chaining `.sort_index()` restores sortedness and enables slicing.

#### Question 3
- **Problem Statement**: A developer calls `.unstack()` on a single-level Series and gets `ValueError`.
- **Incorrect / Buggy Code**:
  ```python
  import pandas as pd

  s = pd.Series([100, 200], index=['Store_A', 'Store_B'])
  # Crashes with ValueError: Index must be a MultiIndex to unstack!
  wide = s.unstack()
  ```
- **Expected Behavior**: A 1-row DataFrame with stores as columns.
- **Corrected Code**:
  ```python
  wide = s.to_frame().T
  ```
- **Root Cause Analysis**: `unstack()` operates strictly on MultiIndex hierarchies (requires $\ge 2$ levels). To rotate a 1D single-level Series into a horizontal DataFrame row, convert to DataFrame and transpose.

#### Question 4
- **Problem Statement**: Stacking a wide inventory table silently drops 50% of the SKUs from the resulting Series.
- **Incorrect / Buggy Code**:
  ```python
  import pandas as pd
  import numpy as np

  inv = pd.DataFrame({'Loc1': [10, np.nan], 'Loc2': [np.nan, 20]}, index=['SKU_A', 'SKU_B'])
  # Drops all cells containing NaN!
  stacked = inv.stack()
  ```
- **Expected Behavior**: Preserve all SKU-location combinations, filling missing stock with 0.
- **Corrected Code**:
  ```python
  stacked = inv.stack(dropna=False).fillna(0)
  ```
- **Root Cause Analysis**: `DataFrame.stack()` defaults to `dropna=True`, silently dropping all rows where cells were `NaN`. Passing `dropna=False` preserves all Cartesian coordinates.

### 12. Rapid-Fire Questions (20 Q&As)

1. **Q: What is the primary operational effect of `DataFrame.stack()`?**
   - **A**: It rotates column headers into the row index hierarchy, transforming a 2D DataFrame into a multi-indexed Series (or a DataFrame with fewer column levels).

2. **Q: What is the primary operational effect of `Series.unstack()`?**
   - **A**: It rotates a specified level of the row MultiIndex into horizontal column headers, transforming a hierarchical Series into a wide 2D DataFrame.

3. **Q: What is the default level rotated by `stack()` and `unstack()`?**
   - **A**: `level=-1`, which corresponds to the innermost (deepest) hierarchy level.

4. **Q: What does `dropna=True` do in `DataFrame.stack()`?**
   - **A**: Automatically drops all rows in the resulting stacked Series where cell values were `NaN`.

5. **Q: What does `fill_value` do in `Series.unstack()`?**
   - **A**: Imputes a replacement scalar into unobserved Cartesian coordinate combinations instead of inserting `NaN`.

6. **Q: What happens if you call `unstack()` on a Series with a single-level index?**
   - **A**: It raises `ValueError: Index must be a MultiIndex to unstack`.

7. **Q: What happens if you call `.T` on a 1D Pandas Series?**
   - **A**: Nothing; transposing a 1D Series is a no-op that returns the exact same Series unmodified.

8. **Q: How do you transpose a Series into a horizontal 1-row DataFrame?**
   - **A**: Call `s.to_frame().T`.

9. **Q: What happens to data types when transposing a DataFrame with mixed dtypes?**
   - **A**: All columns in the transposed DataFrame are upcast to the common supertype, typically Python `object`.

10. **Q: What error is raised if `unstack()` encounters duplicate index keys?**
    - **A**: `ValueError: Index contains duplicate entries, cannot reshape`.

11. **Q: What method swaps two levels in a MultiIndex without altering data?**
    - **A**: `df.swaplevel(i, j, axis=0)`.

12. **Q: Why must you call `.sort_index()` after `swaplevel()`?**
    - **A**: To restore lexicographical sortedness, enabling fast binary search slicing and preventing `UnsortedIndexError`.

13. **Q: What method rearranges 3 or more MultiIndex levels in a custom order?**
    - **A**: `df.reorder_levels(order, axis=0)`.

14. **Q: Can you unstack multiple row levels simultaneously?**
    - **A**: Yes, by passing a list of levels (e.g. `s.unstack(['year', 'quarter'])`), which creates MultiIndex columns.

15. **Q: How do you select data from an inner level of a stacked Series without unstacking?**
    - **A**: Use the cross-section method: `s.xs(key, level='level_name')`.

16. **Q: What is the difference between `df.stack()` and `df.melt()`?**
    - **A**: `stack()` rotates column levels into index hierarchies (returning a Series); `melt()` unpivots columns into flat rows with user-named columns.

17. **Q: How do you flatten MultiIndex columns created by `unstack()`?**
    - **A**: `df.columns = ['_'.join(map(str, c)) for c in df.columns]`, followed by `.reset_index()`.

18. **Q: Does `DataFrame.transpose()` modify data in place?**
    - **A**: No, it returns a new DataFrame (or a strided view under Copy-on-Write) without modifying the original.

19. **Q: What does `future_stack=True` do in Pandas 2.1+?**
    - **A**: Enables the modern ExtensionArray/PyArrow stacking engine, standardizing null preservation and preventing downcasting.

20. **Q: Is `df.stack().unstack()` always guaranteed to equal `df`?**
    - **A**: No; if `df` had `NaN`s, default `dropna=True` in `stack()` permanently drops them unless `dropna=False` is passed.

#### Card 1
- **Front**: Inverse relationship between `stack()` and `unstack()`?
- **Back**: `stack()` moves column levels into the row MultiIndex (wide $ightarrow$ long). `unstack()` moves row MultiIndex levels into column headers (long $ightarrow$ wide).

#### Card 4
- **Front**: Why does transposing mixed-dtype DataFrames degrade performance?
- **Back**: Column-wise dtypes are converted to rows. To store mixed strings, integers, and floats across former rows, Pandas forces all cells into a 2D array of `object` dtype.

#### Card 5
- **Front**: What causes `UnsortedIndexError` after calling `df.swaplevel()`?
- **Back**: `swaplevel()` changes level order in metadata without physically sorting rows. Slicing with `.loc[]` requires lexicographical order. Always chain `.sort_index()`.

#### Card 6
- **Front**: What causes `ValueError: Index contains duplicate entries, cannot reshape` in `unstack()`?
- **Back**: The combination of the remaining row levels and the unstacked level is non-unique. Pandas cannot place two conflicting values in one cell. Fix with `.groupby().sum()`.

#### Card 7
- **Front**: How does `Series.unstack()` differ from `DataFrame.pivot()`?
- **Back**: `unstack()` operates on row `MultiIndex` levels. `pivot()` operates on regular DataFrame columns specified by name.

#### Card 8
- **Front**: How does `DataFrame.stack()` differ from `DataFrame.melt()`?
- **Back**: `stack()` operates on index/column levels, returning a MultiIndex Series. `melt()` unpivots columns into flat rows with explicit `[variable, value]` columns.

#### Card 9
- **Front**: How do you prevent integer columns from upcasting to `float64` during `unstack()`?
- **Back**: Pass `fill_value=0`. This populates missing Cartesian combinations with integer zeros, preventing `NaN` injection.

#### Card 10
- **Front**: How do you extract an inner level from a stacked Series without unstacking?
- **Back**: Use `.xs(key, level='level_name')` or `.loc[(slice(None), key)]`.

#### Card 11
- **Front**: What happens when you call `unstack()` on a DataFrame with existing columns?
- **Back**: The unstacked row level becomes an inner level on the column MultiIndex, multiplying total columns by the number of unstacked categories.

#### Card 12
- **Front**: What does `df.reorder_levels(order, axis=0)` do?
- **Back**: Re-arranges all levels of a MultiIndex into a specified sequence of names or integer positions in a single call.

#### Card 13

- **Back**: `df.columns = ['_'.join(map(str, c)).strip('_') for c in df.columns]`, followed by `df.columns.name = None` and `df = df.reset_index()`.

- **Back**: `level=-1` (the innermost, deepest hierarchy level).

### 14. Section-Specific Pandas Interview Cheat Sheet

#### Core Methods & Signatures
| Method / Signature | Primary Use Case | Output Structure |
| :--- | :--- | :--- |
| `df.stack(level=-1, dropna=True)` | Rotates columns to row index | MultiIndex `Series` or `DataFrame` |
| `s.unstack(level=-1, fill_value=None)` | Rotates row index level to columns | Wide 2D `DataFrame` |
| `df.transpose()` or `df.T` | Swaps row index and column headers | $(N, M) ightarrow (M, N)$ `DataFrame` |
| `s.to_frame().T` | Transposes 1D Series to 1-row DataFrame | $(1, N)$ `DataFrame` |
| `df.swaplevel(i, j, axis=0)` | Swaps two levels in MultiIndex | Reordered `DataFrame` (needs sorting) |
| `df.reorder_levels(order, axis=0)` | Rearranges 3+ MultiIndex levels | Reordered `DataFrame` |
| `df.sort_index(level=...)` | Sorts MultiIndex lexicographically | Sorted `DataFrame` (enables binary search) |

#### Crucial Parameters
| Parameter | Method | Default | Effect & Purpose |
| :--- | :--- | :--- | :--- |
| `level` | `stack` / `unstack` | `-1` | Level index (int) or name (str) to rotate. Supports lists for multi-level. |
| `dropna` | `stack` | `True` | If `True`, omits rows with `NaN` in stacked level. Set `False` for complete panels. |
| `fill_value` | `unstack` | `None` | Imputes replacement scalar (e.g. `0`) into missing Cartesian intersections. |
| `axis` | `swaplevel` | `0` | `0` for row index, `1` for column MultiIndex. |
| `sort` | `stack` / `unstack` | `True` | Sorts the resulting MultiIndex levels lexicographically. |

#### MultiIndex Column Flattening Checklist
```python
# 1. Flatten tuple headers into snake_case strings
df.columns = ['_'.join(map(str, c)).strip('_') for c in df.columns]
# 2. Clear column hierarchy title
df.columns.name = None
# 3. Reset row MultiIndex into standard columns
df = df.reset_index()
```

#### Primary Anti-Patterns
| Anti-Pattern | Fatal Flaw | Modern Production Alternative |
| :--- | :--- | :--- |
| `s.unstack()` on 1-level Series | Crashes with `ValueError` | `s.to_frame().T` |
| `s.T` to transpose a Series | No-op; returns 1D Series unchanged | `s.to_frame().T` |
| Transposing mixed-type tables | Upcasts numbers to slow `object` strings | Keep orientation or use `.melt()` |
| `swaplevel()` without `sort_index()` | Slicing raises `UnsortedIndexError` | `df.swaplevel(0, 1).sort_index()` |
| Positional levels (`level=1`) | Brittle; breaks when groupby keys change | Reference explicit names (`level='year'`) |

### 15. Fresher Answer Evolution Patterns

#### Pattern 1: Unstacking Groupby Outputs
- **Question**: "You grouped by `['region', 'year']` and summed revenue. How do you reshape this so regions are rows and years are columns?"
- **Weak Fresher Answer**: "I would reset the index and then call `df.pivot()`."
- **Interviewer Critique**: "Verbose, inefficient, and shows ignorance of MultiIndex capabilities. Resetting index and calling `pivot()` incurs unnecessary hash table rebuilds."
- **Strong Winning Answer**: "Since the output of `df.groupby(['region', 'year'])['revenue'].sum()` is already a MultiIndex Series, I directly call `.unstack('year', fill_value=0.0)`. This rotates `'year'` from the row index into columns in a single vectorized pass, fills unobserved region-year combinations with 0, and avoids the memory overhead of resetting and re-pivoting."

#### Pattern 2: Transposing Series
- **Question**: "How do you append a calculated Series of summary statistics as a new horizontal row to a DataFrame?"
- **Weak Fresher Answer**: "I would call `df.append(s.T)`."
- **Interviewer Critique**: "Two major bugs: `df.append()` is deprecated and removed in Pandas 2.0+, and calling `.T` on a 1D Series does nothing."
- **Strong Winning Answer**: "Calling `.T` on a Series is a no-op because a Series is 1-dimensional. To transpose it into a horizontal row, I call `s.to_frame().T`. Then, to combine it with the DataFrame, I use modern `pd.concat([df, s.to_frame().T], ignore_index=True)`."

#### Pattern 3: Unsorted MultiIndex Slicing
- **Question**: "You swapped two index levels and tried to slice `.loc['A':'C']`, but got an `UnsortedIndexError`. Why did it happen and how do you fix it?"
- **Weak Fresher Answer**: "Pandas couldn't find the labels, so I should convert the index to a list and loop through it."
- **Interviewer Critique**: "Fails to understand binary search mechanics on sorted indices."
- **Strong Winning Answer**: "`swaplevel()` inverts level order in metadata without physically sorting the underlying rows. Pandas relies on lexicographically sorted MultiIndexes to perform fast binary search range slicing. To fix this, I simply chain `.sort_index()` immediately after `swaplevel()`, which restores sortedness and enables fast $O(\log N)$ slicing."

#### Pattern 4: Stacking Sparse Wide Tables
- **Question**: "You have a 1,000-column wide matrix with 90% missing values. You need to convert it into a key-value format. What method do you choose and why?"
- **Weak Fresher Answer**: "I would use `df.melt()` because it's the standard unpivoting tool."
- **Interviewer Critique**: "Fails to consider memory efficiency. `melt()` retains all 90% `NaN`s by default, creating millions of useless rows."
- **Strong Winning Answer**: "I would choose `df.stack(dropna=True)`. Unlike `melt()` which materializes all null cells into rows unless explicitly filtered, `stack()` automatically drops `NaN`s by default. On a 90% sparse matrix, `stack()` immediately eliminates 90% of redundant cells in compiled C, producing a compact multi-indexed Series that uses a fraction of the memory."

### 16. Questions That Test Understanding (Perturbations)

#### Perturbation 1: `dropna=True` vs `dropna=False` in `stack()`
- **Baseline**: `df.stack(dropna=True)` on a $2 	imes 2$ grid with 2 valid values and 2 NaNs. Output length is 2.
- **Perturbation**: Change parameter to `dropna=False`.
- **Candidate Analysis**: Output length becomes 4. Unobserved cells are explicitly retained as `NaN` in the Series. Demonstrates knowledge of how `dropna` governs sparsity in stacked output.

#### Perturbation 2: `unstack(0)` vs `unstack(1)` on 2-Level MultiIndex
- **Baseline**: `s.unstack(1)` where index is `(store, product)`. Rows are `store`, columns are `product`.
- **Perturbation**: Change to `s.unstack(0)`.
- **Candidate Analysis**: Level 0 (`store`) rotates into columns, leaving `product` as the row index. The table orientation is inverted. Proves understanding of directional level targeting.

#### Perturbation 3: Calling `.T` on Homogeneous vs Heterogeneous DataFrames
- **Baseline**: `df.T` on a table of all `float64` values. Result preserves `float64` dtype with zero-copy strided view.
- **Perturbation**: Add a single string column (`name`) to `df` before transposing.
- **Candidate Analysis**: All columns in the transposed DataFrame are immediately coerced to `object` dtype, disabling C-level vectorization and ballooning memory. Shows understanding of row-versus-column typing invariants.

#### Perturbation 4: Calling `unstack()` with Duplicate Keys
- **Baseline**: `s.unstack()` on a uniquely indexed MultiIndex executes cleanly.
- **Perturbation**: Duplicate an index coordinate `('A', 1)`.
- **Candidate Analysis**: The call crashes with `ValueError: Index contains duplicate entries, cannot reshape`. Demonstrates understanding that `unstack()` requires 1-to-1 coordinate uniqueness.

#### Perturbation 5: Slicing Sorted vs Unsorted MultiIndex
- **Baseline**: `df.sort_index().loc['A':'C']` slices rows cleanly in $O(\log N)$ time.
- **Perturbation**: Remove `.sort_index()` after `df.swaplevel()`.
- **Candidate Analysis**: Raises `UnsortedIndexError` because binary search algorithms fail on non-monotonic index sequences. Proves understanding of MultiIndex physical layout.

  def build_ad_features(ad_logs: pd.DataFrame) -> pd.DataFrame:
      grouped = ad_logs.groupby(['user_id', 'ad_format'])[['impressions', 'clicks']].agg(['mean', 'sum'])
      unstacked = grouped.unstack('ad_format', fill_value=0.0)

  import pandas as pd

  def harmonize_icu_vitals(raw_vitals: pd.DataFrame) -> pd.DataFrame:
      raw_vitals['time_5m'] = pd.to_datetime(raw_vitals['timestamp']).dt.floor('5min')

      grid = (
          raw_vitals
          .groupby(['patient_id', 'time_5m', 'vital_name'])['reading']

          .unstack('vital_name')

### 18. Cross-Concept Bridges

#### NumPy Bridge
- **2D Strided Transposition**: On homogeneous numeric DataFrames, `.T` operates as a zero-copy strided view over the underlying 2D NumPy array buffer.
- **Contiguity Transformation**: Transposing a C-contiguous array converts it into a Fortran-contiguous array, altering cache-line prefetching behavior during downstream matrix operations.
- **Array Flattening**: `stack()` flattens 2D memory blocks into 1D contiguous arrays while indexing via dictionary-encoded codes.

#### SQL Bridge
- **`PIVOT` vs `UNPIVOT`**: `unstack()` corresponds to SQL `PIVOT` (rotating rows to columns). `stack()` corresponds to SQL `UNPIVOT` (rotating columns to rows).
- **Matrix Transposition in SQL**: Transposing arbitrary tables in SQL requires complex dynamic SQL scripts using conditional aggregation (`MAX(CASE WHEN ...)`) across every single row. In Pandas, it is a single operation (`df.T`).

#### Scikit-Learn Bridge
- **Feature Extraction Pipelines**: Machine learning models require 2D arrays `(n_samples, n_features)`. `unstack()` converts relational multi-index groupby aggregations into wide feature matrices ready for `X_train`.
- **Classification Report Transposition**: `sklearn.metrics.classification_report(output_dict=True)` returns a nested dictionary; converting to DataFrame and calling `.T` produces standard reporting tables for model cards.

#### Python Standard Library Bridge
- **Tuple Keys**: A `MultiIndex` is a vectorized abstraction over Python tuples: `{(k1, k2): val}`.
- **`zip()` and Transposition**: In native Python, transposing a list of lists is implemented via `list(zip(*matrix))`. In Pandas, `df.T` executes this across optimized C array blocks.

### 24. Final 2-Minute Revision Summary

#### Core Concepts
- `DataFrame.stack()` rotates columns into the row MultiIndex (wide $ightarrow$ long). Defaults to `dropna=True` and `level=-1`.
- `Series.unstack()` rotates a row MultiIndex level into column headers (long $ightarrow$ wide). Requires a MultiIndex ($\ge 2$ levels).
- Calling `.T` on a 1D Series is a no-op; use `s.to_frame().T` to create a 1-row DataFrame.
- Transposing mixed-type tables forces all data to `object` dtype, destroying performance.
- ALWAYS chain `.sort_index()` after `swaplevel()` or `reorder_levels()` to enable binary search slicing.

#### Top 5 Traps to Dodge
1. **The Series Transpose Trap**: Calling `s.T` and expecting a 2D DataFrame instead of `s.to_frame().T`.
2. **The Unsorted MultiIndex Crash**: Forgetting `.sort_index()` after `swaplevel()`, causing `UnsortedIndexError`.
3. **The Silent NaN Drop**: Stacking sparse tables without realizing `dropna=True` drops missing observations.
4. **The Heterogeneous Transpose**: Transposing mixed tables and accidentally degrading numbers into `object` strings.
5. **The Duplicate Unstack Crash**: Unstacking non-unique indices instead of aggregating with `.groupby().sum()`.

#### Must-Know Production Code Template
```python
import pandas as pd

# Production Groupby + Unstack + Flatten Pipeline
summary = (
    df
    .groupby(['customer_id', 'product_category'])['spend']
    .sum()
    .unstack('product_category', fill_value=0.0)
)
summary.columns = [f"spend_{c}" for c in summary.columns]
summary.columns.name = None
feature_matrix = summary.reset_index()
```
