# Section: 4.3 Boolean Indexing (Conditional Filtering, Combining Conditions, Boolean Masks)

---

## 1. Section Overview

Boolean indexing (also known as logical masking or conditional filtering) is the cornerstone of declarative data selection, outlier rejection, thresholding, and conditional mutation in NumPy. It allows machine learning engineers and data analysts to extract and update elements based on arbitrary logical predicates without writing slow, imperative Python loops.

Under the hood, boolean indexing belongs to NumPy's **advanced indexing** category:
1. **Conditional Filtering**: Evaluating an expression like `arr > 0` returns a boolean array of matching shape where each entry is `True` or `False`. Indexing with this boolean mask (`arr[arr > 0]`) extracts all matching elements into a **flat 1-dimensional array copy**.
2. **Combining Conditions**: Logical combinations require bitwise operators (`&` for AND, `|` for OR, `~` for NOT, `^` for XOR). Because Python's comparison operators (`>`, `<`, `==`) have lower operator precedence than bitwise operators, each conditional clause must be enclosed in parentheses: `(arr > 0) & (arr < 10)`. The Python keywords `and`, `or`, and `not` operate on the truth value of entire objects and cannot be used for element-wise array operations.
3. **Boolean Masks & Masked Mutation**: A boolean mask can be used for extraction (which allocates a new 1D copy on the heap) or for in-place assignment (`arr[mask] = val`), which writes directly to the selected memory locations in place without altering the shape of the original array. Functions like `np.where()`, `np.nonzero()`, and `np.select()` provide alternative control-flow primitives.

Understanding boolean indexing mechanics is essential for preventing operator precedence syntax crashes, avoiding accidental truth-value evaluation exceptions (`ValueError: The truth value of an array with more than one element is ambiguous`), and optimizing data cleaning pipelines.

## 2. Topic-Wise Interview Concepts

### 2.1 Conditional Filtering & Advanced Indexing Mechanics
When an array is evaluated against a scalar condition, NumPy executes a vectorized comparison loop in C, returning a boolean array of identical shape with `dtype=bool` (1 byte per boolean).

```
Input Array: Shape (2, 3), dtype int32
[ [ -5,  10,   0 ],
  [ 25, -12,  30 ] ]

Condition: mask = arr > 0
[ [ False,  True, False ],
  [  True, False,  True ] ]

Extraction: filtered = arr[mask]
Step 1: NumPy scans mask for True entries (count = 3).
Step 2: Heap allocates a brand-new 1D buffer of size 3 * 4 = 12 bytes.
Step 3: Copies matching elements into the new buffer: [ 10, 25, 30 ].
Step 4: Returns a 1D ndarray copy (filtered.base is None).
Output is ALWAYS 1D, even when input is multidimensional!
```

Key technical aspects:
- **Shape Collapse to 1D**: Because the number of elements satisfying a boolean condition is unpredictable and varies across rows and columns, a multidimensional tensor cannot generally retain a rectangular shape after filtering. Therefore, boolean indexing always flattens selected elements into a 1-dimensional array.
- **Copy Guarantee**: Extracting elements via a boolean mask **always allocates a new copy** on the heap ($O(N)$ time and memory). It is never a view.
- **Shape Matching**: The boolean mask's shape must match the target array's shape (or be broadcastable to it). A shape mismatch raises `IndexError: boolean index did not match indexed array along dimension X`.

### 2.2 Combining Conditions & Operator Precedence
In Python, logical operations across boolean arrays require bitwise operators.

```
+-------------------------------------------------------------------------------+
| Python Operator     | Array Operation         | Precedence Hazard             |
+---------------------+-------------------------+-------------------------------+
| `&` (Bitwise AND)   | Element-wise logical AND| HIGHER than `<`, `>`, `==`    |
| `|` (Bitwise OR)    | Element-wise logical OR | HIGHER than `<`, `>`, `==`    |
| `~` (Bitwise NOT)   | Element-wise inversion  | HIGHER than comparison        |
| `^` (Bitwise XOR)   | Element-wise XOR        | HIGHER than comparison        |
| `and`, `or`, `not`  | Object truth evaluation | FAILS on arrays (raises       |
|                     |                         | ValueError: ambiguous)        |
+-------------------------------------------------------------------------------+

Why Parentheses Are Mandatory:
Expression: arr > 0 & arr < 10
Python parses as: arr > (0 & arr) < 10  (because & binds tighter than >)
Result: Evaluates 0 & arr first, then produces chained comparison error!

Correct Syntax: (arr > 0) & (arr < 10)
```

### 2.3 Masked Assignment vs. Extraction
A major distinction exists between extracting elements with a mask and assigning to them in place.

```
================================================================================
Extraction: sub = arr[mask]                     Assignment: arr[mask] = 0
================================================================================
1. Evaluates mask.                             1. Evaluates mask.
2. Allocates brand NEW 1D array on heap.       2. Modifies arr IN PLACE.
3. Copies matching elements.                   3. Overwrites matching memory slots.
4. Returns new array; arr is untouched.        4. Original array shape is PRESERVED!
5. sub.base is None (independent copy).        5. Zero new array allocation.
================================================================================
```

### 2.4 Control-Flow Alternatives: `np.where()`, `np.nonzero()`, and `np.select()`
NumPy provides vectorized branching primitives that complement boolean indexing:
- `np.where(condition, x, y)`: Vectorized ternary operator: returns $x$ where condition is `True`, and $y$ where `False`. Preserves the shape of the input array.
- `np.nonzero(condition)`: Returns a tuple of 1D coordinate arrays representing the indices of all non-zero/True elements.
- `np.select(condlist, choicelist, default)`: Vectorized multi-branch `if-elif-else` evaluation.

## 3. Fresher Interview Questions

### 3.A Basic Interview Questions (20 Questions)

#### Q1: What is boolean indexing in NumPy, and what does it return?
- **Definition**: Boolean indexing selects elements from an array using a boolean array (mask) of the same shape, where elements corresponding to `True` are retained and elements corresponding to `False` are discarded.
- **Technical & Memory Mechanics**: Under the hood, boolean indexing invokes advanced indexing. NumPy scans the boolean mask to count the number of `True` entries ($K$), allocates a new contiguous 1D memory buffer of size $K \times \text{itemsize}$ on the heap, copies the matching elements into it, and returns an independent 1D `ndarray` instance whose `.base` is `None`.
- **Code Example**:
```python
import numpy as np

arr = np.array([[10, -5, 20],
                [-1, 30, -8]])

mask = arr > 0
positive_vals = arr[mask]

print("Mask:\n", mask)
print("Extracted 1D array:", positive_vals)
print("Is independent copy:", positive_vals.base is None)
# Output:
# Mask:
#  [[ True False  True]
#  [False  True False]]
# Extracted 1D array: [10 20 30]
# Is independent copy: True
```
- **Nuances & Pitfalls**: Regardless of the input array's dimensionality (2D, 3D, or 4D), extracting elements via a full boolean mask **always returns a flat 1D array** because the number of matching elements per row or plane is variable.

#### Q2: Why can't you use Python's `and`, `or`, and `not` keywords for combining boolean conditions in NumPy?
- **Definition**: Python's `and`, `or`, and `not` evaluate the truth value of an entire object as a whole by calling `bool(obj)`. They cannot perform element-wise logical operations across arrays.
- **Technical & Memory Mechanics**: When `bool(arr)` is called on an array with more than one element, NumPy cannot determine whether the array is "truthy" (should it be True if all elements are non-zero, or if any element is non-zero?). To prevent ambiguity, NumPy raises `ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()`.
- **Code Example**:
```python
import numpy as np

arr = np.array([1, 5, 10])

# Prohibited: raises ValueError
try:
    _ = arr > 2 and arr < 8
except ValueError as e:
    print("Caught expected truth value error:", e)

# Correct: use bitwise & with parentheses
valid_mask = (arr > 2) & (arr < 8)
print("Valid bitwise mask:", valid_mask)  # [False  True False]
```
- **Nuances & Pitfalls**: In interviews, clearly state: "Use bitwise operators (`&`, `|`, `~`) for element-wise logic on arrays, and reserve `and`/`or` for scalar Python logic."

#### Q3: Why are parentheses mandatory when combining conditions with bitwise operators in NumPy?
- **Definition**: Parentheses are required because Python's bitwise operators (`&`, `|`, `~`, `^`) have higher operator precedence than comparison operators (`<`, `>`, `==`, `<=`, `>=`).
- **Technical & Memory Mechanics**: In the unparenthesized expression `arr > 0 & arr < 10`, Python evaluates `0 & arr` first (bitwise AND between integer 0 and array `arr`), producing an intermediate array of zeros. It then attempts to evaluate `arr > 0 < 10` as a chained comparison, which fails with `ValueError: The truth value of an array with more than one element is ambiguous`.
- **Code Example**:
```python
import numpy as np

arr = np.array([-5, 2, 8, 15])

# Buggy syntax:
try:
    _ = arr > 0 & arr < 10
except ValueError as e:
    print("Precedence error caught:", e)

# Correct parenthesized syntax:
clean = arr[(arr > 0) & (arr < 10)]
print("Filtered values:", clean)  # [2, 8]
```
- **Nuances & Pitfalls**: Forgetting parentheses in compound boolean masks is one of the most common syntax bugs in data science code.

#### Q4: What is the difference between extracting with a mask (`sub = arr[mask]`) and assigning with a mask (`arr[mask] = val`)?
- **Definition**: Extracting with a mask creates a brand-new 1D array copy containing only the matching elements. Assigning with a mask updates the matching elements **in place** within the original array, preserving its original shape and dimensionality.
- **Technical & Memory Mechanics**:
  - `sub = arr[mask]`: Allocates a new heap buffer of size $K \times \text{itemsize}$ ($K$ = count of True). Time and space complexity are $O(N)$.
  - `arr[mask] = val`: Evaluates the mask, traverses the matching indices in C, and writes `val` directly to the existing buffer in place. Time complexity is $O(N)$, but auxiliary space complexity is $O(1)$.
- **Code Example**:
```python
import numpy as np

mat = np.array([[10, -1],
                [-2, 20]])

# 1. Extraction: returns 1D copy
positives = mat[mat > 0]
print("Extracted 1D copy:    ", positives)  # [10, 20]
print("Original mat shape:   ", mat.shape)   # (2, 2)

# 2. In-place assignment: updates buffer directly
mat[mat < 0] = 0
print("Mat after in-place set:\n", mat)
# Output:
# [[10  0]
#  [ 0 20]]
```
- **Nuances & Pitfalls**: In-place assignment (`arr[mask] = 0`) never changes the array's shape; it only overwrites elements at coordinates where the mask is `True`.

#### Q5: What does the bitwise NOT operator (`~`) do to a boolean mask?
- **Definition**: The `~` operator inverts a boolean array element-wise, converting every `True` to `False` and every `False` to `True`.
- **Technical & Memory Mechanics**: NumPy executes a bitwise NOT on the underlying 1-byte boolean representation. It returns a new boolean array of the same shape with inverted truth values.
- **Code Example**:
```python
import numpy as np

scores = np.array([85, 42, 90, 33, 76])
is_passing = scores >= 50

# Invert mask using ~
is_failing = ~is_passing

print("Passing: ", scores[is_passing])  # [85, 90, 76]
print("Failing: ", scores[is_failing])  # [42, 33]
```
- **Nuances & Pitfalls**: Do not use the `not` keyword (`not is_passing`), as it evaluates the truth value of the entire array object and raises a `ValueError`.

#### Q6: How does `np.where(condition, x, y)` differ from boolean indexing `arr[condition]`?
- **Definition**: `np.where(condition, x, y)` evaluates a condition and returns an array with the **same shape as the input**, choosing elements from $x$ where `True` and $y$ where `False`. Boolean indexing `arr[condition]` extracts matching elements into a **collapsed 1D array**.
- **Technical & Memory Mechanics**: `np.where` performs element-wise selection without discarding any positions or collapsing dimensions. It evaluates condition, $x$, and $y$ via broadcasting rules, allocating an output array of shape $\text{broadcast}(\text{condition.shape}, x.\text{shape}, y.\text{shape})$.
- **Code Example**:
```python
import numpy as np

arr = np.array([[1, -2],
                [-3, 4]])

# Boolean indexing: collapses to 1D
filtered = arr[arr > 0]
print("Boolean indexing (1D):", filtered)  # [1, 4]

# np.where: preserves 2D shape, replacing non-matching elements with 0
clamped = np.where(arr > 0, arr, 0)
print("np.where (2D preserved):\n", clamped)
# [[1 0]
#  [0 4]]
```
- **Nuances & Pitfalls**: When `x` and `y` are omitted (`np.where(condition)`), `np.where` acts as an alias for `np.nonzero(condition)`, returning a tuple of coordinate arrays.

#### Q7: What does `np.nonzero(arr)` return, and how does it relate to boolean indexing?
- **Definition**: `np.nonzero(arr)` returns a tuple of 1D arrays containing the integer indices of all non-zero (or `True`) elements along each dimension of `arr`.
- **Technical & Memory Mechanics**: For an array with rank $K$, `np.nonzero()` returns a tuple of $K$ integer arrays. If the mask has $M$ True entries, each array in the tuple has length $M$. Indexing `arr[np.nonzero(mask)]` is mathematically and functionally equivalent to `arr[mask]`.
- **Code Example**:
```python
import numpy as np

mask = np.array([[False, True],
                 [True, False]])

coords = np.nonzero(mask)
print("Nonzero coordinate tuple:", coords)
# (array([0, 1]), array([1, 0])) -> elements at (0, 1) and (1, 0)

arr = np.array([[10, 20],
                [30, 40]])
print("Indexed via nonzero:", arr[coords])  # [20, 30]
print("Indexed via mask:   ", arr[mask])    # [20, 30]
```
- **Nuances & Pitfalls**: `np.nonzero()` produces explicit integer coordinate arrays. If you need the exact row and column indices of matching items (e.g., for spatial tracking), use `np.nonzero()` or `np.argwhere()`.

#### Q8: What is the difference between `np.nonzero()` and `np.argwhere()`?
- **Definition**: `np.nonzero(arr)` returns a tuple of 1D index arrays (one per dimension). `np.argwhere(arr)` returns a single 2D array of shape `(M, ndim)` where each row is a coordinate tuple of a non-zero element.
- **Technical & Memory Mechanics**: `np.argwhere()` takes the output of `np.nonzero()`, stacks the coordinate arrays along axis 1 using `np.transpose(np.nonzero(arr))`, and returns the 2D coordinate matrix.
- **Code Example**:
```python
import numpy as np

grid = np.array([[0, 5],
                 [8, 0]])

nz = np.nonzero(grid)
aw = np.argwhere(grid)

print("np.nonzero format: \n", nz)
# (array([0, 1]), array([1, 0]))

print("np.argwhere format:\n", aw)
# [[0 1]
#  [1 0]]
```
- **Nuances & Pitfalls**: `np.nonzero()` output can be used directly to index arrays: `arr[np.nonzero(cond)]`. `np.argwhere()` output is shaped for inspection and coordinate logging, and cannot be used directly as an indexing tuple without unpacking.

#### Q9: What happens if no elements satisfy a boolean condition: `arr[arr > 100]`?
- **Definition**: If no elements match the condition, NumPy returns an empty 1D array of shape `(0,)` with the same `dtype` as the original array.
- **Technical & Memory Mechanics**: The mask scan finds 0 matching elements ($K = 0$). NumPy allocates a zero-length memory buffer and returns an empty `ndarray`. No exception is raised.
- **Code Example**:
```python
import numpy as np

data = np.array([1, 2, 3, 4, 5])
empty_result = data[data > 100]

print("Result:", empty_result)        # []
print("Shape: ", empty_result.shape)  # (0,)
print("Dtype: ", empty_result.dtype)  # int64
```
- **Nuances & Pitfalls**: Subsequent reduction operations like `.mean()` or `.max()` on an empty array will raise warnings or return `np.nan` (e.g., `RuntimeWarning: Mean of empty slice`). Always check `len(filtered) > 0` before computing statistics.

#### Q10: How do you check if any or all elements in an array satisfy a boolean condition?
- **Definition**: Use `np.any(condition)` to check if at least one element evaluates to `True`, and `np.all(condition)` to check if every element evaluates to `True`.
- **Technical & Memory Mechanics**: `np.any()` executes a logical OR reduction across elements, short-circuiting at the C level when the first `True` is encountered. `np.all()` executes a logical AND reduction, short-circuiting on the first `False`. Both return a boolean scalar.
- **Code Example**:
```python
import numpy as np

readings = np.array([98.6, 99.1, 103.5, 98.4])

has_fever = np.any(readings > 100.0)
all_fever = np.all(readings > 100.0)

print("Any reading > 100.0:", has_fever)  # True
print("All readings > 100.0:", all_fever)  # False
```
- **Nuances & Pitfalls**: Using `np.any()` or `np.all()` is the correct way to evaluate array conditions inside standard Python `if` statements: `if np.any(arr > 0): ...`.

#### Q11: What happens when the shape of a boolean mask does not match the shape of the array?
- **Definition**: If the boolean mask's shape is not identical to the array's shape and cannot be broadcast to it, NumPy raises an `IndexError`.
- **Technical & Memory Mechanics**: NumPy verifies dimensional compatibility. If the mask has rank $M \le N$, it attempts to align the mask with the leading dimensions of the array. If dimensions mismatch and cannot be broadcast, the C validator aborts with `IndexError: boolean index did not match indexed array along dimension X`.
- **Code Example**:
```python
import numpy as np

mat = np.zeros((3, 4))
bad_mask = np.array([True, False])  # Length 2, but axis 0 has size 3

try:
    _ = mat[bad_mask]
except IndexError as e:
    print("Caught shape mismatch error:", e)
# Output: IndexError: boolean index did not match indexed array along dimension 0; dimension is 3 but corresponding boolean dimension is 2
```
- **Nuances & Pitfalls**: A 1D mask of length $R$ can index a 2D array of shape $(R, C)$ along axis 0, selecting matching rows.

#### Q12: How do you filter an array using multiple conditions with the bitwise OR operator (`|`)?
- **Definition**: Use the pipe operator `|` with parenthesized sub-conditions: `arr[(condition1) | (condition2)]`.
- **Technical & Memory Mechanics**: Evaluates both boolean conditions, applies bitwise OR element-by-element, and extracts all elements where at least one condition is `True`.
- **Code Example**:
```python
import numpy as np

sensor_vals = np.array([-15, 0, 25, 80, 110])

# Outlier filter: values below -10 OR above 100
outliers = sensor_vals[(sensor_vals < -10) | (sensor_vals > 100)]
print("Extracted outliers:", outliers)  # [-15, 110]
```
- **Nuances & Pitfalls**: Ensure both conditions are enclosed in parentheses: `(sensor_vals < -10) | (sensor_vals > 100)`.

#### Q13: What is the XOR operator in boolean indexing, and what does it do?
- **Definition**: The caret operator `^` performs element-wise exclusive OR (XOR) on boolean masks. It evaluates to `True` if and only if **exactly one** of the conditions is `True` (one is `True` and the other is `False`).
- **Technical & Memory Mechanics**: NumPy executes a bitwise XOR on the 1-byte boolean representation. It returns `True` where the condition truth values differ, and `False` where both are `True` or both are `False`.
- **Code Example**:
```python
import numpy as np

x = np.array([2, 5, 12, 18])

# Condition A: even numbers (x % 2 == 0) -> [True, False, True, True]
# Condition B: numbers > 10              -> [False, False, True, True]
# XOR (A ^ B): True if even OR > 10, but NOT BOTH!
xor_mask = (x % 2 == 0) ^ (x > 10)

print("Values satisfying XOR:", x[xor_mask])  # [2]
# Explanation:
# 2: even (T), >10 (F) -> T ^ F = T (kept)
# 5: even (F), >10 (F) -> F ^ F = F (dropped)
# 12: even (T), >10 (T) -> T ^ T = F (dropped!)
# 18: even (T), >10 (T) -> T ^ T = F (dropped!)
```
- **Nuances & Pitfalls**: XOR is useful for finding elements that satisfy mutually exclusive criteria (e.g., anomaly detected by model A or model B, but not agreed upon by both).

#### Q14: How does 1D boolean indexing on a 2D array behave: `arr[bool_1d_mask]`?
- **Definition**: When a 1D boolean mask of length $R$ indexes a 2D array of shape $(R, C)$, it acts as a row selector, returning a 2D array containing only the rows where the mask is `True`.
- **Technical & Memory Mechanics**: NumPy aligns the 1D mask with axis 0. If the mask has $M$ True entries, it allocates a new 2D array of shape $(M, C)$ and copies the matching rows into it. The result is a 2D array, not a 1D vector.
- **Code Example**:
```python
import numpy as np

matrix = np.array([[10, 20],
                   [30, 40],
                   [50, 60]])

# 1D boolean mask for rows
row_mask = np.array([True, False, True])

selected_rows = matrix[row_mask]
print("Selected rows shape:\n", selected_rows.shape)  # (2, 2)
print("Selected rows content:\n", selected_rows)
# [[10 20]
#  [50 60]]
```
- **Nuances & Pitfalls**: If you want to select columns, you must slice axis 0 and apply the mask to axis 1: `matrix[:, col_mask]`.

#### Q15: How do you replace all NaN values in a floating-point array with zero using boolean indexing?
- **Definition**: Use `np.isnan(arr)` to generate a boolean mask of NaN locations, then assign 0 to that mask in-place: `arr[np.isnan(arr)] = 0.0`.
- **Technical & Memory Mechanics**: `np.isnan()` evaluates the IEEE-754 quiet/signaling NaN bit patterns, returning a boolean array where `True` indicates `NaN`. Assigning to `arr[np.isnan(arr)]` overwrites those slots in place with `0.0`.
- **Code Example**:
```python
import numpy as np

data = np.array([1.5, np.nan, 3.2, np.nan, 5.0])
print("Before NaN imputation:", data)

data[np.isnan(data)] = 0.0
print("After NaN imputation: ", data)  # [1.5 0.  3.2 0.  5. ]
```
- **Nuances & Pitfalls**: Standard comparison `arr == np.nan` does NOT work because IEEE-754 defines `NaN == NaN` as `False`. Always use `np.isnan()` to detect NaNs.

#### Q16: How do you cap or clip outliers in an array using boolean indexing?
- **Definition**: Identify elements exceeding upper or lower bounds using boolean masks and assign the boundary threshold values to them in place.
- **Technical & Memory Mechanics**: Two separate in-place masked assignments are executed:
  `arr[arr < lower_bound] = lower_bound`
  `arr[arr > upper_bound] = upper_bound`
  Each assignment updates matching memory slots without modifying non-matching elements.
- **Code Example**:
```python
import numpy as np

sensor_stream = np.array([-25.0, 10.0, 55.0, 120.0, 75.0])

# Cap values to valid range [0.0, 100.0]
sensor_stream[sensor_stream < 0.0] = 0.0
sensor_stream[sensor_stream > 100.0] = 100.0

print("Capped sensor values:", sensor_stream)  # [  0.  10.  55. 100.  75.]
```
- **Nuances & Pitfalls**: While boolean masking works, NumPy provides `np.clip(arr, a_min, a_max)` as a single compiled C function that runs faster and avoids generating intermediate boolean masks.

#### Q17: What is `np.select(condlist, choicelist, default)` and when is it preferred over nested `np.where()`?
- **Definition**: `np.select()` evaluates an ordered list of boolean conditions and returns values from the corresponding choice list for the first condition that evaluates to `True`, falling back to `default` if no conditions match.
- **Technical & Memory Mechanics**: It provides clean, vectorized multi-branch (`if-elif-else`) logic without deeply nested `np.where()` calls, executing in $O(N \cdot K)$ time where $K$ is the number of conditions.
- **Code Example**:
```python
import numpy as np

grades = np.array([45, 68, 85, 92, 74])

conditions = [
    grades >= 90,
    grades >= 80,
    grades >= 60
]

choices = ['A', 'B', 'C']

letter_grades = np.select(conditions, choices, default='F')
print("Letter grades:", letter_grades)  # ['F' 'C' 'B' 'A' 'C']
```
- **Nuances & Pitfalls**: `np.select()` evaluates conditions in order from first to last. Once an element matches a condition, later conditions are ignored for that element.

#### Q18: What is `np.extract(condition, arr)`?
- **Definition**: `np.extract(condition, arr)` is a functional equivalent of boolean indexing `arr[condition]`. It flattens both the condition and the array and returns all elements where the condition is `True` as a 1D array.
- **Technical & Memory Mechanics**: `np.extract()` calls `np.nonzero()` on the condition and returns a flat copy of matching elements. It is equivalent to `arr.ravel()[condition.ravel()]`.
- **Code Example**:
```python
import numpy as np

vals = np.array([[10, 20],
                 [30, 40]])
cond = vals > 15

res = np.extract(cond, vals)
print("np.extract result:", res)  # [20, 30, 40]
```
- **Nuances & Pitfalls**: Direct boolean indexing `arr[condition]` is preferred over `np.extract()` because bracket indexing is idiomatic and supported directly by modern array APIs.

#### Q19: Can you assign an array of values to a boolean mask: `arr[mask] = values_array`?
- **Definition**: Yes, provided that `len(values_array)` exactly equals the number of `True` entries in `mask`, or `values_array` can be broadcast to the shape of the selected items.
- **Technical & Memory Mechanics**: NumPy counts the number of `True` entries ($K$) in the mask. If `values_array` has length $K$, it writes each element into the corresponding `True` coordinate sequentially. If the count mismatches, it raises a `ValueError`.
- **Code Example**:
```python
import numpy as np

arr = np.array([1, -1, 2, -2, 3])
mask = arr < 0  # 2 True entries (at indices 1 and 3)

# Assign an array of 2 replacement values
arr[mask] = [100, 200]
print("Array after vectorized masked assignment:", arr)  # [  1 100   2 200   3]
```
- **Nuances & Pitfalls**: If `mask` contains 2 `True` entries and you pass `[100, 200, 300]`, NumPy raises `ValueError: shape mismatch: value array of shape (3,) could not be broadcast to indexing result of shape (2,)`.

#### Q20: What is the memory footprint of a boolean mask array in NumPy?
- **Definition**: In NumPy, each boolean value in a boolean array occupies **1 full byte** (8 bits), not 1 bit.
- **Technical & Memory Mechanics**: A boolean array uses `dtype=bool` (internally `np.bool_`, representing a C `unsigned char`). Because standard CPU memory architectures cannot address individual bits directly without bitwise shift/mask operations, storing booleans as full bytes allows fast, byte-aligned SIMD memory operations.
- **Code Example**:
```python
import numpy as np

mask = np.ones(1000, dtype=bool)
print("Elements in mask: ", mask.size)    # 1000
print("Bytes consumed:    ", mask.nbytes)  # 1000 bytes (1 byte per bool)
print("Itemsize:          ", mask.itemsize)# 1 byte
```
- **Nuances & Pitfalls**: For massive boolean arrays (e.g., 1 billion flags), `np.bool_` consumes 1 GB of RAM. If memory is severely constrained, you can pack 8 booleans into a single byte using `np.packbits()`, reducing memory usage by 87.5% at the cost of bitwise unpacking overhead.

### 3.B Intermediate Interview Questions (20 Questions)

#### Q21: What is the exact algorithmic procedure executed during boolean indexing extraction under the hood?
- **Definition**: Extracting elements via `arr[mask]` is a two-pass advanced indexing routine executed in compiled C.
- **Technical & Memory Mechanics**:
  1. **Pass 1 (Count Matching Elements)**: NumPy iterates through the boolean mask, counting the total number of non-zero entries ($K = \sum \text{mask}$).
  2. **Heap Allocation**: Allocates an output buffer of size $K \times \text{itemsize}$ on the heap.
  3. **Pass 2 (Data Transfer)**: Iterates through the mask again. Whenever an entry is `True`, it computes the source byte offset via strides and copies the element into the destination buffer via `memcpy()`.
  4. Returns a 1D `ndarray` wrapper with `shape=(K,)` and `.base=None`.
- **Code Example**:
```python
import numpy as np

arr = np.arange(10, dtype=np.int64)
mask = (arr % 2 == 0)

filtered = arr[mask]
print("Extracted items:", filtered)
print("Extracted owns memory:", filtered.base is None)  # True
print("Extracted strides:    ", filtered.strides)      # (8,)
```
- **Nuances & Pitfalls**: Because boolean indexing requires scanning the mask twice and allocating a new buffer, it is significantly slower than basic slicing ($O(1)$). In performance-critical loops, avoid generating transient boolean masks repeatedly.

#### Q22: Why does `arr == np.nan` fail to generate a valid boolean mask for missing values?
- **Definition**: The IEEE-754 floating-point standard mandates that `NaN` is not equal to any value, including itself (`np.nan == np.nan` evaluates to `False`).
- **Technical & Memory Mechanics**: When NumPy evaluates `arr == np.nan`, the C comparison function checks IEEE-754 bit representations. Because comparing any number to `NaN` yields `False`, the resulting mask is entirely `False`, even for elements containing `NaN`.

```python
# Correct standard detection:

```
- **Nuances & Pitfalls**: In interviews, state clearly: "Never use equality operators to detect `NaN`. Always use `np.isnan()` or `np.isfinite()`."

#### Q24: What is the performance impact of creating intermediate boolean masks in large numerical pipelines, and how can it be optimized?
- **Definition**: Evaluating compound expressions like `(a > 0) & (b < 10) & (c == 5)` creates temporary boolean arrays on the heap for each sub-expression, causing memory bandwidth saturation on gigabyte-scale datasets.
- **Technical & Memory Mechanics**: Each sub-expression allocates an array of `dtype=bool` ($N$ bytes). For an array with $10^8$ elements (100 million entries), evaluating 3 conditions creates 3 temporary 100 MB boolean buffers (~300 MB of heap churn).
- **Optimization Strategy**: Use `numexpr` or in-place logical operators (`np.logical_and(out=...)`) to evaluate conditions in a single pass without allocating temporary buffers.
- **Code Example**:
```python
import numpy as np

a = np.random.randn(1000000)

# Unoptimized: creates 3 temporary boolean arrays
# 1. temp1 = (a > 0.0)      -> 1 MB
# 2. temp2 = (a < 1.0)      -> 1 MB
# 3. mask  = temp1 & temp2  -> 1 MB
mask_unopt = (a > 0.0) & (a < 1.0)

# Optimized in-place evaluation:
mask_opt = a > 0.0
np.logical_and(mask_opt, a < 1.0, out=mask_opt)

print("Identical results:", np.array_equal(mask_unopt, mask_opt))
```
- **Nuances & Pitfalls**: In memory-constrained production pipelines, chained boolean expressions are a common cause of Out-Of-Memory crashes.

#### Q25: How does boolean mask assignment handle overlapping or duplicate index conditions?
- **Definition**: In boolean mask assignment `arr[mask] = val`, each coordinate in the array corresponds to at most one entry in the boolean mask. Therefore, duplicate assignments do not occur.
- **Technical & Memory Mechanics**: Unlike integer array indexing (where passing duplicate indices `[0, 0, 0]` can lead to non-deterministic assignment behavior depending on vectorization), a boolean mask has a 1-to-1 mapping with array elements. Each element where `mask` is `True` is updated exactly once.
- **Code Example**:
```python

```
- **Nuances & Pitfalls**: Masked assignment `arr[mask] += val` is completely deterministic and free of race conditions because every memory slot is addressed at most once.

#### Q26: What is the difference between `np.logical_and()` and the bitwise AND operator `&` on boolean arrays?
- **Definition**: Functionally, both compute element-wise logical AND on boolean arrays. However, `np.logical_and()` is a NumPy universal function (ufunc) that provides options for `out=`, `where=`, and dtype casting, whereas `&` is operator syntax.
- **Technical & Memory Mechanics**: The `&` operator on boolean arrays calls `np.bitwise_and()`. On `dtype=bool`, bitwise AND and logical AND produce identical results because `0x01 & 0x01 == 0x01`. However, on integer arrays, `&` performs bitwise AND (e.g., `1 & 2 == 0`), whereas `np.logical_and()` evaluates truthiness (e.g., `np.logical_and(1, 2) == True`).
- **Code Example**:
```python

# Bitwise &: 1 & 2 = 0; 2 & 2 = 2

# Logical AND: bool(1) and bool(2) = True; bool(2) and bool(2) = True
print("Logical AND on integers: ", np.logical_and(a, b))  # [True, True]
```
- **Nuances & Pitfalls**: When working with non-boolean arrays, using `&` instead of `np.logical_and()` performs bit-level arithmetic rather than truth-value logic, leading to subtle bugs.

#### Q29: What is `np.packbits()` and how does it optimize storage for boolean masks?
- **Definition**: `np.packbits()` packs a boolean or binary `uint8` array into a compact bit-level representation, storing 8 boolean flags per single byte.
- **Technical & Memory Mechanics**: Standard NumPy booleans consume 8 bits (1 full byte) per element. `np.packbits()` groups elements into blocks of 8 and packs them into the bit positions of a `uint8` integer, reducing memory consumption by a factor of 8 (87.5% memory reduction).
- **Code Example**:
```python
import numpy as np

# Standard boolean mask of 1,000,000 flags (1 MB RAM)
raw_mask = np.random.choice([True, False], size=1000000)
print("Standard boolean mask size:", raw_mask.nbytes / 1024, "KB")  # ~976 KB

# Packed bitmask: 8 flags per byte
packed_mask = np.packbits(raw_mask)
print("Packed bitmask size:       ", packed_mask.nbytes / 1024, "KB")  # ~122 KB

# Unpacking to restore original boolean mask
restored_mask = np.unpackbits(packed_mask)[:len(raw_mask)].view(bool)
assert np.array_equal(raw_mask, restored_mask)
print("Restored mask matches original perfectly!")
```
- **Nuances & Pitfalls**: Packed bitmasks cannot be used directly as indexers (`arr[packed_mask]`). They must be unpacked with `np.unpackbits()` before indexing.

#### Q30: Why does `arr[mask] = val` fail if `val` is an array whose length does not match `np.count_nonzero(mask)`?

- **Technical & Memory Mechanics**: When executing masked assignment, NumPy expects the right-hand side to provide an element for every `True` coordinate. If the lengths mismatch, NumPy cannot determine which values map to which coordinates and raises `ValueError: shape mismatch: value array of shape X could not be broadcast to indexing result of shape Y`.
- **Code Example**:

- **Nuances & Pitfalls**: Supplying a single scalar value (`arr[mask] = 100`) always succeeds because scalar values broadcast across all target positions automatically.

#### Q32: What is the computational complexity of evaluating a boolean mask vs. extracting elements with that mask?
- **Definition**: Evaluating a boolean mask runs in $O(N)$ time and requires $O(N)$ auxiliary memory. Extracting elements with the mask runs in $O(N)$ time and requires $O(K)$ auxiliary memory, where $K$ is the number of `True` elements.
- **Technical & Memory Mechanics**:
  - Mask evaluation (`arr > 0`): Scans $N$ elements and allocates an $N$-byte boolean array on the heap.
  - Extraction (`arr[mask]`): Scans the mask to count $K$ matches, allocates an output buffer of size $K \times \text{itemsize}$, and copies matching bytes.
- **Code Example**:
```python
import numpy as np

arr = np.arange(1000000)

# Pass 1: Mask creation -> O(N) time, O(N) space
mask = arr > 500000

# Pass 2: Extraction -> O(N) scan, O(K) allocation and copy
filtered = arr[mask]

print(f"Mask size: {mask.nbytes / 1024:.1f} KB | Output size: {filtered.nbytes / 1024:.1f} KB")
```
- **Nuances & Pitfalls**: In tight loops, avoid re-evaluating static masks. Cache the mask or use integer indices if the selection pattern does not change across iterations.

#### Q33: How do you invert a complex compound boolean mask without re-evaluating each individual sub-condition?
- **Definition**: Enclose the entire compound expression in parentheses and prepend the bitwise NOT operator `~`: `~( (cond1) & (cond2) )`.
- **Technical & Memory Mechanics**: By De Morgan's laws, $\neg (A \land B) \iff (\neg A) \lor (\neg B)$. Applying `~` to the final combined boolean array inverts every bit in a single $O(N)$ pass without re-evaluating the underlying comparisons.
- **Code Example**:
```python
import numpy as np

data = np.arange(10)
# Compound condition: even numbers between 2 and 8
valid_mask = (data >= 2) & (data <= 8) & (data % 2 == 0)
print("Valid items:  ", data[valid_mask])  # [2, 4, 6, 8]

# Invert entire compound mask in a single operation
invalid_mask = ~valid_mask
print("Inverted items:", data[invalid_mask]) # [0, 1, 3, 5, 7, 9]
```
- **Nuances & Pitfalls**: Applying `~` to the entire expression is cleaner and less error-prone than manually applying De Morgan's laws across multiple sub-conditions.

```python
import numpy as np

def impute_outliers_columnwise(matrix: np.ndarray) -> np.ndarray:

        mean = np.mean(col)

print("Cleaned Matrix with Median Imputation:\n", cleaned)
```

  - *Expected*: Retain 2D shape `(2, 2)` with negative values replaced by zero.
- **Fixed Code**:

#### Q65: Fix silent logical error caused by using `|` on non-boolean integer arrays.
- **Problem Description**: An engineer uses `&` and `|` directly on integer arrays expecting logical evaluation, but triggers bitwise arithmetic instead.


  - *Actual*: `[0, 2]` (Bitwise integer AND arithmetic).
  - *Expected*: Logical evaluation where both non-zero numbers evaluate to `True`.
- **Fixed Code**:

```python
a = np.array([1, 2])
b = np.array([2, 2])

logical_result = (a != 0) & (b != 0)
print("Correct logical result:", logical_result)  # [True, True]
```
- **Explanation**: On integer arrays, `&` performs bitwise bit-masking ($0001_2 \ \& \ 0010_2 = 0000_2$). To perform logical operations, convert integer arrays to boolean masks using comparison operators (`a != 0`) or use `np.logical_and()`.

- **Production Scenario**: An industrial IoT edge controller ingests vibration sensor readings at 10 kHz across 50 channels. Due to electrical noise, occasional voltage spikes produce non-physical readings ($> 500\text{ g}$) or sensor dropouts ($0.0\text{ g}$).
- **Architectural Challenge**: Clean anomalous readings in place without allocating new arrays, replacing dropouts with the channel mean and clipping extreme spikes to $500.0\text{ g}$.

```python
def clean_sensor_stream_inplace(stream: np.ndarray) -> np.ndarray:
    assert stream.ndim == 2, "Expected 2D stream (Samples, Channels)"
    
    # Pass 1: Clip extreme spikes to 500.0 in-place
    stream[stream > 500.0] = 500.0
    stream[stream < -500.0] = -500.0
    
    # Pass 2: Replace exact zero dropouts with column means
    for c in range(stream.shape[1]):
        col = stream[:, c]
        dropout_mask = (col == 0.0)
        if np.any(dropout_mask):
            valid_mean = np.mean(col[~dropout_mask])
            col[dropout_mask] = valid_mean
            
    return stream
```

```python
import numpy as np

def chroma_key_composite(foreground: np.ndarray, background: np.ndarray, color_key: tuple[int, int, int], tolerance: float = 50.0) -> np.ndarray:
    assert foreground.shape == background.shape, "Images must have identical dimensions"
    
    # Calculate Euclidean color distance to green screen key
    key = np.array(color_key, dtype=np.float32)
    diff = foreground.astype(np.float32) - key
    dist = np.sqrt(np.sum(diff**2, axis=-1))  # 2D distance map
    
    # Green screen mask: pixels where distance < tolerance
    is_green = dist < tolerance
    
    # Composite: copy foreground and overwrite green pixels with background
    composite = foreground.copy()
    composite[is_green] = background[is_green]
    
    return composite

# Simulation: 4x4 image

fg[:, :] = [0, 255, 0]        # Solid green screen
fg[1:3, 1:3] = [255, 0, 0]    # Red actor in center

print("Foreground Edge (Background Gray):\n", result[0, 0]) # [128, 128, 128]
```

```python
import numpy as np

def triage_patients_vectorized(vitals: np.ndarray) -> np.ndarray:

        ((hr >= 110.0) & (hr <= 140.0))
    )
    
    conditions = [cond_critical, cond_urgent]
    categories = ["Critical_Level_1", "Urgent_Level_2"]
    
    return np.select(conditions, categories, default="Standard_Level_3")
```

## 4. Top Questions to Definitely Prepare (13 Questions)

### Must Know (5 Questions)
1. **Does boolean indexing return a view or a copy?**
   - *Key Answer Point*: Boolean indexing **always returns an independent copy** on the heap. Because the number of matching elements is unpredictable, it collapses the output into a flat 1D array with `.base is None`.
2. **Why are parentheses mandatory when combining conditions with `&` or `|`?**
   - *Key Answer Point*: Bitwise operators have higher operator precedence than comparison operators (`<`, `>`, `==`). Without parentheses, Python evaluates the bitwise operation between adjacent operands first, causing chained comparison syntax errors.
3. **Why can't you use Python's `and`, `or`, and `not` keywords on NumPy arrays?**
   - *Key Answer Point*: Python logical keywords call `bool(arr)` to evaluate the truthiness of the entire array object as a whole. Because an array contains multiple elements, NumPy raises `ValueError: The truth value of an array with more than one element is ambiguous`.
4. **How does in-place masked assignment `arr[mask] = val` differ from extraction `arr[mask]`?**
   - *Key Answer Point*: Extraction returns a new, collapsed 1D array copy. In-place assignment mutates the existing memory buffer directly, updating matching elements while **preserving the original array's shape and dimensionality**.
5. **Why does `arr == np.nan` fail to create a valid boolean mask for missing values?**
   - *Key Answer Point*: IEEE-754 defines `NaN != NaN`. Comparing any value to `NaN` evaluates to `False`. To detect missing values, you must use `np.isnan(arr)`.

### Good to Know (5 Questions)
6. **What is the difference between `np.where(condition, x, y)` and boolean indexing `arr[condition]`?**
   - *Key Answer Point*: `np.where(cond, x, y)` evaluates element-wise ternary branching, preserving the multidimensional shape of the inputs. Boolean indexing `arr[cond]` extracts matching elements into a flat 1D array.
7. **What is the difference between `np.nonzero(arr)` and `np.argwhere(arr)`?**
   - *Key Answer Point*: `np.nonzero(arr)` returns a tuple of 1D coordinate arrays (one per axis), suitable for direct indexing. `np.argwhere(arr)` returns a single 2D array of coordinate tuples of shape `(M, ndim)`.
8. **What does an all-True or all-False boolean mask return when applied to an array?**
   - *Key Answer Point*: An all-True mask returns a flattened 1D array copy containing all elements. An all-False mask returns an empty 1D array of shape `(0,)`. Both are independent copies.
9. **How much memory does a boolean mask consume in NumPy?**
   - *Key Answer Point*: In NumPy, `dtype=bool` consumes **1 full byte** (8 bits) per element to allow byte-aligned memory access on modern CPUs.
10. **What is `np.select()` and when should it be used over nested `np.where()`?**
    - *Key Answer Point*: `np.select(condlist, choicelist, default)` evaluates an ordered list of boolean conditions in a clean, vectorized `if-elif-else` format, avoiding deeply nested `np.where()` expressions.

### Bonus / Edge-Case (3 Questions)
11. **What happens if you assign a list of 3 elements to a boolean mask that has only 2 `True` entries?**
    - *Key Answer Point*: NumPy raises `ValueError: shape mismatch: value array of shape (3,) could not be broadcast to indexing result of shape (2,)`.
12. **Why does `np.count_nonzero(mask)` run faster than `np.sum(mask)` on boolean arrays?**
    - *Key Answer Point*: `np.sum()` casts the boolean array (`uint8`) to `int64` before executing summation to prevent overflow. `np.count_nonzero()` executes a dedicated C counting loop directly on the boolean bytes without type casting.
13. **What is the effect of indexing a 2D matrix of shape `(R, C)` with a 1D boolean mask of length $R$?**
    - *Key Answer Point*: It acts as a row selector along axis 0, returning a 2D array of shape `(M, C)` containing only the rows where the mask is `True`, preserving the column dimension.

## 5. Mistakes to Avoid (10 Mistakes)

#### Mistake 1: Omitting parentheses in compound boolean expressions.
- **Wrong Code**:
```python
mask = arr > 10 & arr < 50  # ValueError!
```
- **Right Code**:
```python
mask = (arr > 10) & (arr < 50)  # Correct parenthesization
```
- **Why It Fails**: Bitwise `&` binds tighter than `<` and `>`, evaluating `10 & arr` first.
- **Consequence**: Immediate runtime crash with `ValueError: The truth value of an array...`.

#### Mistake 2: Using Python's `and` / `or` keywords instead of bitwise `&` / `|`.
- **Wrong Code**:
```python
filtered = arr[arr > 0 and arr < 10]  # ValueError!
```
- **Right Code**:
```python
filtered = arr[(arr > 0) & (arr < 10)]
```
- **Why It Fails**: `and`/`or` evaluate the truthiness of the entire array object as a whole, which is ambiguous.
- **Consequence**: Immediate runtime crash with `ValueError`.

#### Mistake 3: Using `arr == np.nan` to find missing values.
- **Wrong Code**:
```python
arr[arr == np.nan] = 0.0  # Does NOT replace NaNs!
```
- **Right Code**:
```python
arr[np.isnan(arr)] = 0.0  # Correct detection
```
- **Why It Fails**: `NaN != NaN` under IEEE-754 rules. The comparison mask is entirely `False`.
- **Consequence**: Missing values are silently retained, corrupting downstream calculations.

#### Mistake 4: Mutating the output of boolean extraction expecting the parent array to update.
- **Wrong Code**:
```python
sub = arr[arr > 5]
sub[0] = 999  # Does NOT modify arr!
```
- **Right Code**:
```python
arr[arr > 5] = 999  # Direct in-place masked assignment
```
- **Why It Fails**: Boolean extraction returns an independent copy on the heap.
- **Consequence**: Data modifications are lost without error or warning.

#### Mistake 5: Assuming boolean indexing on a 2D matrix returns a 2D matrix.
- **Wrong Code**:
```python
filtered = mat[mat > 0]
print(filtered.shape)  # Expected (2, 2), but got (3,)!
```
- **Right Code**:
```python
# If 2D shape must be preserved, use np.where():
filtered_2d = np.where(mat > 0, mat, 0)
```
- **Why It Fails**: Boolean indexing collapses matching elements into a flat 1D array.
- **Consequence**: Shape mismatch errors in matrix multiplication or convolutional layers.

#### Mistake 6: Mismatched length in masked sequence assignment.
- **Wrong Code**:
```python
mask = arr > 0  # 3 True entries
arr[mask] = [10, 20]  # ValueError: shape mismatch!
```
- **Right Code**:
```python
arr[mask] = [10, 20, 30]  # Exact match (3 values)
```
- **Why It Fails**: Sequence assignment requires that the right-hand side length match the number of `True` entries in the mask.
- **Consequence**: Immediate runtime crash with `ValueError`.

#### Mistake 7: Using `not` keyword to invert a boolean mask.
- **Wrong Code**:
```python
inverted = not mask  # ValueError!
```
- **Right Code**:
```python
inverted = ~mask     # Bitwise NOT operator
```
- **Why It Fails**: `not` calls `bool()` on the array, which fails on multidimensional arrays.
- **Consequence**: Immediate runtime crash with `ValueError`.

#### Mistake 8: Calling statistical reductions on empty boolean filter results.
- **Wrong Code**:
```python
sub = arr[arr > 1000]
val = sub.mean()  # RuntimeWarning: Mean of empty slice -> returns nan!
```
- **Right Code**:
```python
sub = arr[arr > 1000]
val = sub.mean() if len(sub) > 0 else 0.0
```
- **Why It Fails**: When no elements match, `sub` has shape `(0,)`. Reducing an empty array yields `NaN`.
- **Consequence**: Propagates `NaN` values silently throughout downstream calculations.

#### Mistake 9: Using bitwise operators on non-boolean integer arrays expecting logical evaluation.
- **Wrong Code**:
```python
result = int_arr1 & int_arr2  # Bitwise integer arithmetic, NOT logical AND!
```
- **Right Code**:
```python
result = (int_arr1 != 0) & (int_arr2 != 0)  # Logical boolean evaluation
```
- **Why It Fails**: On integer types, `&` performs bit-level arithmetic ($1 \ \& \ 2 = 0$).
- **Consequence**: Logic errors that silently discard valid non-zero values.

#### Mistake 10: Generating intermediate masks repeatedly inside tight loops.
- **Wrong Code**:
```python
for item in stream:
    mask = (reference > 0) & (reference < 10)  # Re-allocated every step!
```
- **Right Code**:
```python
# Precompute static mask once outside the loop:
mask = (reference > 0) & (reference < 10)
for item in stream:
    process(item[mask])
```
- **Why It Fails**: Evaluating compound boolean expressions allocates new heap buffers on every iteration.
- **Consequence**: Excessive heap allocation and garbage collection pauses in real-time loops.

## 7. Interview Traps (10 Traps)

#### Trap 1: The Dimensional Collapse Trap
- **Trap Question**: "If `mat` is a $4 \times 4$ matrix, what is the shape of `mat[mat > 0]`?"
- **Naive Answer**: "It is a $4 \times 4$ matrix with non-matching elements zeroed out."
- **Trap Unveiled**: Boolean indexing extraction always collapses matching elements into a flat 1D vector. The output shape is `(K,)` where $K$ is the number of `True` entries.
- **Winning Response**:
```python
import numpy as np
mat = np.arange(-5, 11).reshape(4, 4)
res = mat[mat > 0]
print("Shape is collapsed to 1D:", res.shape)  # (10,)
```

#### Trap 2: The Ambiguous Truth Value Trap
- **Trap Question**: "Why does `if arr > 0:` fail in Python?"
- **Naive Answer**: "Because `arr > 0` returns an array, not a boolean."
- **Trap Unveiled**: Python's `if` statement calls `bool(arr > 0)`. Because the array has multiple elements, NumPy cannot decide whether truthiness means `all()` elements are True or `any()` element is True, raising `ValueError: The truth value of an array with more than one element is ambiguous`.
- **Winning Response**:
```python
import numpy as np
arr = np.array([1, 2, 3])
try:
    if arr > 0:
        pass
except ValueError as e:
    print("Caught truth value ambiguity:", e)

# Correct evaluation:
if np.all(arr > 0):
    print("All elements > 0")
```

#### Trap 3: The Precedence Without Parentheses Trap
- **Trap Question**: "What does `arr > 2 & arr < 8` evaluate to?"
- **Naive Answer**: "It creates a mask selecting elements between 2 and 8."
- **Trap Unveiled**: Bitwise `&` has higher precedence than `>` and `<`. Python evaluates `2 & arr` first, resulting in a chained comparison that fails with a `ValueError`.
- **Winning Response**:
```python
import numpy as np
arr = np.array([1, 4, 10])
try:
    _ = arr > 2 & arr < 8
except ValueError as e:
    print("Precedence error caught:", e)
# Fix: (arr > 2) & (arr < 8)
```

#### Trap 4: The `NaN` Equality Comparison Trap
- **Trap Question**: "How do you count the number of NaNs in an array using boolean indexing?"
- **Naive Answer**: "`np.count_nonzero(arr == np.nan)`."
- **Trap Unveiled**: `NaN != NaN` under IEEE-754 rules. `arr == np.nan` evaluates to `False` for every element, returning 0. You must use `np.count_nonzero(np.isnan(arr))`.
- **Winning Response**:
```python
import numpy as np
arr = np.array([1.0, np.nan, 2.0, np.nan])
print("arr == np.nan count: ", np.count_nonzero(arr == np.nan))  # 0 (Wrong!)
print("np.isnan(arr) count: ", np.count_nonzero(np.isnan(arr)))  # 2 (Correct!)
```

#### Trap 5: The In-Place Masked Mutation View Trap
- **Trap Question**: "If I do `sub = arr[arr > 0]` and then `sub[:] = 0`, does `arr` change?"
- **Naive Answer**: "Yes, because indexing in NumPy returns views."

#### Q71: How do you implement vectorized outlier detection and winsorization using boolean indexing in production tabular ML pipelines?
- **Production Context**: Tabular preprocessing pipelines for credit scoring and fraud detection ingest streaming batches of numerical telemetry (e.g., transaction amounts, account age). Outliers exceeding $3\sigma$ (or $1.5 \times \text{IQR}$) skew linear models and gradient boosting split distributions. Allocating multiple intermediate matrices or iterating across rows kills pipeline throughput.
- **Engineering Solution**: Calculate IQR or z-score thresholds vectorially along feature axes, construct boolean masks for lower and upper violations, and apply in-place boolean indexed assignment (`arr[mask] = limit`) to winsorize bounds without allocating duplicate arrays.
```python
import numpy as np

def winsorize_batch_inplace(X: np.ndarray, lower_percentile: float = 1.0, upper_percentile: float = 99.0) -> np.ndarray:
    """
    Winsorize a 2D feature matrix in-place along columns using boolean masks.
    Avoids copying the full matrix, maintaining O(1) auxiliary memory.
    """
    assert X.ndim == 2, "Input feature matrix must be 2D (samples, features)"
    
    # Compute bounds per feature column: shape (1, num_features)
    low_bounds = np.percentile(X, lower_percentile, axis=0, keepdims=True)
    high_bounds = np.percentile(X, upper_percentile, axis=0, keepdims=True)
    
    # Broadcast bounds to construct 2D boolean masks
    low_mask = X < low_bounds
    high_mask = X > high_bounds
    
    # In-place broadcasted assignment
    np.copyto(X, low_bounds, where=low_mask)
    np.copyto(X, high_bounds, where=high_mask)
    return X

# Simulation: 50,000 samples, 20 features
np.random.seed(42)
features = np.random.normal(loc=100.0, scale=15.0, size=(50000, 20))
features[0, 0] = 9999.0  # Massive outlier
features[1, 5] = -500.0  # Massive negative outlier

print("Max value after winsorization:", np.max(features))
print("Min value after winsorization:", np.min(features))
```
- **Interview Key Insight**: Notice the use of `np.copyto(X, bounds, where=mask)` or broadcasted `np.where`. Using `np.copyto` with `where` guarantees zero temporary array allocation compared to `X = np.where(...)` which allocates a brand new 50,000x20 matrix on the heap.

#### Q73: How do you perform zero-allocation missing value imputation with boolean masking in production training loops?

- **Engineering Solution**: Use `np.isnan()` to generate a boolean mask directly over the array, and execute an in-place indexed write `X[np.isnan(X)] = median_values` using column-broadcasted indexing.
```python
import numpy as np

def impute_nans_columnwise_inplace(X: np.ndarray, medians: np.ndarray) -> None:
    """
    Impute NaNs in-place across columns using precalculated median values.
    Zero allocations of secondary feature matrices.
    """
    assert X.shape[1] == len(medians), "Medians length must match feature count"
    nan_mask = np.isnan(X)
    if not np.any(nan_mask):
        return  # Fast path: zero missing values
    
    # Broadcast column medians across rows for masked assignment
    # np.where(nan_mask, medians, X) allocates a new copy.
    # In-place approach:
    row_idx, col_idx = np.nonzero(nan_mask)
    X[row_idx, col_idx] = medians[col_idx]

```

Converting the mask to coordinates via `np.nonzero(nan_mask)` allows direct indexing `X[row_idx, col_idx] = medians[col_idx]` to vectorize replacement across columns without allocating copies.

```python
import numpy as np

def clean_segmentation_mask(pred_mask: np.ndarray, min_area_threshold: int = 500) -> np.ndarray:
    """
    Post-process binary drivable-area mask by removing small disconnected false positive blobs.
    """
    assert pred_mask.ndim == 2 and pred_mask.dtype == bool
    
    # 2D coordinate extraction of positive pixels
    y_coords, x_coords = np.nonzero(pred_mask)
    if len(y_coords) == 0:
        return pred_mask
    
    # Simple bounding box spatial density filter:
    # Filter pixels whose local 3x3 neighborhood has fewer than 4 supporting pixels
    pad_mask = np.pad(pred_mask, pad_width=1, mode='constant', constant_values=False)
    
    # Sum 8-neighborhood using slices
    neighbor_count = (

        pad_mask[1:-1, :-2]                                       + pad_mask[1:-1, 2:] +

    # Remove isolated pixels (speckle noise)
    cleaned_mask = pred_mask & (neighbor_count >= 3)
    return cleaned_mask
```

```python
    Computes weighted sum per row across 2D sequence arrays, ignoring padded tokens.
    """
    assert values.shape == weights.shape
    valid_mask = values != pad_value
    
    # Zero out invalid values and weights
    safe_values = np.where(valid_mask, values, 0.0)
    safe_weights = np.where(valid_mask, weights, 0.0)
    
    weighted_sums = np.sum(safe_values * safe_weights, axis=1)
    weight_totals = np.sum(safe_weights, axis=1)
    
    # Avoid division by zero for completely padded rows
    safe_weight_totals = np.where(weight_totals == 0, 1.0, weight_totals)
    return weighted_sums / safe_weight_totals

vals = np.array([[10.0, 20.0, -999.0], [5.0, -999.0, -999.0]])
wgts = np.array([[1.0, 2.0, 0.0], [3.0, 0.0, 0.0]])
means = masked_weighted_sum(vals, wgts)
assert np.isclose(means[0], (10*1 + 20*2) / 3.0)
assert np.isclose(means[1], 5.0)
```

## 10. Explain This Code (3 Scenarios)

### Scenario 1: `np.where()` Eager Evaluation Side-Effects
```python
import numpy as np

x = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])
# Warning: RuntimeWarning: divide by zero encountered in log / divide
result = np.where(x > 0, 1.0 / x, 0.0)
print("Result:", result)
```
- **What this code does**: Attempts to compute $1/x$ for positive elements and set non-positive elements to 0.0 using `np.where`.
- **Why it was written this way**: The developer intended to guard against division by zero by routing non-positive numbers to the 0.0 branch.
- **Potential risks & alternatives**: Unlike Python's ternary `a if cond else b`, `np.where(cond, x, y)` evaluates both arguments `x` and `y` across the entire array before applying the condition. When $x \le 0$, `1.0 / x` executes across zero and negative values, triggering `RuntimeWarning: divide by zero` and producing `inf`.
- **Alternative**: Pre-condition the denominator or use in-place masking:
```python
out = np.zeros_like(x)
mask = x > 0
out[mask] = 1.0 / x[mask]  # Only evaluates 1.0/x on strictly positive elements!
```

### Scenario 2: Chained Boolean Indexing Assignment Failure
```python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])
# Developer attempts to update the first element greater than 25
arr[arr > 25][0] = 999
print("Array after assignment:", arr)  # [10, 20, 30, 40, 50] -- UNCHANGED!
```
- **What this code does**: Tries to find numbers $> 25$ and mutate the first matching element to 999.
- **Why it was written this way**: The author used familiar Pandas/Python chained indexing syntax `arr[mask][0]`.
- **Potential risks & alternatives**: `arr[arr > 25]` uses boolean indexing, which creates an independent heap-allocated copy `[30, 40, 50]`. The secondary index `[0] = 999` modifies this temporary copy, which is immediately discarded by Python's garbage collector. The original array `arr` remains unchanged.
- **Alternative**: Locate the specific index using `np.nonzero()`:
```python
indices = np.nonzero(arr > 25)[0]
if len(indices) > 0:
    arr[indices[0]] = 999
```

```python
def extract_anomalies(big_telemetry: np.ndarray, threshold: float):
```

- **Buggy Code**:

1. **Does boolean indexing return a view or a copy?**

3. **What does `arr[arr > 0] = 0` do?**  
   Modifies positive elements in-place on the parent array directly without allocating an extracted copy.
4. **Why are parentheses mandatory in `(arr > 0) & (arr < 10)`?**  
   Python bitwise operators (`&`, `|`) have higher precedence than relational operators (`>`, `<`).
5. **What does `np.count_nonzero(mask)` return?**  
   The exact count of `True` elements in the mask without allocating an array of indices.
6. **What is the difference between `np.where(cond)` and `np.nonzero(cond)`?**  
   When called with only a condition, `np.where(cond)` is completely identical to `np.nonzero(cond)`.
7. **What does `np.where(cond, x, y)` do?**  
   Returns elements chosen from `x` where `cond` is True, and `y` where False.
8. **Does `np.where(cond, x, y)` short-circuit?**  
   No, both `x` and `y` are eagerly evaluated across the entire array.
9. **How do you perform multi-condition selection with multiple choices in NumPy?**  
   Use `np.select(condlist, choicelist, default=...)`.
10. **What does `arr[mask].shape` look like for a 2D array?**

## 13. Flashcards (15 Flashcards)

#### Flashcard 1
- **Front**: Why does `arr[mask]` always return an independent copy?
- **Back**: Matching elements are scattered non-linearly across memory. A NumPy view requires regular strides ($\text{offset} = \sum i_k \times s_k$), which is mathematically impossible for arbitrary coordinate subsets.
- **Key Insight**: Reading via boolean indexing allocates new memory; in-place masked assignment (`arr[mask] = x`) modifies memory in place.

#### Flashcard 2
- **Front**: Difference between Python logical operators (`and`, `or`, `not`) and NumPy operators (`&`, `|`, `~`).
- **Back**: `and`, `or`, `not` evaluate truthiness of the entire object as a single scalar boolean. `&`, `|`, `~` evaluate element-wise bitwise operations across arrays.
- **Key Insight**: Always use `&`, `|`, `~` with parentheses around each condition when filtering NumPy arrays.

#### Flashcard 3
- **Front**: What happens during chained indexing assignment: `arr[arr > 0][0] = 99`?
- **Back**: `arr[arr > 0]` creates a temporary copy. `[0] = 99` modifies that temporary copy, which is immediately garbage collected. The parent `arr` remains unchanged.
- **Key Insight**: Never chain indexing when writing to an array. Use `arr[mask] = val` or `np.nonzero()`.

#### Flashcard 4
- **Front**: What is the danger of eager evaluation in `np.where(x > 0, 1.0 / x, 0.0)`?
- **Back**: NumPy evaluates both arguments (`1.0 / x` and `0.0`) across all elements before applying the condition. When $x = 0$, `1.0 / 0` triggers a divide-by-zero runtime warning.
- **Key Insight**: Use in-place assignment or mask-guarded operations when calculations have undefined mathematical domains.

#### Flashcard 5
- **Front**: How does `np.select(condlist, choicelist, default=0)` handle overlapping conditions?
- **Back**: It evaluates conditions in priority order: the first condition in `condlist` that evaluates to `True` for an element determines its value from `choicelist`.
- **Key Insight**: Subsequent matching conditions are ignored for that element.

#### Flashcard 6
- **Front**: What is the output shape of `mat[mat > 5]` when `mat` is a 2D matrix?
- **Back**: A 1D array of shape `(K,)`, where $K$ is the number of elements matching the condition.
- **Key Insight**: Boolean indexing on multidimensional arrays flattens the output because the number of matches per row is irregular.

#### Flashcard 7
- **Front**: How do you count matching elements without allocating an array of indices?
- **Back**: `np.count_nonzero(mask)`.
- **Key Insight**: Avoid `len(np.nonzero(mask)[0])` or `len(arr[mask])` because both allocate intermediate memory.

#### Flashcard 8
- **Front**: How does 1D boolean mask indexing behave on a 2D matrix: `mat[mask_1d]`?
- **Back**: If `mask_1d.shape == (rows,)`, it filters entire rows along axis 0, preserving column structure (shape `(K, cols)`).
- **Key Insight**: Matches tabular row filtering like SQL `WHERE` clauses.

#### Flashcard 9
- **Front**: What does `np.nonzero(mask)` return?
- **Back**: A tuple of 1D integer arrays, one for each dimension of `mask`, containing the coordinates where `mask == True`.
- **Key Insight**: Directly unpackable into indexing syntax: `arr[np.nonzero(mask)]`.

#### Flashcard 10
- **Front**: Why does `np.argwhere(mask)` fail when used directly in `arr[np.argwhere(mask)]`?
- **Back**: `np.argwhere()` returns coordinates as a 2D array of shape `(K, ndim)`. NumPy interprets a 2D index array as advanced indexing across axis 0, distorting dimensions.
- **Key Insight**: Use `np.nonzero(mask)` or `tuple(np.argwhere(mask).T)` for direct indexing.

#### Flashcard 11
- **Front**: How do you safely filter out `np.nan` values from an array?
- **Back**: `clean = arr[~np.isnan(arr)]`.
- **Key Insight**: `np.isnan(arr)` returns a boolean mask of NaN locations; `~` inverts it to select valid numbers.

#### Flashcard 12
- **Front**: What is the memory footprint of a boolean array in NumPy?
- **Back**: 1 byte (8 bits) per boolean element (`np.bool_`), not 1 bit.
- **Key Insight**: A boolean mask over a 100M-element float32 array (400 MB) consumes 100 MB of RAM.

#### Flashcard 13
- **Front**: Difference between `mask.sum()` and `np.count_nonzero(mask)`.
- **Back**: `mask.sum()` sums boolean values as integers (may invoke upcasting). `np.count_nonzero(mask)` uses an optimized C loop that counts non-zeros directly without summation overhead.
- **Key Insight**: `np.count_nonzero()` is faster and more semantically explicit.

#### Flashcard 14
- **Front**: Can a boolean mask have a different shape than the array it indexes?
- **Back**: Only along sliced or broadcastable axes. For full boolean indexing, the mask shape must either match `arr.shape` exactly or match leading dimensions.
- **Key Insight**: Mismatched mask dimensions raise an `IndexError: boolean index did not match indexed array`.

#### Flashcard 15
- **Front**: How do you perform in-place conditional clipping without allocating new memory?
- **Back**: `np.copyto(arr, limit, where=arr > limit)`.
- **Key Insight**: Operates directly on the buffer without allocating an intermediate filtered array.

## 15. Fresher Answer Patterns (4 Patterns)

### Pattern 1: Answering "Why Boolean Indexing Returns a Copy, Not a View"
1. **Core Rule**: State immediately that boolean indexing always returns an independent heap copy, never a view ($O(K)$ time and memory).
2. **Mathematical Mechanics**: Explain that a NumPy view requires regular strided addressing ($\text{Address} = \text{Base} + \sum i_k \times s_k$). Because boolean conditions match arbitrary, non-contiguous elements across memory, no constant stride vector can represent the extracted subset.
3. **Contrast with Slicing**: Explicitly contrast with basic slicing (`arr[1:4]`), which preserves regular strides and returns a zero-copy view.
4. **Assignment Exception**: Clarify that while reading returns a copy, in-place masked assignment (`arr[mask] = val`) directly mutates the parent array's buffer without allocating a secondary copy.

### Pattern 2: Answering "Difference Between Python Logical Operators and NumPy Bitwise Operators"
1. **Scalar vs Vector**: Explain that Python's `and`, `or`, and `not` evaluate the truthiness of the entire container object as a single truth value, raising `ValueError` on multi-element arrays.
2. **Element-wise SIMD**: Explain that NumPy uses bitwise operators (`&`, `|`, `~`, `^`) to execute vectorized element-wise boolean operations across arrays.
3. **Operator Precedence**: Point out the critical gotcha that bitwise operators have higher precedence than comparison operators (`>`, `<`), making parentheses mandatory: `(arr > 0) & (arr < 10)`.

### Pattern 3: Answering "np.where() vs. Boolean Masking: When to Use Which"
1. **Filtering vs Replacement**: Use boolean masking (`arr[mask]`) when extracting a subset of elements (reducing array length). Use `np.where(cond, x, y)` when transforming or replacing elements while preserving array shape.
2. **Coordinate Needs**: Mention that `np.where(cond)` with a single argument returns coordinate index tuples, which is useful when element positions are required.
3. **Eager Evaluation Warning**: Note that `np.where(cond, x, y)` evaluates both `x` and `y` across the entire array, so it does not prevent mathematical errors (like division by zero) unless arguments are pre-conditioned.

### Pattern 4: Answering "How In-Place Boolean Assignment Works Despite Reading Returning a Copy"
1. **Syntax Mechanics**: Clarify that `arr[mask] = val` does not execute `temp = arr[mask]` followed by `temp = val`.
2. **C-Level PyArray_Putmask**: Explain that Python desugars this into `arr.__setitem__(mask, val)`, calling NumPy's internal C-level `PyArray_Putmask` function.
3. **Direct Buffer Mutation**: The C routine scans the mask and writes `val` directly to the target memory offsets of `arr`, completely avoiding intermediate memory allocation.

## 16. Questions That Test Understanding (5 Questions)

#### Perturbation 1: Omitting parentheses in multi-condition boolean indexing.
- **Base Code**:
```python
import numpy as np
arr = np.array([5, 15, 25])
res = arr[(arr > 10) & (arr < 20)]  # Returns [15]
```
- **Perturbation**: Changing `(arr > 10) & (arr < 20)` to `arr > 10 & arr < 20`.
- **What Changes & Why**:
  - In Python, bitwise `&` has higher operator precedence than comparison operators `>` and `<`.
  - The perturbed expression is parsed as `arr > (10 & arr) < 20`.
  - Because `10 & arr` performs bitwise AND between integer 10 and array `arr`, it evaluates to an integer array, which then attempts a chained comparison that fails with `ValueError: The truth value of an array with more than one element is ambiguous`.
- **Memory & System Impact**: Omitting parentheses causes an immediate runtime syntax or evaluation error. Parentheses around every individual condition are strictly mandatory in NumPy and Pandas.

#### Perturbation 2: Using `np.where(cond, x, y)` vs. in-place boolean assignment `arr[cond] = x`.
- **Base Code**:
```python
import numpy as np
data = np.ones((5000, 5000), dtype=np.float64)  # 200 MB
# Replace negative values with 0
data[data < 0] = 0.0
```
- **Perturbation**: Replacing with `data = np.where(data < 0, 0.0, data)`.
- **What Changes & Why**:
  - `data[data < 0] = 0.0` uses `PyArray_Putmask` to write 0.0 directly into the existing 200 MB buffer. Auxiliary memory allocated is only the temporary boolean mask (25 MB). Total memory peak: ~225 MB.
  - `np.where(data < 0, 0.0, data)` evaluates all branches and allocates a completely new 200 MB array on the heap to store the result, before reassigning the variable `data`. Total memory peak: ~425 MB.
- **Memory & System Impact**: In memory-constrained production environments or training loops, `np.where` doubles peak memory usage, which can trigger an Out-Of-Memory (OOM) killer crash.

#### Perturbation 3: Indexing with a 2D boolean mask vs. indexing with two 1D coordinate vectors.

  - `mat[mask_2d]` internally invokes boolean advanced indexing.
  - `mat[rows, cols]` invokes integer advanced indexing using coordinate arrays.
- **Memory & System Impact**: `np.nonzero(mask_2d)` allocates two coordinate arrays of length $K$. If $K$ is large, generating and passing coordinate tuples has slightly higher memory overhead than passing the boolean mask directly. However, coordinate indexing allows decoupling row and column transformations.

#### Perturbation 4: Reading via boolean mask vs. writing via boolean mask.
- **Base Code**:

- **Perturbation**: In-place assignment directly on the mask: `arr[arr > 2] = 999`.

  - In the perturbation, `arr[arr > 2] = 999` modifies the parent array in place, resulting in `arr` becoming `[1, 2, 999, 999, 999]`.

#### Q81: Pandas Integration: How does Boolean Indexing in Pandas differ mechanically from NumPy?
- **Core Concept**: Alignment by Index vs. Alignment by Position.
- **Detailed Comparison**:

#### Q84: Statistics & Probability Integration: How do Boolean Masks implement Monte Carlo Rejection Sampling?
- **Core Concept**: Sampling from complex target distributions $p(x)$ using an envelope proposal distribution $q(x)$.
- **Detailed Comparison**:
  - Rejection sampling draws proposals $x \sim q(x)$ and uniform random variates $u \sim \mathcal{U}(0, 1)$.
  - A proposal is accepted if $u \le \frac{p(x)}{M \cdot q(x)}$.
  - In vectorized NumPy implementations, millions of candidates are generated simultaneously, and an acceptance boolean mask isolates valid samples in a single $O(N)$ SIMD operation.
```python
import numpy as np

def sample_standard_normal_rejection(n_samples: int, seed: int = 42) -> np.ndarray:
    """
    Samples standard normal variates using Laplace proposal distribution and boolean mask acceptance.
    """
    rng = np.random.default_rng(seed)
    # Over-sample candidates
    proposals = rng.laplace(loc=0.0, scale=1.0, size=n_samples * 2)
    u = rng.uniform(0.0, 1.0, size=n_samples * 2)
    
    # Normal / (M * Laplace) acceptance ratio
    # M = sqrt(2 * e / pi) approx 1.3155
    M = np.sqrt(2.0 * np.e / np.pi)
    p_x = (1.0 / np.sqrt(2.0 * np.pi)) * np.exp(-0.5 * proposals**2)
    q_x = 0.5 * np.exp(-np.abs(proposals))
    
    accept_mask = u <= (p_x / (M * q_x))
    accepted = proposals[accept_mask]
    return accepted[:n_samples]

samples = sample_standard_normal_rejection(50000)
print(f"Sample mean: {np.mean(samples):.4f}, std: {np.std(samples):.4f}")
```

## 19. What to Memorize

1. **Copy Guarantee**: Reading via boolean indexing (`arr[mask]`) **always** returns an independent heap-allocated copy ($O(K)$ time and memory).
2. **In-Place Write Exception**: Writing via boolean indexing (`arr[mask] = val`) directly mutates the parent array's buffer via `PyArray_Putmask` ($O(1)$ auxiliary memory).
3. **Bitwise Operators**: Always use `&`, `|`, `~`, `^` on NumPy boolean arrays; never use `and`, `or`, `not`.
4. **Mandatory Parentheses**: Bitwise operators bind tighter than relational operators. Always wrap conditions: `(arr > 10) & (arr < 50)`.
5. **Flattening Rule**: Boolean indexing on an $N$-dimensional array ($N \ge 2$) with a matching $N$-dimensional mask collapses the output into a **1D array** of shape `(K,)`.
6. **Row Filtering Rule**: A 1D boolean mask of shape `(M,)` indexing a 2D matrix of shape `(M, N)` preserves rank 2, returning shape `(K, N)`.
7. **Eager Evaluation in `np.where`**: `np.where(cond, x, y)` evaluates both `x` and `y` completely before applying `cond`.
8. **High-Speed Counting**: Use `np.count_nonzero(mask)` rather than `mask.sum()` or `len(np.nonzero(mask)[0])`.
9. **Coordinate Extraction**: `np.nonzero(mask)` returns a tuple of 1D arrays that can directly index multidimensional arrays: `mat[np.nonzero(mask)]`.
10. **Multi-Condition Categorization**: Use `np.select(condlist, choicelist, default=...)` with short-circuit evaluation order.

## 20. What to Understand

1. **Underlying C Implementation (`PyArray_Putmask`)**:
   - When Python encounters `arr[mask] = val`, it translates this into a C routine that iterates through the data buffer and mask buffer simultaneously.
   - For every element where `mask != 0`, the pointer writes the cast value of `val` directly into the array's memory location.
   - This eliminates temporary array allocations, maximizing cache performance.

2. **Why Irregular Strides Prevent Views**:
   - A NumPy view is strictly defined by an offset and constant strides: $\text{Byte Address} = \text{Base} + i_0 \cdot s_0 + i_1 \cdot s_1 + \dots$
   - Because boolean conditions match arbitrary indices (e.g., indices 0, 4, 7, 8), the step distance between matching elements varies dynamically.
   - It is mathematically impossible to represent an irregular sequence using fixed stride constants. Hence, NumPy must allocate a new contiguous buffer and copy matching elements into it.

3. **SIMD Vectorization of Boolean Masks**:
   - Comparison operations (`arr > threshold`) execute using vector comparison instructions (e.g., `VCMPGTPS` in AVX2/AVX-512).
   - In modern CPU architectures, 16 float32 values or 64 boolean values are compared in a single clock cycle.
   - Bitwise operations (`&`, `|`, `~`) operate directly across 512-bit vector registers with zero branching, eliminating CPU branch misprediction penalties.

4. **Cache Line Utilization and Memory Footprint**:
   - A boolean array in NumPy uses **1 byte (8 bits) per element**, not 1 bit, to allow direct byte-addressability by C pointers.
   - For massive datasets (e.g., 100M elements), generating a boolean mask requires 100 MB of RAM.
   - Reading `arr[mask]` traverses memory non-sequentially, which can cause CPU L1/L2 cache misses if matching elements are far apart.

```python
    col_means = np.mean(features, axis=0, keepdims=True)
    col_stds = np.std(features, axis=0, keepdims=True)
    col_stds = np.where(col_stds == 0, 1.0, col_stds)
    
    z_scores = np.abs((features - col_means) / col_stds)
    outlier_mask = z_scores > outlier_threshold
    
    # 3. Row filtering with compound bitwise criteria
    # Keep rows where label is valid AND row has fewer than 2 outliers
    valid_labels = (labels == 0) | (labels == 1)
    clean_rows = valid_labels & (outlier_mask.sum(axis=1) < 2)
    
    # Extract clean subsets (Allocates independent copies)
    clean_X = features[clean_rows]
    clean_y = labels[clean_rows]
    
    # 4. Multi-tier categorical assignment using np.select
    feature_magnitude = np.linalg.norm(clean_X, axis=1)
    conditions = [
        feature_magnitude > 10.0,
        feature_magnitude > 5.0
    ]
    tiers = np.select(conditions, choices=["HIGH", "MEDIUM"], default="LOW")
    
    return clean_X, clean_y
```
