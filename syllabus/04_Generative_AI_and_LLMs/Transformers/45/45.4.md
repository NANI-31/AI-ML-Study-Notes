Recommended Learning Order
If your ultimate goal is Generative AI / LLM development, I would study the topics in this order:
Python → NumPy → Pandas → Data Visualization → EDA → Machine Learning → Deep Learning → PyTorch → Transformers → Hugging Face → LLMs → Prompt Engineering → Embeddings → Vector Databases → RAG → Fine-Tuning → LoRA/QLoRA → Quantization → Agents → Deployment.
This gives you a much stronger foundation than learning Transformers alone, because you will understand both the mathematics behind attention and how to actually build applications with modern Transformer/LLM models.
