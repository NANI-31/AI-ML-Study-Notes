### 18. Performance & Best Practices

Cover every important performance pattern:

**Vectorization:**
- Replace Python loops with NumPy operations — explain the 100x speedup
- Benchmark example: loop vs vectorized for 1M elements

**Memory efficiency:**
- Use the smallest dtype that fits
- Avoid `np.append()` in loops — O(n²)! Use pre-allocation or lists
- In-place operations: `a += 1` vs `a = a + 1`
- Use `out=` on ufuncs

**Contiguity:**
- C-order array operations on columns are slower
- `np.ascontiguousarray()` before column-heavy operations

**Common mistakes:**
- Using `==` to compare floats → use `np.isclose()`
- `np.int8` overflow (silent wrap-around!)
- Using `a.resize()` vs `np.resize()` (very different behavior!)
- `np.empty()` values are garbage — never read without writing first
- List comprehensions with NumPy arrays (converts to Python objects — very slow)
- `a and b` vs `a & b` on boolean arrays

Include **before/after code examples** for each optimization.
