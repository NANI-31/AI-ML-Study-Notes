### 5. Lookup & Reference Functions

This is one of the most important sections — cover thoroughly:

**VLOOKUP (legacy but still widely used):**
- `VLOOKUP(search_key, range, column_index, is_sorted)`
- Exact match: `is_sorted=FALSE`
- Approximate match: `is_sorted=TRUE`
- Limitations: can only look right, breaks when columns inserted
- Common mistakes: not locking the lookup range, wrong column index

**XLOOKUP (modern replacement — Google Sheets 2022+):**
- `XLOOKUP(search_key, lookup_range, return_range, if_not_found, match_mode, search_mode)`
- Left lookups (looks any direction)
- Return multiple columns
- `if_not_found` parameter (cleaner than wrapping in IFERROR)
- `match_mode`: 0 exact, -1 next smaller, 1 next larger, 2 wildcard
- Example: look up product price by name, return multiple fields

**HLOOKUP:**
- `HLOOKUP(search_key, range, row_index, is_sorted)` — horizontal lookup

**INDEX + MATCH (powerful combination):**
- `INDEX(range, row_num, col_num)` — return value at position
- `MATCH(search_key, range, match_type)` — return position of value
- `INDEX(data, MATCH(lookup_val, col, 0))` — flexible lookup in any direction
- Two-way lookup: `INDEX(data, MATCH(row_val, rows, 0), MATCH(col_val, cols, 0))`
- Example: find salary for an employee by name and department

**Other reference functions:**
- `OFFSET(reference, rows, cols, height, width)` — dynamic range
- `INDIRECT(ref_text)` — reference from text string
- `ADDRESS(row, col)` — cell address as text
- `ROW(reference)`, `COLUMN(reference)` — row/column number
- `ROWS(range)`, `COLUMNS(range)` — count rows/columns
- `CHOOSE(index, val1, val2, ...)` — select from list by index

Clearly distinguish VLOOKUP vs XLOOKUP vs INDEX+MATCH — when to use each.
