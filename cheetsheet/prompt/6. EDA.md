### 4. Missing Value Analysis

This is one of the most critical EDA steps — cover thoroughly:

**Detecting missing values:**
- `df.isna().sum()` — count NaN per column
- `df.isna().mean() * 100` — percentage NaN per column
- `df.isna().sum().sort_values(ascending=False)` — sorted
- `df[df['col'].isna()]` — rows with missing values in a column
- `df.isna().any(axis=1)` — rows with any missing value
- `df.isna().all(axis=1)` — rows that are entirely NaN
- `df.notna().sum()` — count non-null per column

**Visualizing missing values:**
```python
import missingno as msno   # optional library
msno.matrix(df)
msno.bar(df)
msno.heatmap(df)
```

Or with Seaborn/Matplotlib:
```python
sns.heatmap(df.isna(), cmap='viridis', cbar=False)
```

**Missing value heatmap — manual approach:**
```python
missing_pct = df.isna().mean() * 100
missing_pct[missing_pct > 0].sort_values().plot.barh()
```

**Classification of missing data:**
- MCAR — Missing Completely At Random
- MAR — Missing At Random
- MNAR — Missing Not At Random
- Explain how the type affects the chosen imputation strategy

**Strategies for handling missing values:**
- Drop rows with `dropna()`
- Drop columns above a threshold: `df.dropna(axis=1, thresh=...)`
- Fill with mean (numeric, symmetric distribution)
- Fill with median (numeric, skewed distribution)
- Fill with mode (categorical)
- Fill with a constant sentinel value (`-1`, `"Unknown"`, `0`)
- Forward fill / backward fill (time series)
- Interpolation (time series)
- Create an indicator column (is_missing flag)
- Advanced: KNN imputation, MICE (mention, don't implement)

**Decision guide:**
- Less than 5% missing → safe to drop or fill simply
- 5–30% missing → impute carefully
- More than 30% missing → consider dropping the column or flagging it

### 6. Data Type Validation & Cleaning

Cover:

**Checking and fixing data types:**
- `df.dtypes` — current types
- Converting to numeric: `pd.to_numeric(df['col'], errors='coerce')` — coerce converts errors to NaN
- Converting to datetime: `pd.to_datetime(df['col'], format=..., errors='coerce')`
- Converting to category: `df['col'].astype('category')`
- Converting to integer: `.astype(int)` — will fail if NaN present; use `.astype('Int64')` for nullable int

**Common type problems:**
- Numbers stored as strings (e.g., `"$1,234.56"` or `"1,234"`)
  - Strip currency: `df['price'].str.replace('[$,]', '', regex=True).astype(float)`
- Dates stored as strings
  - `pd.to_datetime(df['date_col'])`
- Booleans stored as `"Yes"`/`"No"` or `1`/`0`
  - `df['active'].map({'Yes': True, 'No': False})`
- Whitespace in string columns
  - `df['col'] = df['col'].str.strip()`
- Mixed types in a column (numeric and text)
  - `pd.to_numeric(df['col'], errors='coerce')` to force numeric, NaN where conversion fails

**Standardizing categorical values:**
- Inconsistent case: `"male"`, `"Male"`, `"MALE"` → `df['gender'].str.title()`
- Extra spaces: `" New York "` → `"New York"` via `.str.strip()`
- Synonyms: `"M"`, `"Male"`, `"male"` → map to canonical form with `.replace()` or `.map()`

### 7. Univariate Analysis — Numeric Variables

This is the heart of EDA — understand each variable independently:

**Summary statistics:**
- `df['col'].describe()` — count, mean, std, min, quartiles, max
- `df['col'].mean()`, `df['col'].median()`, `df['col'].mode()[0]`
- `df['col'].std()`, `df['col'].var()`
- `df['col'].skew()` — measure of asymmetry
- `df['col'].kurt()` — measure of tail heaviness (kurtosis)
- `df['col'].quantile([0.01, 0.05, 0.25, 0.5, 0.75, 0.95, 0.99])`

**Visualizing numeric distributions:**
- Histogram: `sns.histplot(df['col'], bins=30, kde=True)`
- KDE plot: `sns.kdeplot(df['col'], fill=True)`
- Box plot: `sns.boxplot(y=df['col'])`
- Violin plot: `sns.violinplot(y=df['col'])`
- ECDF: `sns.ecdfplot(df['col'])`

**Interpreting distributions:**
- Symmetric (normal-like)
- Right-skewed (long tail to the right — common in revenue, income)
- Left-skewed (long tail to the left)
- Bimodal (two peaks — suggests two subpopulations)
- Uniform
- Exponential

**Interpreting summary statistics:**
- Mean vs median: if they differ significantly → distribution is skewed
- High std relative to mean → high variability
- Very high kurtosis → heavy tails, potential extreme outliers

### 9. Outlier Detection & Treatment

Cover the main outlier detection methods:

**Statistical methods:**
- Z-score method: `|z| > 3` are outliers
  ```python
  from scipy import stats
  z_scores = np.abs(stats.zscore(df['col']))
  outliers = df[z_scores > 3]
  ```
- IQR method (more robust to skewed data):
  ```python
  Q1 = df['col'].quantile(0.25)
  Q3 = df['col'].quantile(0.75)
  IQR = Q3 - Q1
  lower = Q1 - 1.5 * IQR
  upper = Q3 + 1.5 * IQR
  outliers = df[(df['col'] < lower) | (df['col'] > upper)]
  ```
- Modified Z-score with median (most robust)
- Percentile capping: cap at 1st and 99th percentiles

**Visual methods:**
- Box plot — whiskers show IQR bounds, dots are outliers
- Scatter plot — look for isolated points
- Histogram — extreme values in tails
- Z-score plot

**Domain knowledge:**
- Sometimes "outliers" are valid data (billionaire income in a survey)
- Sometimes they are data entry errors (`age = 999`)
- Check each outlier in context

**Treatment strategies:**
- Remove (only if clearly erroneous)
- Cap/clip (winsorize) to percentile bounds
- Transform (log transform reduces right-skew impact)
- Flag as a feature (`is_outlier = 1`)
- Leave in (if the outlier is real and informative)

### 10. Bivariate Analysis — Numeric vs Numeric

Cover:

**Correlation analysis:**
- `df.corr()` — Pearson correlation matrix (linear relationships)
- `df.corr(method='spearman')` — Spearman rank correlation (monotonic, non-linear)
- `df.corr(method='kendall')` — Kendall Tau (robust to outliers)
- Interpreting correlation:
  - |r| < 0.3 → weak
  - 0.3–0.7 → moderate
  - |r| > 0.7 → strong
  - Correlation ≠ causation

**Visualizing numeric-numeric relationships:**
- Scatter plot: `sns.scatterplot(data=df, x='col1', y='col2', alpha=0.3)`
- Scatter with regression line: `sns.regplot(data=df, x='col1', y='col2')`
- Correlation heatmap:
  ```python
  mask = np.triu(np.ones_like(corr, dtype=bool))
  sns.heatmap(corr, annot=True, fmt='.2f', mask=mask, cmap='coolwarm', center=0)
  ```
- Pair plot: `sns.pairplot(df[numeric_cols].sample(500))`
- Hexbin for large datasets: `plt.hexbin(df['x'], df['y'], gridsize=30, cmap='Blues')`
- `sns.jointplot(data=df, x='col1', y='col2', kind='kde')`

**Key things to look for:**
- Positive vs negative correlation
- Linear vs non-linear relationships
- Multicollinearity (when building models)
- Clusters or subgroups in scatter plots

## 16. Complete EDA Workflow Template

Provide a complete, runnable Python EDA template that can be applied to any tabular dataset:

```python
# =====================================================
# COMPLETE EDA TEMPLATE
# =====================================================

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.ticker as ticker
import seaborn as sns
from scipy import stats

sns.set_theme(style='whitegrid', palette='muted')
plt.rcParams['figure.figsize'] = (10, 6)

# ── 1. LOAD DATA ───────────────────────────────────
df = pd.read_csv('data.csv', parse_dates=['date_col'])

# ── 2. FIRST LOOK ──────────────────────────────────
print(f"Shape: {df.shape}")
print(f"Columns: {df.columns.tolist()}")
df.head()
df.info()
df.describe(include='all')

# ── 3. DATA TYPES ──────────────────────────────────
numeric_cols = df.select_dtypes(include='number').columns.tolist()
categorical_cols = df.select_dtypes(include='object').columns.tolist()
datetime_cols = df.select_dtypes(include='datetime').columns.tolist()
print(f"Numeric: {len(numeric_cols)}, Categorical: {len(categorical_cols)}, Datetime: {len(datetime_cols)}")

# ── 4. MISSING VALUES ──────────────────────────────
missing = df.isna().sum()
missing_pct = df.isna().mean() * 100
missing_df = pd.DataFrame({'count': missing, 'pct': missing_pct})
print(missing_df[missing_df['count'] > 0].sort_values('pct', ascending=False))

# ── 5. DUPLICATES ──────────────────────────────────
print(f"Duplicate rows: {df.duplicated().sum()}")

# ── 6. UNIVARIATE — NUMERIC ────────────────────────
for col in numeric_cols:
    print(f"\n{col}: mean={df[col].mean():.2f}, median={df[col].median():.2f}, skew={df[col].skew():.2f}")

# ── 7. UNIVARIATE — CATEGORICAL ────────────────────
for col in categorical_cols:
    print(f"\n{col}: {df[col].nunique()} unique")
    print(df[col].value_counts().head(5))

# ── 8. OUTLIERS (IQR) ──────────────────────────────
for col in numeric_cols:
    Q1, Q3 = df[col].quantile([0.25, 0.75])
    IQR = Q3 - Q1
    outliers = df[(df[col] < Q1 - 1.5*IQR) | (df[col] > Q3 + 1.5*IQR)]
    if len(outliers) > 0:
        print(f"{col}: {len(outliers)} outliers ({len(outliers)/len(df)*100:.1f}%)")

# ── 9. CORRELATION ─────────────────────────────────
corr = df[numeric_cols].corr()
mask = np.triu(np.ones_like(corr, dtype=bool))
sns.heatmap(corr, annot=True, fmt='.2f', mask=mask, cmap='coolwarm', center=0)
plt.title('Correlation Matrix')
plt.tight_layout()
plt.show()

# ── 10. DISTRIBUTION PLOTS ─────────────────────────
fig, axes = plt.subplots(len(numeric_cols), 2, figsize=(14, 4*len(numeric_cols)))
for i, col in enumerate(numeric_cols):
    sns.histplot(df[col], ax=axes[i, 0], kde=True, bins=30)
    axes[i, 0].set_title(f'{col} — Distribution')
    sns.boxplot(y=df[col], ax=axes[i, 1])
    axes[i, 1].set_title(f'{col} — Box Plot')
plt.tight_layout()
plt.show()
```

Explain every step clearly so users can adapt it to any dataset.
