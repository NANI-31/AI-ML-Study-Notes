**Global theme:**
- `sns.set_theme()` — set style + context + palette + font in one call
- `sns.reset_defaults()` — reset to Matplotlib defaults
- `sns.reset_orig()` — reset to original Matplotlib settings

### 3. Relational Plots — Exploring Relationships

Cover each plot type with explanation of when to use it, key parameters, and realistic examples:

**`sns.relplot()` — Figure-level relational plots:**
- `kind='scatter'` (default)
- `kind='line'`
- `col=`, `row=` — faceted small multiples
- `hue=`, `size=`, `style=` — visual grouping dimensions
- Returns a `FacetGrid` object

**`sns.scatterplot()` — Axes-level scatter plot:**
- `x=`, `y=`, `hue=`, `size=`, `style=`, `palette=`, `alpha=`, `ax=`
- Using size to encode a third variable
- Using style (marker) to encode a fourth variable
- Example: scatter plot of customer age vs purchase amount, colored by segment, sized by loyalty score

**`sns.lineplot()` — Axes-level line plot:**
- `x=`, `y=`, `hue=`, `style=`, `size=`, `units=`, `estimator=`, `errorbar=`
- Automatic confidence intervals with `errorbar='ci'`
- `estimator=None` to plot raw data without aggregation
- Example: monthly revenue trend by region

For each, also explain:
- The difference between figure-level (`relplot`) and axes-level (`scatterplot`, `lineplot`) functions
- When to use `hue=` vs `col=`/`row=` for grouping

### 4. Distribution Plots — Understanding Data Distributions

Cover:

**`sns.displot()` — Figure-level distribution plots:**
- `kind='hist'` — histogram
- `kind='kde'` — KDE (kernel density estimate)
- `kind='ecdf'` — empirical CDF
- `col=`, `row=`, `hue=`, `facet_kws=`

**`sns.histplot()` — Axes-level histogram:**
- `x=`, `y=`, `hue=`, `bins=`, `binwidth=`, `stat=` (`'count'`, `'density'`, `'probability'`, `'percent'`, `'frequency'`), `multiple=` (`'layer'`, `'dodge'`, `'stack'`, `'fill'`), `cumulative=`, `kde=`
- Overlapping histograms with `hue=` and `alpha`
- Example: distribution of employee salaries by department

**`sns.kdeplot()` — Axes-level KDE:**
- `x=`, `y=`, `hue=`, `fill=`, `bw_adjust=`, `cut=`, `cumulative=`, `levels=` (for 2-D)
- 2-D KDE with bivariate density
- Example: joint density of age and income

**`sns.ecdfplot()` — Empirical CDF:**
- `x=`, `hue=`, `complementary=`

**`sns.rugplot()` — Rug plot:**
- Add tick marks along axis to show data points

**`sns.jointplot()` — Joint distribution plot:**
- `x=`, `y=`, `kind=` (`'scatter'`, `'kde'`, `'hist'`, `'hex'`, `'reg'`, `'resid'`)
- `marginal_kws=`, `joint_kws=`
- Returns a `JointGrid` object

**`sns.pairplot()` — Pairwise relationships:**
- `data=`, `hue=`, `diag_kind=` (`'auto'`, `'hist'`, `'kde'`), `kind=` (`'scatter'`, `'kde'`, `'hist'`, `'reg'`), `corner=True`
- `plot_kws=`, `diag_kws=`
- Returns a `PairGrid` object

For each, explain:
- When to use each distribution plot
- Common parameters and their effects
- A realistic example

### 5. Categorical Plots — Visualizing Categorical Data

Cover the full family of categorical plots:

**Figure-level:**
- `sns.catplot()` — unified figure-level function for all categorical plots
  - `kind=` parameter selects the plot type

**Axes-level categorical plot functions:**

*Strip and swarm plots (show all individual data points):*
- `sns.stripplot()` — jittered points
  - `x=`, `y=`, `hue=`, `jitter=`, `dodge=`, `order=`, `native_scale=`
- `sns.swarmplot()` — non-overlapping points
  - Good for small datasets

*Box plots:*
- `sns.boxplot()` — quartiles, median, whiskers, outliers
  - `x=`, `y=`, `hue=`, `order=`, `palette=`, `width=`, `flierprops=`
  - Grouped box plots with `hue=`
  - Example: salary distribution by department and gender

*Violin plots:*
- `sns.violinplot()` — KDE + box plot
  - `x=`, `y=`, `hue=`, `split=`, `inner=` (`'box'`, `'quart'`, `'point'`, `'stick'`, `None`), `bw_adjust=`, `scale=` (`'area'`, `'count'`, `'width'`)
  - `split=True` — half-violin on each side for two groups

*Combined:*
- `sns.boxenplot()` — letter-value plot (extended box plot for large datasets)
- Overlaying strip on box: `sns.boxplot()` + `sns.stripplot()` on same `ax`
- Overlaying swarm on violin

*Bar plots (showing mean + CI):*
- `sns.barplot()` — mean with confidence interval
  - `x=`, `y=`, `hue=`, `estimator=`, `errorbar=` (`'ci'`, `'pi'`, `'se'`, `'sd'`, `None`), `capsize=`, `order=`
  - Distinguish `sns.barplot()` (mean + CI) from a raw bar chart

*Count plots:*
- `sns.countplot()` — bar chart of category frequencies
  - `x=` or `y=`, `hue=`, `order=`, `palette=`
  - Example: count of customers by segment

*Point plots:*
- `sns.pointplot()` — point estimates with CI connected by lines
  - `x=`, `y=`, `hue=`, `estimator=`, `dodge=`
  - Good for interaction effects

Explain clearly:
- Categorical vs ordinal vs nominal — and which plot suits which
- When to use bar vs point vs box vs violin
- `order=` to control category ordering

### 6. Regression Plots — Visualizing Statistical Relationships

Cover:

**`sns.lmplot()` — Figure-level regression (most common):**
- `x=`, `y=`, `data=`, `hue=`, `col=`, `row=`, `scatter=`, `fit_reg=`

- `logistic=True` — logistic regression line
- `ci=` — confidence interval width
- `robust=True` — robust regression
- `lowess=True` — LOWESS smoother
- Returns a `FacetGrid`

**`sns.regplot()` — Axes-level regression:**
- Same parameters as `lmplot()` but returns an `Axes`
- Can be used inside `plt.subplots()` layouts
- Example: regression of advertising spend vs sales

**`sns.residplot()` — Residual plot:**
- Visualize residuals from a linear regression

**`sns.jointplot(kind='reg')` — Regression with marginal distributions**

Explain:
- Difference between `lmplot()` and `regplot()`
- When regression plots are more informative than scatter plots
- How to interpret confidence bands
