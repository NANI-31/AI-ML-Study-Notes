#### 1. Client Architecture & Collection Lifecycle

- **Target Folder:** `GEN AI/8. ChromaDB/01_client_collections/`
- **Core API & Methods:** `chromadb.Client()`, `chromadb.PersistentClient(path=...)`, `chromadb.HttpClient(host=..., port=...)`, `client.create_collection()`, `client.get_collection()`, `client.get_or_create_collection()`, `client.delete_collection()`, `client.list_collections()`, `client.reset()`, `Settings` configuration
- **Core Topics:** Ephemeral in-memory vs. persistent on-disk clients, client-server HTTP configurations, collection naming constraints (3–63 chars, alphanumeric, no consecutive periods), metadata assignment during collection creation, and collection deletion safeguards.
- **RAG / GenAI Applications:** Multi-environment client bootstrapping (local testing vs. Docker containerized API), isolated collection routing per document repository.

#### 2. CRUD Data Ingestion & State Operations

- **Target Folder:** `GEN AI/8. ChromaDB/02_crud_data_management/`
- **Core API & Methods:** `collection.add()`, `collection.upsert()`, `collection.update()`, `collection.delete()`, `collection.get()`, `collection.count()`, parameters: `ids`, `documents`, `metadatas`, `embeddings`, `uris`
- **Core Topics:** Unique ID generation schemes (UUIDs vs. deterministic hash IDs), batch ingestion mechanics and optimal batch size limits, atomic insertion vs. updating existing records via `upsert()`, deleting by ID list vs. metadata filter, retrieving records by ID with pagination (`limit`, `offset`), and handling missing or malformed payloads.
- **RAG / GenAI Applications:** Real-time knowledge base document synchronization, incremental updates when source documentation changes, automated stale document purging.

#### 3. Embeddings & Embedding Functions

- **Target Folder:** `GEN AI/8. ChromaDB/03_embeddings_embedding_functions/`
- **Core API & Methods:** `embedding_functions.DefaultEmbeddingFunction` (ONNX `all-MiniLM-L6-v2`), `SentenceTransformerEmbeddingFunction`, `OpenAIEmbeddingFunction`, `HuggingFaceEmbeddingFunction`, `CohereEmbeddingFunction`, `GooglePalmEmbeddingFunction`, custom `EmbeddingFunction` subclasses
- **Core Topics:** Implementing the `EmbeddingFunction` interface (`__call__(input: Documents) -> Embeddings`), embedding dimension compatibility (e.g., 384 vs. 1536 vs. 3072), local CPU/GPU execution vs. remote cloud API rate-limiting, and preventing the fatal dimension mismatch error when querying existing collections.
- **RAG / GenAI Applications:** Swapping proprietary embedding models (OpenAI `text-embedding-3-small`) with privacy-compliant on-premises models (SentenceTransformers) in regulated enterprise RAG pipelines.

#### 4. Vector Distance Metrics & HNSW Indexing Mathematics

- **Target Folder:** `GEN AI/8. ChromaDB/04_distance_metrics_hnsw_math/`
- **Core API & Methods:** Collection metadata configuration: `{"hnsw:space": "cosine" | "l2" | "ip"}`, `hnsw:construction_ef`, `hnsw:M`, `hnsw:search_ef`, `hnsw:num_threads`
- **Core Topics:** Mathematical formulations: Squared Euclidean ($L_2 = \sum (u_i - v_i)^2$), Cosine Distance ($1 - \frac{u \cdot v}{\|u\|_2 \|v\|_2}$), Inner Product ($IP = 1 - \sum u_i v_i$ for normalized vectors); Hierarchical Navigable Small World (HNSW) graphs: trade-offs between memory footprint, indexing speed, query latency, and recall accuracy.
- **RAG / GenAI Applications:** Selecting the mathematically optimal space for normalized embeddings, tuning search precision (`search_ef`) vs. latency in high-throughput query APIs.

#### 5. Querying & Semantic Retrieval Mechanics

- **Target Folder:** `GEN AI/8. ChromaDB/05_querying_semantic_retrieval/`
- **Core API & Methods:** `collection.query()`, `query_texts`, `query_embeddings`, `n_results`, `include=['documents', 'metadatas', 'distances', 'embeddings', 'uris', 'data']`, result dictionary structure
- **Core Topics:** Text-based query auto-embedding vs. pre-computed query vectors, multi-query batching (`query_texts=["q1", "q2"]`), unpacking nested result dictionaries, distance threshold filtering, relationship between distance values and semantic relevance scores.
- **RAG / GenAI Applications:** Top-$K$ chunk retrieval for context window packing, multi-query expansion handling, confidence scoring for fallback search.

#### 6. Metadata Filtering & Logical Operators (`where`)

- **Target Folder:** `GEN AI/8. ChromaDB/06_metadata_filtering_logical_ops/`
- **Core API & Methods:** `where` clause dictionaries: `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$nin`, compound operators: `$and`, `$or`
- **Core Topics:** Filtering vector searches by structured attributes, operator nesting rules (e.g., combining `$and` with multiple `$in` expressions), type restrictions (strings, ints, floats, booleans only), avoiding unindexed metadata query bottlenecks.
- **RAG / GenAI Applications:** Role-based access control (filtering chunks where `tenant_id == user_org`), temporal filtering (`published_year >= 2024`), category filtering (`doc_type == "contract"`).

#### 7. Document Content Filtering (`where_document`)

- **Target Folder:** `GEN AI/8. ChromaDB/07_document_content_filtering/`
- **Core API & Methods:** `where_document` clause: `$contains`, `$not_contains`, combining `where` (metadata) and `where_document` (content) in a single `query()`
- **Core Topics:** Substring matching within raw document text during vector similarity search, case sensitivity rules, negative filtering with `$not_contains`, compound content queries via `$and`/`$or`.
- **RAG / GenAI Applications:** Enforcing mandatory keywords (e.g., retrieving only chunks containing "Section 4.1" or "Clause B"), filtering out boilerplate disclaimer text.

#### 12. Advanced Retrieval: Hybrid Search, Reranking & MMR

- **Target Folder:** `GEN AI/8. ChromaDB/12_hybrid_search_reranking_mmr/`
