#### 1. RAG Architecture Foundations & Pipeline Anatomy

- **Target Folder:** `01_rag_architecture_foundations/`
- **Core Topics:** Naive RAG vs. Advanced RAG vs. Modular RAG; Knowledge cutoffs vs. hallucinations; Ingestion $\to$ Retrieval $\to$ Augmentation $\to$ Generation lifecycle; RAG vs. Fine-Tuning vs. Long-Context Windows (cost, latency, data privacy, and knowledge freshness trade-offs); Parametric memory (model weights) vs. Non-parametric memory (external retrieval).
- **Failure Modes & Scenarios:** Evaluating when fine-tuning is required (style/syntax) vs. when RAG is mandatory (factual accuracy/private enterprise documents); analyzing context length limits and retrieval latency trade-offs.

---

#### 2. Document Loading, Parsing & Multimodal Ingestion

- **Target Folder:** `02_document_loading_multimodal_ingestion/`
- **Core Topics:** Document loaders (PDFs, DOCX, Markdown, HTML, CSV, JSON); Layout-aware parsing (headers, lists, tables, footnotes); OCR engines for scanned documents; Extracting and preserving rich metadata (breadcrumbs, section hierarchy, page numbers, timestamps, author, document IDs); Incremental ingestion and change-data-capture (CDC).
- **Failure Modes & Scenarios:** Parsing multi-column academic PDFs without merging text across columns; extracting financial tabular data without destroying row-column relationships; automated duplicate document detection.

---

#### 3. Text Chunking Strategies & Granularity

- **Target Folder:** `03_chunking_strategies_granularity/`
- **Core Topics:** Chunk size vs. chunk overlap mathematics; Fixed-character chunking vs. Token-based chunking; Recursive character text splitting (`RecursiveCharacterTextSplitter`); Sentence and paragraph splitting; Semantic chunking (embedding distance thresholding between consecutive sentences); Structure-aware splitting (Markdown headers, HTML tags, programming code syntax); Small2Big / Parent-Document chunking patterns.
- **Failure Modes & Scenarios:** Eliminating the "boundary context loss" problem where key answers straddle chunk boundaries; tuning chunk size to avoid embedding noise (chunks too large) vs. loss of semantic meaning (chunks too small).

---

#### 4. Vector Embeddings & Similarity Metrics

- **Target Folder:** `04_vector_embeddings_similarity_metrics/`
- **Core Topics:** Dense vector embeddings (OpenAI `text-embedding-3`, BGE, Cohere, Sentence-Transformers); Geometric similarity metrics: Cosine Similarity, Dot Product, and Euclidean Distance ($L_2$ norm); Embedding normalization and dimensionality reduction (Matryoshka Representation Learning); Asymmetric search (short query vs. long passage embeddings); Domain-specific and multilingual embedding models.
- **Failure Modes & Scenarios:** Diagnosing vector drift across embedding versions; performance trade-offs of 1536 vs. 768 vs. 384 dimensions; selecting the correct metric when vectors are unnormalized vs. normalized to unit length.

---

#### 5. Vector Databases & Storage Architecture

- **Target Folder:** `05_vector_databases_storage/`
- **Core Topics:** Dedicated vector databases (Pinecone, Qdrant, Weaviate, Milvus, Chroma) vs. relational vector extensions (`pgvector`, Elasticsearch); Collection architecture, namespaces, and partition keys; Vector CRUD operations; Metadata payload storage and inverted index filtering; Persistence, clustering, read/write replication, and backup strategies.
- **Failure Modes & Scenarios:** Pre-filtering vs. Post-filtering metadata (the "empty result set" problem when post-filtering low-cardinality metadata); optimizing memory footprints between disk-backed vs. in-memory vector stores.

---

#### 6. ANN (Approximate Nearest Neighbor) Indexing Algorithms

- **Target Folder:** `06_ann_indexing_algorithms/`
- **Core Topics:** Exact Flat search (KNN) vs. Approximate Nearest Neighbors (ANN); Hierarchical Navigable Small World (HNSW) graphs (layers, `efConstruction`, `M`, `efSearch`); Inverted File Indexing (IVF) with Voronoi cells; Quantization techniques: Product Quantization (PQ) and Scalar Quantization (SQ); Index build time vs. recall vs. query latency trade-offs.
- **Failure Modes & Scenarios:** Diagnosing recall drops in high-dimensional vector spaces; tuning `M` and `efSearch` for high-throughput production workloads; quantifying index memory usage during scale-up.

---

#### 7. Retrieval Strategies & Semantic Search

- **Target Folder:** `07_retrieval_strategies_mmr/`
- **Core Topics:** Standard Top-$K$ retrieval; Similarity score thresholding; Maximum Marginal Relevance (MMR) for diversity and redundancy reduction ($\lambda \cdot \text{Sim}(q, d) - (1-\lambda) \cdot \max \text{Sim}(d, d_i)$); Contextual compression retrievers; Hierarchical / Parent-Document retrieval (searching child chunks, returning parent passages); Self-Querying retrievers (translating natural language into vector filters).
- **Failure Modes & Scenarios:** Resolving retrieval redundancy where Top-5 results are near-duplicate chunks; retrieving small chunks for precise matching while passing large chunks to the LLM for sufficient reasoning context.

---

#### 8. Hybrid Search & Fusion Algorithms

- **Target Folder:** `08_hybrid_search_rrf_fusion/`
- **Core Topics:** Combining sparse lexical retrieval (BM25, TF-IDF) with dense semantic retrieval (Vector Search); Sparse-Dense hybrid representations (SPLADE, BGE-M3); Reciprocal Rank Fusion (RRF) algorithm ($RRF(d) = \sum \frac{1}{k + r(d)}$); Weighted score combination and score normalization (Min-Max scaling); Exact keyword match preservation (part numbers, acronyms, dates).
- **Failure Modes & Scenarios:** Preventing vector search failures on exact domain terms, model numbers, or rare technical jargon; tuning the RRF smoothing constant $k$ and dense/sparse balance weights.

---

#### 9. Query Transformation, Expansion & Routing

- **Target Folder:** `09_query_transformation_expansion/`
- **Core Topics:** Query rewriting and query normalization; Multi-Query expansion (generating multiple perspective queries via LLM); Hypothetical Document Embeddings (HyDE - generating a synthetic answer to search for real documents); Step-Back prompting (abstracting broad conceptual queries); Sub-question decomposition for multi-hop questions; Semantic and classifier-based query routing.
- **Failure Modes & Scenarios:** Eliminating conversational ambiguity in follow-up chat queries (co-reference resolution); preventing HyDE hallucination drift when generating hypothetical passages for obscure technical domains.

---

#### 10. Re-Ranking & Cross-Encoder Architectures

- **Target Folder:** `10_reranking_cross_encoders/`
- **Core Topics:** Bi-Encoder architecture (fast, independent query/document embeddings) vs. Cross-Encoder architecture (deep all-to-all cross-attention); Two-stage retrieval pipelines (Retrieve Top-50 via Bi-Encoder $\to$ Rerank to Top-5 via Cross-Encoder); Reranker models (Cohere Rerank, BAAI/BGE-Reranker, ColBERT late interaction); Relevance scoring thresholds.
- **Failure Modes & Scenarios:** Balancing latency overhead of cross-encoders in real-time user-facing applications; filtering out irrelevant passages that scored high on vector similarity but low on exact relevance.

---

#### 11. Context Engineering & Compression

- **Target Folder:** `11_context_engineering_compression/`
- **Core Topics:** Context window budgeting; The "Lost-in-the-Middle" phenomenon (LLM attention degradation on middle context chunks); Context re-ordering (placing high-relevance chunks at the start and end of the prompt); Contextual compression (extracting only relevant sentences from retrieved chunks); Extractive vs. Abstractive chunk summarization; Deduplication of overlapping retrieved context.
- **Failure Modes & Scenarios:** Preventing prompt token bloat and latency spikes; resolving contradictory information across retrieved documents from different publication dates.

---

#### 12. Prompt Engineering, Grounded Generation & Citations

- **Target Folder:** `12_prompt_engineering_grounded_generation/`
- **Core Topics:** RAG prompt templates (System instructions, Retrieved context delimiter, User query); Strict grounding constraints ("Answer solely based on the provided context"); Handling unanswerable / out-of-domain queries ("If information is missing, state 'I do not know'"); Automated inline source citations `[1]`, `[Doc-ID]`; Structured outputs using JSON Schemas / Pydantic validation.
- **Failure Modes & Scenarios:** Eliminating subtle LLM hallucinations where the model supplements incomplete context with internal training memory; validating citation accuracy against retrieved source spans.

---

#### 13. RAG Evaluation Frameworks & Quality Metrics

- **Target Folder:** `13_rag_evaluation_ragas_metrics/`
- **Core Topics:** The RAG Triad (Context Relevance, Groundedness / Faithfulness, Answer Relevance); Retrieval evaluation metrics: Hit Rate@K, Mean Reciprocal Rank (MRR), Normalized Discounted Cumulative Gain (NDCG), Precision@K, Recall@K; Generation evaluation metrics: Faithfulness, Semantic Similarity, Factual Correctness; Evaluation frameworks: RAGAS, TruLens, DeepEval; LLM-as-a-Judge methodology and judge bias mitigation.
- **Failure Modes & Scenarios:** Constructing synthetic test datasets (Golden QA datasets) with automated ground truth; diagnosing whether a low-quality response stems from a Retrieval Failure vs. a Generation Failure.

---

#### 14. Advanced & Agentic RAG (Self-RAG, CRAG, Adaptive RAG)

- **Target Folder:** `14_agentic_rag_self_corrective/`
- **Core Topics:** Passive RAG vs. Active / Agentic RAG; Self-RAG (reflection tokens: `[Retrieve]`, `[IsRel]`, `[IsSup]`, `[IsUse]`); Corrective RAG (CRAG - evaluating retrieval confidence, triggering web search fallback when confidence is low); Adaptive RAG (routing between no-retrieval, iterative retrieval, and multi-step retrieval based on query complexity); Multi-turn conversation state and agent memory.
- **Failure Modes & Scenarios:** Preventing infinite agent retrieval loops; handling complex multi-hop queries requiring sequential chained lookups across multiple documents.

---

#### 15. Graph RAG, Structured Data & Multimodal Integration

- **Target Folder:** `15_graph_rag_structured_multimodal/`
- **Core Topics:** Knowledge Graph RAG (GraphRAG - entities, relationships, communities, and global summary retrieval); Hybrid Vector + Graph search; Structured data RAG (Text-to-SQL, schema linking, few-shot SQL generation, query execution and safety); Multimodal RAG (ColPali vision-based document retrieval, CLIP embeddings, multimodal LLMs for charts, diagrams, and visual tables).
- **Failure Modes & Scenarios:** Answering holistic dataset questions (e.g., "What are the main themes across all 5,000 documents?") that vector search fails to capture; preventing destructive SQL execution (read-only transactions, schema guardrails).

---

#### 16. Production MLOps, Security & Scalability

- **Target Folder:** `16_production_mlops_security_caching/`
- **Core Topics:** RAG security vulnerabilities: Indirect prompt injection through poisoned documents, context poisoning, and sensitive data leakage; Enterprise Access Control (Document-level and chunk-level Role-Based Access Control [RBAC], tenant isolation); Semantic caching (GPTCache) to eliminate redundant LLM and retrieval calls; Streaming responses and asynchronous concurrency; Observability and tracing (LangSmith, Arize Phoenix, OpenTelemetry).
- **Failure Modes & Scenarios:** Enforcing strict user ACLs during vector search (ensuring User A never retrieves confidential HR documents); mitigating prompt injection attacks hidden within retrieved web pages or customer emails.
