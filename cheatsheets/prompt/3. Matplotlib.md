### 16. Performance & Best Practices

Cover:

- `plt.close(fig)` — always close figures to free memory
- `plt.close('all')` — close all figures
- Use `fig, ax = plt.subplots()` (OO API) for scripts and libraries
- Use `plt.` (pyplot) for quick interactive exploration
- Avoid `plt.show()` inside loops (batch renders are faster)
- Blitting in animations for performance
- Use `ax.plot()` once with pre-computed arrays vs calling plot in a loop
- Memory: avoid creating figures in a loop without closing them
- Fast rendering for large datasets: `ax.plot()` with reduced marker density, `ax.scatter()` with alpha

- Legend not showing — missing `label=` parameter or `ax.legend()` not called
- Tick labels overlapping — fix with `plt.tight_layout()` or `rotation=45`
- Date axis not formatted correctly
- Colorbar takes too much space — use `shrink=0.8`
- `ax` object lost when using `plt.subplot()` — use `fig, axes = plt.subplots()`
