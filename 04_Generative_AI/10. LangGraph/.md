#### 1. Core Graph Architecture & Runtime Execution

- **Target Folder:** `GEN AI/4. LangGraph/01_core_graph_runtime/`
- **Core API & Primitives:** `StateGraph`, `START`, `END`, `.compile()`, `.invoke()`, `.ainvoke()`, `recursion_limit`, node registration (`.add_node()`), static edges (`.add_edge()`)
- **Core Topics:** Graph vs. chain paradigms, deterministic directed graphs vs. cyclic stateful workflows, compilation phase validation (unreachable nodes, missing sinks), node function signatures (state in, state update out), synchronous vs. asynchronous execution loops, handling recursion depth limits and max iteration exceptions.
- **Production Scenarios:** Building linear sequential pipelines, single-node iterative loops, handling infinite loop runaway guardrails.

---

#### 2. State Schemas, Reducers & Channel Mechanics

- **Target Folder:** `GEN AI/4. LangGraph/02_state_schemas_reducers/`
- **Core API & Primitives:** `TypedDict`, `dataclasses`, `pydantic.BaseModel`, `MessagesState`, `Annotated[list, add]`, `operator.add`, custom reducer callables, channel keys
- **Core Topics:** Default state overwriting vs. additive reducers, custom list accumulation and deduplication reducers, input/output schemas (restricting user-facing inputs while maintaining internal private channels), schema validation, and immutable state updating semantics.
- **Production Scenarios:** Tracking conversational context, accumulating tool execution artifacts, managing intermediate scratchpads across multi-step reasoning.

---

#### 3. Control Flow, Conditional Edges & Dynamic Branching

- **Target Folder:** `GEN AI/4. LangGraph/03_edges_conditional_routing/`
- **Core API & Primitives:** `.add_conditional_edges()`, path functions, path mapping dictionaries, `tools_condition`, entry point routing
- **Core Topics:** Dynamic routing based on model outputs or evaluation scores, conditional entry points from `START`, fan-out branching to parallel nodes, fan-in convergence to collector nodes, self-correction reflection cycles, and fallback paths for unhandled edge states.
- **Production Scenarios:** Routing queries between fast lightweight models and slow reasoning models, evaluating code generation outputs for syntax errors before execution.

---

#### 4. The Command API (Unified State Updates & Routing)

- **Target Folder:** `GEN AI/4. LangGraph/04_command_api/`
- **Core API & Primitives:** `Command(update={...}, goto="node_name")`, `Command(resume=...)`, `Command(graph=Command.PARENT)`, multi-target `goto=["node_a", "node_b"]`
- **Core Topics:** Eliminating redundant conditional edge definitions by co-locating state updates and navigation inside node returns, dynamic multi-hop routing, crossing subgraph boundaries to navigate parent graphs, and type-safe command outputs.
- **Production Scenarios:** Dynamic decision-making nodes that update confidence metrics and immediately trigger specialized recovery or termination nodes in a single atomic step.

---

#### 5. Send API & Dynamic Map-Reduce Workflows

- **Target Folder:** `GEN AI/4. LangGraph/05_send_api_map_reduce/`
- **Core API & Primitives:** `Send(node_name, custom_state)`, dynamic edges, map phase fan-out, reduce phase aggregation with channel reducers
- **Core Topics:** Dynamic parallel execution when the number of worker tasks is only known at runtime, worker-isolated state schemas, map-reduce architectures, parallel query decomposition, and handling partial failures across parallel tasks.
- **Production Scenarios:** Parallel web search across 5 decomposed sub-questions, distributed multi-document summarization, ensemble multi-agent candidate generation.

---

#### 6. Tool Calling & ToolNode Architecture

- **Target Folder:** `GEN AI/4. LangGraph/06_tool_calling_toolnode/`
- **Core API & Primitives:** `@tool`, `ToolNode(tools)`, `tools_condition`, `llm.bind_tools()`, `AIMessage.tool_calls`, `ToolMessage`, `handle_tool_errors`
- **Core Topics:** Function calling schemas, parsing tool call arguments, executing tools in parallel vs. sequential order, injecting `ToolMessage` results back into chat history, error catching and auto-healing prompts for malformed arguments.
- **Production Scenarios:** Building reliable ReAct agents, database SQL querying tools with automatic query correction, API integration with rate-limit retries.

---

#### 7. Persistence, Checkpointing & Thread Isolation

- **Target Folder:** `GEN AI/4. LangGraph/07_persistence_checkpointers/`
- **Core API & Primitives:** `MemorySaver`, `SqliteSaver`, `PostgresSaver`, `checkpoint_ns`, `thread_id`, `config={"configurable": {"thread_id": "..."}}`, `.get_state()`, `.get_state_history()`
- **Core Topics:** State checkpoint lifecycle (saving after every superstep), multi-tenant session isolation using `thread_id`, state snapshot inspection, resuming interrupted or failed executions, durable workflow recovery across worker crashes.
- **Production Scenarios:** Resuming long-running research tasks across server restarts, multi-user chat session state persistence in PostgreSQL.

---

#### 8. Short-Term Context & Cross-Thread Long-Term Memory

- **Target Folder:** `GEN AI/4. LangGraph/08_memory_short_long_term/`
- **Core API & Primitives:** `trim_messages()`, `RemoveMessage`, `BaseStore`, `InMemoryStore`, `AsyncPostgresStore`, namespace tuples `store.put(namespace, key, value)`, semantic search across memory
- **Core Topics:** Thread-scoped short-term memory management (message windowing, summarization nodes), long-term cross-session user profile stores, namespace hierarchies (`(user_id, "preferences")`), semantic memory indexing, and resolving memory conflicts.
- **Production Scenarios:** Chatbots remembering user dietary preferences across separate sessions, dynamic context window pruning to prevent LLM token overflow.

---

#### 9. Human-in-the-Loop (HITL), Interrupts & Time Travel

- **Target Folder:** `GEN AI/4. LangGraph/09_human_in_the_loop_interrupts/`
- **Core API & Primitives:** `interrupt(payload)`, `Command(resume=...)`, `.update_state(config, values, as_node=...)`, historical checkpoint forking (Time Travel)
- **Core Topics:** Pausing execution before high-stakes tool calls (fund transfers, email sending), rendering approval payloads to human reviewers, resuming graphs with human feedback, manually modifying graph state during interrupts, rewinding execution to previous checkpoints and replaying with altered parameters.
- **Production Scenarios:** Financial transaction approval workflows, human-edited email drafting, debugging agent reasoning loops via time travel.

---

#### 10. Streaming Architecture (Tokens, Updates & Events)

- **Target Folder:** `GEN AI/4. LangGraph/10_streaming_modes_events/`
- **Core API & Primitives:** `.stream()`, `.astream()`, `stream_mode="values"`, `stream_mode="updates"`, `stream_mode="messages"`, `stream_mode="custom"`, `.astream_events()`, `version="v2"`, `StreamPart`
- **Core Topics:** Emitting state values at every step vs. emitting only delta updates per node, token-by-token LLM output streaming, custom streaming tags for UI progress bars, structured event filtering, and frontend UI synchronization.
- **Production Scenarios:** Real-time ChatGPT-like streaming interfaces with visible intermediate reasoning steps, progress indicators for long-running multi-tool workflows.

#### 11. Subgraphs & Hierarchical Multi-Agent Systems

- **Target Folder:** `GEN AI/4. LangGraph/11_subgraphs_multi_agent/`
- **Core API & Primitives:** Subgraphs as nodes, parent-child state channel mapping, Supervisor pattern, Hierarchical Teams, agent handoffs, router architectures
- **Core Topics:** Modular graph composition, state encapsulation (preventing worker clutter in parent state), supervisor-coordinated specialist teams (Researcher, Coder, Reviewer), peer-to-peer handoffs via explicit transfer tools, subgraph checkpoint persistence modes.
- **Production Scenarios:** Software engineering team graphs (Planner -> Developer -> Code Reviewer -> Tester), multi-department enterprise customer support routing.

#### 12. Agentic RAG, Corrective RAG (CRAG) & Self-RAG

- **Target Folder:** `GEN AI/4. LangGraph/12_agentic_rag_crag/`
- **Core API & Primitives:** Retrieval nodes, document grading nodes, query rewrite nodes, hallucination check nodes, web search fallback tools
- **Core Topics:** Transforming static RAG pipelines into autonomous cyclic graphs, document relevance scoring, automated query rewriting when retrieval returns irrelevant chunks, detecting LLM hallucinations against ground truth context, and fallback routing to external search APIs.
- **Production Scenarios:** High-precision legal document question-answering with verification loops, technical customer support with automated web fallback.

---

#### 13. Functional API (`@entrypoint` & `@task`)

- **Target Folder:** `GEN AI/4. LangGraph/13_functional_api_tasks/`
- **Core API & Primitives:** `@entrypoint`, `@task`, `task.result()`, native Python control flow (`if`, `for`, `while`), checkpointing in functional workflows
- **Core Topics:** Comparing Functional API vs. Graph API (`StateGraph`), embedding persistence, streaming, and interrupts into standard imperative Python code, running concurrent tasks with `asyncio.gather()`, and deciding when to choose Functional over Graph API.
- **Production Scenarios:** Wrapping existing procedural Python scripts with durable execution and human approval without drawing explicit node/edge diagrams.
