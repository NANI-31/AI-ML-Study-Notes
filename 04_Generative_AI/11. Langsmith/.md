#### 1. LangSmith Fundamentals, Setup & Tracing Architecture

- **Target Folder:** `GEN AI/5. Langsmith/01_fundamentals_setup_tracing/`
- **Core API & SDK Methods:** `Client()`, `LANGSMITH_API_KEY`, `LANGSMITH_TRACING=true`, `LANGSMITH_PROJECT`, `LANGSMITH_ENDPOINT`, `RunTree`, `@traceable` decorator
- **Core Topics:** What is LangSmith vs. LangChain vs. traditional APMs (Datadog/OpenTelemetry); run vs. trace definitions; parent-child run hierarchy; execution tree visualization; project separation (dev, staging, prod); tagging runs (`tags=["v1.2", "staging"]`); custom metadata injection (`metadata={"user_id": "123", "session_id": "abc"}`); client initialization and authentication.
- **LLMOps Scenarios:** Setting up zero-code automatic tracing for Python applications; configuring secure multi-tenant project isolation; decoupling development experiments from live production traces.

---

#### 2. LLM & Chat Model Tracing (Tokens, Latency & Cost Analytics)

- **Target Folder:** `GEN AI/5. Langsmith/02_llm_chat_token_monitoring/`
- **Core API & SDK Methods:** Chat message abstractions (`SystemMessage`, `HumanMessage`, `AIMessage`, `ToolMessage`), `UsageMetadata`, `token_usage`, `prompt_tokens`, `completion_tokens`, latency metrics (`time_to_first_token`, total duration)
- **Core Topics:** Tracing raw completion vs. chat model invocations; monitoring streaming chunk latencies and Time-To-First-Token (TTFT); token accounting across diverse model providers (OpenAI, Anthropic, Gemini, Ollama); mapping token volumes to dollar pricing curves; diagnosing rate limits (HTTP 429), timeouts, and authentication failures directly in trace logs.
- **LLMOps Scenarios:** Detecting token spikes in customer conversation loops; tracking per-user and per-feature API spending; identifying slow generation bottlenecks across multi-model endpoints.

---

#### 3. LangChain & LCEL Chain Observability

- **Target Folder:** `GEN AI/5. Langsmith/03_langchain_lcel_tracing/`
- **Core API & SDK Methods:** `RunnableSequence`, `RunnableParallel`, `RunnableBranch`, `RunnablePassthrough`, `with_config()`, `callbacks`, output parsers (`PydanticOutputParser`, `StrOutputParser`)
- **Core Topics:** Automatic tracing of LangChain Expression Language (LCEL) chains; capturing step-by-step intermediate data flow; tracing parallel branch executions (`RunnableParallel`); debugging output parser schema validation errors; inspecting streaming responses; identifying silent chain drops and fallback trigger events.
- **LLMOps Scenarios:** Debugging structured JSON extraction failures in extraction pipelines; diagnosing latency bottlenecks in chained multi-step reasoning prompts.

---

#### 4. LangGraph & Agent Trajectory Tracing

- **Target Folder:** `GEN AI/5. Langsmith/04_langgraph_agent_observability/`
- **Core API & SDK Methods:** `StateGraph`, `CompiledGraph`, node tracing, conditional edge transitions, `Command`, checkpointers (`MemorySaver`, `SqliteSaver`), state snapshots, `interrupt`
- **Core Topics:** Graph execution visualization; tracing node entry/exit states; tracking state updates across iterations; visualizing dynamic conditional routing; detecting infinite loop traps; human-in-the-loop breakpoint inspection; tracing multi-agent supervisor/worker hierarchies and tool dispatch execution.
- **LLMOps Scenarios:** Pinpointing the exact node where an autonomous coding agent made an invalid decision; inspecting corrupted graph state dictionaries during multi-turn customer support conversations.

---

#### 5. Prompt Engineering, Versioning & Prompt Hub

- **Target Folder:** `GEN AI/5. Langsmith/05_prompt_engineering_hub/`
- **Core API & SDK Methods:** LangSmith Prompt Hub integration (`hub.pull()`, `hub.push()`), `ChatPromptTemplate`, prompt version commits (`commit_hash`), prompt playground, variable injection
- **Core Topics:** Collaborative prompt management; tracking prompt git-style commit history; dynamic template variable formatting; system vs. few-shot prompt structuring; testing prompt adjustments in the interactive playground; comparing prompt outputs side-by-side; rollback mechanisms for degraded prompt iterations.
- **LLMOps Scenarios:** Managing enterprise prompt libraries across engineering and product teams; performing safe canary deployments of new system instructions.

---

#### 6. Dataset Creation & Curation

- **Target Folder:** `GEN AI/5. Langsmith/06_datasets_curation/`
- **Core API & SDK Methods:** `Client.create_dataset()`, `Client.create_examples()`, `Client.read_dataset()`, dataset types (`kv`, `llm`, `chat`), dataset splitting (`train`, `test`, `validation`)
- **Core Topics:** Golden dataset construction; converting production failure traces directly into new test examples ("trace-to-dataset"); uploading datasets from CSV, JSON, and Pandas DataFrames; managing input schemas and ground-truth references; curating adversarial and edge-case test suites; versioning datasets.
- **LLMOps Scenarios:** Curating a 500-example golden benchmark for customer Q&A; isolating regression-prone user queries into a dedicated continuous integration test suite.

---

#### 7. Deterministic & Rule-Based Evaluators

- **Target Folder:** `GEN AI/5. Langsmith/07_deterministic_evaluators/`
- **Core API & SDK Methods:** Custom evaluation functions (`RunEvaluator`, callable evaluators returning `{"key": ..., "score": ...}`), exact match, regex containment, Pydantic schema validation, latency/token threshold asserts
- **Core Topics:** Fast, cost-free deterministic evaluation; string normalization and Levenshtein distance checks; JSON syntax and schema compliance verification; verifying presence/absence of restricted keywords (PII/compliance checks); setting hard upper bounds on token count and execution time.
- **LLMOps Scenarios:** Automated unit tests verifying that an LLM always outputs valid RFC 8259 JSON matching a strict Pydantic model before deployment.

---

#### 8. LLM-as-a-Judge & Model-Based Evaluation

- **Target Folder:** `GEN AI/5. Langsmith/08_llm_judge_evaluations/`
- **Core API & SDK Methods:** `LangChainStringEvaluator`, criteria evaluators (`"helpfulness"`, `"relevance"`, `"correctness"`), custom judge prompt templates, pairwise comparison evaluators, structured grading schemas
- **Core Topics:** Principles of LLM-as-a-Judge; rubric design and scoring guidelines (binary vs. 1–5 Likert scales); reference-based (ground truth) vs. reference-free evaluation; mitigating judge biases (position bias, verbosity bias, self-enhancement bias); pairwise A/B response ranking; calibrating judge agreement with human reviewers.
- **LLMOps Scenarios:** Automated grading of open-ended conversational responses for brand voice compliance and technical correctness using GPT-4o as a judge.

---

#### 9. RAG (Retrieval-Augmented Generation) Observability & Triad Evaluation

- **Target Folder:** `GEN AI/5. Langsmith/09_rag_observability_evaluation/`
- **Core API & SDK Methods:** RAG tracing, retriever callbacks, context evaluation, Ragas integration, faithfulness evaluators, answer relevance evaluators
- **Core Topics:** Tracing the complete RAG lifecycle (query transformation $\rightarrow$ embedding $\rightarrow$ vector DB query $\rightarrow$ reranking $\rightarrow$ context packing $\rightarrow$ generation); isolating retrieval failures (missing context, wrong documents) from generation failures (hallucinations, non-adherence); RAG Triad evaluation metrics (Context Relevance, Faithfulness/Groundedness, Answer Relevance).
- **LLMOps Scenarios:** Diagnosing whether an inaccurate customer answer stemmed from top-$k$ retriever chunk omissions or model hallucination despite correct context.

---

#### 10. Agent & Tool-Use Trajectory Evaluation

- **Target Folder:** `GEN AI/5. Langsmith/10_agent_trajectory_evaluation/`
- **Core API & SDK Methods:** Trajectory evaluators, tool call evaluators, step count monitors, state transition verifiers
- **Core Topics:** Evaluating intermediate reasoning steps vs. final outputs; tool selection accuracy; tool argument schema compliance; measuring reasoning efficiency (penalizing repetitive loops and wasted tool calls); error recovery verification (how gracefully the agent handles tool exceptions); multi-step task success rate.
- **LLMOps Scenarios:** Measuring whether an SQL-generation agent successfully self-corrects after receiving a database syntax error without exceeding 3 iteration steps.

---

#### 11. Experiments, Benchmarking & CI/CD Regression Gates

- **Target Folder:** `GEN AI/5. Langsmith/11_experiments_benchmarking_cicd/`
- **Core API & SDK Methods:** `evaluate()` runner, experiment naming and tracking, comparing experiment runs in the UI, statistical significance, GitHub Actions evaluation pipelines
- **Core Topics:** Running repeatable batch evaluations against datasets using `evaluate()`; comparing model candidates (e.g., GPT-4o vs. Claude 3.5 Sonnet vs. Llama 3 70B) on cost, latency, and quality; regression testing before merging prompt updates; establishing passing score thresholds as pull request blocking gates in CI/CD.
- **LLMOps Scenarios:** Implementing an automated GitHub Actions check that blocks merging any prompt change that causes accuracy on the golden dataset to drop by $>1\%$.

---

#### 12. Production Monitoring, Feedback Loops & Quality Drift

- **Target Folder:** `GEN AI/5. Langsmith/12_production_monitoring_feedback/`
- **Core API & SDK Methods:** `Client.create_feedback()`, `Client.update_run()`, feedback keys (`"user_score"`, `"thumbs_up"`, `"correction"`), production monitoring charts, alert rules
- **Core Topics:** Collecting explicit user feedback (thumbs up/down, text corrections) and attaching it to specific run IDs; implicit feedback collection (user copy actions, follow-up churn); setting up real-time production alerts (error spikes, latency degradations, token anomalies); tracking prompt drift and model performance drift over time; human-in-the-loop review queues and active learning cycles.
- **LLMOps Scenarios:** Automatically sending runs with user "thumbs-down" ratings into a LangSmith annotation queue for human review and inclusion into the next evaluation dataset.
