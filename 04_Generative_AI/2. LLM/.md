#### 1. Tokenization & Input Representation

- **Core Topics:** Character vs. Word vs. Subword Tokenization, Byte Pair Encoding (BPE), WordPiece, SentencePiece, Byte-level BPE (tiktoken / GPT-4), Vocabulary construction, Special tokens (`BOS`, `EOS`, `PAD`, `UNK`, `MASK`, chat delimiters), Token IDs vs. String mappings, Padding, Truncation, Attention mask generation, Out-Of-Vocabulary (OOV) elimination, and Tokenizer compression efficiency (bytes-per-token ratio).
- **Key Concepts / Equations:** Merge rules, frequency pair calculation, tokenizer training on raw corpora, context window budgeting.

---

#### 2. Embeddings & Vector Spaces

- **Core Topics:** Word2Vec (CBOW, Skip-Gram), GloVe vs. Contextual Embeddings, Dense semantic vectors, Embedding dimensions ($d_{model}$), Token embedding lookup tables, Projection matrices, Semantic similarity metrics (Cosine Similarity, Dot Product, Euclidean distance, Manhattan distance), Dimensionality normalization ($L_2$ norm), Vector space clustering, and Semantic search retrieval.
- **Key Concepts / Equations:** $\cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$, normalized inner product properties, semantic arithmetic (e.g., King - Man + Woman = Queen).

---

#### 3. Transformer Architecture & Component Mechanics

- **Core Topics:** Original Transformer anatomy (Vaswani et al.), Encoder-only (BERT), Decoder-only (GPT, LLaMA), Encoder-Decoder (T5), Residual connections and gradient flow, Layer Normalization (Post-LN vs. Pre-LN vs. RMSNorm), Feed-Forward Networks (FFN / MLP), Gated Linear Units (SwiGLU, GeGLU), Output projection layer (Unembedding / LM Head), Weight tying, and Logits-to-probabilities computation.
- **Key Concepts / Equations:** $\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}} \odot \gamma$, $\text{SwiGLU}(x) = (xW \cdot \text{Swish}(xV))W_2$.

---

#### 4. Attention Mechanisms (Self, Multi-Head, GQA, FlashAttention)

- **Core Topics:** Scaled Dot-Product Attention, Query ($Q$), Key ($K$), Value ($V$) projections, Attention matrix computation, Scaling factor $\frac{1}{\sqrt{d_k}}$ preventing vanishing gradients in Softmax, Multi-Head Attention (MHA), Causal/Autoregressive lower-triangular masking, Multi-Query Attention (MQA), Grouped-Query Attention (GQA), Attention complexity ($O(N^2)$ time/memory), and FlashAttention (SRAM tiling and kernel fusion).
- **Key Concepts / Equations:** $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right)V$, head splitting and concatenation mechanics, memory footprint of $QK^T$.

---

#### 5. Positional Encoding & Context Window Scaling

- **Core Topics:** Permutation invariance problem in self-attention, Absolute Sinusoidal Positional Encoding, Learned Positional Embeddings, Relative Positional Encodings (T5, DeBERTa), Rotary Position Embeddings (RoPE), ALiBi (Attention with Linear Biases), Context length extrapolation vs. interpolation, YaRN (Yet another RoPE extensioN), Position-Interpolation (PI), and Long-context evaluation (Needle-In-A-Haystack).
- **Key Concepts / Equations:** 2D rotation matrix application in complex space $R_{\Theta, m}^d x_m$, ALiBi linear penalty slope $m \cdot (i - j)$.

---

#### 6. Pretraining, Language Modeling & Scaling Laws

- **Core Topics:** Causal Language Modeling (CLM) objective, Masked Language Modeling (MLM), Cross-Entropy loss, Perplexity ($\text{PPL} = e^{\text{Loss}}$), Teacher forcing, Pretraining data pipelines (filtering, minhash deduplication, toxicity filtering, synthetic text), Chinchilla scaling laws (optimal tokens-to-parameters ratio $\approx 20:1$), Kaplan scaling laws, Compute budgets (FLOPs calculation $6ND$), Learning rate warmup, and Cosine decay schedules.
- **Key Concepts / Equations:** $\mathcal{L}_{\text{CLM}} = -\frac{1}{T} \sum_{t=1}^T \log P(x_t \mid x_{<t})$, FLOPs estimation for training and forward pass.

---

#### 7. Inference Mechanics, KV Cache & Decoding Strategies

- **Core Topics:** Autoregressive generation lifecycle: Prefill phase (compute-bound) vs. Decode phase (memory-bandwidth bound), Key-Value (KV) Cache mechanics, KV cache memory footprint calculations, Greedy decoding, Beam search, Stochastic sampling, Temperature scaling, Top-$k$ filtering, Top-$p$ (Nucleus) sampling, Min-$p$ sampling, Repetition/Frequency/Presence penalties, and Speculative decoding.
- **Key Concepts / Equations:** $\text{softmax}(z_i / T)$, KV Cache size formula: $2 \times \text{layers} \times \text{heads} \times d_{\text{head}} \times \text{seq\_len} \times \text{precision\_bytes}$.

---

#### 8. Quantization & Model Compression

- **Core Topics:** Precision formats (FP32, FP16, BF16, INT8, INT4, FP8), Dynamic vs. Static quantization, Post-Training Quantization (PTQ) vs. Quantization-Aware Training (QAT), Weight-only vs. Weight-Activation quantization, Zero-point and Scale factor calculations, Outlier activations, GPTQ (second-order Hessian optimization), AWQ (Activation-aware Weight Quantization), bitsandbytes NormalFloat4 (NF4) with Double Quantization, and Knowledge Distillation.
- **Key Concepts / Equations:** $X_{\text{quant}} = \text{round}\left(\frac{X}{\text{scale}}\right) + \text{zero\_point}$, asymmetric vs. symmetric quantization range mapping.

---

#### 9. Prompt Engineering, In-Context Learning & Structured Outputs

- **Core Topics:** Zero-shot, One-shot, and Few-shot prompting, Instruction formatting, System vs. User vs. Assistant roles, Chain-of-Thought (CoT) prompting, Zero-shot CoT ("Let's think step by step"), Self-Consistency decoding, Tree of Thoughts (ToT), Directional stimulus prompting, JSON Schema enforcement, Function / Tool Calling specifications, Grammar-guided decoding (GBNF / Outlines), and Prompt Injection vulnerabilities (Direct & Indirect).
- **Key Concepts / Equations:** Schema validation via Pydantic, constrained token masking during sampling for structured JSON.

---

#### 10. Instruction Tuning (SFT) & Chat Templating

- **Core Topics:** Pretrained base models vs. Instruct/Chat models, Supervised Fine-Tuning (SFT) lifecycle, Instruction-response dataset curation, Multi-turn conversation datasets (ShareGPT, UltraChat), Chat templates (`apply_chat_template`, Jinja2 format, `<|im_start|>`, `<|im_end|>`), Loss masking on prompt tokens (computing loss strictly on target completions), Catastrophic forgetting, and Curriculum learning.
- **Key Concepts / Equations:** Cross-entropy loss masking with label `-100` on input prompt tokens, data formatting pipelines.

---

#### 11. Parameter-Efficient Fine-Tuning (PEFT, LoRA & QLoRA)

- **Core Topics:** Motivation for PEFT over full-parameter tuning, Prefix Tuning, Prompt Tuning, Adapters, Low-Rank Adaptation (LoRA), Decomposition matrices $W = W_0 + \Delta W = W_0 + \frac{\alpha}{r} (B \times A)$, Rank ($r$) and Scaling factor ($\alpha$), Initializing $A \sim \mathcal{N}(0, \sigma^2)$ and $B = 0$, Target modules selection ($W_q, W_k, W_v, W_o, \text{gate, up, down}$), LoRA weight merging, and QLoRA (4-bit base model + 16-bit LoRA adapters + Paged Optimizers).
- **Key Concepts / Equations:** Memory reduction calculation: trainable parameters from billions to millions, forward pass with $\frac{\alpha}{r}BAx$.

---

#### 12. Alignment, RLHF & Direct Preference Optimization (DPO)

- **Core Topics:** The Alignment Problem (Helpful, Honest, Harmless - HHH), 3-stage RLHF pipeline: SFT $\to$ Reward Model (RM) training $\to$ Reinforcement Learning policy optimization, Bradley-Terry preference model, Proximal Policy Optimization (PPO), KL-divergence penalty preventing policy collapse ($\beta D_{KL}(\pi_\theta \parallel \pi_{\text{ref}})$), Direct Preference Optimization (DPO) deriving closed-form loss without reward model or PPO, Kahneman-Tversky Optimization (KTO), and Sycophancy.
- **Key Concepts / Equations:** $\mathcal{L}_{\text{DPO}}(\pi_\theta; \pi_{\text{ref}}) = -\mathbb{E}_{(x, y_w, y_l)}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}\right)\right]$.

---

#### 13. Retrieval-Augmented Generation (RAG) Fundamentals

- **Core Topics:** RAG motivation (parametric memory limits, hallucinations, outdated training cutoff), End-to-end naive RAG workflow, Document ingestion and parsing (PDFs, Markdown, HTML), Text chunking strategies (Fixed-size with overlap, Recursive character chunking, Sentence splitting, Semantic chunking), Embedding text chunks, Vector databases (ChromaDB, Pinecone, Qdrant, Milvus), Index structures (HNSW, Flat, IVF), Top-$k$ similarity retrieval, and Prompt context injection.
- **Key Concepts / Equations:** Chunk overlap math, HNSW graph search time vs. recall trade-offs, context window token budget management.

---

#### 14. Advanced RAG, Query Transformation & Reranking

- **Core Topics:** Limitations of naive RAG (Lost-in-the-Middle, semantic drift), Query transformation (Query rewriting, Query expansion, Multi-query generation, Step-back prompting), Hypothetical Document Embeddings (HyDE), Sparse vs. Dense retrieval (BM25 keyword search + Dense bi-encoders), Hybrid search with Reciprocal Rank Fusion (RRF), Cross-Encoder Rerankers (e.g., Cohere, BGE-Reranker), Contextual compression, and Hierarchical / Parent-Child document retrieval.
- **Key Concepts / Equations:** Reciprocal Rank Fusion formula: $\text{RRF\_Score}(d) = \sum_{m \in M} \frac{1}{k + r_m(d)}$.

---

#### 15. Autonomous LLM Agents, Tool Calling & Memory Systems

- **Core Topics:** Definition of AI Agents (LLM as reasoning engine), ReAct pattern (Reasoning + Acting + Observing), Planning strategies (Plan-and-Solve, Reflexion, Self-Correction), Tool integration (Search engines, Python code execution, SQL query generators, API calls), Agent Memory architecture (Short-term context buffer, Conversation summary memory, Vector long-term episodic memory), Multi-agent collaboration architectures (Supervisor-worker, Swarm, Debate), and Sandboxing / Safety guardrails against unauthorized tool actions.
- **Key Concepts / Equations:** ReAct prompt-observation trace cycles, state transitions in directed acyclic agent execution graphs (LangGraph).

---

#### 16. LLM Evaluation, Benchmarking, Safety & Guardrails

- **Core Topics:** Traditional NLP metrics (BLEU, ROUGE, Exact Match), Perplexity evaluation, Standard LLM benchmarks (MMLU, GSM8K, HumanEval, ARC, HellaSwag, Chatbot Arena Elo ratings), LLM-as-a-Judge (single-answer grading, pairwise comparison, position bias, verbosity bias), RAG Triad evaluation metrics (Context Relevance, Groundedness / Faithfulness, Answer Relevance via Ragas / TruLens), Safety guardrails (NeMo Guardrails, Llama Guard), and Prompt injection / Jailbreaking defenses.
- **Key Concepts / Equations:** Precision/Recall of retrieved contexts, Faithfulness score computation ($| \text{claims in answer verified by context} | / | \text{total claims} |$).
