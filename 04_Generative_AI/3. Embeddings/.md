#### 1. Mathematical Foundations & Vector Similarity Metrics

- **Target Folder:** `GEN AI/6. Embeddings/01_mathematical_foundations_similarity/`
- **Core Math & Operations:** Vectors in $\mathbb{R}^d$, vector magnitude ($\|v\|_2$), Dot Product ($\mathbf{u} \cdot \mathbf{v}$), Cosine Similarity ($\frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$), Cosine Distance ($1 - \text{sim}$), Euclidean Distance ($L_2$), Manhattan Distance ($L_1$), Unit Vector Normalization ($v / \|v\|$).
- **Core Topics:** Geometric interpretation of vector spaces; why dot product equals cosine similarity for $L_2$-normalized vectors; triangle inequality and metric space properties; curse of dimensionality in high-dimensional spaces ($d > 512$); computational complexity and hardware SIMD acceleration.
- **Real-World Scenarios:** Optimizing cosine search on billion-scale normalized vector indexes using hardware-accelerated dot product instructions; diagnosing scale distortion in unnormalized vectors.

#### 2. Word, Subword & Classical Dense Embeddings

- **Target Folder:** `GEN AI/6. Embeddings/02_word_subword_classical_embeddings/`
- **Core Algorithms & Frameworks:** One-Hot Encoding, TF-IDF, Word2Vec (Skip-Gram vs. Continuous Bag of Words / CBOW), Negative Sampling, Hierarchical Softmax, GloVe (co-occurrence matrix factorization), FastText (character $n$-grams).
- **Core Topics:** Evolution from sparse lexical vectors to dense semantic representations; the distributional hypothesis; vector arithmetic and analogical reasoning ($\vec{\text{King}} - \vec{\text{Man}} + \vec{\text{Woman}} \approx \vec{\text{Queen}}$); handling Out-Of-Vocabulary (OOV) tokens; static vs. contextualized representations (polysemy limitation).
- **Real-World Scenarios:** Fast keyword matching and lexical baseline feature extraction in resource-constrained search systems; building low-latency domain dictionary representations.

#### 3. Transformer & Sentence Embedding Architectures

- **Target Folder:** `GEN AI/6. Embeddings/03_sentence_transformers_pooling/`
- **Core Architectures & Models:** Bi-Encoders, Sentence-BERT (`sentence-transformers` library), BERT / RoBERTa / ModernBERT backbones, Pooling mechanisms (`mean_pooling`, `cls_pooling`, `max_pooling`), Attention masking.
- **Core Topics:** Why naive BERT token embeddings yield poor sentence-level semantic representations; Siamese network and bi-encoder architecture; calculating mean pooling over non-padded token vectors; token embeddings vs. sequence embeddings; cross-encoders vs. bi-encoders; embedding dimension scaling (384-d vs. 768-d vs. 1024-d).
- **Real-World Scenarios:** Running local sentence embedding inference in CPU-only microservices; extracting sentence embeddings using PyTorch with explicit attention mask handling.

#### 4. Commercial & Open-Source Embedding Models & Benchmarks

- **Target Folder:** `GEN AI/6. Embeddings/04_commercial_oss_models_benchmarks/`
- **Core Providers & Models:** OpenAI (`text-embedding-3-small`, `text-embedding-3-large`, `text-embedding-ada-002`), Cohere (`embed-english-v3.0`, `embed-multilingual-v3.0`), Google Vertex/Gemini (`text-embedding-004`), Hugging Face MTEB leaders (BGE, E5, GTE, Nomic-Embed, ModernBERT embeddings).
- **Core Topics:** Commercial API embeddings vs. self-hosted open-weights models; input token context windows (512 vs. 8,192 tokens); MTEB (Massive Text Embedding Benchmark) evaluation criteria (Retrieval, Classification, Clustering, Reranking, STS); query instruction prefixes (e.g., `"Represent this sentence for searching relevant passages:"` in BGE/E5); cost, token latency, and rate-limit engineering.
- **Real-World Scenarios:** Model selection trade-offs between cost ($/1M tokens), inference latency, context window limits, and retrieval accuracy for enterprise knowledge bases.

#### 5. Document Chunking & Context Window Strategies

- **Target Folder:** `GEN AI/6. Embeddings/05_chunking_context_window_strategies/`
- **Core Strategies & Splitters:** Fixed-size chunking with overlap, Recursive Character Splitting (`RecursiveCharacterTextSplitter`), Token-aware chunking (`tiktoken`), Semantic Chunking (cosine distance thresholding between adjacent sentences), Document structure-aware chunking (Markdown, HTML, JSON, Code).
- **Core Topics:** The chunking dilemma (small chunks preserve fine-grained precision, large chunks preserve broader contextual coherence); chunk overlap mechanics preventing boundary information loss; context truncation when documents exceed model limits; Hierarchical and Parent-Child chunking (indexing small chunk vectors while retrieving larger parent context for LLM generation).
- **Real-World Scenarios:** Designing optimal chunking boundaries for technical API documentation, legal contracts with nested clauses, and multi-page financial reports.

#### 6. Vector Search & Approximate Nearest Neighbors (ANN) Algorithms

- **Target Folder:** `GEN AI/6. Embeddings/06_vector_search_ann_algorithms/`
- **Core Algorithms & Data Structures:** Exact $k$-NN (brute-force linear scan), Inverted File Index (IVF), Hierarchical Navigable Small World (HNSW), Random Projection Trees (Annoy), Product Quantization (PQ), Scalar Quantization (SQ).
- **Core Topics:** The $O(N \cdot d)$ scaling bottleneck of exact search; graph-based navigation in high-dimensional spaces (HNSW layers, entry points, `M` max edges, `efSearch` / `efConstruction` parameters); clustering centroids with IVF (`nlist`, `nprobe`); vector quantization compressing 32-bit floats to 8-bit or 1-bit; trade-offs between recall percentage, QPS (queries per second), build time, and RAM footprint.
- **Real-World Scenarios:** Tuning HNSW hyperparameters (`M=16, efSearch=64`) to achieve 98%+ recall with sub-5ms search latency across 10 million indexed vectors.

#### 7. Vector Databases & Dedicated Vector Stores

- **Target Folder:** `GEN AI/6. Embeddings/07_vector_databases_chromadb_faiss/`
- **Core Vector Stores:** ChromaDB, FAISS (Facebook AI Similarity Search), Pinecone, Qdrant, Milvus, Weaviate, PostgreSQL (`pgvector`), SQLite (`sqlite-vss` / `sqlite-vec`).
- **Core Operations:** Collection creation, batch embedding upsert, metadata payload attachment, vector distance query (`query(query_embeddings, n_results)`), combined vector + boolean metadata filtering (pre-filtering vs. post-filtering vs. single-stage filtering), persistent vs. in-memory indexing.
- **Real-World Scenarios:** Implementing tenant-isolated vector collections with hybrid metadata filtering (e.g., filtering `{"user_id": "123", "created_year": {"$gte": 2024}}` alongside semantic search).

#### 8. Embeddings in Retrieval-Augmented Generation (RAG) Pipelines

- **Target Folder:** `GEN AI/6. Embeddings/08_embeddings_in_rag_pipelines/`
- **Core Pipeline Mechanics:** The complete RAG indexing and query flow, semantic drift between user queries and stored passages, asymmetric retrieval challenges (short questions vs. long explanatory passages), Query Transformation (HyDE - Hypothetical Document Embeddings, Multi-Query expansion, Step-Back prompting).
- **Core Topics:** Why user queries frequently fail cosine matching against raw documents; HyDE generation (generating a synthetic passage with an LLM and embedding the passage rather than the raw query); query-document embedding space alignment; assembling retrieved context chunks into LLM prompt templates; handling semantic hallucinations caused by irrelevant retrieved context.
- **Real-World Scenarios:** Building an enterprise customer support RAG engine using HyDE to bridge colloquial user questions with formal technical manual chunks.

#### 9. Hybrid Search & Sparse-Dense Retrieval Fusion

- **Target Folder:** `GEN AI/6. Embeddings/09_hybrid_search_sparse_dense_fusion/`
- **Core Retrieval Methods:** Dense Semantic Retrieval (Embedding Cosine), Sparse Lexical Retrieval (BM25, TF-IDF, SPLADE / Learned Sparse Embeddings), Score Normalization (Min-Max, Sigmoid), Reciprocal Rank Fusion (RRF), Convex Combination ($\alpha \cdot \text{Dense} + (1 - \alpha) \cdot \text{Sparse}$).
- **Core Topics:** Failure modes of pure semantic search (exact keyword mismatches, serial numbers, product SKUs, proper nouns); failure modes of pure keyword search (synonyms, vocabulary mismatch, semantic intent); mathematical formulation of RRF ($RRF(d) = \sum \frac{1}{k + r_i(d)}$); tuning $\alpha$ weighting; unified indexing of dense vectors and inverted keyword indexes.
- **Real-World Scenarios:** Building an e-commerce product search combining semantic product descriptions with exact part number and brand name matching.

#### 10. Cross-Encoder & Reranking Models

- **Target Folder:** `GEN AI/6. Embeddings/10_cross_encoders_reranking_models/`
- **Core Models & Frameworks:** Cross-Encoders, Cohere Rerank API, BGE-Reranker (`BAAI/bge-reranker-large`), `cross-encoder/ms-marco-MiniLM-L-6-v2`, FlagEmbedding.
- **Core Topics:** The architectural divergence between Bi-Encoders and Cross-Encoders; why cross-encoders cannot be pre-indexed into vector databases (cross-attention across query and passage tokens simultaneously); Two-Stage Retrieval Architecture:
  1. _Stage 1 (Retrieval):_ Fast bi-encoder vector search retrieving top $K=50$ or $K=100$ candidate chunks.
  2. _Stage 2 (Reranking):_ Accurate cross-encoder scoring re-ordering candidates to produce top $N=5$ chunks for the LLM.
- **Real-World Scenarios:** Upgrading a standard RAG pipeline with a cross-encoder reranker to boost retrieval NDCG@5 from 0.72 to 0.89 while keeping latency under 150ms.

- **Real-World Scenarios:** Building a cross-border retail catalogue search where users upload product photos or type queries in native languages to retrieve matching inventory.

#### 12. Matryoshka Embeddings, Quantization & Memory Optimization

- **Target Folder:** `GEN AI/6. Embeddings/12_matryoshka_quantization_compression/`
- **Core Techniques:** Matryoshka Representation Learning (MRL), Nested Subvector Slicing (e.g., 1536-d $\to$ 512-d $\to$ 256-d), Scalar Quantization (float32 $\to$ int8), Binary Quantization (float32 $\to$ 1-bit binary with Hamming distance), Dimensionality Reduction (PCA, UMAP, t-SNE).
- **Core Topics:** How MRL trains models so front sub-dimensions preserve primary semantic variance; mathematical truncation and re-normalization ($v[:k] / \|v[:k]\|_2$); performance retention curves across truncated dimensions; achieving 96% vector storage RAM reduction with int8/binary quantization; visual exploratory analysis of embedding clusters with 2D/3D UMAP projections.
- **Real-World Scenarios:** Scaling a vector search index from $100\text{ GB}$ of RAM down to $3\text{ GB}$ using binary quantization and Matryoshka 512-d truncation with less than 2% recall degradation.

#### 13. Contrastive Learning & Embedding Model Fine-Tuning

- **Target Folder:** `GEN AI/6. Embeddings/13_contrastive_learning_finetuning/`
- **Core Training Objectives & Losses:** Contrastive Loss, Multiple Negatives Ranking Loss (MNRL), InfoNCE Loss, Cosine Similarity Loss, Triplet Margin Loss.
- **Core Datasets & Pairs:** Positive Pairs (Query, Relevant Passage), Hard Negative Mining (passages with high lexical overlap but irrelevant semantic answer), Synthetic Training Data Generation via LLMs (generating domain questions for raw chunks).
- **Core Topics:** When off-the-shelf general models fail on specialized domains (clinical healthcare, legal contracts, proprietary codebases); constructing training tuples `(query, positive, negative)`; batch size importance in contrastive learning; parameter-efficient fine-tuning (LoRA / PEFT) for embedding backbones; preventing catastrophic forgetting.
- **Real-World Scenarios:** Fine-tuning an open-source BGE embedding model on 50,000 internal enterprise finance reports to double retrieval precision on proprietary financial terminology.
