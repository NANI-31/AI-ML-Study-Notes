#### 1. Series & DataFrame Fundamentals & Attributes

- **Target Folder:** `basics/2. Pandas/01_series_dataframe_basics/`
- **Core API & Methods:** `pd.Series()`, `pd.DataFrame()`, `.index`, `.columns`, `.dtypes`, `.shape`, `.size`, `.ndim`, `.values`, `.to_numpy()`, `.info()`, `.describe()`, `.head()`, `.tail()`, `.memory_usage()`, `.copy()`
- **Core Topics:** Automatic index alignment, Series vs. 1D NumPy array differences, DataFrame object model (column-oriented storage of heterogeneous Series), view vs. copy semantics (`deep=True` vs. `deep=False`), metadata inspection, and summary statistics.
- **ML / Real-World Applications:** Inspecting raw imported dataset dimensions, validating feature schemas, detecting object vs. numeric columns before model ingestion.

---

#### 2. Data Selection & Indexing (`.loc`, `.iloc`, `.at`, `.iat`)

- **Target Folder:** `basics/2. Pandas/02_indexing_selection/`
- **Core API & Methods:** `.loc[]`, `.iloc[]`, `.at[]`, `.iat[]`, `df[col]`, `df[[cols]]`, boolean slicing, callable indexing (lambdas in indexers), index alignment during slice assignments
- **Core Topics:** Label-based inclusive slicing (`.loc['a':'c']`) vs. position-based half-open slicing (`.iloc[0:3]`), scalar fast-path lookups (`.at`/`.iat`), hierarchical multi-axis slicing, index preservation, and resolving the infamous `SettingWithCopyWarning`.
- **ML / Real-World Applications:** Separating feature matrix $X$ and target vector $y$, slicing training/validation folds, cell-level ground-truth correction.

---

#### 3. DataFrame Operations & Structural Mutations

- **Target Folder:** `basics/2. Pandas/03_dataframe_operations/`
- **Core API & Methods:** `.assign()`, `.drop()`, `.rename()`, `.set_index()`, `.reset_index()`, `.reindex()`, `.insert()`, `.pop()`, `.truncate()`, arithmetic methods with `.add()`, `.sub()`, `.mul()`, `.div()` with `fill_value`
- **Core Topics:** Adding calculated features, method chaining patterns, dropping rows/columns (`axis=0` vs. `axis=1`), inplace modification vs. immutable returning methods, renaming columns with functions/dictionaries, and custom index realignment.
- **ML / Real-World Applications:** Feature engineering (ratio features, log conversions), pipeline column renaming to match production model APIs, index resetting after filtering.

---

#### 4. Filtering & Conditional Selection

- **Target Folder:** `basics/2. Pandas/04_filtering_conditional/`
- **Core API & Methods:** Bitwise operators (`&`, `|`, `~`, `^`), `.isin()`, `.between()`, `.query()`, `.filter()`, `.where()`, `.mask()`, `np.where()` integration
- **Core Topics:** Multi-condition boolean masking, operator precedence and mandatory parenthesis rules, dynamic filtering with strings using `.query()`, regex column filtering via `.filter(regex=...)`, conditional value replacement with `.where()` vs. `.mask()`.
- **ML / Real-World Applications:** Segmenting customer cohorts, filtering out outlier records, isolating fraudulent transaction classes, creating binary indicator target variables.

---

#### 5. Missing Data & Data Cleansing

- **Target Folder:** `basics/2. Pandas/05_missing_data_cleaning/`
- **Core API & Methods:** `.isna()`, `.isnull()`, `.notna()`, `.dropna()` (`how='any'/'all'`, `thresh`, `subset`), `.fillna()`, `.ffill()`, `.bfill()`, `.interpolate()` (`method='linear'/'polynomial'`), `.replace()`
- **Core Topics:** Representations of missingness (`np.nan`, `None`, `pd.NA`), missing value propagation in arithmetic, threshold-based row/column dropping, group-wise mean/median/mode imputation, temporal forward/backward filling, and interpolation boundaries.
- **ML / Real-World Applications:** Pre-modeling data hygiene, handling missing sensor data, preventing data leakage during imputation (fitting imputation statistics strictly on train sets).

---

#### 6. Data Types, Categoricals & Memory Optimization

- **Target Folder:** `basics/2. Pandas/06_dtypes_memory_optimization/`
- **Core API & Methods:** `.astype()`, `pd.to_numeric(errors='coerce')`, `pd.Categorical()`, `.memory_usage(deep=True)`, `select_dtypes()`, downcasting (`to_numeric(downcast=...)`), nullable integer dtypes (`Int64`), boolean dtypes (`boolean`)
- **Core Topics:** Python objects vs. NumPy contiguous memory vs. Pandas extension arrays, memory footprint reduction via categorical encoding (`category` dtype), ordered vs. unordered categories, handling corrupted numbers with `coerce`, and numeric downcasting (`float64` to `float32`).
- **ML / Real-World Applications:** Compressing 10GB datasets to fit in 2GB RAM for model training, encoding low-cardinality string features for tree-based models.

---

#### 7. Vectorized String Operations (`.str`)

- **Target Folder:** `basics/2. Pandas/07_string_operations/`
- **Core API & Methods:** `.str.lower()`, `.str.upper()`, `.str.strip()`, `.str.contains()`, `.str.startswith()`, `.str.endswith()`, `.str.split(expand=True)`, `.str.replace(regex=True)`, `.str.extract()`, `.str.extractall()`, `.str.cat()`, `.str.len()`
- **Core Topics:** Vectorized text manipulation, handling null values gracefully in string accessors, regex pattern matching and named capture group extraction, splitting single text columns into multi-column DataFrames, and string normalization.
- **ML / Real-World Applications:** Cleaning unstructured text columns (emails, phone numbers, addresses), extracting numerical IDs from alphanumeric codes, basic NLP feature preprocessing.

---

#### 8. Sorting, Ranking & Window Selection

- **Target Folder:** `basics/2. Pandas/08_sorting_ranking_windows/`
- **Core API & Methods:** `.sort_values()` (`by`, `ascending=[True, False]`, `na_position`), `.sort_index()`, `.rank()` (`method='average'/'min'/'max'/'first'/'dense'`), `.nlargest()`, `.nsmallest()`, `.take()`
- **Core Topics:** Multi-column sorting with mixed ascending/descending directions, handling `NaN` placement during sort, tie-breaking algorithms in `.rank()`, percentile ranking, and efficient top-$K$ retrieval using `.nlargest()` vs. full sorting.
- **ML / Real-World Applications:** Model prediction ranking, identifying top-performing marketing campaigns, non-parametric feature ranking, extracting highest-loss error instances.

---

#### 9. GroupBy & Aggregations

- **Target Folder:** `basics/2. Pandas/09_groupby_aggregations/`
- **Core API & Methods:** `.groupby()`, `.agg()`, `.aggregate()`, named aggregations (`col_name=('target', 'func')`), `.transform()`, `.filter()`, `.apply()`, `.groups`, `.get_group()`, `.as_index=False`
- **Core Topics:** Split-Apply-Combine paradigm, aggregating single and multiple columns with custom/built-in functions, broadcasting group aggregates back to original rows via `.transform()`, filtering groups by aggregate properties (`.filter()`), and performance implications of `.apply()`.
- **ML / Real-World Applications:** Feature engineering target encoding statistics (group mean/std), calculating customer transaction frequency and lifetime value, normalizing features within groups.

---

#### 10. Merging, Joining & Concatenation

- **Target Folder:** `basics/2. Pandas/10_merging_joining_concat/`
- **Core API & Methods:** `pd.merge()`, `pd.concat()`, `DataFrame.join()`, `combine_first()`, parameters: `how` (`'inner'`, `'left'`, `'right'`, `'outer'`, `'cross'`), `on`, `left_on`, `right_on`, `suffixes`, `validate`, `indicator=True`
- **Core Topics:** Relational algebra joins, Cartesian products, handling overlapping column names with suffixes, integrity validation (`validate='one_to_many'/'many_to_one'`), diagnosing unmerged keys via `_merge` indicator, and stacking DataFrames along axes (`axis=0` vs. `axis=1`).
- **ML / Real-World Applications:** Denormalizing relational database tables for ML training datasets, joining feature stores with label tables, appending cross-validation fold outputs.

---

#### 11. Reshaping, Pivoting & Crosstabs

- **Target Folder:** `basics/2. Pandas/11_reshaping_pivoting/`
- **Core API & Methods:** `.pivot()`, `pd.pivot_table()` (`values`, `index`, `columns`, `aggfunc`, `fill_value`, `margins`), `pd.melt()` (`id_vars`, `value_vars`, `var_name`, `value_name`), `.stack()`, `.unstack()`, `pd.crosstab()`, `pd.get_dummies()`
- **Core Topics:** Wide-to-long vs. long-to-wide transformations, handling multi-level index outputs after unstacking, computing margin totals in pivot tables, frequency cross-tabulations, and one-hot encoding categorical variables.
- **ML / Real-World Applications:** Preparing tidy datasets for visualization, converting transaction logs into user-feature matrices, one-hot encoding categorical features for linear and neural network models.

---

#### 12. Date & Time Series Manipulation

- **Target Folder:** `basics/2. Pandas/12_datetime_timeseries/`
- **Core API & Methods:** `pd.to_datetime()`, `pd.date_range()`, `.dt` accessor (`year`, `month`, `day`, `dayofweek`, `quarter`, `is_month_end`), `df.resample()` (downsampling with `mean()`, upsampling with `asfreq()`), `.rolling()`, `.expanding()`, `.shift(periods=...)`, `.diff()`
- **Core Topics:** Datetime indexing, frequency strings (`'D'`, `'M'`, `'W'`, `'h'`), time delta arithmetic, rolling window statistics vs. expanding cumulative metrics, lag and lead feature generation with `.shift()`, and handling missing timestamps in financial data.
- **ML / Real-World Applications:** Time series forecasting feature engineering (lag features, rolling moving averages, volatility indicators, calendar feature extraction).

---

#### 13. Data Ingestion & Export (I/O Optimization)

- **Target Folder:** `basics/2. Pandas/13_io_reading_writing/`
- **Core API & Methods:** `pd.read_csv()`, `.to_csv()`, `pd.read_excel()`, `pd.read_parquet()`, `.to_parquet()`, `pd.read_json()`, `pd.read_sql()`, parameters: `chunksize`, `usecols`, `dtype`, `parse_dates`, `na_values`, `compression`
- **Core Topics:** High-performance I/O patterns, columnar Parquet vs. row-based CSV storage efficiency, streaming multi-gigabyte files via iterator chunks (`chunksize`), memory-efficient column subset loading with `usecols`, and SQL connection queries.
- **ML / Real-World Applications:** Ingesting big datasets under strict RAM constraints, establishing fast data caching pipelines with Apache Parquet, connecting directly to analytical data warehouses.

---

#### 14. Functional Programming, Vectorization & Performance

- **Target Folder:** `basics/2. Pandas/14_vectorization_apply_functional/`
- **Core API & Methods:** `.apply()`, `.map()`, `.map()` / `.applymap()`, `.pipe()`, `.itertuples()`, `.iterrows()`, NumPy ufuncs on Series, Cython / Numba integration overview
- **Core Topics:** Vectorization hierarchy and performance benchmarks (Vectorized ufuncs > `.apply()` > `.itertuples()` > `.iterrows()`), method chaining with `.pipe()` for clean preprocessing pipelines, row-wise vs. column-wise `.apply(axis=0/1)`, and avoiding Python loop overhead.
- **ML / Real-World Applications:** Production data preprocessing pipelines, complex custom metric calculations, optimizing feature engineering steps in real-time inference microservices.
