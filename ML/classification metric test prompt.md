1. Use the Reference File Correctly

First, thoroughly analyze the supplied `test.md` in `ML/regression/classification metrics/`.

Identify:

- Topics and subtopics covered:
  - Confusion Matrix Anatomy:
    - Actual vs. Predicted contingency table layout (rows = ground truth, columns = model prediction)
    - True Positives (TP), True Negatives (TN), False Positives (FP / Type I error), False Negatives (FN / Type II error)
    - Total sample conservation: $\text{Total} = TP + TN + FP + FN$
    - Actual positives ($P = TP + FN$) and actual negatives ($N = TN + FP$)
    - Predicted positives ($TP + FP$) and predicted negatives ($TN + FN$)
  - Core Metric Definitions and Mathematical Formulations:
    - Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$
    - The Accuracy Paradox: why high accuracy is completely misleading in severe class imbalance (e.g., 99% accuracy by predicting majority class 100% of the time while missing every minority anomaly)
    - Precision (Positive Predictive Value): $\frac{TP}{TP + FP}$ — purity of positive alerts
    - Recall (Sensitivity / True Positive Rate / Hit Rate): $\frac{TP}{TP + FN}$ — coverage of actual ground-truth positives
    - Specificity (True Negative Rate): $\frac{TN}{TN + FP}$ — coverage of actual ground-truth negatives
    - False Positive Rate (FPR / Fall-out): $\frac{FP}{TN + FP} = 1 - \text{Specificity}$
    - False Negative Rate (FNR / Miss Rate): $\frac{FN}{TP + FN} = 1 - \text{Recall}$
  - The F1 Score & Harmonic Mean Mechanics:
    - $F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2TP}{2TP + FP + FN}$
    - Why the harmonic mean is used instead of arithmetic mean: harmonic mean heavily penalizes extreme imbalances between precision and recall, pulling the score toward the lower value
    - Mathematical relationship: $F_1 \le \frac{\text{Precision} + \text{Recall}}{2}$, with equality holding if and only if $\text{Precision} = \text{Recall}$
    - Exclusion of True Negatives: why $F_1$ does not use $TN$ in its formula, making it invariant to large numbers of easy background negative instances
  - Generalized $F_\beta$ Metric:
    - Formula: $F_\beta = (1 + \beta^2) \frac{\text{Precision} \times \text{Recall}}{\beta^2 \times \text{Precision} + \text{Recall}}$
    - Weighting dynamics: $\beta > 1$ (e.g., $F_2$) weights recall higher than precision; $\beta < 1$ (e.g., $F_{0.5}$) weights precision higher than recall
  - Decision Thresholds and Cutoff Dynamics:
    - Continuous probability scores $P(y=1|x) \in [0, 1]$ generated by sigmoid / softmax
    - Default decision threshold of $0.5$ vs. operational business thresholds
    - Lowering the cutoff (e.g., $0.5 \to 0.1$): expands positive predictions, generally increasing recall while decreasing precision
    - Raising the cutoff (e.g., $0.5 \to 0.8$): restricts positive predictions, increasing precision while reducing recall
    - Non-monotonic precision behavior: scenarios where lowering the threshold captures only true positives, causing precision to temporarily rise
  - Asymmetric Error Costs & Domain Objective Alignment:
    - Prioritizing Recall over Precision: high cost of False Negatives (cancer detection, fatal disease screening, financial fraud alerts, defect detection in critical aerospace hardware)
    - Prioritizing Precision over Recall: high cost of False Positives (email spam filtering, search engine top results, automated account bans, legal prosecution)
  - ROC (Receiver Operating Characteristic) Curve & AUC-ROC:
    - Axes: True Positive Rate (TPR / Recall) on y-axis vs. False Positive Rate (FPR) on x-axis across all thresholds $\tau \in [0, 1]$
    - Landmark points: $(0, 0)$ at $\tau = 1.0$; $(1, 1)$ at $\tau = 0.0$; perfect classifier at $(0, 1)$
    - Diagonal line $y = x$: performance of pure random guessing ($AUC = 0.5$)
    - Area Under the Curve (AUC): Wilcoxon-Mann-Whitney rank probability interpretation — probability that a randomly drawn positive instance receives a higher predicted score than a randomly drawn negative instance
    - Invariance properties: threshold-independent, scale-invariant to monotonic probability transforms
    - Limitation: can be overly optimistic under severe class imbalance because the large $TN$ denominator keeps $FPR$ artificially suppressed
  - Precision-Recall (PR) Curve & Average Precision:
    - Axes: Precision on y-axis vs. Recall on x-axis across all thresholds
    - Baseline random classifier: horizontal line at $y = \frac{P}{P + N}$ (the positive class prevalence)
    - Why PR curves are strictly superior to ROC curves for highly skewed imbalanced datasets (e.g., fraud rate = $0.1\%$)
    - Area Under the PR Curve (AUC-PR) / Average Precision (AP)
  - Multiclass Classification Evaluation & Averaging Schemes:
    - Multi-class confusion matrix ($K \times K$ grid): true labels on rows, predictions on columns
    - Diagonal entries ($C_{ii}$) represent correct classifications
    - Off-diagonal entries ($C_{ij}, i \ne j$) represent cross-class confusion patterns
    - Macro-averaging: arithmetic mean of metric computed independently for each class $\frac{1}{K} \sum \text{Metric}_k$ (treats all classes equally, highlights minority class struggles)
    - Weighted-averaging: mean of per-class metrics weighted by class support $\sum \frac{N_k}{N_{\text{total}}} \text{Metric}_k$
    - Micro-averaging: globally aggregates all TP, FP, FN across classes before calculating metric (dominated by majority classes; micro-precision = micro-recall = micro-F1 = overall accuracy)
  - Advanced Evaluation Metrics:
    - Matthews Correlation Coefficient (MCC): $\frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}} \in [-1, +1]$
    - Log Loss (Cross-Entropy Loss): penalizes confident wrong predictions logarithmically
    - Cohen's Kappa ($\kappa$): agreement adjusted for chance
  - Scikit-learn Evaluation APIs & Workflows:
    - `confusion_matrix(y_true, y_pred)`: parameter ordering `y_true` first, `y_pred` second; outputs `[[TN, FP], [FN, TP]]`
    - `accuracy_score()`, `precision_score()`, `recall_score()`, `f1_score(y_true, y_pred, average=...)`, `fbeta_score(beta=...)`
    - `classification_report(y_true, y_pred, target_names=...)`
    - `predict(X)` (discrete class labels based on default $0.5$ threshold) vs. `predict_proba(X)` (class probability matrix $[P(y=0), P(y=1)]$)
    - `roc_curve(y_true, y_score)` and `roc_auc_score(y_true, y_score)`: requiring continuous probability scores, NOT discrete binary predictions
    - `precision_recall_curve(y_true, y_score)`
    - Stratified splitting: `train_test_split(X, y, test_size=..., stratify=y)` preventing zero-minority test sets
- Important definitions:
  - Confusion Matrix, Type I Error, Type II Error, Accuracy Paradox, Precision, Recall, Sensitivity, Specificity, True Positive Rate, False Positive Rate, Harmonic Mean, F1 Score, F-beta Score, Cutoff / Decision Threshold, ROC Curve, AUC-ROC, Precision-Recall Curve, Average Precision, Macro Average, Micro Average, Weighted Average, Matthews Correlation Coefficient, Log Loss, Stratified Splitting
- Common mistakes and misconceptions:
  - Passing discrete predictions from `.predict()` into `roc_auc_score()` instead of probabilities from `.predict_proba()[:, 1]`
