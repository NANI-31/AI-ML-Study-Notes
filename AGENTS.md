## Active Roadmap Enforcement Rules (`6. RAG`, `9. LangChain`, & `10. LangGraph`)

Whenever creating, modifying, or refactoring any `.py` webapp lesson file under `04_Generative_AI/6. RAG/`, `04_Generative_AI/9. LangChain/`, or `04_Generative_AI/10. LangGraph/`:

1. **Mandatory Master Specification**:
   - For `6. RAG`: Strictly adhere to [`04_Generative_AI/6. RAG/UNIVERSAL_LESSON_FORMAT.md`](file:///d:/Data/GitHub/AI-ML-Study-Notes/04_Generative_AI/6.%20RAG/UNIVERSAL_LESSON_FORMAT.md). Master reference implementation: [`04_Generative_AI/6. RAG/webapp/1. Introduction to RAG/1.1 What is RAG.py`](file:///d:/Data/GitHub/AI-ML-Study-Notes/04_Generative_AI/6.%20RAG/webapp/1.%20Introduction%20to%20RAG/1.1%20What%20is%20RAG.py).
   - For `9. LangChain`: Strictly adhere to [`04_Generative_AI/9. LangChain/UNIVERSAL_LESSON_FORMAT.md`](file:///d:/Data/GitHub/AI-ML-Study-Notes/04_Generative_AI/9.%20LangChain/UNIVERSAL_LESSON_FORMAT.md). Core standard: LangChain v0.3+ LCEL, Runnables (`RunnableSequence`, `RunnableParallel`), and structured tool calling (`bind_tools`).
   - For `10. LangGraph`: Strictly adhere to [`04_Generative_AI/10. LangGraph/UNIVERSAL_LESSON_FORMAT.md`](file:///d:/Data/GitHub/AI-ML-Study-Notes/04_Generative_AI/10.%20LangGraph/UNIVERSAL_LESSON_FORMAT.md). Core standard: Cyclic state machines, `StateGraph`, channel reducers (`add_messages`), checkpointers (`MemorySaver`, `SqliteSaver`), human-in-the-loop interrupts (`interrupt()`), and multi-agent systems.

2. **Core Layout & Design Rules**:
   - **Continuous Vertical Scroll Flow**: All content on a single scrollable page (`st.set_page_config(layout="wide")`). Top-level `st.tabs` are strictly forbidden.
   - **Mandatory 1:1 Section Density**: Every numbered bullet point under a lesson in the syllabus text file (`rag.txt` for RAG, `langchain.txt` for LangChain, `langgraph.txt` for LangGraph) MUST receive its own dedicated `st.header` section (`st.header("X. <Topic Name>", divider="rainbow")`). Never compress, merge, or collapse multiple syllabus topics into a single generic overview or multi-column layout. Section count is locked by formula: `Total Sections = 1 (Architecture Blueprint) + K (Roadmap Bullets) + 1 (Production Code) + 1 (Interactive Workbench) + 1 (Technical Interview Prep) + 1 (Self-Assessment Checklist) = K + 5`.
   - **Clean Single Sequential Section Numbering (Strictly Zero Compound Numbering)**: Section headers MUST ALWAYS use clean, single sequential integer numbering from 1 to N (`st.header("1. <Blueprint>", divider="rainbow")`, `st.header("2. <Topic 1 Title>", divider="rainbow")`, ..., `st.header(f"{K+2}. Production Implementation: ...")`). Strictly prohibit compound, dotted, or nested section numbering (e.g. NEVER use `st.header("2. 1. ...")`, `st.header("2.1 ...")`, `st.header("3. 2. ...")`, or `st.header("4. 3. ...")`). Do NOT prefix the roadmap bullet index after the section index.
   - **Modern Engineering Contrastive Perspective**:
     - *For RAG*: Contrast Naive RAG vs Modern Advanced/Agentic RAG (e.g., dense vector lookup vs hybrid BM25 + dense search with Reciprocal Rank Fusion, cross-encoder rerankers, semantic parent-document chunking, and Self-RAG/CRAG loops).
     - *For LangChain*: Contrast legacy abstractions (`LLMChain`, `AgentExecutor`, `SimpleSequentialChain`) vs modern LCEL (`prompt | model | parser`), native tool calling (`bind_tools`), and async streaming (`astream_events`).
     - *For LangGraph*: Contrast rigid linear DAGs and standalone chains vs cyclic multi-agent state machines, explicit type-safe state schemas, persistent thread checkpointers, and deterministic human-in-the-loop approvals.
   - **Zero LaTeX Math Notation**: Never use `$$...$$` or `$x$`. Always use plain English / Unicode representations (e.g., `similarity_score >= 0.75`, `O(N * d)`, `rank(doc)`).
   - **Heavy Multi-Tier Architectural & Topic Diagrams (Mandatory Top-to-Bottom Flow)**: Dark theme Graphviz (`bgcolor="#0B1120"`), colored cluster tiers (`#1E293B`), storage cylinders, and protocol edges (`#38BDF8`).
     - **Mandatory Top-to-Bottom (`rankdir=TB;`) Layout**: Strictly prohibit long horizontal `rankdir=LR;` pipelines (more than 3–4 sequential nodes). Long pipelines must use `rankdir=TB;` so they expand vertically with readable fonts (`fontsize=11`) and margins (`margin="0.2,0.1"`).
     - **Mandatory `st.expander` Container for Blueprints**: Wrap architectural diagrams in `with st.expander("🔍 View Complete Architectural Blueprint (Top-to-Bottom Flow)", expanded=True):` calling `st.graphviz_chart(..., use_container_width=True)`.
     - **Contextual In-Section Diagrams (Mandatory Whenever Required)**: Diagrams must NOT be restricted to Section 1 alone. Whenever any roadmap topic section covers a multi-step workflow, data structure, or algorithmic mechanism, it MUST include a dedicated contextual Graphviz diagram inside that section.
   - **Data Structure Diagrams**: Render document chunks, token arrays, dense embedding vectors, layer towers, and VectorDB/IndexDB schemas using HTML-like table labels (`shape=plaintext, label=<<table ...>...</table>>`).
   - **Graphviz XML Rule**: Text inside HTML-like labels (`< ... >`) is parsed by a strict XML parser. Never use raw `&`, `<`, or `>` in headers or cells (always use `and` or `&amp;` instead of bare `&`).

3. **Mandatory Pedagogical Endings**:
   - **Section K+4: Technical Interview Preparation & Production Traps** (Exactly 5 Q&As + 4 Traps [2 error, 2 warning] + 4 Flashcards).
   - **Section K+5: Self-Assessment Checklist** (Exactly 6 Checkboxes + clean `st.success(...)` completion banner. Strictly prohibit `st.balloons()`).

4. **Code & Path Discipline**:
   - Exactly 5 standard imports (`streamlit`, `pandas`, `numpy`, `graphviz`, `typing`).
   - Strictly prohibit `import os` and `from pathlib import Path`.
   - All relative paths inside notebooks/scripts must be direct strings without `try`/`except`.
   - **Module Scope for Interactive Workbench Classes**: Any classes, functions, or execution pipelines needed by the Interactive Workbench (Section K+3) must be defined in real Python module scope within the script. Never define executable classes solely inside string literals passed to `st.code('''...''')`, as this prevents runtime instantiation and raises `NameError`.
