#### 1. Estimator API Architecture & Dataset Mechanics

- **Target Folder:** `ML/scikit-learn/01_estimator_api_datasets/`
- **Core API & Classes:** Estimator vs. Transformer vs. Predictor interfaces (`fit()`, `transform()`, `fit_transform()`, `predict()`, `predict_proba()`, `decision_function()`, `score()`), `Bunch` object, `sklearn.datasets` (`load_iris`, `load_breast_cancer`, `load_wine`, `load_digits`, `load_diabetes`, `fetch_california_housing`), synthetic generators (`make_classification`, `make_regression`, `make_blobs`, `make_moons`, `make_circles`)
- **Core Concepts:** Uniform API design principles, state preservation during `fit()`, trailing underscore attribute convention (`coef_`, `intercept_`, `classes_`), 2D feature matrix $X$ shape $(n\_samples, n\_features)$ vs. 1D target vector $y$ shape $(n\_samples,)$, sparse matrix representations (`scipy.sparse.csr_matrix`), and dataset metadata inspection.
- **ML / Real-World Scenarios:** Synthesizing imbalanced multi-class datasets for benchmarking, verifying API contracts in custom estimators.

---

#### 2. Data Preprocessing, Imputation & Feature Scaling

- **Target Folder:** `ML/scikit-learn/02_preprocessing_scaling/`
- **Core API & Classes:** `SimpleImputer` (`strategy='mean'/'median'/'most_frequent'/'constant'`), `KNNImputer`, `MissingIndicator`, `OneHotEncoder` (`drop='first'/'if_binary'`, `handle_unknown='ignore'/'infrequent_if_exist'`, `sparse_output`), `OrdinalEncoder`, `StandardScaler`, `MinMaxScaler`, `RobustScaler`, `MaxAbsScaler`, `Normalizer`
- **Core Concepts:** When scaling is mandatory (gradient descent, distance metrics in KNN/SVM, regularized regression) vs. scale invariance in decision trees; centering vs. variance scaling; handling outliers with median/IQR scaling (`RobustScaler`); zero-preserving scaling (`MaxAbsScaler`); handling out-of-vocabulary categorical levels during inference; sparse vs. dense output memory trade-offs.
- **ML / Real-World Scenarios:** Preprocessing raw customer records containing missing values, skewed incomes, and nominal categories without data leakage.

---

#### 3. Data Splitting & Cross-Validation Strategies

- **Target Folder:** `ML/scikit-learn/03_splitting_cross_validation/`
- **Core API & Classes:** `train_test_split`, `KFold`, `StratifiedKFold`, `ShuffleSplit`, `StratifiedShuffleSplit`, `GroupKFold`, `TimeSeriesSplit`, `cross_val_score`, `cross_validate`, `cross_val_predict`
- **Core Concepts:** Train/validation/test isolation; `random_state` reproducibility; stratified splitting for preserving class ratios in imbalanced datasets; group-aware cross-validation to prevent patient/customer data leakage across folds; forward-chaining walk-forward validation for temporal data (`TimeSeriesSplit`); multi-metric evaluation via `cross_validate`.
- **ML / Real-World Scenarios:** Designing a leak-free validation strategy for clinical trial datasets with grouped patient records and time-series financial streams.

---

#### 4. Feature Extraction, Text Preprocessing & Mathematical Transforms

- **Target Folder:** `ML/scikit-learn/04_feature_extraction_engineering/`
- **Core API & Classes:** `CountVectorizer`, `TfidfVectorizer` (`ngram_range`, `max_df`, `min_df`, `stop_words`, `sublinear_tf`), `PolynomialFeatures` (`degree`, `interaction_only`, `include_bias`), `SplineTransformer`, `PowerTransformer` (`method='box-cox'/'yeo-johnson'`), `QuantileTransformer` (`output_distribution='normal'`), `TargetEncoder` (Scikit-learn 1.3+)
- **Core Concepts:** Bag-of-Words and TF-IDF weighting calculations; $n$-gram tokenization; sublinear term frequency scaling; generating non-linear feature interactions; transforming skewed distributions toward Gaussian normality; out-of-fold target encoding to avoid target leakage in high-cardinality categoricals.
- **ML / Real-World Scenarios:** Engineering polynomial interaction features for housing price estimation and building TF-IDF representations for spam/sentiment text classification.

---

#### 5. Feature Selection & Dimensionality Reduction

- **Target Folder:** `ML/scikit-learn/05_feature_selection_dimensionality/`
- **Core API & Classes:** `VarianceThreshold`, `SelectKBest`, `SelectPercentile` (scoring functions: `f_classif`, `f_regression`, `chi2`, `mutual_info_classif`, `mutual_info_regression`), `RFE`, `RFECV`, `SelectFromModel`, `PCA` (`n_components`, `explained_variance_ratio_`, `svd_solver`), `TruncatedSVD`, `KernelPCA`, `IncrementalPCA`
- **Core Concepts:** Filter vs. Wrapper vs. Embedded feature selection paradigms; linear correlation ($F$-test) vs. non-linear dependencies (Mutual Information); recursive feature elimination with cross-validated pruning (`RFECV`); covariance decomposition and orthogonal axes in PCA; scree plots and cumulative explained variance thresholding; Truncated SVD for sparse TF-IDF matrices (LSA).
- **ML / Real-World Scenarios:** Compressing 5,000 genomic or image features down to 50 principal components while preserving 95% total variance.

---

#### 6. Linear Models & Regularized Regression

- **Target Folder:** `ML/scikit-learn/06_linear_regularized_regression/`
- **Core API & Classes:** `LinearRegression`, `Ridge`, `RidgeCV`, `Lasso`, `LassoCV`, `ElasticNet`, `ElasticNetCV`, `HuberRegressor`, `RANSACRegressor`, `SGDRegressor`
- **Core Concepts:** Ordinary Least Squares (OLS) closed-form normal equation vs. iterative gradient solvers; assumptions of linear regression (homoscedasticity, linearity, multicollinearity); L2 Ridge penalty ($\frac{1}{2}\alpha ||w||_2^2$) shrinking weights smoothly; L1 Lasso penalty ($\alpha ||w||_1$) driving coefficients strictly to zero for automatic feature selection; ElasticNet trade-off (`l1_ratio`); robust loss functions for outlier resistance (Huber loss).
- **ML / Real-World Scenarios:** Predicting continuous financial loan default losses while handling severe feature collinearity and selecting a sparse feature subset.

---

#### 7. Linear & Probabilistic Classification

- **Target Folder:** `ML/scikit-learn/07_classification_linear_probabilistic/`
- **Core API & Classes:** `LogisticRegression`, `LogisticRegressionCV`, `SGDClassifier`, `KNeighborsClassifier`, `KNeighborsRegressor`, `NearestNeighbors`, `GaussianNB`, `MultinomialNB`, `BernoulliNB`, `ComplementNB`
- **Core Concepts:** Sigmoid activation and log-odds transformation; log-loss cost optimization; multi-class strategies (`'ovr'` vs. `'multinomial'`); solver selection (`'lbfgs'`, `'saga'`, `'liblinear'`) based on dataset size and penalty; inverse regularization strength $C = \frac{1}{\lambda}$; Minkowski distance metrics ($p=1$ Manhattan, $p=2$ Euclidean); KD-Tree vs. Ball-Tree spatial search; Naive Bayes conditional independence assumption and Laplace smoothing ($\alpha$).
- **ML / Real-World Scenarios:** Classifying customer churn probability using regularized logistic regression and building low-latency spam filters via Multinomial Naive Bayes.

---

#### 8. Support Vector Machines (SVM)

- **Target Folder:** `ML/scikit-learn/08_support_vector_machines/`
- **Core API & Classes:** `SVC`, `SVR`, `LinearSVC`, `LinearSVR`, `OneClassSVM`
- **Core Concepts:** Maximal margin hyperplane; soft-margin formulation; slack variables ($\xi_i$); regularization parameter $C$ (margin width vs. classification penalty); support vector identification (`support_vectors_`, `n_support_`); kernel trick: Linear, Polynomial (`degree`, `coef0`), Radial Basis Function (`gamma`), Sigmoid; $\epsilon$-insensitive loss tube in SVR; computational scaling $\mathcal{O}(n^2) - \mathcal{O}(n^3)$ and why `LinearSVC` is preferred on large datasets.
- **ML / Real-World Scenarios:** Classifying non-linearly separable medical tumor biopsies using RBF kernel SVM with calibrated probability scaling (`probability=True`).

---

#### 9. Decision Trees & Tree Mechanics

- **Target Folder:** `ML/scikit-learn/09_decision_trees/`
- **Core API & Classes:** `DecisionTreeClassifier`, `DecisionTreeRegressor`, `plot_tree`, `export_text`, `export_graphviz`
- **Core Concepts:** Recursive binary splitting; splitting criteria: Gini Impurity ($1 - \sum p_i^2$) vs. Information Gain / Entropy ($-\sum p_i \log_2 p_i$); variance reduction / MSE in regression trees; tree pre-pruning regularization: `max_depth`, `min_samples_split`, `min_samples_leaf`, `max_features`, `max_leaf_nodes`; cost-complexity pruning via minimal cost-complexity parameter `ccp_alpha`; decision boundary geometry (axis-aligned orthogonal splits).
- **ML / Real-World Scenarios:** Building interpretable credit risk decision trees and extracting explicit rule sets for compliance auditing.

---

#### 10. Ensemble Learning: Bagging, Boosting & Stacking

- **Target Folder:** `ML/scikit-learn/10_ensemble_bagging_boosting/`
- **Core API & Classes:** `RandomForestClassifier`, `RandomForestRegressor`, `ExtraTreesClassifier`, `BaggingClassifier`, `AdaBoostClassifier`, `GradientBoostingClassifier`, `GradientBoostingRegressor`, `HistGradientBoostingClassifier`, `VotingClassifier`, `VotingRegressor`, `StackingClassifier`, `StackingRegressor`
- **Core Concepts:** Bootstrap Aggregating (Bagging) reducing variance; Out-of-Bag (`oob_score_`) error estimation; random subspace method; Gini/MDI feature importance vs. permutation importance; Sequential Boosting reducing bias; exponential loss in AdaBoost; pseudo-residuals and gradient descent in function space (Gradient Boosting); histogram-based binning (`HistGradientBoosting`) for large data; hard vs. soft voting; multi-model stacking with meta-learners.
- **ML / Real-World Scenarios:** Benchmarking Random Forest against Gradient Boosting and building an ensemble stacking pipeline for fraud detection competitions.

#### 11. Model Evaluation, Diagnostic Metrics & Imbalance Handling

- **Target Folder:** `ML/scikit-learn/11_model_evaluation_metrics/`
- **Core API & Classes:** `accuracy_score`, `precision_score`, `recall_score`, `f1_score` (averaging: `'macro'`, `'micro'`, `'weighted'`), `confusion_matrix`, `ConfusionMatrixDisplay`, `classification_report`, `roc_curve`, `roc_auc_score`, `RocCurveDisplay`, `precision_recall_curve`, `PrecisionRecallDisplay`, `log_loss`, `mean_squared_error`, `root_mean_squared_error`, `mean_absolute_error`, `r2_score`, `mean_absolute_percentage_error`
- **Core Concepts:** Type I vs. Type II errors; precision-recall trade-offs; AUC-ROC interpretation (ranking probability) vs. Precision-Recall AUC for heavily skewed classes; $R^2$ coefficient of determination vs. MSE/RMSE/MAE; handling class imbalance via `class_weight='balanced'`; decision threshold calibration.
- **ML / Real-World Scenarios:** Diagnosing a 99.5% imbalanced fraud detection model where accuracy is misleading, shifting classification thresholds based on PR curves to maximize recall.

#### 12. Pipelines, ColumnTransformer & Data Leakage Prevention

- **Target Folder:** `ML/scikit-learn/12_pipelines_column_transformer/`
- **Core API & Classes:** `Pipeline`, `make_pipeline`, `ColumnTransformer`, `make_column_transformer`, `make_column_selector`, `FeatureUnion`, `TransformedTargetRegressor`
- **Core Concepts:** Constructing end-to-end reproducible ML pipelines; applying heterogeneous preprocessing to numeric vs. categorical subsets via `ColumnTransformer`; handling unselected columns (`remainder='passthrough'/'drop'`); inspecting and tuning internal pipeline steps (`named_steps`, double-underscore parameter syntax `step__param`); why pipelines mathematically prevent data leakage during cross-validation.
- **ML / Real-World Scenarios:** Building a single production-ready Scikit-learn Pipeline object combining imputation, scaling, one-hot encoding, feature selection, and XGBoost/Random Forest.

---

#### 13. Hyperparameter Optimization & Model Persistence

- **Target Folder:** `ML/scikit-learn/13_hyperparameter_tuning_selection/`
- **Core API & Classes:** `GridSearchCV`, `RandomizedSearchCV`, `HalvingGridSearchCV`, `HalvingRandomSearchCV`, `ParameterGrid`, `ParameterSampler`, `joblib.dump()`, `joblib.load()`
- **Core Concepts:** Exhaustive grid search vs. stochastic sampling over probability distributions (`scipy.stats`); successive halving tournament search; tuning pipeline hyperparameters using `estimator__parameter` notation; `cv_results_` DataFrame analysis; `best_estimator_`, `best_score_`, `best_params_`; nested cross-validation (inner CV for tuning, outer CV for unbiased performance assessment); serialization safety and version compatibility in `joblib`.
- **ML / Real-World Scenarios:** Tuning a 5-hyperparameter Random Forest pipeline over 100 iterations with 5-fold CV and serializing the optimal model artifact for API deployment.

#### 14. Unsupervised Learning: Clustering & Anomaly Detection

- **Target Folder:** `ML/scikit-learn/14_clustering_anomaly_detection/`
- **Core API & Classes:** `KMeans` (`init='k-means++'`, `n_clusters`, `n_init`, `inertia_`), `MiniBatchKMeans`, `DBSCAN` (`eps`, `min_samples`), `AgglomerativeClustering` (`linkage='ward'/'complete'/'average'`), `GaussianMixture`, `silhouette_score`, `davies_bouldin_score`, `calinski_harabasz_score`, `IsolationForest` (`contamination`, `n_estimators`), `LocalOutlierFactor` (`novelty=True/False`)
- **Core Concepts:** Centroid-based K-Means vs. Density-based DBSCAN (discovering arbitrary shapes and identifying noise points labeled `-1`); Ward's hierarchical linkage and dendrograms; assessing cluster cohesion and separation using Silhouette analysis and the Elbow method (inertia curves); probabilistic soft clustering with Gaussian Mixtures (BIC/AIC selection); tree-based isolation and local density estimation for anomaly detection.
- **ML / Real-World Scenarios:** Segmenting e-commerce customer behavioral vectors with K-Means and detecting fraudulent financial transactions using an Isolation Forest.
